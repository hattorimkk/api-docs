# Create an Upgraded Smart+ Catalog Search Ads Campaign for Website and App
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Sales Search Ads Campaign > Create an Upgraded Smart+ Search Ads Campaign for Website and App > Create an Upgraded Smart+ Catalog Search Ads Campaign for Website and App
> Độ dài nguồn: 53325 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article walks you through the steps to create an Upgraded Smart+ Catalog Search Ads Campaign for Website and App.

Upgraded Smart+ Catalog Search Ads Campaigns for Website and App are Upgraded Smart+ Sales Search Ads Campaigns that use catalog products to drive sales on both your website and your app. To configure this campaign type, set the following campaign-level parameters:
- `objective_type`: `WEB_CONVERSIONS`
- `sales_destination`: `WEB_AND_APP`
- `catalog_enabled`: `true`

# Prerequisites

Creating Search Ads Campaigns for Website and App requires setting up a catalog in your Business Center first.

To set up the catalog:

1. Create a catalog using [/catalog/create/](slug:create-a-catalog).
The catalog type can be any of the following:

- E-commerce
- hotel
- flight
- destination
- entertainment

2. Upload products to the catalog using [/catalog/product/upload/](slug:upload-products-via-a-json-schema) (JSON schema), [/catalog/product/file/](slug:upload-products-via-a-file-url) (CSV feed template), or [/catalog/feed/create/](slug:create-a-feed)(online data feed schedule).

3. Check the product handling results.

- For CSV feed and JSON schema, use [/catalog/product/log/](slug:get-the-product-handling-log).
  - Pass in the `feed_log_id` obtained from Step 2. If the field `error_affected_products` in the response is not null, examine the issue details and return to Step 2 to reupload the product.
- For online feed, use [/catalog/feed/log/](slug:get-the-log-of-a-feed)
