# Create an Upgraded Smart+ Non-Catalog Search Ads Campaign for Website and App
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Sales Search Ads Campaign > Create an Upgraded Smart+ Search Ads Campaign for Website and App > Create an Upgraded Smart+ Non-Catalog Search Ads Campaign for Website and App
> Độ dài nguồn: 32059 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article walks you through the steps to create an Upgraded Smart+ Non-Catalog Search Ads Campaign for Website and App.

Upgraded Smart+ Non-Catalog Search Ads Campaign for Website and App are Upgraded Smart+ Sales Search Ads Campaigns that drive sales on both your website and your app without using catalog products. To configure this campaign type, set the following campaign-level parameters:
- `objective_type`: `WEB_CONVERSIONS`
- `sales_destination`: `WEB_AND_APP`
- `catalog_enabled`: `false`
