# Create Community Interaction ads
> Đường dẫn: Use Cases > Campaign creation > Create Community Interaction ads
> Độ dài nguồn: 33183 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article walks you through the steps to create Community Interaction ads.

# Introduction
With the Community Interaction objective, you can build and nurture your connections with one of the most valuable communities that exists today - the TikTok community. This objective allows you to drive follower growth or increase traffic to different landing pages on TikTok.

**You can use Campaign Management API to create Community Interaction ads, and this helps you streamline your ad creation experience, and elevate operational efficiency and scalability.**

# Prerequisites
- You've gained access to TikTok API for Business. See [Get Started - Step by step workflow](doc:1735713609895937) for details. 
  - To create Community Interaction ads, you need relevant permissions. See [API Reference](doc:1735713875563521) to find out permissions required for endpoints (including the endpoints listed in the "Steps" section) and see [Update app permissions](doc:1738855280338946) to find out how to configure permissions.
