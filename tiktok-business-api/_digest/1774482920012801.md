# Create a Lead Generation ad with optimization location as Instant Form
> Đường dẫn: Use Cases > Campaign creation > Create Lead Generation ads > Create a Lead Generation ad with optimization location as Instant Form
> Độ dài nguồn: 16082 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article introduces how to create a Lead Generation ad with optimization location as Instant Form, driving lead-related actions on the Instant Form that loads natively within TikTok.

# Prerequisite
1. Create an Instant Form.

To create an Instant Form, use [Instant Page Editor SDK](doc:1740307202170881) and set `businessType` to `1`.

2. Call [/page/get/](doc:1820826387779586) to get the page ID via `page_id`.

# Steps
## 1. Create a campaign
Create a campaign using [/campaign/create/](doc:1739318962329602). Note that the following requirements must be met.

| Setting | Requirement | Parameter | How to configure the parameter |
|---|---|---|---|
| Advertising objective | Lead Generation | `objective_type` | `LEAD_GENERATION` |
| Smart+ Campaign | Disabled ⏎ To learn about how to create a Smart+ Lead Generation Campaign with optimization location as Instant Form, see [Create Smart+ Lead Generation Campaigns](doc:1827645480080385). | / | / |

### Example

Request

```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/campaign/create/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id": "{{advertiser_id}}",
    "objective_type": "LEAD_GENERATION",
    "campaign_name": "{{campaign_name}}",
    "budget_mode": "BUDGET_MODE_TOTAL",
    "budget": {{budget}}
}'
```
