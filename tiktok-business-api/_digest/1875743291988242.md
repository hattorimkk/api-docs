## Phần mở đầu của nguồn
This article walks you through the steps to create an Upgraded Smart+ E-commerce Search Ads Campaign for Web.

This campaign type dynamically leverages your E-commerce catalog products to populate and deliver targeted web ads.

To configure this campaign type, set `catalog_enabled` to `true` and `catalog_type` to `ECOMMERCE` at the campaign level. By integrating E-commerce Catalog Ads, the system will automatically generate diverse ad creatives, including catalog videos, catalog carousels, and single videos.

# Prerequisites

Creating an E-commerce Search Ads Campaign for Web requires setting up an E-commerce catalog in your Business Center first.

To set up the catalog:

1. Create an **E-commerce** catalog using [/catalog/create/](slug:create-a-catalog).
2. Upload products to the catalog using [/catalog/product/upload/](slug:upload-products-via-a-json-schema) (JSON schema), [/catalog/product/file/](slug:upload-products-via-a-file-url) (CSV feed template), or [/catalog/feed/create/](slug:create-a-feed)(online data feed schedule).
3. Check the product handling results.
