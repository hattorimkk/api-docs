# How to connect a ready-made agent to TikTok for Business MCP Server
> Đường dẫn: TikTok for Business MCP Server > How to connect a ready-made agent to TikTok for Business MCP Server
> Độ dài nguồn: 6522 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
If you are using an existing, MCP-compatible AI platform, you can connect it directly to the TikTok Ads platform without writing any code. The platform will handle the connection and authorization flow for you, allowing your AI agent to execute advertising operations through standardized MCP tool calls.

This guide walks you through the connection process, from initial configuration to your first successful interaction.

If you want to build a custom agent, see [How to connect a custom agent to TikTok for Business MCP Server](slug:how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server) instead.

> **Note:** 
> In early July, Claude made a change to their MCP tools management, which caused tools over 256 to be omitted by default. As of July 20th, Claude has fixed this issue. To resolve the issue permanently, refresh the tool list once, or switch to the layered version of our MCP server (`https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer`).

## Before you start
Before you begin, ensure you have:
- **A TikTok for Business account.** This account is required to authorize TikTok for Business MCP Server so your AI agent can act on your behalf within the TikTok for Business ecosystem. If you do not have an account, [create a TikTok for Business account](slug:create-a-tiktok-for-business-account) before proceeding.
- **An MCP-compatible AI agent or platform.** Your agent or platform must support the Model Context Protocol.
