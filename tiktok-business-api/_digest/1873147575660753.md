# Create an Upgraded Smart+ non-DC App Search Ads Campaign
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ App Promotion Search Ads Campaign > Create an Upgraded Smart+ non-DC App Search Ads Campaign
> Độ dài nguồn: 68270 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article explains how to create an Upgraded Smart+ non-DC App Search Ads Campaign.

This setup is an App Search Ads Campaign with the iOS 14 dedicated setting disabled. To configure it, set the `campaign_type` parameter to `REGULAR_CAMPAIGN` or leave it unspecified.

# Steps

## Steps for App Install Campaigns
An App Install Campaign is an App Search Ads Campaign that gets people to install and use your app. For such campaigns, set the `app_promotion_type` parameter to `APP_INSTALL`.

### Create a campaign
Create a campaign using [/smart_plus/campaign/create/](slug:create-an-upgraded-smart-campaign).

Note that the following requirements must be met. To find a complete list of parameters, see [/smart_plus/campaign/create/](slug:create-an-upgraded-smart-campaign).
