When [connecting a custom agent to TikTok for Business MCP Server](slug:how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server), you have the option to authenticate requests using an API access token. This guide explains the benefits of this approach and provides step-by-step instructions for implementation.

# Why use an API access token
Using an API access token offers several significant advantages for your custom agent integration:
- **Long-term authorization:** Standard user authorization for the MCP Server is valid for a 30-day window, requiring reauthorization after expiration. An API access token provides long-term access, remaining valid indefinitely unless the advertiser explicitly revokes it or the token is invalidated via the [/oauth2/revoke_token/](slug:revoke-a-long-term-access-token) endpoint.
- **Streamlined setup for existing developers:** If you have an existing integration with the TikTok [Marketing API](slug:marketing-api), you can reuse your current Marketing API token to authenticate MCP requests. This eliminates the need to complete a separate authorization process.
- **Granular permission control:** Obtaining an API access token utilizes the standard API authorization workflow. This allows advertisers to review and select precise, granular permissions, minimizing the risk of over-sharing.
