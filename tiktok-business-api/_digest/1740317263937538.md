# (Deprecated) Submit materials
> Đường dẫn: API Reference > (Deprecated) Dynamic Scene > (Deprecated) Submit materials
> Độ dài nguồn: 2674 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
Use this endpoint to submit materials for dynamic scene creation.

After you submit the materials, use [/dynamic_scene/task/create/](doc:1740317320231938) to create an asynchronous task.
 > **Note:** The Dynamic Scene API is now in beta. If you would like access to this feature, please apply for the allowlisting using the [Allowlist Management](https://ads.tiktok.com/marketing_api/blog/detail/7102266224578396162) page. 

## Request

**Endpoint**

https://business-api.tiktok.com/open_api/v1.3/dynamic_scene/material/submit/

**Method** POST

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token {Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162).|
```

**Parameters**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|advertiser_id {Required}|string| Advertiser  ID. |
#|slots {Required}|object[]|Max size is 6.|
##|order {Required}|number|The order of slot in the story arc, ranging from 0 to 5.|
##|tag {Required}|string|The tag of a slot.|
##|video_ids {Required}|string[]|You can get video IDs through [Video Upload](doc:1737587322856449) endpoint. Note: You can only pass in no more than 10 videos in this field. |
##|mute|boolean|Whether to turn on the original soundtrack of a slot. The default value is `false`. If you set it to `true`, then `bgm_volume` is `100`. <br> Note: In the case of no background music (`auto_soundtrack` is `false` and there is no `music_ids`), you are not allowed to set `mute`
