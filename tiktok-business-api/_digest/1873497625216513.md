# How to connect a custom agent to TikTok for Business MCP Server
> Đường dẫn: TikTok for Business MCP Server > How to connect a custom agent to TikTok for Business MCP Server
> Độ dài nguồn: 28648 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
If you are building a custom agent, you can connect it directly to the TikTok for Business MCP Server. This gives your agent direct, programmatic access to the TikTok Ads platform using standard Model Context Protocol (MCP) tool calls.

Because your custom agent operates independently, it must handle its own OAuth 2.0 authorization flow. This guide walks you through the complete lifecycle: from discovering the server configuration and registering your client application, to securing user consent via PKCE (Proof Key for Code Exchange) and executing your first MCP tool.

If you want to use an existing, MCP-compatible AI platform, see [How to connect a ready-made agent to TikTok for Business MCP Server](slug:how-to-connect-to-tiktok-for-business-mcp-server) instead.

> **Important:** 
> Each MCP server path issues its own tokens. A token obtained for one server path (for example, `tt-ads-mcp-layer`) is strictly scoped to that path and cannot be used to authenticate against a different path (for example, `tt-ads-mcp-flat`). If your agent connects to multiple server paths, you must complete a separate OAuth flow for each one.

## Các đề mục trong tài liệu
- Path 1: When using an MCP access token
- 1. Discover the OAuth configuration
- 2. Register your agent
- 3. Request user authorization
- 4. Exchange the authorization code for tokens
- 5. Call MCP tools
- Retrieve available tools
- Execute a tool
- 6. Refresh the access token
- 7. (Optional) Revoke the access token
- Path 2: When using an API access token
- 1. Get an API access token
- 2. Call MCP tools
- Retrieve available tools
- Execute a tool
- 3. (Optional) Revoke the API access token
