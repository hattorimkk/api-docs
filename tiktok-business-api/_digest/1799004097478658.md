# Set up events with data layer
> Đường dẫn: Marketing API > Ad Measurement > Guides > Google Tag Manager (GTM) Integration > Set up events with data layer
> Độ dài nguồn: 18632 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
The data layer is an object used by Google Tag Manager (GTM) and `gtag.js` to pass information to tags. Your website code can interact with the data layer to store or send data by using the Google Tag or Tag Manager JavaScript APIs, that is, `gtag()` or `dataLayer.push()`.

We have developed two templates, the [TikTok Pixel template](https://tagmanager.google.com/gallery/#/owners/tiktok/templates/gtm-template-pixel) and the [TikTok Events API template](https://tagmanager.google.com/gallery/#/owners/tiktok/templates/gtm-template-eapi), to parse data layer events and send the events to TikTok using the Pixel and Events API.

> **Note:** 
> If you plan to use the data layer to pass information to tags, it's highly recommended to use the interactive flow in TikTok Events Manager to set up the integration of Pixel or Events API with GTM. This flow automatically installs the templates and all the necessary tags, variables, and triggers for processing and sending data layer events to TikTok. For more information, see: • [TikTok Pixel only setup](doc:1799004034003969) • [Events API and Pixel setup](doc:1799004052020225)

The events and parameters recognized by the TikTok templates align with the recommendations provided by Google.
