# (Deprecated) Run a report
> Đường dẫn: API Reference > (Deprecated) Dynamic Scene > (Deprecated) Run a report
> Độ dài nguồn: 11236 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
Use this endpoint to run a report of dynamic scene videos.

> **Note:** The Dynamic Scene API is now in beta. If you would like access to this feature, please apply for the allowlisting using the [Allowlist Management](https://ads.tiktok.com/marketing_api/blog/detail/7102266224578396162) page.

**Endpoint**

https://business-api.tiktok.com/open_api/v1.3/dynamic_scene/report/get/

**Method** GET

**Header**
