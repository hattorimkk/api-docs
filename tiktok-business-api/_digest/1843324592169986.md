# Create an Upgraded Smart+ Lead Generation Campaign with Location as Instant Form
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Lead Generation Campaigns > Create an Upgraded Smart+ Lead Generation Campaign with Location as Instant Form
> Độ dài nguồn: 31394 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
An Upgraded Smart+ Lead Generation Campaign with Location as Instant Form is an Upgraded Smart+ Lead Generation Campaign with `promotion_target_type` set to `INSTANT_PAGE`. 

# Prerequisites
Ensure that you have an existing Instant Form within your ad account.
- To create an Instant Form, use [Instant Page Editor SDK](doc:1740307202170881) and set `businessType` to `1`. Then call [/page/get/](doc:1820826387779586) to get the page ID of the Instant Form through `page_id`.
