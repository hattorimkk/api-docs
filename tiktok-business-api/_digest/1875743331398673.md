# Create an Upgraded Smart+ Streaming Search Ads Campaign for Web
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Sales Search Ads Campaign > Create an Upgraded Smart+ Search Ads Campaign for Web > Create an Upgraded Smart+ Streaming Search Ads Campaign for Web
> Độ dài nguồn: 35458 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article walks you through the steps to create an Upgraded Smart+ Streaming Search Ads Campaign for Web.

This campaign type dynamically leverages your entertainment catalog products to populate and deliver targeted web ads.

To configure this campaign type, set `catalog_enabled` to `true` and `catalog_type` to `TRAVEL_ENTERTAINMENT` at the campaign level. Additionally, specify the entertainment catalog by passing the `catalog_id` at the ad group level. By integrating Streaming Ads, the system will automatically generate diverse ad creatives, including catalog videos and single videos.

# Prerequisites

Creating Streaming Search Ads Campaigns for Web requires setting up an entertainment catalog in Business Center first.

To set up the catalog:

1. Create an entertainment catalog using [/catalog/create/](slug:create-a-catalog).

> **Note**: The entertainment catalog is currently an allowlist-only feature and is invitation-only because this catalog type is under Alpha Testing. If you would like to access it, please contact your TikTok representative. However, acceptance into the Alpha Test is not guaranteed.

2. Upload products to the catalog using [/catalog/product/upload/](slug:upload-products-via-a-json-schema) (JSON schema), [/catalog/product/file/](slug:upload-products-via-a-file-url) (CSV feed template), or [/catalog/feed/create/](slug:create-a-feed)(online data feed schedule).

3. Check the product handling results.
