The TikTok App Events SDK for React Native is maintained in a [public GitHub repository](https://github.com/tiktok/tiktok-business-react-native-sdk) and published on npm as [`@tiktok-for-business/react-native-sdk`](https://www.npmjs.com/package/@tiktok-for-business/react-native-sdk). It provides a typed TypeScript API over the TikTok for Business native iOS and Android SDKs.

## Prerequisites
Before you begin, ensure you have the following from your TikTok for Business account:
- Your app's **App ID** — the Android package name (e.g., `com.example.app`) or the numeric Apple App Store ID (e.g., `123456789`), depending on the target platform.
- A **TikTok App ID** from your app's settings page in Events Manager, for each platform.
- An **App Secret** for verification, from your app's settings page in Events Manager.
If you do not have these, refer to [Getting started](slug:tiktok-app-events-sdk-getting-started) before proceeding further.
