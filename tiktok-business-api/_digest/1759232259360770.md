# Create Video Shopping Ads with products from Showcase
> Đường dẫn: Use Cases > Campaign creation > Create Shopping Ads > Create Video Shopping Ads > Create Video Shopping Ads with products from Showcase
> Độ dài nguồn: 25487 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
Showcase is a feature on TikTok that allows customers to shop directly from a seller’s or a creator’s account. You can find the Showcase tab when tapping the shopping bag icon on the profile page of a TikTok account. Showcase displays products from a single TikTok Shop or multiple TikTok Shops. You can learn more about how to use Showcase [here](https://ads.tiktok.com/help/article?aid=10013245&redirected=1).

This article introduces how to create Video Shopping Ads with products from Showcase.
> **Note:** 
>  •  The flags of Required/ Conditional in the following parameter tables are only applicable for Video Shopping Ads with products from Showcase. •  Creating Video Shopping Ads with products from Showcase is currently an allowlist-only feature. If you would like to access it, please contact your TikTok representative.

## 1.Create a campaign
Create a campaign using `/campaign/create/`. The following table only lists the parameters related to Shopping Ads. To find out the other parameters required for creating campaigns, refer to [/campaign/create/](doc:1739318962329602).

> **Note:** 
> Currently, Campaign Budget Optimization is not supported for Shopping Ads with products from Showcase.
