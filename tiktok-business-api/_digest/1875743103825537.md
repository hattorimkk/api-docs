# Create an Upgraded Smart+ Sales Search Ads Campaign
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Sales Search Ads Campaign
> Độ dài nguồn: 881 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article explains how to create an Upgraded Smart+ Search Ads Campaign using the Sales objective.

Depending on where you want to drive your sales traffic (your conversion destination), you can route users to a website, an app, or both. For detailed instructions on configuring these specific routing destinations, refer to the following guides:

- To route sales traffic to a website, see [Create an Upgraded Smart+ Search Ads Campaign for Web](slug:create-an-upgraded-smart-search-ads-campaign-for-web).
- To route sales traffic to an app, see [Create an Upgraded Smart+ Catalog Search Ads Campaign for App](slug:create-an-upgraded-smart-catalog-search-ads-campaign-for-app).
- To route sales traffic to both a website and an app, see [Create an Upgraded Smart+ Search Ads Campaign for Website and App](slug:create-an-upgraded-smart-search-ads-campaign-for-website-and-app).
