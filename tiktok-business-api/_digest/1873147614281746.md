# Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as Website
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Lead Generation Search Ads Campaign > Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as Website
> Độ dài nguồn: 27997 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article explains how to create an Upgraded Smart+ Lead Generation Search Ads Campaign with Location as Website. 

This setup drives users to your external site to capture leads by setting the `promotion_target_type` parameter to `EXTERNAL_WEBSITE`.

# Steps
## 1. Create a campaign
