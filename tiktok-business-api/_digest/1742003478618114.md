## Phần mở đầu của nguồn
This article introduces how to create Catalog Listing Ads.
> **Note:** We are ending our Catalog Listing Ads (CLA) soon and closing out all active CLA campaigns. In the coming months, we will be consolidating CLA with Video Shopping Ads into a unified Shopping Ads solution. We will have more to share on integration opportunities for this new solution in the near future and look forward to introducing new catalog-powered placements and formats to deliver more immediate value for our advertisers.

>  **Note:** 
>  The flags of `Required`/ `Conditional` in the following parameter tables are only applicable for Catalog Listing Ads.

# 1. Create a campaign
Create a campaign using [/campaign/create/](doc:1739318962329602). The following table lists the related parameters. 

>  **Note:** 
>  Currently, Campaign Budget Optimization is not supported for Shopping Ads.

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID |
| objective_type  **(Required)** | string | Advertising objective. Use `PRODUCT_SALES` for Shopping Ads. |
| budget_mode {+Conditional} | string | How you'd like to set your budget. For example, you can set a daily budget. To learn about how to set budget modes, see [Budget](doc:1739381246298114). |
| budget {+Conditional} | float | Campaign budget. Required when `budget_mode` is `BUDGET_MODE_DAY` or `BUDGET_MODE_TOTAL`. To learn about the minimum budget and how to set budget modes, see [Budget](doc:17393812462981
