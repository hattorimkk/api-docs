# Create an Upgraded Smart+ Non-Catalog Search Ads Campaign for Web
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Sales Search Ads Campaign > Create an Upgraded Smart+ Search Ads Campaign for Web > Create an Upgraded Smart+ Non-Catalog Search Ads Campaign for Web
> Độ dài nguồn: 31621 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article walks you through the steps to create an Upgraded Smart+ Non-Catalog Search Ads Campaign for Web.

This specific campaign type drives web traffic without relying on a structured product catalog to deliver ads.

To configure this campaign type, either set the `catalog_enabled` parameter to `false` or leave it unspecified at the campaign level.
