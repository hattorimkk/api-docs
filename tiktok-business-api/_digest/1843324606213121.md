# Create an Upgraded Smart+ Lead Generation Campaign with Location as Website
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Lead Generation Campaigns > Create an Upgraded Smart+ Lead Generation Campaign with Location as Website
> Độ dài nguồn: 28182 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
An Upgraded Smart+ Lead Generation Campaign with Location as Website is an Upgraded Smart+ Lead Generation Campaign with `promotion_target_type` set to `EXTERNAL_WEBSITE`. 

# Steps
## 1. Create a campaign
