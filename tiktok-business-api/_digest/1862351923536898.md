# In-app ad revenue reporting
> Đường dẫn: Marketing API > Ad Measurement > Guides > TikTok App Events SDK > Additional features > In-app ad revenue reporting
> Độ dài nguồn: 31003 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
Starting from SDK version 1.5.0, in-app advertising mediation revenue reporting is supported. Simply use the code examples below based on the mediation partner you are using.

> **Important:** 
> •  For MAX and ironSource mediation, ensure all revenue is sent in USD. 
>
> •  **The ad-revenue dictionary schema is per-mediation-platform.** The keys the SDK reads are selected by `device_ad_mediation_platform` and are not interchangeable. Do not reuse one dictionary-builder across providers.
>
> •  Ensure that parameters are not null.
