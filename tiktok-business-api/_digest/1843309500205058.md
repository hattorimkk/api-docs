# Create Upgraded Smart+ App Campaigns
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ App Campaigns
> Độ dài nguồn: 919 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article walks you through the steps to create Upgraded Smart+ App Campaigns using the App Promotion objective.

Depending on your iOS 14 Dedicated Campaign (DC) requirements and whether you plan to leverage a catalog, you can build a non-DC campaign, a DC campaign, or O2O Catalog Ads.
- To create an Upgraded Smart+ non-DC App Campaign without a catalog, see [Create an Upgraded Smart+ non-DC App Campaign](doc:1853377390815233).
- To create an Upgraded Smart+ DC App Campaign without a catalog, see [Create an Upgraded Smart+ DC App Campaign](doc:1853377803841537).
- To create an Upgraded Smart+ App Campaign powered by an O2O catalog, see [Create Upgraded Smart+ App O2O Catalog Ads](slug:create-upgraded-smart-app-o2o-catalog-ads).
- To create an Upgraded Smart+ App Campaign powered by a travel catalog, see [Create Upgraded Smart+ App Travel Catalog Ads](slug:create-upgraded-smart-app-travel-catalog-ads).
