# Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as Instant Form
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Lead Generation Search Ads Campaign > Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as Instant Form
> Độ dài nguồn: 29940 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article explains how to create an Upgraded Smart+ Lead Generation Search Ads Campaign with Location as Instant Form. 

This setup allows you to collect leads natively on TikTok by setting the `promotion_target_type` parameter to `INSTANT_PAGE`.

# Prerequisites

Ensure that you have an existing Instant Form within your ad account.

- To create an Instant Form, use [Instant Page Editor SDK](slug:instant-page-editor-sdk) and set `businessType` to `1`. Then call [/page/get/](slug:get-the-page-id) to get the page ID of the Instant Form through `page_id`.
