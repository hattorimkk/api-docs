# Create Upgraded Smart+ Travel Ads
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Web Campaigns > Create Upgraded Smart+ Travel Ads
> Độ dài nguồn: 40405 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
Upgraded Smart+ Travel Ads are Upgraded Smart+ Web Campaigns that use catalog products from travel (hotel, flight, or destination) catalogs to deliver ads.

For such campaigns, you need to set `catalog_enabled` to `true` and `catalog_type` to `TRAVEL_ENTERTAINMENT` at the campaign level and specify a hotel, flight, or destination catalog through `catalog_id` at the ad group level. By utilizing Upgraded Smart+ Travel Ads, you can automatically generate ads in diverse formats such as catalog video, catalog carousel, and single video.

# Prerequisite

Creating Travel Ads requires setting up a travel (hotel, flight, or destination) catalog in a Business Center first.

To set up the catalog:

1. Create a travel (hotel, flight, or destination) catalog using [/catalog/create/](doc:1740306481704961).

2. Upload products to the catalog using [/catalog/product/upload/](doc:1740497429681153) (JSON schema), [/catalog/product/file/](doc:1740496787164161) (CSV feed template), or [/catalog/feed/create/](doc:1740665161957377)(online data feed schedule).
