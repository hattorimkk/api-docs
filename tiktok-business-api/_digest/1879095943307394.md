## Phần mở đầu của nguồn
When [building custom agents](slug:how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server) that integrate with numerous TikTok for Business MCP tools, token consumption can quickly escalate. The primary driver of this cost is preloading all tool definitions—especially those with verbose natural language descriptions—into the agent's context. This guide outlines best practices for optimizing tool usage.

## Identify token consumption sources
Token usage in MCP integrations typically comes from the following areas:
- **Tool definitions:** Loading large numbers of input schemas and descriptions before the agent knows which tools it needs.
- **Tool results:** Passing large, unfiltered JSON responses back to the model.
- **Agent history:** Retaining tool calls, results, and messages across a long session.
- **Agent reasoning:** Repeating tool selection and execution when the available tools are difficult to distinguish.
For example, if an agent loads 40 tools but typically uses only two, the other 38 definitions occupy context without helping the current task. Similar or overlapping definitions can also make tool and parameter selection less reliable.
