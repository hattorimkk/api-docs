## Phần mở đầu của nguồn
This article explains how to create an Upgraded Smart+ Search Ads Campaign that uses the Sales objective along with a website conversion destination.

- To configure a web campaign without a product catalog, see [Create an Upgraded Smart+ Non-Catalog Search Ads Campaign for Web](slug:create-an-upgraded-smart-non-catalog-search-ads-campaign-for-web).
- To configure a web campaign powered by an E-commerce catalog, see [Create an Upgraded Smart+ E-commerce Search Ads Campaign for Web](slug:create-an-upgraded-smart-e-commerce-search-ads-campaign-for-web).
- To configure a web campaign powered by a travel catalog (hotel, flight, or destination), see [Create an Upgraded Smart+ Travel Search Ads Campaign for Web](slug:create-an-upgraded-smart-travel-search-ads-campaign-for-web).
- To configure a web campaign powered by an entertainment catalog, see [Create an Upgraded Smart+ Streaming Search Ads Campaign for Web](slug:create-an-upgraded-smart-streaming-search-ads-campaign-for-web).
