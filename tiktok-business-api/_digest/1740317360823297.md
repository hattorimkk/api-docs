# (Deprecated) Get all videos
> Đường dẫn: API Reference > (Deprecated) Dynamic Scene > (Deprecated) Get all videos
> Độ dài nguồn: 6710 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
Use this endpoint to get all videos that are generated from a material package.

> **Note:** The Dynamic Scene API is now in beta. If you would like access to this feature, please apply for the allowlisting using the [Allowlist Management](https://ads.tiktok.com/marketing_api/blog/detail/7102266224578396162) page. 

## Request

**Endpoint**

https://business-api.tiktok.com/open_api/v1.3/dynamic_scene/get/

**Method** GET

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token {Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162).|
```

**Parameters**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|advertiser_id {Required}|string| Advertiser  ID. |
|material_package_id {Required}|string|Material Package ID.|
| page | number | Page that you want to get. |
| page_size | number | Number of results on each page. Default value: 10. |
```
