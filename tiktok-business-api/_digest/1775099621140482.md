# Optimize Landing page view in Video Shopping Ads
> Đường dẫn: Use Cases > Campaign creation > Create Shopping Ads > Create Video Shopping Ads > Create Catalog Ads > Optimize Landing page view in Video Shopping Ads
> Độ dài nguồn: 9037 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article walks you through the steps to use the optimization goal Landing page view in Video Shopping Ads.

## Prerequisites
- Using the optimization goal Landing page view in Shopping Ads is currently an allowlist-only feature. If you would like to access it, please contact your TikTok representative.

## Steps

### 1. Create a campaign

Create a campaign by using [/campaign/create/](doc:1739318962329602). The parameter requirements listed in the section [Create Video Shopping Ads with products from catalogs-1. Create a campaign](doc:1750361698613249) must be met.

#### Example

Request
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/campaign/create/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id": "{{advertiser_id}}",
    "objective_type": "PRODUCT_SALES",
    "campaign_product_source": "CATALOG",
    "budget_mode":"BUDGET_MODE_TOTAL",
    "budget": {{budget}},
    "campaign_name":"{{campaign_name}}"
}'
```

Response
```http
// curl
{
    "code": 0,
    "message": "OK",
    "request_id": "{{request_id}}",
    "data": {
        "budget_optimize_on": false,
        "modify_time": "{{modify_time}}",
        "operation_status": "ENABLE",
        "budget": {{budget}},
        "objective_type": "PRODUCT_SALES",
        "secondary_status": "CAMPAIGN_STATUS_ENABLE",
        "budget_mode": "BUDGET_MODE_TOTAL",
        "campaign_name": "{{campaign_name}}",
