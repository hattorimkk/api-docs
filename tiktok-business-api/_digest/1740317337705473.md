# (Deprecated) Get the results of an async task
> Đường dẫn: API Reference > (Deprecated) Dynamic Scene > (Deprecated) Get the results of an async task
> Độ dài nguồn: 6858 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
Use this endpoint to get the results of an async task.

If the task completes (`status` = `SUCCESS`), you can call [/dynamic_scene/get/](doc:1740317360823297) to download videos that are generated from the material package you submit.

> **Note:** The Dynamic Scene API is now in beta. If you would like access to this feature, please apply for the allowlisting using the [Allowlist Management](https://ads.tiktok.com/marketing_api/blog/detail/7102266224578396162) page. 

## Request

**Endpoint**

https://business-api.tiktok.com/open_api/v1.3/dynamic_scene/task/get/

**Method** GET

**Header**
