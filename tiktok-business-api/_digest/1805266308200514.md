# Payload Converter
> Đường dẫn: Marketing API > Ad Measurement > Guides > Events API 2.0 > Payload Converter
> Độ dài nguồn: 26381 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This guide takes you through the process of using the Payload Converter for the Events API. 

The Payload Converter provides a solution that automatically identifies the channel of an external payload, such as Meta, at TikTok's server side. It then converts it into a format equivalent for TikTok. As a result, advertisers can directly send pre-constructed events to TikTok via Events API.

## Before you begin
Please follow these [steps](doc:1771100865818625) to get started with web data connection with TikTok to start sending events to TikTok using the Payload Converter.

## Send Requests
To send new events, make a `POST` request to Events API's endpoint: [https://business-api.tiktok.com/open_api/v1.3/event/track/](doc:1771101303285761).

| Header Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. ⏎ To obtain an access token, refer to [Events API 2.0 - Authentication](doc:1771101130925058). |
| X-Event-Source-ID  **(Required)** | string | Pixel ID. |
| Content-Type **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |
| X-Ttp-Cookie | string | For setting up deduplication between TikTok Pixel and Events API. ⏎ See Deduplication with Payload Converter for more details |
