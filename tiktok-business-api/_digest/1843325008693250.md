# Create Upgraded Smart+ Automotive Ads for Inventory
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Lead Generation Campaigns > Create Upgraded Smart+ Automotive Ads > Create Upgraded Smart+ Automotive Ads for Inventory
> Độ dài nguồn: 62369 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
Upgraded Smart+ Automotive Ads for Inventory are Upgraded Smart+ Automotive Ads created using an Auto-Inventory catalog. 

# Prerequisite

Creating Automotive Ads for Inventory requires setting up an **Auto-Inventory catalog** in Business Center first.

To set up the catalog:

1. Create an Auto-Inventory catalog using [/catalog/create/](doc:1740306481704961).

2. Upload products to the catalog using [/catalog/product/upload/](doc:1740497429681153) (JSON schema), [/catalog/product/file/](doc:1740496787164161) (CSV feed template), or [/catalog/feed/create/](doc:1740665161957377)(online data feed schedule).

3. Check the product handling results.
	- For CSV feed and JSON schema, use [/catalog/product/log/](doc:1740570027173889).
		- Pass in the `feed_log_id` obtained from Step 2. If the field `error_affected_products` in the response is not null, examine the issue details and return to Step 2 to reupload the product.
	- For online feed, use [/catalog/feed/log/](doc:1740665225631810).
		- Pass in the `feed_id` obtained from Step 2. If the field `error_count` in the response is not 0, examine your online feed and return to Step 2 to reupload the product.

4. (Optional) Create an Auto-Inventory product set using [/catalog/set/create/](doc:1740572891104257).
If you want to have products selected from a product set at the ad level, creating a product set is necessary. Otherwise, you can skip this step.

5. (Optional) Invite members to Business Center and grant the admin permission us
