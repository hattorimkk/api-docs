# (Deprecated) Create Dynamic Showcase Ads
> Đường dẫn: Use Cases > Campaign creation > (Deprecated) Create Dynamic Showcase Ads > (Deprecated) Create Dynamic Showcase Ads
> Độ dài nguồn: 17161 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
To create Dynamic Showcase Ads, please follow the steps:
1. Create a catalog.
2. Upload products to the catalog.
3. Optional: Create a product set to filter products that you want to promote.
4. Bind event sources to the catalog.
5. Create a DSA campaign.
6. Create an ad group.
7. Create an ad.

> **Note:** Starting from Feb.16, 2023, you can no longer create Dynamic Showcase Ads.  To ensure a smooth API integration, we recommend you migrate to [Video Shopping Ads](doc:1741942291730434)  under Product Sales objective. The modification of existing Dynamic Showcase Ads through API will be supported till the end of March, and may be extended on a case-by-case basis. If you need extra transition time, please contact your TikTok representatives.

# 1. Create a catalog

A catalog is an asset that allows you to store information about the products you want to promote on TikTok. When you create a catalog you can create ads that showcase specific products with up-to-date information about each product, like price, availability, sizes, and more.
