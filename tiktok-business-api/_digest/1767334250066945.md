# (To be deprecated) Update a Legacy Smart+ Campaign
> Đường dẫn: API Reference > (To be deprecated) Legacy Smart+ > (To be deprecated) Update a Legacy Smart+ Campaign
> Độ dài nguồn: 65433 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
Use this endpoint to update a Smart+ Campaign. Not all information of a Smart+ Campaign can be modified (For example, **placement**). The endpoint supports incremental updates. 
> **Note:** 
> You can not update a Smart+ Campaign via [/campaign/update/](doc:1739320422086657), [/adgroup/update/](doc:1739586761631745), and [/ad/update/](doc:1739953405142018). 

> **Important:** 
> - **Upgraded Smart+ API**:
>     - We are actively upgrading the Smart+ API to deliver enhanced capabilities and performance. The new Upgraded Smart+ API is already launched. Learn more about [Upgraded Smart+ Campaign](doc:1853452461203458) and [available Upgraded Smart+ API endpoints](doc:1843301794874370).
>     - **Get started**:
>         - **Reporting**: No additional allowlist required.
>         - **Campaign Management**: To access the upgraded Smart+ experience, contact your TikTok sales representative to have your ad account allowlisted. If your ad account is already in the allowlist, you can directly use the Upgraded Smart+ API creation and modification endpoints.  
> - **Legacy API Deprecation**: 
>     - After **March 31, 2026**, you will no longer be able to create legacy Smart+ Campaigns using the [/campaign/spc/create/](doc:1767334204047362) endpoint.
>     - Note that legacy Smart+ Campaigns that have not been migrated will not be transitioned to the new API automatically. Attempts to use the legacy Smart+ API endpoint afterward will result in errors, rendering new campaign creation vi
