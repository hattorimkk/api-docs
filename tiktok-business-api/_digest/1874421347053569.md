# Create Upgraded Smart+ Web Generic Catalog Ads
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Web Campaigns > Create Upgraded Smart+ Web Generic Catalog Ads
> Độ dài nguồn: 51848 ký tự (đã rút gọn)

## Phần mở đầu của nguồn
This article walks you through the steps to create Upgraded Smart+ Web Generic Catalog Ads.

Upgraded Smart+ Web Generic Catalog Ads are Upgraded Smart+ Web Campaigns that use generic catalog products to deliver ads.

For such campaigns, you need to set `catalog_enabled` to `true` and `catalog_type` to `GENERIC` at the campaign level. By utilizing Upgraded Smart+ Web Generic Catalog Ads, you can automatically generate ads in diverse formats such as catalog video, catalog carousel, and single video.

# Prerequisites
Creating Upgraded Smart+ Web Generic Catalog Ads requires setting up a generic catalog in your Business Center first.

To set up the catalog, see [Create a generic catalog](slug:create-a-generic-catalog).
