# Use cases — tổng quan, Audience, Báo cáo

Tài liệu này cung cấp cái nhìn tổng quan về các tình huống sử dụng (use cases) tiêu biểu của TikTok API for Business. Thông qua việc tích hợp API, bạn có thể tự động hóa quy trình quảng cáo, quản lý tệp đối tượng, khởi tạo chiến dịch, thu thập khách hàng tiềm năng và trích xuất báo cáo dữ liệu theo nhu cầu kinh doanh.

## Tổng quan các tình huống sử dụng (`Use Cases`)
<a id="doc-1735713713137730"></a>

> Đường dẫn: Use Cases

TikTok API for Business cho phép bạn xây dựng các chức năng theo nhu cầu doanh nghiệp của mình, giúp việc quảng cáo trở nên tự động hóa, thông minh và tùy biến hơn. Chương này cung cấp cái nhìn tổng quan về các tình huống sử dụng của TikTok API for Business:

- [Tích hợp tệp đối tượng (Audience integration)](use-case-audience.md#doc-1758526010304514): Bạn có thể sử dụng Audience API để tạo tệp đối tượng và áp dụng vào các nhóm quảng cáo (ad groups) của mình.
- [Tạo chiến dịch (Campaign creation)](use-case-tao-chien-dich-p1.md#doc-1758526151905281): Bạn có thể sử dụng Campaign Management API để tạo nhiều loại quảng cáo khác nhau, chẳng hạn như Shopping Ads và Spark Ads.
- [Thu thập khách hàng tiềm năng (Lead generation)](use-case-lead-generation.md#doc-1739289524101122): Bạn có thể sử dụng Leads API hoặc Subscription API để truy xuất dữ liệu khách hàng tiềm năng (leads).
- [Báo cáo (Reporting)](use-case-bao-cao.md#doc-1758528841973762): Bạn có thể sử dụng Reporting API để khởi chạy báo cáo đồng bộ hoặc bất đồng bộ tùy chỉnh theo nhu cầu kinh doanh.
- [Đăng ký Webhook (Webhook subscription)](use-case-webhook.md#doc-1810521709205505): Bạn có thể đăng ký webhook để nhận cập nhật theo thời gian thực về khách hàng tiềm năng, trạng thái xét duyệt quảng cáo, cảnh báo bão hòa/suy giảm quảng cáo (ad fatigue status) hoặc trạng thái ủy quyền Spark Ads của video cho đơn hàng TikTok Creator Marketplace (TCM).
- [Yêu cầu dữ liệu Media Mix Modeling (Media Mix Modeling data request)](use-case-mmm.md#doc-1825298892472513): Bạn có thể sử dụng Media Mix Modeling (MMM) API để truy cập dữ liệu MMM cho một hoặc nhiều tài khoản quảng cáo.
