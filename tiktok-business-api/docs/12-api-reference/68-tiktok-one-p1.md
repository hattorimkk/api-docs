# Get, renew or revoke a Creator access token
> Đường dẫn: API Reference > TikTok One > Get, renew or revoke a Creator access token
- To get or renew the short-term Creator access token, you can use /tt_user/oauth2/token/ and /tt_user/oauth2/refresh_token/ respectively.
	- The `/tt_user/oauth2/token/` endpoint now requires `redirect_uri` for better security. The short-term Creator access token remains valid for 24 hours, whereas the Creator refresh token remains valid for a year. You can get the access token using `/tt_user/oauth2/token/` and refresh it daily with the refresh token via `/tt_user/oauth2/refresh_token/` within one year. However, after one year, you need the creator to reauthorize it.
- To revoke a Creator access token, use /tt_user/oauth2/revoke/.

Sử dụng endpoint này để lấy thông tin a Creator access token.

**Method** POST

|---|---|---|

**Parameters**

| Trường (Field) | Kiểu dữ liệu | Mô tả chi tiết |
|---|---|---|

| client_secret ****(Bắt buộc)**** | string | Secret of your developer app. ⏎ To find the **Secret**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |

# Check TTO Creator Status
> Đường dẫn: API Reference > TikTok One > Check TTO Creator Status
Sử dụng endpoint này để kiểm tra if TikTok users have already become TikTok One (TTO) Creators. 

Bạn có thể kiểm tra trạng thái của tối đa 20 người dùng cùng lúc bằng `tto_tcm_account_id` và `handle_names`.

## Yêu cầu gọi API (Request)

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tto/tcm/creator/status/get/

**Method** GET

**Header**

| Trường (Field) | Kiểu dữ liệu | Mô tả chi tiết |
|---|---|---|
| Access-Token   ****(Bắt buộc)**** | string | Access token authorized by TTO Creator Marketplace accounts. ⏎ Để biết chi tiết, xem [Authentication](../10-organic-api/tiktok-one-api.md#doc-1825117875361793). |

**Parameters**

| Trường (Field) | Kiểu dữ liệu | Mô tả chi tiết |
|---|---|---|
| tto_tcm_account_id  ****(Bắt buộc)**** | string | The ID of the TTO Creator Marketplace account. ⏎ To obtain the IDs of the accounts that you can access via `Access-Token`, use [/tto/oauth2/tcm/](68-tiktok-one-p1.md#doc-1815693478150146). |
| handle_names  ****(Bắt buộc)**** | string[] | The handle names of TikTok Creators. ⏎ Kích thước tối đa: 20. |

### Ví dụ lệnh cURL (Example)

# Get TTO Public Media Insights
> Đường dẫn: API Reference > TikTok One > Get TTO Public Media Insights
Sử dụng endpoint này để lấy thông tin information about the videos of a creator on [TikTok One (TTO) Creator Marketplace](https://ads.tiktok.com/creative/creatormarketplace).

## Comparing TCM and TTO Creator Marketplace endpoints

Bảng sau nêu sự khác biệt giữa các endpoint TikTok Creator Marketplace (TCM) và TTO Creator Marketplace.

| Changes | TCM Endpoint | TTO Creator Marketplace Endpoint |
|---|---|---|
| Endpoint path | /v1.3/tcm/creator/public/video/list/ | /v1.3/tto/tcm/creator/public/video/list/ |
| Same request parameters | `video_ids` ⏎ `cursor` ⏎ `limit` | `video_ids` ⏎ `cursor` ⏎ `limit` |
| Deprecated request parameters | N/A | `creator_id` |
| New request parameters | N/A | `tto_tcm_account_id` ⏎ `handle_name` |
| Same response parameters | `posts` ⏎ `posts.video_id` ⏎ `posts.caption` ⏎ `posts.likes` ⏎ `posts.comments` ⏎ `posts.shares` ⏎ `posts.video_views` ⏎ `posts.embed_url` ⏎ `posts.thumbnail_url` ⏎ `posts.create_time` ⏎ `posts.display_name` ⏎ `page_info` ⏎ `page_info.has_more` ⏎ `page_info.cursor` | `posts` ⏎ `posts.video_id` ⏎ `posts.caption` ⏎ `posts.likes` ⏎ `posts.comments` ⏎ `posts.shares` ⏎ `posts.video_views` ⏎ `posts.embed_url` ⏎ `posts.thumbnail_url` ⏎ `posts.create_time` ⏎ `posts.display_name` ⏎ `page_info` ⏎ `page_info.has_more` ⏎ `page_info.cursor` |
| Deprecated response parameters | N/A | `posts.engagement_count` ⏎ `posts.engagement_rate` |
| New response parameters | N/A | `posts.favorites` |

## Yêu cầu gọi API (Request)

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tto/tcm/creator/public/video/list/

**Method** GET

**Header**

| Trường (Field) | Kiểu dữ liệu | Mô tả chi tiết |
|---|---|---|
| Access-Token  ****(Bắt buộc)**** | string | Access token authorized by a TTO Creator Marketplace account. ⏎ Để biết chi tiết, xem [Authentication](../10-organic-api/tiktok-one-api.md#doc-1825117875361793). |

**Parameters**

| Trường (Field) | Kiểu dữ liệu | Mô tả chi tiết |
|---|---|---|
|tto_tcm_account_id ***(Bắt buộc)***|string|The ID of the TTO Creator Marketplace account.<br><br>To obtain the IDs of the accounts that you can access via `Access-Token`, use [/tto/oauth2/tcm/](68-tiktok-one-p1.md#doc-1815693478150146).|
|handle_name ***(Bắt buộc)***|string|The handle name of the TTO Creator Marketplace creator that you want to search for.<br><br>The exact match is supported.<br><br><span style="color:darkred"><b>Note</b></span>: If you specify the handle name of a creator that is not on TTO Creator Marketplace yet, an error will occur.|
|video_ids|string[]|The IDs of the videos to filter the results by.<br><br>Kích thước tối đa: 25.<br><br>If this field is not specified, the results won't be filtered by video IDs.|
|cursor|number|The timestamp cursor of the video from which you want to retrieve subsequent videos.<br><br>If the response parameter `has_more` is `true`, pass the returned `cursor` to this parameter in the next request to retrieve the subsequent videos.<br><br>Giá trị mặc định: 0. By default, the most recent videos will be returned.|
|limit|number|The number of posts to return for each request.<br><br>Value range: 1-25.<br><br>Giá trị mặc định: 10.|

```http
--header 'Access-Token: {{access_token}}' \
```

# Discover TTO creators
> Đường dẫn: API Reference > TikTok One > Discover TTO creators
Sử dụng endpoint này để tìm kiếm TikTok One (TTO) creators.

## Comparing TCM and TTO Creator Marketplace endpoints

Bảng sau nêu sự khác biệt giữa các endpoint TikTok Creator Marketplace (TCM) và TTO Creator Marketplace.

| Changes | TCM Endpoint | TTO Creator Marketplace Endpoint |
|---|---|---|
| Endpoint path | /v1.3/tcm/creator/discover/ | /v1.3/tto/tcm/creator/discover/ |
| Same request parameters | `min_followers` ⏎ `max_followers` ⏎ `languages` ⏎ `min_avg_views` ⏎ `max_avg_views` ⏎ `sort_field` ⏎ `page` ⏎ `page_size` | `min_followers` ⏎ `max_followers` ⏎ `languages` ⏎ `min_avg_views` ⏎ `max_avg_views` ⏎ `sort_field` ⏎ `page` ⏎ `page_size` |
| Deprecated request parameters | N/A | `tcm_account_id` ⏎ `country_code` ⏎ `engagement_rate` ⏎ `mobile_os` ⏎ `creator_categories` ⏎ `max_campaign_count` ⏎ `min_campaign_count` ⏎ `has_responsive_badge` ⏎ `major_audience_country_code` ⏎ `major_audience_gender` ⏎ `major_audience_age` ⏎ `query` |
| New request parameters | N/A | `tto_tcm_account_id` ⏎ `country_codes` ⏎ `state_provinces` ⏎ `content_label_ids` ⏎ `industry_label_ids` ⏎ `min_creator_price` ⏎ `max_creator_price` ⏎ `creator_price_currency` ⏎ `min_median_views` ⏎ `max_median_views` ⏎ `min_engagement_rate` ⏎ `max_engagement_rate` ⏎ `follower_country_codes` ⏎ `follower_gender_ratio` ⏎ `follower_age` ⏎ `keyword_search` ⏎ `sort_order` ⏎ `highly_responsive` ⏎ `highly_active` ⏎ `high_potential_to_drive_sales` ⏎ `high_quality_content_creator` |

# Create or update a TTO Creator Marketplace campaign
> Đường dẫn: API Reference > TikTok One > Create or update a TTO Creator Marketplace campaign
Sử dụng endpoint này để tạo or update a TikTok One (TTO) Creator Marketplace campaign.  

Bạn có thể tạo chiến dịch cùng với bất kỳ loại liên kết mời nào sau đây:
- A campaign-level invite link to associate videos with a specific campaign.
- A brand-level invite link to associate videos with your brand account.

Để tìm hiểu thêm về các loại liên kết mời, xem [TTO Creator Marketplace Content Linking](../10-organic-api/tiktok-one-api.md#doc-1830337139853313).

> **Note:** 
> - Orders are no longer used. Campaign reporting provides performance data for individual videos instead of orders.
> - Campaign codes are no longer used. Creators should now use invite links to tag videos. 
> - The campaigns that are created via this endpoint will be displayed on [the TTO Creator Marketplace platform](https://ads.tiktok.com/creative/creatormarketplace).
> - After you create a TTO Creator Marketplace campaign, if a creator wants to publish a video on your platform, you can ask the creator to directly link a video to the campaign during publication by specifying `tto_invite_link` in [/business/video/publish/](01-accounts-p1.md#doc-1762228496095234).

# Send or revoke a TTO video linking request
> Đường dẫn: API Reference > TikTok One > Send or revoke a TTO video linking request
Dùng endpoint này để gửi yêu cầu liên kết video công khai của nhà sáng tạo với chiến dịch TikTok One (TTO) Creator Marketplace, hoặc thu hồi yêu cầu đó.

**Method** POST

**Header**

| Content-Type  ****(Bắt buộc)**** | string | Định dạng dữ liệu yêu cầu. ⏎ Allowed format: `application/json`. |

**Parameters**

| Trường (Field) | Kiểu dữ liệu | Mô tả chi tiết |

## Hướng dẫn thực hành Data Retrieval (Python & cURL)

Dưới đây là mã nguồn mẫu minh họa quy trình gọi API thực tế cho phân hệ **TikTok One — phần 1/2**:

### cURL mẫu
```bash
curl -s -X GET "https://business-api.tiktok.com/open_api/v1.3/example/get/?advertiser_id=YOUR_ADVERTISER_ID" \
  -H "Access-Token: YOUR_ACCESS_TOKEN"
```

### Python script mẫu
```python
import requests
import json

ACCESS_TOKEN = "YOUR_ACCESS_TOKEN"
ADVERTISER_ID = "YOUR_ADVERTISER_ID"
BASE_URL = "https://business-api.tiktok.com/open_api/v1.3"

headers = {
    "Access-Token": ACCESS_TOKEN,
    "Content-Type": "application/json"
}

def execute_request():
    url = f"{BASE_URL}/example/get/"
    params = {"advertiser_id": ADVERTISER_ID}
    response = requests.get(url, headers=headers, params=params)
    data = response.json()
    if data.get("code") == 0:
        print("Truy vấn thành công:", data.get("data"))
        return data.get("data")
    else:
        print(f"Lỗi: {data.get('code')} - {data.get('message')}")
        return None

if __name__ == "__main__":
    execute_request()
```
