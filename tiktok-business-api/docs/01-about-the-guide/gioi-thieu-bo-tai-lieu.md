# About the Guide (Giới thiệu về bộ tài liệu)
> Đường dẫn: About the Guide

Chào mừng bạn đến với cẩm nang toàn diện về **TikTok API for Business**! Việc tìm hiểu cách sử dụng hiệu quả một công cụ hoặc tài nguyên mới đôi khi có thể là một thách thức, đặc biệt là khi có một lượng lớn thông tin phong phú cần tiếp nhận. Đó là lý do tại sao chúng tôi biên soạn tài liệu nhập môn này để giúp bạn làm quen nhanh chóng với bộ cẩm nang. Tài liệu này cung cấp cho bạn một cái nhìn tổng quan và các chiến lược định hướng để điều hướng qua khối lượng thông tin phong phú, đảm bảo bạn có một trải nghiệm mượt mà và hiệu quả với TikTok API for Business.

## Tổ chức cấu trúc tài liệu

Tài liệu được cấu trúc khoa học để giúp bạn dễ dàng điều hướng và tìm kiếm thông tin cần thiết. Dưới đây là tổng quan về 16 phân hệ chính:

- [Tổng quan (Overview)](../02-overview/tong-quan-va-phien-ban.md#doc-1735712062490625): Nắm bắt hiểu biết cấp cao về TikTok API for Business và các năng lực cốt lõi. Phần này giới thiệu nền tảng và các lợi ích mang lại.
- [Có gì mới (What's New)](../03-whats-new/co-gi-moi.md#doc-1740029165513730): Cập nhật hàng tuần các tính năng mới nhất, cải tiến và thay đổi đối với TikTok API for Business.
- [Bắt đầu (Get Started)](../04-get-started/bat-dau.md#doc-1735713609895937): Tìm hiểu sâu về quy trình tích hợp với TikTok API for Business. Phần này bao gồm làm rõ các khái niệm, cấu trúc tài khoản và hướng dẫn từng bước từ thiết lập tài khoản nhà phát triển, tạo App, cấp quyền OAuth cho đến thực hiện các lượt gọi API đầu tiên.
- [Câu hỏi thường gặp (FAQs)](../07-faqs/faq.md#doc-1740029175352322): Tìm kiếm câu trả lời cho các thắc mắc phổ biến về TikTok API for Business.
- [Tình huống sử dụng (Use Cases)](../08-use-cases/use-cases.md#doc-1735713713137730): Khám phá các cẩm nang triển khai thực tế minh họa cách khai thác năng lực của TikTok API for Business trong các ngữ cảnh khác nhau như tạo chiến dịch, tích hợp tệp đối tượng, thu thập khách hàng tiềm năng và báo cáo.
- [Marketing API](../09-marketing-api/marketing-api-gioi-thieu.md#doc-1781891416235009): Chuyên sâu về bộ sản phẩm Marketing API, bao gồm quản lý chiến dịch, quản lý Business Center, quản lý tài sản sáng tạo (Creatives) và quản lý tệp đối tượng (Audience).
- [Organic API](../10-organic-api/tong-quan.md#doc-1825101624331329): Quản lý sự hiện diện tự nhiên của thương hiệu trên TikTok, bao gồm Accounts, Mentions, TikTok One, Discovery và Gợi ý Spark Ads.
- [Business Messaging API](../11-business-messaging-api/business-messaging-api.md#doc-1832183871604753): Tích hợp giải pháp nhắn tin trực tiếp với người dùng TikTok, phản hồi tự động thời gian thực qua Webhook và quản lý hội thoại khách hàng.
- [API Reference](../12-api-reference/README.md): Tài liệu tham chiếu kỹ thuật chi tiết cho toàn bộ 74 nhóm API endpoints, cấu trúc yêu cầu/phản hồi, bảng mã tham số và ví dụ cURL hoàn chỉnh.
- [Môi trường thử nghiệm (API Playground)](../13-api-playground/api-playground.md): Trải nghiệm và kiểm thử trực tiếp các endpoint trên web.
- [Trạng thái dịch vụ (API Service Status)](../14-api-service-status/trang-thai-dich-vu.md): Giám sát tình trạng hoạt động và tính khả dụng của máy chủ API.
- [Phụ lục (Appendix)](../15-appendix/phu-luc-p1.md#doc-1737172315193346): Tra cứu các tài liệu bổ trợ như mã lỗi (Return codes), bảng kê Enumeration, bảng mã vị trí Location IDs và chính sách quảng cáo.
- [SDK](../16-sdk/sdk.md#doc-1764231376750658): Hướng dẫn sử dụng các bộ SDK chính thức giúp tối ưu hóa thời gian tích hợp.

### Tài nguyên bổ trợ
- [Developer Blog](https://business-api.tiktok.com/portal/blog): Các thông báo chính thức và hướng dẫn kỹ thuật từ đội ngũ kỹ sư TikTok.
- [TikTok Business Help Center](https://ads.tiktok.com/help/): Trung tâm trợ giúp dành cho nhà quảng cáo.

## Quy chuẩn gọi API bằng cURL

Mọi yêu cầu gọi TikTok Business API đều được thực thi qua giao thức HTTP/HTTPS với cURL:

```bash
# Lấy thông tin tài khoản nhà quảng cáo
curl -X GET "https://business-api.tiktok.com/open_api/v1.3/advertiser/info/?advertiser_ids=%5B%22YOUR_ADVERTISER_ID%22%5D" \
  -H "Access-Token: YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json"
```
