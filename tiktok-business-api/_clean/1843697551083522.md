# Enable or disable Comment-to-Message for a TikTok account
> Đường dẫn: API Reference > Business Messaging > Direct messages > Enable or disable Comment-to-Message for a TikTok account
Use this endpoint to enable or disable the Comment-to-Message feature for a TikTok account.

The Comment-to-Message feature enables businesses to proactively engage with users by sending direct messages in response to high-intent comments on their video posts. A high-intent comment is one that expresses a strong intention to purchase or seek further information. When you enable this feature, the TikTok system will identify those high-intent comments, allowing you to send customized replies using  [/business/message/send/](doc:1832184403754242) and assist these users more effectively.

> **Note:** 
> - The Comment-to-Message feature is only available for TikTok accounts registered in Vietnam, Indonesia, and Thailand. 
> - Once you enable Comment-to-Message for a TikTok account, the TikTok account can only reply to comments published by TikTok accounts that are registered in the APAC, LATAM, and METAP regions. 

## Before you start
Ensure the TikTok account meets the following eligibility requirements:

- The account owner is over 18 years old.
- The account is a [Verified Business Account](https://ads.tiktok.com/help/article/about-business-registration) or a TikTok Account with Advanced Access with [TikTok Messaging Ads](https://ads.tiktok.com/help/article/about-tiktok-messaging-ads) history in the last 7 days. Learn more [about TikTok account entitlements](https://ads.tiktok.com/resources/help/article/about-tiktok-account-entitlements). 
  - To confirm whether your TikTok account is already a Verified Business Account or a TikTok Account with Advanced Access, use [/business/get/](slug:get-profile-data-of-a-tiktok-account) and check whether the response parameter `has_advanced_access` is `true` for the TikTok account.
- The messaging permissions "Potential connections" and "Other on TikTok" of the account are set to "Requests".

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/message/direct_reply/update/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok account owner. ⏎ To obtain an access token, use [/tt_user/oauth2/token/](doc:1738084387220481). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `application/json`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| business_id  **(Required)** | string | Application specific unique identifier for the TikTok account. ⏎ Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1738084387220481) to this field. |
| direct_reply_type  **(Required)** | string | The type of direct reply. ⏎ Enum value: •  `COMMENT_TO_MESSAGE`: Comment-to-Message. Once you enable this feature, the TikTok system will identify high-intent comments, enabling you to send customized replies to assist these users more effectively. |
| operation_status  **(Required)** | string | The operation to perform. ⏎ Enum values: • `ENABLE`: To enable the Comment-to-Message feature. • `DISABLE`: To disable the Comment-to-Message feature. |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/message/direct_reply/update/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "business_id": "{{business_id}}",
    "direct_reply_type": "COMMENT_TO_MESSAGE",
    "operation_status": "ENABLE"
}'
```
