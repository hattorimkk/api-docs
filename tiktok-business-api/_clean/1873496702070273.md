# MCP Authorization
> Đường dẫn: API Reference > MCP Authorization
The Model Context Protocol (MCP) is an open standard that allows you to establish secure, two-way connections between your AI applications and TikTok for Business data sources. The MCP Authorization API enables you to connect your custom agent to TikTok for Business MCP server.

To learn more about how to establish the connection, see [How to connect a custom agent to TikTok for Business MCP Server](slug:how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server).

This group consists of the following endpoints:

- [Get authorization server metadata](slug:get-authorization-server-metadata)
- [Discover authorization servers](slug:discover-authorization-servers)
- [Register a client application](slug:register-a-client-application)
- [Request user authorization](slug:request-user-authorization)
- [Exchange an MCP authorization code for tokens](slug:exchange-an-mcp-authorization-code-for-tokens)
- [Refresh an MCP access token](slug:refresh-an-mcp-access-token)
- [Revoke an MCP token](slug:revoke-an-mcp-token)
- [Use MCP tools](slug:use-mcp-tools)
