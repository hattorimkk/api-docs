# Discover authorization servers
> Đường dẫn: API Reference > MCP Authorization > Discover authorization servers
Use this endpoint to retrieve the MCP resource metadata, which includes the authorization servers that control access to the resource.

You should use this to discover the correct authorization server when your agent initiates from the MCP resource.

# Request
**Endpoint** https://business-api.tiktok.com/.well-known/oauth-protected-resource/open_mcp/{server}/

**Method** GET

**Path parameters**

| Field | Data Type | Description |
|---|---|---|
| server  **(Required)** | string | The specific TikTok for Business MCP server URL. ⏎ Enum values: `tt-ads-mcp-flat`, `tt-ads-mcp-layer`. ⏎ To learn more about how these server URLs differ, see [Choose your server URL](https://business-api.tiktok.com/portal/docs/how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server/v1.3#anchor-3). |

## Example

> **Note:** 
> The example below uses `tt-ads-mcp-layer` as the `{server}` value. You can replace this with your chosen server value.

```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/.well-known/oauth-protected-resource/open_mcp/tt-ads-mcp-layer'
```

# Response

| Field | Data Type | Description |
|---|---|---|
| resource | string | The official canonical URL for the requested MCP resource. |
| authorization_servers | string[] | The list of URLs for the authorization servers associated with this MCP server. |
| scopes_supported | string[] | The list of supported permission scopes. ⏎ Enum value: • `mcp:tt4b`: the necessary permissions to access TikTok for Business MCP server features. ⏎ Example: `["mcp:tt4b"]`. |
| bearer_methods_supported | string[] | The list of supported bearer token transport methods. ⏎ A bearer token is an OAuth 2.0 access token where possession of the token itself is sufficient for access. ⏎ Enum value: •  `header`: You need to pass the token in the HTTP authorization header. ⏎ Example: `["header"]`. |

## Example
```http
// curl
{
  "resource": "https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer",
  "authorization_servers": [
    "https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer/oauth"
  ],
  "scopes_supported": ["mcp:tt4b"],
  "bearer_methods_supported": ["header"]
}
```
