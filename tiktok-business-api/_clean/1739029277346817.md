# Delete blocked words
> Đường dẫn: API Reference > Ad Comments - Blocked Words > Delete blocked words
Use this endpoint to delete one or more blocked words from the blocked word list. 

When a blocked word is deleted, comments that contain this word will become public instead of being visible only to the commentor. 

## Request

**Endpoint**
https://business-api.tiktok.com/open_api/v1.3/blockedword/delete/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Content type of the request. Allowed value: `application/json` |

**Parameters**

| Field | Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID |
| blocked_words  **(Required)** | string[] | List of blocked words that you want to delete. ⏎ **Note**: If you attempt to delete a word that is not on the blocked word list, no errors will occur. |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/blockedword/delete/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
  "advertiser_id": "{{advertiser_id}}",
  "blocked_words": [
    "hell"
  ]
}'
```
## Response

| Field | Type | Description |
|---|---|---|
| message | string | The return message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| code | number | The return code. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| data | object | The returned data |
| request_id | string | Unique ID of the request |
