# Revoke an MCP token
> Đường dẫn: API Reference > MCP Authorization > Revoke an MCP token
Use this endpoint to revoke an access token or refresh token, allowing you to end a connection early.

The endpoint is idempotent.

# Request
**Endpoint** https://business-api.tiktok.com/open_mcp/{server}/oauth/revoke/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/x-www-form-urlencoded`. |

**Path parameters**

| Field | Data Type | Description |
|---|---|---|
| server  **(Required)** | string | The specific TikTok for Business MCP server URL. ⏎ Enum values: `tt-ads-mcp-flat`, `tt-ads-mcp-layer`. ⏎ To learn more about how these server URLs differ, see [Choose your server URL](https://business-api.tiktok.com/portal/docs/how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server/v1.3#anchor-3). |

## Example

> **Note:** 
> The example below uses `tt-ads-mcp-layer` as the `{server}` value. You can replace this with your chosen server value.

```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer/oauth/revoke' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'token={{token}}' \
--data-urlencode 'token_type_hint=access_token'
```

# Response

A successful request returns HTTP `200 OK`.

| Field | Data Type | Description |
|---|---|---|
| revoked | boolean | Whether your request to revoke the token was successful. ⏎ Supported values: `true`, `false`. ⏎ **Note**: This field will return `true` even if you send an unknown, invalid, or already-expired token. This is because the endpoint is idempotent. If the token cannot be used anyway, the server safely ignores it and considers the revocation successful. |

## Example
```http
// curl
{
    "revoked": true
}
```

## Error response

A failure returns HTTP `400 Bad Request`.

| Field | Data Type | Description |
|---|---|---|
| error | string | Error code. ⏎ To learn about the possible errors and descriptions, see [List of possible errors](https://business-api.tiktok.com/portal/docs/revoke-an-mcp-token/v1.3#anchor-2-2-1). |
| error_description | string | The human-readable description of the error. ⏎ To learn about the possible errors and descriptions, see [List of possible errors](https://business-api.tiktok.com/portal/docs/revoke-an-mcp-token/v1.3#anchor-2-2-1). |

### List of possible errors

| error | error_description |
|---|---|
| `invalid_request` | `token is required.` |
| `invalid_request` | `token_type_hint invalid` |
