# Create an Upgraded Smart+ DC App Search Ads Campaign
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ App Promotion Search Ads Campaign > Create an Upgraded Smart+ DC App Search Ads Campaign
This article explains how to create an Upgraded Smart+ DC App Search Ads Campaign.

This setup is an App Search Ads Campaign with the iOS 14 dedicated campaign setting enabled. To configure it, set the `campaign_type` parameter to `IOS14_CAMPAIGN`.

# Steps
## 1. Create a campaign
Create a campaign using [/smart_plus/campaign/create/](slug:create-an-upgraded-smart-campaign). 

Note that the following requirements must be met. To find a complete list of parameters, see [/smart_plus/campaign/create/](slug:create-an-upgraded-smart-campaign).
