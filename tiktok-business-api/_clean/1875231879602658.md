# Create Upgraded Smart+ App O2O Catalog Ads
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ App Campaigns > Create Upgraded Smart+ App O2O Catalog Ads
This article walks you through the steps to create Upgraded Smart+ App Online-to-Offline (O2O) Catalog Ads.

Based on your iOS 14 Dedicated Campaign (DC) requirements, you can choose to set up either non-DC or DC App O2O Catalog Ads.

- To create a non-DC Campaign using an O2O catalog, see [Create Upgraded Smart+ non-DC App O2O Catalog Ads](slug:create-upgraded-smart-non-dc-app-o2o-catalog-ads).
- To create a DC Campaign using an O2O catalog, see [Create Upgraded Smart+ DC App O2O Catalog Ads](slug:create-upgraded-smart-dc-app-o2o-catalog-ads).
