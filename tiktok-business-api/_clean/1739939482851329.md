# Delete a member from a BC or revoke a member invitation
> Đường dẫn: API Reference > BC Members > Delete a member from a BC or revoke a member invitation
Use this endpoint to delete a member in a Business Center or revoke a member invitation. You need to be an Admin of the Business Center.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/bc/member/delete/

**Method** POST

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token{Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162).|
|Content-Type {Required}|string|The content type of the request.<br>Allowed value: `"application/json"`  |

```

**Parameters**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|bc_id {Required} | string | Business Center ID.|
| user_id {+Conditional}| string| Required when you want to remove existing members.<br><br>User ID.<br><br>To obtain the user IDs of existing members in a Business Center, use [/bc/member/get/](doc:1739939404802049) and check the returned `user_id`. |
| user_email {+Conditional}| string |  Required when you want to revoke the member invitation for a user.<br><br>User email. <br><br>To obtain the user emails of invited members for a Business Center, use [/bc/member/get/](doc:1739939404802049) and check the returned `user_email`. |
```

### Example

```http
// curl
curl -H "Access-Token:xxx" -H "Content-Type:application/json" -X POST \
-d '{
    "bc_id": "BC_ID",
    "user_id": "USER_ID",
    "user_email": "USER_EMAIL"
}' \
https://business-api.tiktok.com/open_api/v1.3/bc/member/delete/
```
