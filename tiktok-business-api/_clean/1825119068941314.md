# Get trending videos related to tracks
> Đường dẫn: API Reference > Discovery > Get trending videos related to tracks
Use this endpoint to retrieve the top trending videos that use a popular track in a selected region. 

## Before you start
Call [/discovery/cml/trending_list/](doc:1825119063013505) to obtain a list of popular tracks from the Commercial Music Library.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/discovery/cml/video_list/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok creators. ⏎ To obtain an access token, use [/tt_user/oauth2/token/](doc:1738084387220481). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| business_id  **(Required)** | string | Application specific unique identifier for the TikTok account. ⏎ Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1738084387220481) to this field. |
| commercial_music_id  **(Required)** | string | The ID of the track. |
| country_code | string | The code of the location to filter the results by. ⏎ Default value: `US`. ⏎ See [Location code](doc:1737585867307010) for the supported values. |

### Example
```http
// curl
curl --location  --request GET 'https://business-api.tiktok.com/open_api/v1.3/discovery/cml/video_list/?business_id={{business_id}}&commercial_music_id={{commercial_music_id}}&country_code=US' \
--header 'Access-Token: {{Access-Token}}'
```
