# Delete an existing comment on an owned video
> Đường dẫn: API Reference > Accounts > Comments > Delete an existing comment on an owned video
Use this endpoint to delete an** owned comment** on an organic video posted by an owned TikTok Account.

> **Note:** 
>   • Comments made by other users cannot be deleted, and can only be hidden. You can hide comments using [/business/comments/hide/](doc:1762228474532865). • The comment webhook event [comment.update](doc:1810515104773122) enables you to get notifications within five minutes of a comment or reply being deleted from any public video associated with an owned TikTok account. To subscribe to the comment webhook, see [Subscribe to the comment update event](doc:1810521730276354).

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/comment/delete/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok creators. ⏎ To obtain an access token, use [/tt_user/oauth2/token/](doc:1833997638479041). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

``` xtable
|Field{20%}|Data Type{10%}| Param Location{15%}|Description{55%}|
|--- |--- |--- |--- |
| business_id {Required} | string | Body | Application specific unique identifier for the TikTok account. <br>Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1833997638479041) to this field.|
| comment_id {Required} | string | Body |Unique identifier for <strong>owned comment </strong>on an owned TikTok video to delete.. This can be accessed via the [/business/comment/list/](doc:1760232109619202) endpoint as the `comment_id` for each comment listed. |
```
### Example
```http
// curl
curl -L -X POST 'https://business-api.tiktok.com/open_api/v1.3/business/comment/delete/' \
-H 'Content-Type: application/json' \
-H 'Access-Token: 1234a16d2e08c3f17d1984a1be07d00406p3LIAF7vEpxliox8GRpCINv70x' \
--data-raw '{
  "business_id": "b3d2f73d-4b8c-47fb-85c3-cd571287754b",
  "comment_id": "b3d2f73d-4b8c-47fb-85c3-cd571287754b"
}'
```
