# Manage the new follower message for a TikTok account
> Đường dẫn: Business Messaging API > Guides > Manage automatic messages for a TikTok account > Manage the new follower message for a TikTok account
This article walks you through the steps for managing the new follower message for a TikTok account using Business Messaging API.
## Introduction
A new follower message is an automated greeting sent to users the moment they follow you. With the Business Messaging API, you can create a new follower message or modify the default one to suit your brand's voice. Each TikTok account can have one customized new follower message.

**You can use Business Messaging API to greet followers in a personalized and engaging way, fostering stronger connections and enhancing the overall user experience.**

## Prerequisites

- You've gained access to TikTok API for Business. See [Get Started - Step by step workflow](slug:get-started-guide) for details.
  - To manage the new follower message for a TikTok account, you need relevant permissions. See [API Reference](slug:api-reference) to find out permissions required for endpoints (including the endpoints listed in the "Steps" section) and see [Update app permissions](slug:app-permissions) to find out how to configure permissions.
- You have followed the steps in [Authorization](slug:authorization) and [Authentication](slug:business-messaging-api-authentication) to obtain a TikTok account access token and the Application specific unique ID for the TikTok account.
- If you want to use the new follower message feature, you need to ensure that the TikTok account is a [Verified Business Account](https://ads.tiktok.com/help/article/about-business-registration) or a TikTok Account with Advanced Access with [TikTok Messaging Ads](https://ads.tiktok.com/help/article/about-tiktok-messaging-ads) history in the last 7 days. Learn more [about TikTok account entitlements](https://ads.tiktok.com/resources/help/article/about-tiktok-account-entitlements). 
  - To confirm whether your TikTok account is already a Verified Business Account or a TikTok Account with Advanced Access, use [/business/get/](slug:get-profile-data-of-a-tiktok-account) and check whether the response parameter `has_advanced_access` is `true` for the TikTok account.
## Steps

To manage the new follower message for a TikTok account, follow these steps:

1. **Check the availability of the new follower message for the TikTok account** using [/business/message/capabilities/get/](slug:check-the-capability-of-a-business-account-for-a-conversation).
  - Set `capability_types` to `["FOLLOW_WELCOME"]`.
2. **Retrieve the specific message options available for the TikTok account** using [/business/message/auto_message/get/](slug:get-the-automatic-messages-for-a-business-account).
  - If `capability_result` returned in step 1 is `true`, check the `button_options` returned from this endpoint to confirm the exact new follower message settings available for the account.

3. **Set up the new follower message** using [/business/message/auto_message/create/](slug:create-an-automatic-message-for-a-business-account).
  - Set `auto_message_type` to `FOLLOW_WELCOME` and specify your configuration in the `follow_welcome` object.

4. **Verify the status of the new follower message** using [/business/message/auto_message/get/](slug:get-the-automatic-messages-for-a-business-account).
  - Set `auto_message_type` to `FOLLOW_WELCOME` and confirm that the `audit_status` of the message is `APPROVED` and `operation_status` is `ENABLE`.

5. **Handle potential issues**.
  - If `audit_status` is not `APPROVED`:
    1. Update the new follower message using [/business/message/auto_message/update/](slug:update-the-automatic-message-for-a-business-account).
    2. Recheck the status with [/business/message/auto_message/get/](slug:get-the-automatic-messages-for-a-business-account).
  - If `operation_status` is `DISABLE`:
    - Enable the new follower message setting using [/business/message/auto_message/status/update/](slug:turn-on-or-turn-off-an-automatic-message-for-a-business-account) and set `operation_status` to `ENABLE`.
