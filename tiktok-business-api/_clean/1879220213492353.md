# Create Upgraded Smart+ App Travel Catalog Ads
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ App Campaigns > Create Upgraded Smart+ App Travel Catalog Ads
This article walks you through the steps to create Upgraded Smart+ App Travel Catalog Ads.

Upgraded Smart+ App Travel Catalog Ads are App Campaigns that operate with the iOS 14 dedicated campaign setting disabled, utilizing travel (hotel, flight, or destination) catalog products for ad delivery.

To set up this campaign type, apply the following campaign-level parameters: set `campaign_type` to `REGULAR_CAMPAIGN` (or leave it unspecified), set `catalog_enabled` to `true`, and set `catalog_type` to `TRAVEL_ENTERTAINMENT`.

# Prerequisites
- Creating App Travel Catalog Ads is currently an allowlist-only feature. If you would like to access it, please contact your TikTok representative.
- Creating App Travel Catalog Ads requires setting up a travel (hotel, flight, or destination) catalog in a Business Center first.

To set up the catalog:

1. Create a travel (hotel, flight, or destination) catalog using [/catalog/create/](slug:create-a-catalog).

2. Upload products to the catalog using [/catalog/product/upload/](slug:upload-products-via-a-json-schema) (JSON schema), [/catalog/product/file/](slug:upload-products-via-a-file-url) (CSV feed template), or [/catalog/feed/create/](slug:create-a-feed)(online data feed schedule).

3. Check the product handling results.
   - For CSV feed and JSON schema, use [/catalog/product/log/](slug:get-the-product-handling-log).
     - Pass in the `feed_log_id` obtained from Step 2. If the field `error_affected_products` in the response is not null, examine the issue details and return to Step 2 to reupload the product.
   - For online feed, use [/catalog/feed/log/](slug:get-the-log-of-a-feed).
     - Pass in the `feed_id` obtained from Step 2. If the field `error_count` in the response is not 0, examine your online feed and return to Step 2 to reupload the product.

4. Confirm that the catalog contains one or more available catalog products via the value of `approved` returned from [/catalog/overview/](slug:get-the-overview-of-a-catalog). Only available products can be delivered in your ads. The minimum number of required available catalog products varies based on your desired ad format:
   - If you want to use the Single Video or Catalog Video ad format, ensure the catalog contains at least one available catalog product.
   - If you want to use the Catalog Carousel ad format, ensure the catalog contains at least two available catalog products.

5. (Optional) Create a product set using [/catalog/set/create/](slug:create-a-product-set-by-conditions). If you want to have products selected from a product set, creating a product set is necessary. Otherwise, you can skip this step.

6. (Optional) Invite members to Business Center and grant the Admin permission using [/bc/member/invite/](slug:invite-members-to-a-bc). You can also choose `advertiser_role` that you want to assign to the members invited.

7. (Optional) Share a catalog with members and grant catalog management access using [/bc/asset/assign/](slug:assign-an-asset). Make sure to specify `CATALOG` in the `asset_type` field and `ADMIN` in the `catalog_role` field.
