# Unavailable tools in the TikTok for Business MCP Server on Claude Connector Directory
> Đường dẫn: TikTok for Business MCP Server > How to connect a ready-made agent to TikTok for Business MCP Server > Unavailable tools in the TikTok for Business MCP Server on Claude Connector Directory
You can [connect the TikTok for Business MCP Server to Claude](slug:how-to-connect-claude-to-tiktok-for-business-mcp-server) either through the Claude Connector Directory or via manually specified server URLs.

While the Connector Directory offers a streamlined setup, it includes a restricted set of tools compared to the manual configuration. Review the list of excluded tools below to ensure you choose the connection method that supports your workflow requirements.
