# Ad
> Đường dẫn: Marketing API > Campaign Management > Guides > Ad
Ad is the content that is presented to the target audience. This may include video or image material, ad text and call-to-action texts.

**See [here](doc:1740673047618561) for details about mapping relationships between campaign features on TikTok Ads Manager and API configurations.**
