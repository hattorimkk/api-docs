# Create a catalog
> Đường dẫn: API Reference > Catalog Management > Create a catalog
Use this endpoint to create and set up your catalog using information such as name, targeted locations, and currency.  

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/catalog/create/

**Method** POST

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token {Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162).|
|Content-Type {Required}|string|Request content type. <br>Accepted Value: `application/json`.  |
```

**Parameters**

``` xtable
| Field | Type | Description |
|--- |--- |--- |
| bc_id {Required} | string | Business Center ID. |
| name {Required} | string | Catalog name. <br><br>Length limit: 128 characters.|
| catalog_type {Required} | string | Catalog type. <br>Enum values: <ul><li>`ECOM`: E-commerce catalog. </li><li> `HOTEL`: hotel catalog.</li><li>`FLIGHT`: flight catalog.</li><li> `DESTINATION`: destination catalog.</li><li> `ENTERTAINMENT`: entertainment catalog.</li><li>`AUTO_VEHICLE`: Auto-Inventory catalog.<ul><li>When `catalog_type` is `AUTO_MODEL`, see [List of region codes and currencies for Auto-Inventory and Auto-Model catalogs](https://business-api.tiktok.com/portal/docs/create-a-catalog/v1.3#anchor-0-2-1) to find out the supported `region_code` and `currency` values.</li></ul></li><li>`AUTO_MODEL`: Auto-Model catalog.<ul><li>When `catalog_type` is `AUTO_MODEL`, see [List of region codes and currencies for Auto-Inventory and Auto-Model catalogs](https://business-api.tiktok.com/portal/docs/create-a-catalog/v1.3#anchor-0-2-1) to find out the supported `region_code` and `currency` values.</li></ul></li><li>`MINI_SERIES`: mini series catalog.</li><li>`GENERIC`: generic catalog.</li><li>`ONLINE_TO_OFFLINE`: online-to-offline catalog.<ul><li>When `catalog_type` is `ONLINE_TO_OFFLINE`, see [List of region codes and currencies for online-to-offline catalogs](https://business-api.tiktok.com/portal/docs/create-a-catalog/v1.3#anchor-0-2-2) to find out the supported `region_code` and `currency` values.</li></ul></li></ul><p><span style="color:darkred"><b>Note</b></span>: <ul><li>The entertainment catalog is currently an allowlist-only feature and is invitation-only because this catalog type is under Alpha Testing. If you would like to access it, please contact your TikTok representative. However, acceptance into the Alpha Test is not guaranteed.</li><li>The mini series catalog is currently an allowlist-only feature and is invitation-only because the catalog type is under testing. If you would like to access it, please contact your TikTok representative. However, acceptance into the test is not guaranteed. </li></ul> |
| catalog_conf {Required} | object | Catalog configuration information. |
#|region_code {Required} | string | The region code of the primary targeting region.<br><br> To get a list of available countries and regions, use [/catalog/available_country/get/](doc:1740491257516034). Select a region code from the region codes returned in `region_codes`.<br><br>To find out the corresponding region for a region code, refer to [Appendix - Location code](doc:1737585867307010).<br><br>Example: `US`.<br><br><p><span style="color:darkred"><b>Note</b></span>: Once set, this field cannot be updated.</p>|
#|currency {Required} | string | Currency for the primary targeting region. <br><br>For supported currencies, seethe <b>Code</b> column in [Budget verification ratio and precision of each currency](doc:1737585839634433).<br><br><p><span style="color:darkred"><b>Note</b></span>: Once set, this field cannot be updated.</p>|
#|channel |string| Channel for creating the catalog.<br><br> Enum values: <ul><li>`PARTNER`: Partners.</li><li>`CLIENT`: Direct advertisers.</li></ul><br><br><p><span style="color:darkred"><b>Note</b></span>: Once set, this field cannot be updated.</p>|
#|additional_config_list|object[]|Valid only when `catalog_type` is `MINI_SERIES`.<br><br>Details of additional targeting regions.<br><br>No max size.<br><br><p><span style="color:darkred"><b>Note</b></span>: <ul><li>Once set, this field cannot be updated.</li><li>If you want to target multiple regions through mini series catalogs, specify the additional targeting regions through `additional_config_list` during catalog creation. Then upload short drama series that target multiple regions.</li></ul></p>|
##|region_code {+Conditional}|string|Required when `additional_config_list` is specified.<br><br>The region code of the additional targeting region.<br><br>To get a list of available countries and regions, use [/catalog/available_country/get/](doc:1740491257516034). Select a region code from the region codes returned in `region_codes`.<br><br>To find out the corresponding region for a region code, refer to [Appendix - Location code](doc:1737585867307010).<br><br>Example: `GB`.<br><br><p><span style="color:darkred"><b>Note</b></span>: <ul><li>Once set, this field cannot be updated.</li><li>Duplicate region codes are not supported.</li></ul></p>|
##|currency {+Conditional}|string|Required when `additional_config_list` is specified.<br><br>Currency for the additional targeting region.<br><br>For supported currencies, see the <b>Code</b> column in [Budget verification ratio and precision of each currency](doc:1737585839634433).<br><br>Example: `GBP`.<br><br><p><span style="color:darkred"><b>Note</b></span>: <ul><li>Once set, this field cannot be updated.</li><li>You can only specify up to one currency for each additional targeting region.</li></ul></p>|
```

### Example

```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/catalog/create/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "bc_id": "{{bc_id}}",
    "name": "{{name}}",
    "catalog_type": "ECOM",
    "catalog_conf": {
        "region_code": "US",
        "currency": "USD"
        }
    }'
```
