# Unlink a TikTok account from a Business Center
> Đường dẫn: API Reference > BC Assets > Unlink a TikTok account from a Business Center
Use this endpoint to unlink a TikTok account from a Business Center.

Once a TikTok account is unlinked from a Business Center, all active ads that are using this TikTok account may be paused, and the account may lose access to [Business Suite](https://ads.tiktok.com/resources/help/article/navigate-web-business-suite).

## Before you start

Ensure you are an Admin of the Business Center. To confirm your permission to a Business Center, use [/bc/get/](slug:get-business-centers) and check whether the returned `user_role` is `ADMIN`.

### Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/bc/asset/tt_account/unlink/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](slug:marketing-api-authentication). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `application/json`. |

**Parameters**

| Field | Type | Description |
|---|---|---|
| bc_id  **(Required)** | string | Business Center ID. ⏎ To obtain the list of Business Centers that you can access, use [/bc/get/](slug:get-business-centers). |
| asset_ids  **(Required)** | string[] | A list of asset IDs of the TikTok accounts to unlink. ⏎ To obtain the asset IDs of TikTok accounts linked to a Business Center, use [/bc/asset/get/](slug:get-assets) and set `asset_type` to `TT_ACCOUNT`. ⏎ Max size: 1. |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/bc/asset/tt_account/unlink/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "bc_id": "{{bc_id}}",
    "asset_ids": [
        "{{asset_id}}"
    ]
}'
```
