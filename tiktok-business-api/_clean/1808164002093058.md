# Create Community Interaction ads
> Đường dẫn: Use Cases > Campaign creation > Create Community Interaction ads
This article walks you through the steps to create Community Interaction ads.

# Introduction
With the Community Interaction objective, you can build and nurture your connections with one of the most valuable communities that exists today - the TikTok community. This objective allows you to drive follower growth or increase traffic to different landing pages on TikTok.

**You can use Campaign Management API to create Community Interaction ads, and this helps you streamline your ad creation experience, and elevate operational efficiency and scalability.**

# Prerequisites
- You've gained access to TikTok API for Business. See [Get Started - Step by step workflow](doc:1735713609895937) for details. 
  - To create Community Interaction ads, you need relevant permissions. See [API Reference](doc:1735713875563521) to find out permissions required for endpoints (including the endpoints listed in the "Steps" section) and see [Update app permissions](doc:1738855280338946) to find out how to configure permissions.

## 2. Create an ad group
Create an ad group using [/adgroup/create/](doc:1739499616346114). Note that the following requirements must be met.

| Setting | Requirement | Parameter | How to configure the parameter |
|---|---|---|---|
| Interaction type | TikTok account ⏎ **Note**: Creating Community Interaction ad groups with interaction type as Live is not supported via API. | / | / ⏎ **Note**: All Community Interaction ad groups created through the API use "TikTok account" as the default interaction type. |
| Placements | **Select Placement** with only TikTok placement ⏎ Optionally, you can specify the following TikTik subplacements:  • In-feed. Ads will be placed in the For You feed and might also be placed in Profile Page and Following feeds. • Search feed (supported with allowlist) • TikTok Lite (supported with allowlist), a streamlined version of TikTok that features a smaller app size and faster video loading speed. The TikTok Lite subplacement is currently available for Japan or South Korea as targeting locations. | `placement_type` ⏎ `placements` ⏎ `tiktok_subplacements` | Set `placement_type` to `PLACEMENT_TYPE_NORMAL`, and set `placements` to `["PLACEMENT_TIKTOK"]` ⏎ Optionally, you can specify the following TikTik subplacements via `tiktok_subplacements`:  • `IN_FEED` • `SEARCH_FEED` • `TIKTOK_LITE`to-be-deprecated ⏎ **Note**:  • Starting July 19th, 2025, you will no longer be able to create or copy ad groups using the TikTok Lite subplacement (`TIKTOK_LITE`). To ensure a smooth and uninterrupted ad creation experience, we recommend that you avoid creating new ad groups with this subplacement or copying campaigns that contain such ad groups. • Using the Search feed subplacement (`SEARCH_FEED`) in your ad group is currently an allowlist-only feature. If you would like to access it, please contact your TikTok representative.  • Using the TikTok Lite subplacement (`TIKTOK_LITE`) in your ad group is currently an allowlist-only feature. If you would like to access it, please contact your TikTok representative.  • If you pass `tiktok_subplacements`, you need to at least include `IN_FEED` in the `tiktok_subplacements` value.  • To include `TIKTOK_LITE` in the `tiktok_subplacements` value, you need to include locations in Japan or South Korea in your targeted locations (`location_ids`). Otherwise, an error will occur. • If you include `SEARCH_FEED` or `TIKTOK_LITE` in the `tiktok_subplacements` value, you cannot set `brand_safety_type` to `THRID_PARTY`. |
| Optimization goal | Any of the following optimization goals:  • Follow • TikTok page visits | `optimization_goal` | Any of the following values: • `FOLLOWERS` • `PAGE_VISIT` |
| Bid Strategy | Any of the following types:  • Maximum Delivery • Cost Cap | `bid_type` ⏎ `bid_price` ⏎ `conversion_bid_price` | Any of the following values for `bid_type`:  • `BID_TYPE_NO_BID` • `BID_TYPE_CUSTOM` • If `bid_type` is `BID_TYPE_CUSTOM` and `optimization_goal` is `FOLLOWERS`, pass `conversion_bid_price` at the same time. • If `bid_type` is `BID_TYPE_CUSTOM` and `optimization_goal` is `PAGE_VISIT`, pass `bid_price` at the same time. |

| Delivery Type | • If Bid Strategy is Maximum Delivery, you can only set Delivery Type to Standard.  • If Bid Strategy is Cost Cap, you can set Delivery Type to Standard or Accelerated. | `pacing` | • If `bid_type` is `BID_TYPE_NO_BID`, you can only set `pacing` to `PACING_MODE_SMOOTH`.  •  If `bid_type` is `BID_TYPE_CUSTOM`, you can set `pacing` to `PACING_MODE_SMOOTH` or `PACING_MODE_FAST`. |
| Split test | Supported ⏎ Community Interaction ad groups can be used in [/split_test/create/](doc:1742666471475201) to create split tests. | / | / |

## 3. Create an ad
Create an ad using [/ad/create/](doc:1739953377508354). Note that the following requirements must be met.

Setting
Requirement
Parameter
How to configure the parameter

Smart Creative
Disabled You cannot pass is_smart_creative in [/ad/aco/create/](doc:1739473063234626) to create Smart Creative Community Interaction ads.
/
/

Ad format
Single Video
ad_format
SINGLE_VIDEO

Identity
Any of the following options: • Authorized User • TikTok User • TikTok Account User in Business Center
identity_type
Any of the following values: • AUTH_CODE • TT_USER • BC_AUTH_TT To learn about how to create Spark Ads, refer to [Create Spark Ads](doc:1739470744631298).

identity_id
Pass a valid value. To get the list of identities under your ad account, use [/identity/get/](doc:1740218420781057).

identity_authorized_bc_id
Pass a valid value when identity_type is BC_AUTH_TT

Destination
• If optimization goal is specified as Follow at the ad group level, the destination is the TikTok account profile page. • If optimization goal is specified as TikTok page visits at the ad group level, you can choose any of the following types: • Account profile • You don't need to provide a TikTok page URL or a TikTok Instant Page. • Other TikTok page • You need to provide a TikTok page URL. • TikTok Instant Page • You need to provide a Custom TikTok Instant Page.
tiktok_page_category landing_page_url page_id
• If optimization_goal is set to FOLLOWERS at the ad group level, you don't need to pass tiktok_page_category, landing_page_url and page_id. • If optimization_goal is set to PAGE_VISIT at the ad group level, you need to pass tiktok_page_category to specify the exact destination: • If you want to set the Destination to Account profile, set tiktok_page_category to PROFILE_PAGE and don't pass landing_page_url and page_id. • If you want to set the Destination to Other TikTok page, set tiktok_page_category to OTHER_TIKTOK_PAGE and pass the TikTok page URL of a Playlist Page, Hashtag Page, Music Page, or Branded Effect Page via landing_page_url. Do not pass page_id.  • To obtain a TikTok page URL, tap on the top right corner of the TikTok page you want to promote within your TikTok app, and click to copy the URL. • If you want to set the Destination to TikTok Instant Page, set tiktok_page_category to TIKTOK_INSTANT_PAGE and pass the ID of a TikTok Instant Page via page_id. Do not pass landing_page_url. • To obtain Custom TikTok Instant Pages within your ad account, use [/page/get/](doc:1820826387779586) and set business_type to TIKTOK_INSTANT_PAGE.

Call-to-action
• If optimization goal is specified as Follow at the ad group level: Disabled. • If optimization goal is specified as TikTok page visits at the ad group level: Specify a standard call-to-action or a dynamic call-to-action.
call_to_action call_to_action_id
• If optimization_goal is set to FOLLOWERS at the ad group level, do not pass call_to_action and call_to_action_id. • If optimization_goal is set to PAGE_VISIT at the ad group level, specify a standard call-to-action via call_to_action or a dynamic call-to-action via call_to_action_id.  • To learn about the supported values for call_to_action, see [Enumeration - Call-to-action](doc:1737174886619138). • To learn about how to obtain a call_to_action_id, see [Dynamic CTAs](doc:1740307296329730).

Interactive add-on (Optional)
Disabled or enabled with the following type: • Reminder Countdown Sticker **Note**: If you specify the TikTok subplacement Search feed at the ad group level, you cannot use Reminder Countdown Sticker.
card_id
Not passed or specify the ID of the following creative portfolio type: • Reminder Countdown Sticker (sticker_type as REMINDER_COUNTDOWN or LIVE_REMINDER_COUNTDOWN) To create a creative portfolio, use [/creative/portfolio/create/](doc:1739091950439426). • To learn about how to get the ID of a Countdown Sticker portfolio, see [Stickers](doc:1749019667506177). **Note**: If you include SEARCH_FEED in the tiktok_subplacements value at the ad group level, you cannot use Reminder Countdown Sticker via card_id at the ad level.
