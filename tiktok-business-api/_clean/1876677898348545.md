# How to connect Claude to TikTok for Business MCP Server
> Đường dẫn: TikTok for Business MCP Server > How to connect a ready-made agent to TikTok for Business MCP Server > How to connect Claude to TikTok for Business MCP Server
If you are using Claude, you can connect your Claude account directly to the TikTok Ads platform through the TikTok for Business Model Context Protocol (MCP) Server.

Imagine being able to launch hundreds of ad campaigns in just a few minutes, or scaling up your top-performing ads with a single request. You can also ensure that your ad creatives and product catalogs are autonomously optimized around the clock. The TikTok for Business MCP Server transforms these everyday marketing workflows into native capabilities for your AI agents. This provides your team with a robust, first-class foundation to build and scale your operations on TikTok Ads.

This guide walks you through the connection process, from initial configuration to your first successful interaction. Simply connect, authorize your account, and provide instructions so that Claude can execute advertising operations based entirely on your everyday language.

## Before you start
Before you begin, ensure:
- **You have a TikTok for Business account.** This account is required to authorize TikTok for Business MCP Server so Claude can act on your behalf within the TikTok for Business ecosystem. If you do not have an account, [create a TikTok for Business account](slug:create-a-tiktok-for-business-account) before proceeding.
- **You have a Claude account on the Pro or Max plan.**
- **You understand the differences between the two connection methods.** You can add the server [manually](https://business-api.tiktok.com/portal/docs/how-to-connect-claude-to-tiktok-for-business-mcp-server/v1.3#anchor-0-2-1-2) or [via the Connector Directory](https://business-api.tiktok.com/portal/docs/how-to-connect-claude-to-tiktok-for-business-mcp-server/v1.3#anchor-0-2-1-1). Keep in mind that the Connector Directory method provides almost the same set of tools, except for certain tools such as finance management ones. If your workflow requires these capabilities, use the manual connection method. For a complete comparison, see [Unavailable tools in the TikTok for Business MCP Server on Claude Connector Directory](slug:unavailable-tools-in-the-tiktok-for-business-mcp-server-on-claude-connector-directory). 
> **Note:** 
> TikTok for Business MCP Server is publicly available to all users, so you can start using it immediately without applying for any additional permissions.

## Step-by-step connection process
### Step 1: Add the MCP Server and authorize
You can connect the MCP server either by selecting it from the Connector Directory or by typing in the server URL manually.

You can add the MCP Server either directly via Connector Directory or by manually specifying the server URL.

#### Option 1 (Recommended): via Connector Directory
Because the TikTok for Business MCP Server is already officially listed in the Connector Directory, you can easily add it from the built-in list of connectors in Claude.

##### 1. Find and add the MCP server
a. Log in to your Claude account. On the left-side menu, click **Customize**.

b. Open the **Connectors** tab, and search for "TikTok" on the discovery page.

c. Locate the MCP server in the list and click to connect.

##### 2. Authorize the connection
When your agent first connects to TikTok for Business MCP Server, you are prompted to authorize the connection via your TikTok for Business account.

a. If you are not already signed in to TikTok Ads Manager, you are asked to sign in first.

b. Review the permissions requested.

c. Click **Authorize** to grant your AI agent access to your TikTok for Business resources. After authorization, your agent can make tool calls on your behalf.

> **Note:** 
> Authorization lifespan: User authorization for the TikTok for Business MCP Server connection remains valid for a **30-day window**. After 30 days, you will need to reauthorize the connection using the same TikTok for Business account.

#### Option 2: via manual addition
##### 1. Choose your server URL
If you prefer to add the TikTok for Business MCP Server manually, you can choose from two distinct server URLs based on your needs.

| Server Type | URL | When to use |
|---|---|---|
| Full Disclosure | `https://business-api.tiktok.com/open_mcp/tt-ads-mcp-flat` | All around 400 tools load at connection time. Use it when your AI platform has a large context window and can handle the full tool library without performance degradation. ⏎ Explore the full tool library in [Available tools in TikTok for Business MCP Server](slug:available-tools-in-tiktok-for-business-mcp-server). |
| Progressive Disclosure | `https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer` | Only around 40 core tools load initially; additional tools are discoverable on-demand. Use it for token-conscious setups or agents with limited context windows. |

### Step 2: Interact with your AI agent
Your agent is now connected to TikTok for Business MCP Server. Start a conversation with your agent and reference TikTok Ads operations in your prompts. The agent discovers and calls the appropriate MCP tools to fulfill your requests.

> **Note:** 
> Be aware of concurrency limits when managing Upgraded Smart+ Ads. Specifically, if you are using the `smart_plus_ad_create`, `smart_plus_ad_update`, or `smart_plus_ad_status_update` tools, restrict your creation or update calls for a single Upgraded Smart+ Ad to no more than one operation per 5 seconds. Failing to throttle these requests might trigger a concurrency error.

**Example prompts to get started:**
- "Create a new Upgraded Smart+ Campaign for my latest product."
- "Show me the performance report for all active campaigns this week."
- "Upload this E-commerce catalog and check for any diagnostic issues."
