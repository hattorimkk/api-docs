# Update ads
> Đường dẫn: API Reference > Ads > Update ads
Use this endpoint to modify the creatives of your regular ads such as call-to-action, ad name, text, image and video material. 

> **Important:** 
> Creating non-Spark Ads using Custom Identities in ad groups that deliver to Automatic Placement or Select Placement when TikTok is included is no longer supported for existing ad accounts. All new ad accounts created on or after January 15, 2026 cannot create non-Spark Ads using Custom Identities for these placements. Existing ads remain unaffected and editable. Ad campaigns that deliver only to Pangle or Global App Bundle placements are not be affected by Custom Identity deprecation. Learn more [about changes coming to Custom Identity](https://ads.tiktok.com/help/article/about-changes-coming-to-custom-identity) and [migrate to Spark Ads](doc:1848048566169730).

To update creative materials for Smart Creative ads, use the [/ad/aco/update/](doc:1739473077112833) endpoint.

Incremental updates in this endpoint are only supported for the following fields when `patch_update` is set to `true`. 
 - `ad_name` 
 - `identity_id` 
 - `identity_type` 
 - `identity_authorized_bc_id`
 - `video_id`
 - `image_ids`
 - `music_id`
 - `tiktok_item_id`
 - `ad_text`
 - `ad_texts`

For other fields, you can only use full update mode and pass in all the necessary parameters to update the ad. Otherwise, some parameters may be overwritten as null value. However, if you would like incremental updates to be supported for other fields as well, please contact your TikTok representative.

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/ad/update/

**Method** POST

**Header**
