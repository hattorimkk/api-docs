# Saved Audience
> Đường dẫn: API Reference > Audience > Saved Audience
Saved Audience allows you to store your targeting settings and reuse them to create future ad groups. See [Create a Saved Audience](doc:1780156510696449) to learn more about this feature and how to apply the Saved Audience to your ad group. 
> **Note:**  Currently, we don't allow you to update a Saved Audience. 

This group consists of the following endpoints: 
- [Create a Saved Audience](doc:1780154541898754)
- [Get details of Saved Audiences](doc:1780154619404290)
- [Delete Saved Audiences](doc:1780154666312706)
