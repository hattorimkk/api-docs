# Upload an image
> Đường dẫn: API Reference > Business Messaging > Direct messages > Upload an image
Use this endpoint to upload an image. 

## Before you start
- Because of the sensitive nature of direct message data, TikTok has implemented a higher level of due diligence for developers that will process direct messages on behalf of TikTok account users. Ensure that you [have completed the necessary data security and privacy reviews and obtained access to Business Messaging API](slug:access-to-business-messaging-api) before calling this endpoint.
- You can use [/business/message/capabilities/get/](doc:1836061597865986) to query if the TikTok account can send a media attachment to a conversation.
- Ensure the TikTok account is a TikTok Account with Advanced Access or Verified Business Account. Learn more [about TikTok account entitlements](https://ads.tiktok.com/resources/help/article/about-tiktok-account-entitlements). To confirm this, use [/business/get/](slug:get-profile-data-of-a-tiktok-account) and check whether the response parameter `has_advanced_access` is `true` for the TikTok account.
- Ensure the TikTok account owner is over 18 years old.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/message/media/upload/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | A short-term access token authorized by the TikTok account owner. ⏎ For details, see [Authentication](doc:1832184175482945). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `multipart/form-data`. |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| business_id {Required}| string | Application specific unique identifier for the TikTok account. <br><br> Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1832184175482945) to this field. |
|file {Required}|file|Multimedia File.<br><br>File size limit: 3MB.<br><br>Supported image file format: JPG and PNG.|
|media_type {Required}|string|Multimedia type.<br><br>Currently, we only support `IMAGE` as the multimedia type.|
```

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/message/media/upload/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: multipart/form-data' \
--form 'business_id="{{business_id}}"' \
--form 'file=@"/Users/xxx/ss.png"' \
--form 'media_type="IMAGE"'
```

## Response

``` xtable
|Field{30%}|Type{15%}|Description{55%}|
|---|---|---|
|code |number|Response code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097). |
|message|string|Response message. For details, see [Appendix - Return Codes](doc:1737172488964097).|
|request_id |string|The log ID of a request, which uniquely identifies the request.  |
|data |object|Returned data.|
#|media_id|string|Media ID of the uploaded image.<br><br>Validity period: 30 days. Once the Media ID expires, you need to re-upload the image to obtain a new Media ID.|
```
