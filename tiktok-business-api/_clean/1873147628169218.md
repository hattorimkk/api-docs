# Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as TikTok direct messages
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Lead Generation Search Ads Campaign > Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as TikTok direct messages
This article explains how to create an Upgraded Smart+ Lead Generation Campaign optimized for TikTok direct messages (also known as Upgraded Smart+ TikTok Direct Messaging Ads). 

This setup allows users to directly message your authorized TikTok account in-app by clicking the "Send message" call-to-action button on your ad.

# Prerequisites

The owner of the authorized TikTok account has set **Potential connections** and **Others on TikTok** to **Requests** for Direct Messages on the TikTok account, allowing anyone to send direct messages to the TikTok account. To learn how to configure the settings, refer to [How to manage who can message you](https://www.tiktok.com/support/faq_detail?id=7543897461052529158&category=web_account).
