# Delete a playable asset
> Đường dẫn: API Reference > Playable Ads > Delete a playable asset
Use this endpoint to delete a playable asset. 

Only saved playable assets can be deleted. You can use [/playable/save/](slug:save-a-playable-creative) to save a playable asset.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/playable/delete/

**Method** POST

**Header**
``` xtable
| Field | Type | Description |
|---|---|---|
| Access-Token {Required} | string | Authorized access token. For details, see [Authentication](doc:1738373164380162).|
```
**Parameters**
``` xtable
| Field | Type | Description |
|---|---|---|
| advertiser_id {Required} | string | Advertiser ID. |
| playable_id {Required} | string | Playable asset ID. |
```

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/playable/delete/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id": "{{advertiser_id}}",
    "playable_id": "{{playable_id}}"
}'
```
