# Get the status of a comment export task
> Đường dẫn: API Reference > Ad Comments > Get the status of a comment export task
Use this endpoint to check the status of a comment export task.

When the task completes, you can call [/comment/task/download/](doc:1738088341958658) to download the exported data. 

## Request

**Endpoint**
https://business-api.tiktok.com/open_api/v1.3/comment/task/check/

**Method** GET

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID |
| task_id  **(Required)** | string | Task ID |

### Example

```http
// curl
curl --get -H "Access-Token:xxx" \
--data-urlencode "advertiser_id=ADVERTISER_ID" \
--data-urlencode "task_id=TASK_ID" \
https://business-api.tiktok.com/open_api/v1.3/comment/task/check/
```

## Response

| Field | Type | Description |
|---|---|---|
| - | - | - |
| message | string | The return message. For Details, see [Appendix - Return Codes](doc:1737172488964097). |
| code | number | The return code. For details, see [Appendix-Return Code](doc:1737172488964097). |
| data | object | Data |
| ↳ task_id | string | Task ID |
| ↳ status | string | Task status. Enum values: `RUNNING`, `SUCCEED`, `FAILED`. |
| request_id | string | Unique ID of the request |

### Example

```http
// Success-Response
HTTPS/1.1 200 OK
{
    "message": "OK",
    "code": 0,
    "data": {}
}
```
