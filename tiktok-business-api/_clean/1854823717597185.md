# Messaging limits for Business Messaging API
> Đường dẫn: Business Messaging API > Guides > Manage direct messages for a TikTok account > Messaging limits for Business Messaging API
For a TikTok account's non-mutual follow conversations handled via the Business Messaging API, the following messaging limits apply:
- **Initial 48-hour window**: After receiving the first message from a TikTok user, TikTok account can send up to 10 messages within the next 48 hours.
- **Active conversation window**: If the TikTok user replies to the TikTok account's message, a new interaction window starts. Within 48 hours after each last reply from the TikTok user, the TikTok account can send an unlimited number of messages to that user.
- **Inactive conversation limit**: If more than 48 hours have passed since the TikTok user's last reply, the TikTok account is limited to sending a maximum of three additional messages. This restriction remains in effect until the TikTok user responds again, which will reactivate the unlimited messaging window for the next 48 hours.
- **Example flow**: 
TikTok user sends first message
→ TikTok account can send up to 10 messages in 48 hours
→ TikTok user replies
→ TikTok account can send unlimited messages in the next 48 hours
→ If TikTok user doesn't reply for over 48 hours
→ TikTok account can only send three more messages
→ TikTok user replies again
→ Unlimited messaging window reopens for 48 hours, and additional three more messages after 48 hours until the TikTok user replies again.
