# Revoke a long-term access token
> Đường dẫn: API Reference > Authentication > Revoke a long-term access token
Use this endpoint to revoke a long-term access token. This is a new endpoint in TikTok API for Business v1.3. 

A long-term access token is a type of token that you can obtain after receiving authorization from an ad account, a Business Center account, or a TikTok One Creator Marketplace account. The token does not expire. 

## Request 
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/oauth2/revoke_token/ 

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| app_id **(Required)** | string | ID of your developer app. ⏎ To find the **App ID**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| secret **(Required)** | string | Secret of your developer app. ⏎ To find the **Secret**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| access_token **(Required)** | string | The long-term access token that you want to revoke. ⏎ You can create a new access token via [/oauth2/access_token/](doc:1739965703387137) or [/oauth/token/](doc:1739965703387137). |

### Example
```http
// curl
curl --location  --request POST 'https://business-api.tiktok.com/open_api/v1.3/oauth2/revoke_token/' \
--header 'Access-Token: {{access_token}}' \
--header 'Content-Type: application/json' \
--data '{
    "app_id": "{{app_id}}",
    "secret": "{{secret}}",
    "access_token": "{{access_token}}"
}'
```

## Response

| Field | Type | Description |
|---|---|---|
| code | number | Return code, see [Return Code](doc:1737172488964097) |
| message | string | Returned messages, see [Return information](doc:1737172488964097) |
| request_id | string | The log ID of a request, which uniquely identifies the request. |
| data | object | Return data. |
| ↳ app_id | string | ID of your developer app. |
| ↳ advertiser_ids | string[] | The ID list of ad accounts that the token can no longer access. |
