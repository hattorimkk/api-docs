# Upload a comment image
> Đường dẫn: API Reference > Accounts > Comments > Upload a comment image
Use this endpoint to upload an image for a new comment or for a reply to an existing comment and receive an `image_uri` that you can include when calling the [/business/comment/create/](doc:1762228442072066) or [/business/comment/reply/create/](doc:1762228448779266) endpoint.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/comment/image/upload/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `multipart/form-data`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| image_file  **(Required)** | file | The image file which will be used to generate a new comment or to add reply to an existing comment thread. ⏎ Maximum size: 5 MB. ⏎ Maximum resolution: 1080 x 1920 pixels or 1920 x 1080 pixels. ⏎ Minimum resolution: 360 x 360 pixels. ⏎ File types supported: JPG, JPEG, WebP, or PNG. |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/comment/image/upload/' \
--header 'Access-Token: {{Access-Token}}' \
--form 'business_id="{{business_id}}"' \
--form 'image_file=@"{{image_file}}"'
```

## Response

| Field | Type | Description |
|---|---|---|
| request_id | string | Unique identifier for the API request. ⏎ **Note**: Please record this field for all API requests. Important for issue reports and troubleshooting. |
| code | integer | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Appendix - Return Information](doc:1737172488964097). |
| data | object | Returned data. |
| ↳ image_uri | string | URI for the uploaded image. ⏎ Returned when an accepted image type is uploaded. |
| ↳ width | integer | Width of the `image_file`. ⏎ **Example**: 720. |
| ↳ height | integer | Height of the `image_file`. ⏎ **Example**: 900. |

### Example
