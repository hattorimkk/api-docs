# Create, update, or delete a rule set within an ad account
> Đường dẫn: API Reference > Tools > Create, update, or delete a rule set within an ad account
Use this endpoint to create, update, or delete a rule set within an ad account.

> **Note:** 
> - Creating rule sets is currently an allowlist-only feature. If you would like to access it, please contact your TikTok representative.
> - You can create up to 20 rule sets for each ad account.

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/smart_plus/value_rule_set/create_or_update/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](slug:marketing-api-authentication). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `application/json`. |

**Parameters**

| Field | Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| operation_type  **(Required)** | string | Operation type. ⏎ Enum values: • `CREATE`: To create a new rule set. • `UPDATE`: To update an existing rule set. • `DELETE`: To delete an existing rule set. |
| value_rule_set  **(Required)** | object | Details of the rule set. |
| ↳ value_rule_set_id {+Conditional} | string | • Required when `operation_type` is `UPDATE` or `DELETE`. • Not supported when `operation_type` is `CREATE`. ⏎ The ID of the rule set that you want to update or delete. ⏎ To retrieve existing rule sets within an ad account, use [/smart_plus/value_rule_set/get/](slug:get-rule-sets-within-an-ad-account). |
| ↳ rule_set_name {+Conditional} | string | • Required when `operation_type` is `CREATE`. • Optional when `operation_type` is `UPDATE`. • Not supported when `operation_type` is `DELETE`. ⏎ The name of the rule set. ⏎ Length limit: 512 characters. ⏎ **Note**: Duplicate rule set names are not supported. |
| ↳ rules {+Conditional} | object[] | • Required when `operation_type` is `CREATE`. • Optional when `operation_type` is `UPDATE`. • Not supported when `operation_type` is `DELETE`. ⏎ Details of rules in the rule set. ⏎ Each rule set can contain up to 10 rules. ⏎ **Note**: Duplicate rules or criteria are not supported in one rule set. |
| ↳↳ order {+Conditional} | number | Required when `rules` is specified. ⏎ The order of the rule in the rule set. ⏎ Use consecutive integers starting from 1 (for example, 1, 2, and 3, rather than 1, 3, and 5). ⏎ When you configure multiple rules in a rule set, this order indicates their priority. The system will prioritize rule application based on the rule order. If a person meets the criteria for multiple rules, we'll only apply the first applicable rule in the list. ⏎ For example: ⏎ Rule 1: Increase bid by 20% for ages 25–34 in the United States ⏎ Rule 2: Increase bid by 50% for iOS operating system ⏎ So a US-based iOS user aged 25–34 matches both rules, but only gets a 20% bid increase because Rule 1 comes first. |
| ↳↳ rule_id | string | Valid only when `operation_type` is `UPDATE`. ⏎ Rule ID. • When this field is specified, the `rule_id` will stay the same after the rule set update. • When this field is not specified, the system will generate a new `rule_id` after the rule set update. |
| ↳↳ rule_name {+Conditional} | string | Required when `rules` is specified. ⏎ Rule name. |
| ↳↳ criteria {+Conditional} | object[] | Required when `rules` is specified. ⏎ Details of criteria for the rule. ⏎ You can specify up to two criteria per rule. If you include two criteria in a single rule, the system triggers the rule only when a person meets both criteria. |
| ↳↳↳ criteria_type {+Conditional} | string | Required when `criteria` is specified. ⏎ Criterion type. ⏎ Enum values: • `CRITERIA_TYPE_GENDER`: Genders. • `CRITERIA_TYPE_AGE`: Ages. • `CRITERIA_TYPE_LOCATION`: Locations. • `CRITERIA_TYPE_OS`: Operating systems. • `CRITERIA_TYPE_AUDIENCE`: Audience |
| ↳↳↳ value {+Conditional} | object | Required when `criteria` is specified. ⏎ Details of value or values for the criterion. |
| ↳↳↳↳ gender {+Conditional} | string | Required when `criteria_type` is `CRITERIA_TYPE_GENDER`. ⏎ Gender. ⏎ Enum values: • `GENDER_MALE`: Male. • `GENDER_FEMALE`: Female. |
| ↳↳↳↳ age_groups {+Conditional} | string[] | Required when `criteria_type` is `CRITERIA_TYPE_AGE`. ⏎ A list of age groups. ⏎ Enum values: • `AGE_18_24`: 18-24. • `AGE_25_34`: 25-34. • `AGE_35_44`: 35-44. • `AGE_45_54`: 45-54. • `AGE_55_100`: 55+. |
| ↳↳↳↳ location {+Conditional} | object | Required when `criteria_type` is `CRITERIA_TYPE_LOCATION`. ⏎ Details of values for the location criterion. |
| ↳↳↳↳↳ location_ids {+Conditional} | string[] | Required when `location` is specified. ⏎ A list of location IDs. • To get the available locations and corresponding IDs based on your placement and objective, use the [/tool/targeting/search/](slug:search-for-location-targeting-tags) or [/tool/region/](slug:get-available-locations-by-different-settings) endpoint. • To get the list of location IDs, see [Location IDs](slug:location-ids). |
| ↳↳↳↳ operating_systems {+Conditional} | string[] | Required when `criteria_type` is `CRITERIA_TYPE_OS`. ⏎ A list of operating systems. ⏎ Enum values: • `ANDROID`: Android. • `IOS`: iOS. |
| ↳↳↳↳ audience_ids {+Conditional} | string[] | Required when `criteria_type` is `CRITERIA_TYPE_AUDIENCE`. ⏎ A list of audience IDs. ⏎ The audience can be a custom audience, lookalike audience, or saved audience. ⏎ Max size: 5. ⏎ Ensure each audience is valid. • To retrieve valid custom or lookalike audience IDs within an ad account, use [/dmp/custom_audience/list/](slug:get-all-audiences) and select audiences with `is_valid` as `true`. • To retrieve saved audience IDs within an ad account, use [/dmp/saved_audience/list/](slug:get-details-of-saved-audiences). ⏎ **Note**: Duplicate audience IDs are not supported. |
| ↳↳ adjust_percentage {+Conditional} | number | Required when `rules` is specified. ⏎ Bid adjustment percentage. • For bid increases: [1, 50]. • For bid decreases: [-70, -1]. ⏎ An `adjust_percentage` of -70 represents a bid decrease of 70% when the conditions defined in `criteria` are met. |

### Example
#### Create a rule set
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/smart_plus/value_rule_set/create_or_update/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
---data '{
    "advertiser_id": "{{advertiser_id}}",
    "operation_type": "CREATE",
    "value_rule_set": {
        "rule_set_name": "{{rule_set_name}}",
        "rules": [
            {
                "order": 1,
                "rule_name": "{{rule_name}}",
                "criteria": [
                    {
                        "criteria_type": "CRITERIA_TYPE_GENDER",
                        "value": {
                            "gender": "GENDER_FEMALE"
                        }
                    }
                ],
                "adjust_percentage": 10
            }
        ]
    }
}'
```

#### Update a rule set
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/smart_plus/value_rule_set/create_or_update/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id": "{{advertiser_id}}",
    "operation_type": "UPDATE",
    "value_rule_set": {
        "value_rule_set_id": "{{value_rule_set_id}}",
        "rule_set_name": "{{rule_set_name}}",
        "rules": [
            {
                "order": 1,
                "rule_name": "{{rule_name}}",
                "criteria": [
                    {
                        "criteria_type": "CRITERIA_TYPE_AUDIENCE",
                        "value": {
                            "audience_ids": [
                                "{{audience_ids}}"
                            ]
                        }
                    }
                ],
                "adjust_percentage": 8
            }
        ]
    }
}'
```

#### Delete a rule set
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/smart_plus/value_rule_set/create_or_update/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id": "{{advertiser_id}}",
    "operation_type": "DELETE",
    "value_rule_set": {
        "value_rule_set_id": "{{value_rule_set_id}}"
    }
}'
```
