# Create Upgraded Smart+ DC App O2O Catalog Ads
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ App Campaigns > Create Upgraded Smart+ App O2O Catalog Ads > Create Upgraded Smart+ DC App O2O Catalog Ads
Upgraded Smart+ DC App O2O Catalog Ads are App Campaigns that operate with the iOS 14 dedicated campaign setting enabled, utilizing online-to-offline catalog products for ad delivery.

To set up this campaign type, apply the following campaign-level parameters: set `campaign_type` to `IOS14_CAMPAIGN`, set `catalog_enabled` to `true`, and set `catalog_type` to `ONLINE_TO_OFFLINE`.

# Prerequisites
- Creating App O2O Catalog Ads is currently an allowlist-only feature. If you would like to access it, please contact your TikTok representative.
- Creating App O2O Catalog Ads requires setting up an O2O catalog in your Business Center first.
  - To set up the catalog, see [Create an online-to-offline catalog](slug:create-an-online-to-offline-catalog).
