# Update a product set
> Đường dẫn: API Reference > Catalog Product Sets > Update a product set
Use this endpoint to update the filter conditions or name of a product set. You only need to include the fields that you want to update the values for.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/catalog/set/update/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `"application/json"`. |

**Parameters**

| Field | Type | Description |
|---|---|---|
| bc_id  **(Required)** | string | Business Center ID. |
| catalog_id  **(Required)** | string | The catalog ID. |
| product_set_id  **(Required)** | string | The product set ID. |
| product_set_name{+Conditional} | string | You need to pass at least `product_set_name` or `conditions` or both. ⏎ The product set name. ⏎ Length limit: 128 characters. |
| conditions{+Conditional} | object | You need to pass at least `product_set_name` or `conditions` or both. ⏎ The filter conditions. ⏎ **Note**: If you pass multiple conditions through this object, we recommend limiting the combined total number of values in the conditions to a maximum of 1,024. Otherwise, a timeout is likely to occur. |
| ↳ and/or{+Conditional} | object[] | Required when `conditions` is passed. ⏎ The logical operator that will be applied to the filter conditions. You must specify either `and` or `or`. `and` stands for the AND logical operator. `or` stands for the OR logical operator. |
| ↳↳ field{+Conditional} | string | Required when `conditions` is passed. ⏎ The field that the filter will be applied to. For enum values, see [Product set operators and fields – Filter fields](doc:1740673108747265). |
| ↳↳ operation{+Conditional} | string | Required when `conditions` is passed. ⏎ The filter operator. For enum values, see [Product set operators and fields – Operators](doc:1740673108747265). |
| ↳↳ value{+Conditional} | string/string[] | Required when `conditions` is passed. ⏎ The expected value. ⏎ Depending on the operator you specify via `operation`, this field can be a single value or multiple values in a list. See [Product set operators and fields – Operators](doc:1740673108747265) to learn about the type of value you need to specify. ⏎ **Note**: If you pass multiple values through this field, the maximum allowed number of values is 1,024. |

### Example-the object Conditions
```example
// conditions
    "conditions": {
        "and": [
            {
                "field": "gender",
                "operation": "EQUAL",
                "value": "MALE"
            },
            {
                "field": "price",
                "operation": "GTE",
                "value": 50
            },
            {
                "field": "brand",
                "operation": "I_CONTAIN",
                "value": ["TikTok", "xxxxx"]
            }
        ]
    }
```

### Example

```http
// curl
curl -X POST -H "Access-Token:YOUR_ACCESS_TOKEN" \
-H "Content-Type:application/json" \
-d '{\"bc_id\": BC_ID,\"catalog_id\": CATALOG_ID,\"name\": NAME},\"conditions\": [CONDITIONS]}' \
https://business-api.tiktok.com/open_api/v1.3/catalog/set/update/
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | The return code. For the complete list of error codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | The return message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| request_id | string | The request ID. |
| data | object | Returned data. |
| ↳ product_set_id | string | The product set ID. |
| ↳ product_set_name | string | The product set name. |
| ↳ product_count | number | The number of products in the product set. |
