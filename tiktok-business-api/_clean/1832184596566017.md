# Update the automatic message for a TikTok account
> Đường dẫn: API Reference > Business Messaging > Automatic messages > Update the automatic message for a TikTok account
Use this endpoint to update an automatic message for a TikTok account.

After you update an automatic message, use [/business/message/auto_message/get/](doc:1832184619749377) to verify the status of the message. 

## Before you start
- Because of the sensitive nature of direct message data, TikTok has implemented a higher level of due diligence for developers that will process automatic messages on behalf of TikTok account users. Ensure that you [have completed the necessary data security and privacy reviews and obtained access to Business Messaging API](slug:access-to-business-messaging-api) before calling this endpoint.
- Ensure the TikTok account is a TikTok Account with Advanced Access or Verified Business Account. Learn more [about TikTok account entitlements](https://ads.tiktok.com/resources/help/article/about-tiktok-account-entitlements). To confirm this, use [/business/get/](slug:get-profile-data-of-a-tiktok-account) and check whether the response parameter `has_advanced_access` is `true` for the TikTok account.
- Ensure the TikTok account owner is over 18 years old.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/message/auto_message/update/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | A short-term access token authorized by the TikTok account owner. ⏎ For details, see [Authentication](doc:1832184175482945). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| business_id {Required}| string | Application specific unique identifier for the TikTok account. <br><br> Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1832184175482945) to this field. |
| auto_message_id {Required}| string | The ID of the automatic message. <br><br>To retrieve the automatic messages for a TikTok account, use [/business/message/auto_message/get/](doc:1832184619749377).|
| auto_message_type{Required} | string | The type of automatic message.<br><br>Enum values: <ul><li>`WELCOME_MESSAGE`: welcome message. A welcome message is a message that is automatically sent to a user when they start a direct message conversation with you.</li><li>`SUGGESTED_QUESTION`: suggested question. A suggested question is a frequently asked question displayed at the beginning of a chat. When the user selects a suggested question, the user will automatically receive the corresponding preset answer.</li><li>`CHAT_PROMPT`: chat prompt. A chat prompt is an interactive button displayed above the input box. When users tap a chat prompt, the system will automatically generate a corresponding question for users to start the conversation.</li><li>`FOLLOW_WELCOME`: new follower message. A new follower message is a message that is automatically sent to a user when they follow you. This message is sent to new followers once a day and may be briefly delayed for a more natural experience.</li></ul><br><p><span style="color:darkred"><b>Note</b></span>: An automatic message that is pending review cannot be updated. To check the review status of an automatic message, use [/business/message/auto_message/get/](doc:1832184619749377) and ensure the returned `audit_status` for the automatic message is not `REVIEWING`. |
| welcome_message {+Conditional} | object | Required when `auto_message_type` is `WELCOME_MESSAGE`.<br><br>Information about the welcome message. |
#| content{+Conditional}  | string | Required when `welcome_message` is passed.<br><br>The text of the welcome message.<br><br>Example: `Hi there, Please leave us a message and we will respond to you shortly. Thank you!`. |
| suggested_question {+Conditional} | object | Required when `auto_message_type` is `SUGGESTED_QUESTION`.<br><br>Information about the suggested question.<br><br>You can only update one suggested question per call.<br>To update multiple suggested questions, call `/business/message/auto_message/update/` multiple times. |
#| question{+Conditional}  | string | Required when `suggested_question` is passed.<br><br>A frequently asked question to help users start a conversation.<br><br>Length limit: 80 characters. |
#| answer{+Conditional}  | string | Required when `suggested_question` is passed.<br><br>The preset answer that will be automatically sent when a user selects the question.<br><br>Length limit: 200 characters. |
| chat_prompt {+Conditional} | object | Required when `auto_message_type` is `CHAT_PROMPT`.<br><br>Information about the chat prompt. |
#| title{+Conditional}  | string | Required when `chat_prompt` is passed.<br><br>The name of the prompt button that is displayed above the input box.<br><br>Length limit: 18 characters.<br><br>You can use text, system emojis, and both English and non-English languages.<br><br>To ensure optimal display, keep the name concise and clear. |
#| content {+Conditional} | string | Required when `chat_prompt` is passed.<br><br>The corresponding question for the prompt that the system automatically generates for users to start the conversation when users tap the chat prompt.<br><br>Length limit: 150 characters.<br><br>You can use text, system emojis, and both English and non-English languages. |
|follow_welcome {+Conditional}|object|Required when `auto_message_type` is `FOLLOW_WELCOME`.<br><br>The configuration details for the new follower message.|
#|message {+Conditional}|string|Required when `follow_welcome` is specified.<br><br>The text of the new follower message.<br><br>You can use `&#123;s_nickname&#125;` as a placeholder for the follower's name. For example, if you configure the message as "Hi &#123;`s_nickname`&#125;, thanks for following!", a follower named "John" receives "Hi John, thanks for following!"<br><br>Length limit: 500 characters.|
#|interaction {+Conditional}|string|Required when `follow_welcome` is specified.<br><br>The way that followers can interact with the new follower message.<br><br>Enum values:<ul><li>`NONE`: None.</li><li>`QUICK_REPLY`: quick reply. You need to specify `quick_reply_text` simultaneously.</li><li>`QUICK_ACTION`: quick action. You need to specify `quick_action_type` simultaneously.</li></ul>|
#|quick_reply_text {+Conditional}|string|Required when `interaction` is `QUICK_REPLY`.<br><br>The text of the quick reply message.<br><br>For example, if the quick reply message is "Yes, show me!", the follower can tap the message button to send the exact message "Yes, show me!".<br><br>Length limit: 20 characters.|
#|quick_action_type {+Conditional}|string|Required when `interaction` is `QUICK_ACTION`.<br><br>The type of quick action.<br><br>Enum values:<ul><li>`SHOP`: Shop. To let followers browse your products. You must be a TikTok Shop seller or creator with active listings.</li><li>`JOIN_GROUP`: Join group. To let followers join your group chat to stay engaged. You must be a TikTok Shop seller or have 10K+ followers.</li></ul>|
```

### Example
#### Update a welcome message
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/message/auto_message/update/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "business_id": "{{business_id}}",
    "auto_message_id": "{{auto_message_id}}",
    "auto_message_type": "WELCOME_MESSAGE",
    "welcome_message": {
        "content": "{{content}}"
    }
}'
```
#### Update a suggested question
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/message/auto_message/update/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "business_id": "{{business_id}}",
    "auto_message_id": "{{auto_message_id}}",
    "auto_message_type": "SUGGESTED_QUESTION",
    "suggested_question": {
        "question": "{{question}}",
        "answer":"{{answer}}"
    }
}'
```
#### Update a chat prompt
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/message/auto_message/update/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "business_id": "{{business_id}}",
    "auto_message_id": "{{auto_message_id}}",
    "auto_message_type": "CHAT_PROMPT",
    "chat_prompt": {
        "title": "{{title}}",
        "content":"{{content}}"
    }
}'
```
