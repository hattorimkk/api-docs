# HTTP Status Codes for MCP Authorization API
> Đường dẫn: API Reference > MCP Authorization > HTTP Status Codes for MCP Authorization API
The MCP Authorization API endpoints use the following standard HTTP Status Codes to indicate success or failure:

| HTTP Status Code | Meaning | Typical Causes |
|---|---|---|
| 400 | Bad Request | Client-side error. This includes missing fields, invalid registration metadata, invalid grants, redirect URI mismatches, PKCE mismatches, or MCP server mismatches. |
| 401 | Unauthorized | Missing or invalid access token at the time of the request. The token may be missing, invalid, expired, or revoked. |
| 403 | Forbidden | Insufficient permissions. The token does not have the required scope to perform the requested action. |
| 500 | Internal Server Error | Invalid downstream response. The server received a malformed or incomplete response from the internal authentication service. |
| 503 | Service Unavailable | The authorization service or a core dependency is temporarily down (for example, RPC transport failure). |
