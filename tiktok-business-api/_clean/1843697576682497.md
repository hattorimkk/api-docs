# Get the Comment-to-Message setting of a TikTok account
> Đường dẫn: API Reference > Business Messaging > Direct messages > Get the Comment-to-Message setting of a TikTok account
Use this endpoint to get the status of the Comment-to-Message feature for a TikTok account.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/message/direct_reply/get/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok account owner. ⏎ To obtain an access token, use [/tt_user/oauth2/token/](doc:1738084387220481). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| business_id  **(Required)** | string | Application specific unique identifier for the TikTok account. ⏎ Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1738084387220481) to this field. |
| direct_reply_type  **(Required)** | string | The type of direct reply. ⏎ Enum value: •  `COMMENT_TO_MESSAGE`: Comment-to-Message. Once you enable this feature, the TikTok system will identify high-intent comments, enabling you to send customized replies to assist these users more effectively. |

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/business/message/direct_reply/get/?business_id={{business_id}}&direct_reply_type=COMMENT_TO_MESSAGE' \
--header 'Access-Token: {{Access-Token}}'
```

## Response

| Field | Type | Description |
|---|---|---|
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| request_id | string | The log ID of a request, which uniquely identifies the request. |
| data | object | Returned data. |
| ↳ business_id | string | Application specific unique identifier for the TikTok account. |
| ↳ direct_reply_type | string | The type of direct reply. ⏎ Enum value: •  `COMMENT_TO_MESSAGE`: Comment-to-Message. Once you enable this feature, the TikTok system will identify high-intent comments, enabling you to send customized replies to assist these users more effectively. |
| ↳ operation_status | string | The status of the direct reply type (`direct_reply_type`). ⏎ Enum values: •   `ENABLE`: Enabled. • `DISABLE`: Disabled. ⏎ If you want to enable or disable this setting, use [/business/message/direct_reply/update/](doc:1843697551083522). |
