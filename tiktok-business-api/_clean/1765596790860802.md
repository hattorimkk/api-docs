# Delete an Offline Event set
> Đường dẫn: API Reference > Events 1.0 > Offline Events > Delete an Offline Event set
Use this endpoint to delete an Offline Event set under an advertiser account.

> **Important:** 
> By using Events API endpoints, you agree to the [TikTok Business Products (Data) Terms](https://ads.tiktok.com/i18n/official/policy/business-products-terms) and that you will not share sensitive data with TikTok.
## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/offline/delete/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|---|---|---|
| advertiser_id {Required} | string | Advertiser ID. |
| event_set_id {Required} | string | ID of the Offline Event set that you want to delete. <br> You can get Offline Event set IDs under an advertiser account via [/offline/get/](doc:1765596808589313). |
```
### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/offline/delete/' 
--header 'Access-Token: {{Access-Token}}' 
--header 'Content-Type: application/json' 
--data-raw '{
    "advertiser_id":"{{advertiser_id}}",
    "event_set_id":"{{event_set_id}}"
}'
```
