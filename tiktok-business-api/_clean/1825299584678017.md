# Obtain the download URL for MMM data
> Đường dẫn: API Reference > Media Mix Modeling > Obtain the download URL for MMM data
Use this endpoint to obtain the download URL for Media Mix Modeling (MMM) data.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/mmm/api/download/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| mmm_request_id {Required} | string | Unique identifier for the MMM data request.<br><br> <ul><li>To create an MMM data request and obtain the data request ID, use [/mmm/api/create/](slug:create-an-mmm-data-request).</li><li>To retrieve historical MMM data requests, including data request IDs, use [/mmm/api/history/](slug:get-the-mmm-data-request-history). </li></ul>|
```

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/mmm/api/download/?mmm_request_id={{mmm_request_id}}' \
--header 'Access-Token: {{Access-Token}}'
```
## Response

``` xtable
|Field{30%}|Type{15%}|Description{55%}|
|---|---|---|
|code |number|Response code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097). |
|message|string|Response message. For details, see [Appendix - Return Codes](doc:1737172488964097).|
|request_id |string|The log ID of a request, which uniquely identifies the request.  |
|data |object|Returned data.|
#| download_url| string | A URL to download the compressed CSV file for MMM data. <br><br> Validity period: seven days. <br>Once the URL expires, you need to call [/mmm/api/download/](slug:obtain-the-download-url-for-mmm-data) to obtain a new URL. <br><br> To learn about the available MMM data fields, see [MMM templated data schema](https://bytedance.sg.larkoffice.com/sheets/YDwDsKe5whGQWdtaZVrlD9BHgIc). |
```
