# Get info of an app
> Đường dẫn: API Reference > Events 1.0 > App Events > Get info of an app
Use this endpoint to obtain the details of an App.
> **Important:** 
> By using Events API endpoints, you agree to the [TikTok Business Products (Data) Terms](https://ads.tiktok.com/i18n/official/policy/business-products-terms) and that you will not share sensitive data with TikTok.
## Request

**Endpoint**  
https://business-api.tiktok.com/open_api/v1.3/app/info/

**Method** GET

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token {Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162).|
```

**Parameters**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|advertiser_id {Required}|string| Advertiser ID. |
|app_id {Required}|string|App ID. |
```

### Example

``` xcodeblock
(code curl http)
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/app/info/?advertiser_id={{advertiser_id}}&app_id={{app_id}}' \
--header 'Access-Token: {{Access-Token}}'
(/code)
```

## Response

``` xtable
|Field{35%}|Data Type{10%}|Description{55%}|
|---|---|---|
|code |number|Return code, see [Appendix-Return Codes](doc:1737172488964097).  |
|message |string|Return message, see [Appendix-Return Codes](doc:1737172488964097).  |
|request_id|string|The log id of a request, which uniquely identifies the request. |
|data |object|Return data.|
#|app |object|Details of the mobile app.  |
##|advertiser_id |string|Advertiser ID. |
##|app_platform_id |string|App platform ID. |
##|app_name |string|App name.  |
##|self_attribution_enabled |boolean | Whether self-attribution, rather than third-party attribution, has been enabled for the App.|
##|skan_allowed|string| Whether the app can be used to create iOS 14 Dedicated Campaigns to target devices running iOS 14.5+ versions. Enum values: `ALLOWED`, `NOT_ALLOWED`. For an app to be used to create iOS 14 Dedicated Campaigns, the advertiser needs to verify the ownership of the app in Event Manager in TikTok Ads Manager. |
##| advanced_dedicated_campaign_allowed | boolean | Whether the App can be used in Advanced Dedicated Campaigns. <br><br>To learn about how to create such campaigns, see [Create Advanced Dedicated Campaigns](doc:1797011827608577). <br><br> Supported values: `true`, `false`. |
##|is_attribution_flex_enable|boolean|Whether the mobile app is eligible for attribution source and data source configuration during Upgraded Smart+ Ad Group creation.<br><br>Supported values: `true`, `false`.|
##|download_url |string|App download link. |
##|icon |object|App icon information. |
###|height |number|Icon height.  |
###|web_uri |string|Icon image ID.|
###|width |number|Icon width.  |
##|app_id |string|App ID. |
##|package_name |string|App package name.  |
##|tiktok_apps|object[]| TikTok App ID information.|
###|tiktok_app_id|string|TikTok App ID. Returned only if the Mobile Measurement Partner for tracking is supported.|
##|partner |object|Third-party tracking partner information.  |
###|partner_id |string|Partner ID.  |
###|partner_logo |string|Partner LOGO URI.  |
###|partner_name |string|Partner name.  |
##|platform |string| App platform. Enum values: `ANDROID`,`IOS`. |
##|enable_retargeting |string|Indicates whether you'd like to enable retargeting attribution. <br>Enum values: `RETARGETING`, `NON_RETARGETING`.<br><br><p><span style="color:darkred"><b>Note</b></span>: Currently, regardless of the value specified for this field, the Enable Retargeting Attribution setting will not take effect on your App. To enable retargeting attribution for your App, go to Events Manager.|
##|tracking_url |object|Tracking links from third-party tracking partners. |
###|click_url |string| Tracking link for clicks. It is provided by your tracking partner. Normally you can get the link from their websites.|
###|impression_url |string|The default tracking link for impressions. It is generated by your tracking partner. Normally you can get the link from their websites.|
###|retargeting_click_url|string| Tracking link for retargeting clicks. It is generated by your tracking partner. Normally you can get the link from their websites.|
###|retargeting_impression_url|string| Tracking link for retargeting impressions. It is generated by your tracking partner. Normally you can get the link from their websites.|
##|create_time |string|Time created. |
```
