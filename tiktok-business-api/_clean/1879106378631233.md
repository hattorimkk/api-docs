# Manage published MCP servers
> Đường dẫn: Skill and MCP management > Get started with MCP server management > Manage published MCP servers
Once your MCP server is live on Agentic Hub, you can iterate on it, control its marketplace visibility, or remove it entirely. This section covers all ongoing management tasks.

## Upload a new version
As your AI capabilities evolve, keep your published MCP server up to date by uploading new versions. Version updates go through the standard review process, but your existing published version remains live throughout, ensuring zero downtime for advertisers currently using your MCP server.

**Steps**

1. On the My Agentic Hub page, locate the MCP server with a **Published** status and click **Manage**.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/aBZyg8AEZkv0wEjEXrUZ9/54b0c0a3f34faec7b349f1e4277c2b6e/locate_a_Skill_with_a_Published_status_and_click_Manage.png)

2. On the MCP server detail page, click **Upload New Manifest**.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/4QmMEunnExZSUm2UUliRzZ/010dcb9bff0c83d50ff44b7b4aa1aecf/click_Upload_New_Manifest.png)

3. Complete the upload form with your latest details.

Ensure that the new version number in the **Version (SemVer)** field is strictly higher than the current published version. For example, if the current published version is 1.0.0, use 1.1.0 or higher.
> **Important:** 
> **Server name** cannot be changed during a version update.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/6tNGZZnl9aM0Mhw4q4jVCT/cf57a9e8d984310f99dc3315c59ba595/Complete_the_upload_form_with_your_latest_details_1.png)

![Asset](https://images.ctfassets.net/5jqet0ab9qci/6ZZ9dTlUHXTQdVVTbKcJ6f/0d525e39ca70c90fe5918c0c15d564b9/Complete_the_upload_form_with_your_latest_details_2.png)

4. Click **Submit Version** to finalize the submission.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/2AYvFncEpkr8aYSgRAXAu1/f9e2ed5b659421df425d4d47aa5d5d5a/Click_Submit_Version.png)

**Version review outcomes**

After submission, the new version enters the review queue. Once the review is complete, you can review the result from the MCP server detail page.
- **Approved:** The new version replaces the previous version.
- **Rejected:** Your currently published version remains live and unaffected. The new version shows a **Rejected** status on the MCP server detail page with reviewer feedback. See [Handle a rejected version update](https://business-api.tiktok.com/portal/docs/troubleshoot-mcp-server-issues/v1.3#anchor-0-2) for recovery steps.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/5mhjaOo5qD5mrchu8gQlZG/f48479c7c365b7f1e6dcdc399d7e99f7/The_new_version_shows_a_Rejected_status.png)

## Control visibility on Agentic Hub
Manage your MCP server's marketplace presence with the visibility toggle. This feature lets you temporarily hide an MCP server from the Agentic Hub marketplace without deleting it, preserving your configuration, review history, and installed user base for when you are ready to re-list.

**When to use the visibility toggle**
- **Scheduled maintenance:** Hide your MCP server while deploying breaking changes, then re-enable once stable.
- **Seasonal campaigns:** Temporarily remove industry-specific MCP servers outside of peak periods.
- **Compliance holds:** Quickly pull an MCP server from discovery while resolving regulatory or policy questions.
- **Pre-launch staging:** Toggle off visibility for an approved MCP server you are not yet ready to promote publicly.
**Visibility states**

| State | Discovery behavior | Existing installs |
|---|---|---|
| Available (on) | Appears on Discovery pages. Advertisers can find and access it. | Fully functional. |
| Hidden (off) | Removed from all discovery surfaces. Not searchable by new advertisers. | Display an "unpublished" status. Functionality may be limited. |

**Steps**

1. On the My Agentic Hub page, locate an MCP server with a **Published** status and click **Manage**.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/aBZyg8AEZkv0wEjEXrUZ9/54b0c0a3f34faec7b349f1e4277c2b6e/locate_a_Skill_with_a_Published_status_and_click_Manage.png)

2. On the MCP server detail page, adjust the **Toggle Visibility** setting:
- Set to **on** to make the MCP server visible and accessible on Agentic Hub.
- Set to **off** to hide the MCP server from all discovery pages.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/2hIyPDGKWiAXEGpblAIUaB/d5ea38792cd7660b6e889a5f8e64cbaf/adjust_the_Toggle_Visibility_setting.png)

3. Verify the updated state on the My Agentic Hub page:
- The **Visibility** column displays **Available** (visible) or **Hidden** (not visible).
> **Note:** 
> Visibility changes are immediate and do not require review. You can toggle visibility as often as needed.

## Delete an MCP server
Delete an MCP server permanently when you need to retire it entirely. Common reasons for deletion include discontinuing a product, rebranding under a new an MCP server name, or removing a prototype that is no longer needed.
> **Important:** 
> Deletion is irreversible. Once deleted:
> •  The MCP server is permanently removed from your account.
> •  Advertisers who installed the MCP server lose access immediately.
> •  You cannot recover or restore the deleted MCP server.
> If you want to temporarily remove your MCP server from the marketplace without deleting it, [use the visibility toggle](#item-link-anchor-0-2) instead.

**Steps**

1. On the My Agentic Hub page, locate the MCP server you want to delete and click **Manage**.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/6GO2ei5KOcv9kxBT8iejYj/d293285b4d1cd555086ebd403d2be5dd/locate_the_MCP_server_you_want_to_delete_and_click_Manage.png)

2. On the MCP server detail page, click **Delete Server**.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/2Htopg6ik8ikcY3IzHDBD1/a6da930bb1a937a30b300b3ff814f700/click_Delete_Server.png)

3. In the confirmation dialog, click **Confirm** to permanently delete the MCP server.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/4xVwlGLfoDQDFvYZu2HBJj/2385b8e227e567e923587593522dda85/click_Confirm_to_permanently_delete_the_MCP_server.png)

4. The MCP server is permanently removed and no longer appears on the My Agentic Hub page.
