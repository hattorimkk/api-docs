# Get additional interest categories by ID
> Đường dẫn: API Reference > Tools > Get additional interest categories > Get additional interest categories by ID
Use this endpoint to get additional interest categories by ID.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tool/interest_keyword/get/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| keyword_query | object[] | Information of the additional interest category you want to get. ⏎ Max size = 50. |
| ↳ keyword_id  **(Required)** | string | Additional interest category ID. |
| ↳ language | string | Additional interest category language. Default value: `en`. ⏎ Supported languages: `fr`, `id`, `it`, `ja`, `ms`, `ar`, `vi`, `en`, `ru`, `es`, `th`, `tr`, `hi`, `zh`, `de`, `ko`. |
| filtering | object | Filtering conditions. |
| ↳ audience_type | string | The audience type that you want to filter by. Enum values: • `GENERAL_INTEREST`:  General interest. The audiences have a general, long-term interest in a video category. • `PURCHASE_INTENTION`: Purchase intent. The audiences' recent behavior suggests they may buy something related to a content category.Default value: `GENERAL_INTEREST`. |

### Example
```curl
// http
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/tool/interest_keyword/get/?advertiser_id= {{ADVERTISER_ID}}&keyword_query=[{"keyword_id": "{{keyword_id}}"}]' \
--header 'Access-Token: {{Access-Token}}' \
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | The return code. For the complete list of error codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | The return message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| request_id | string | The log ID of a request, which uniquely identifies the request. |
| data | object | Return data. |
| ↳ keywords | object[] | List of additional interest categories. |
| ↳↳ keyword | string | Additional interest category. |
| ↳↳ keyword_id | string | Additional interest category ID. |
| ↳↳ status | string | Whether an additional interest category will be effective. ⏎ Enum values: `EFFECTIVE`, `INEFFECTIVE`. ⏎ An additional interest category is effective if using it can reach a reasonable number of people. ⏎ An additional interest category is ineffective if the projected audience size is too small. ⏎ **Note**: Only effective additional interest categories can be used in ad groups to target audiences. |
