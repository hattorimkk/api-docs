# Obtain the authorized Creator permissions
> Đường dẫn: API Reference > TikTok One > Obtain the authorized Creator permissions
Use this endpoint to get the permission scopes of the TikTok account authorized by the TikTok account user. 

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tt_user/token_info/get/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| app_id  **(Required)** | string | ID of your developer application. ⏎ You can find the **App ID** by navigating to **[My Apps](https://ads.tiktok.com/marketing_api/apps/)** > **App Detail** > **Basic Information**. |
| access_token  **(Required)** | string | Authorized access token for permission verification. ⏎ To get an access token that is generated after a TikTok One (TTO) creator grants you the permission scopes of a TikTok creator account, see [/tt_user/oauth2/token/](https://business-api.tiktok.com/portal/docs/get-renew-or-revoke-a-creator-access-token/v1.3#item-link-Obtain%20a%20Creator%20access%20token). |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tt_user/token_info/get/'
--header 'Content-Type: application/json'
--data-raw '{
    "app_id":"{{app_id}}",
    "access_token":"{{access_token}}"
}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | The return code. For the complete list of error codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | The return message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| request_id | string | The log id of a request, which uniquely identifies the request. |
| data | object | Returned data. |
| ↳ app_id | string | ID of your developer application. |
| ↳ scope | string | Scope of permissions for the specified access token. ⏎ For instance, `"user.info.basic,video.list"`. |
| ↳ creator_id | string | Application specific unique ID of the TikTok creator account. |
