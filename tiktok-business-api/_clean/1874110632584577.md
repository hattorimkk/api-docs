# Create a creative pre-review task
> Đường dẫn: API Reference > Creative Pre-review > Create a creative pre-review task
Use this endpoint to create a pre-review task for your creatives.

A pre-review task is a process initiated to evaluate and assess the compliance and quality of your creatives before they are used to create ads, ensuring that they meet TikTok advertising guidelines and standards.

After you create the task, call [/creative/pre_review/task/get/](slug:get-the-result-of-a-creative-pre-review-task) to check the task result. The time required to process each task may vary based on the number of creatives. The average processing time of each pre-review task is around five minutes.

# Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/creative/pre_review/task/create/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](slug:marketing-api-authentication). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `application/json`. |

**Parameters**

| Field | Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| material_list  **(Required)** | object[] | The list of creatives to submit for pre-review. ⏎ Size range: 1-5. |
| ↳ material_type  **(Required)** | string | The material type of the creative. ⏎ Enum values: • `VIDEO`: video. • `IMAGE`: image. • `AD_TEXT`: ad text. • `LANDING_PAGE_URL`: landing page URL. |
| ↳ material_id  **(Required)** | string | The ID or content of the creative. • When `material_type` is `VIDEO`, specify a video ID. • To search for video IDs within your ad account, use [/file/video/ad/search/](slug:search-for-videos) and check the returned `video_id`. • When `material_type` is `IMAGE`, specify an image ID. • To search for image IDs within your ad account, use [/file/image/ad/search/](slug:search-for-images) and check the returned `image_id`. • When `material_type` is `AD_TEXT`, specify an ad text. • When `material_type` is `LANDING_PAGE_URL`, specify a landing page URL. |
| location_codes  **(Required)** | string[] | The codes of the locations that you want to target. ⏎ Max size: 1. ⏎ For enum values, see [List of values for `location_codes` or `location_code`](https://business-api.tiktok.com/portal/docs/create-a-creative-pre-review-task/v1.3#anchor-1-1). ⏎ Example: `US`. |
| is_ecommerce | boolean | Whether the creatives are intended for use in E-commerce ads, including [GMV Max Campaigns](slug:create-gmv-max-campaigns) and Catalog Ads. ⏎ Supported values: `true`, `false`. ⏎ Default value: `false`. |

## Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/creative/pre_review/task/create/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id": "{{advertiser_id}}",
    "material_list": [
        {
            "material_type": "VIDEO",
            "material_id": "{{material_id}}"
        },
        {
            "material_type": "IMAGE",
            "material_id": "{{material_id}}"
        },
        {
            "material_type": "AD_TEXT",
            "material_id": "{{material_id}}"
        }
    ],
    "location_codes": [
        "US"
    ],
    "is_ecommerce": false
}'
```

# Response

| Field | Data Type | Description |
|---|---|---|
| - | - | - |
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](slug:return-codes-appendix). |
| message | string | Response message. For details, see [Appendix - Return Codes](slug:return-codes-appendix). |
| request_id | string | The log ID of the request, which uniquely identifies a request. |
| data | object | Returned data. |
| ↳ pre_review_task_id | string | The ID of the pre-review task. ⏎ To obtain the result of the pre-review task, pass the value of this field to the `task_id` field in [/creative/pre_review/task/get/](slug:get-the-result-of-a-creative-pre-review-task). |
