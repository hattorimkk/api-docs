# Delete a Pixel Event
> Đường dẫn: API Reference > Events 1.0 > Pixel Events > Delete a Pixel Event
Use this endpoint to delete Pixel events. 
> **Important:** 
> By using Events API endpoints, you agree to the [TikTok Business Products (Data) Terms](https://ads.tiktok.com/i18n/official/policy/business-products-terms) and that you will not share sensitive data with TikTok.

`Note`: You cannot delete Pixel events bound to ad groups.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/pixel/event/delete/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Request message type ⏎ Allowed format: `"application/json"` |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID |
| event_id  **(Required)** | string | Event ID. You can get the event ID from the `event_id ` field in the response of the [/pixel/list/](doc:1740858697598978) endpoint. |

### Example

```http
// curl
curl -H "Access-Token:xxx" -H "Content-Type:application/json" -X POST \
-d '{
    "advertiser_id": "ADVERTISER_ID", 
    "event_id": "EVENT_ID"
}' \
https://business-api.tiktok.com/open_api/v1.3/pixel/event/delete/
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Return code, see [Appendix-Return code](doc:1737172488964097). |
| message | string | Return message, see [Appendix-Return information](doc:1737172488964097). |
| data | object | Return data. |
| request_id | string | The log id of a request, which uniquely identifies the request. |

// Success-Response
HTTPS/1.1 200 OK
{
