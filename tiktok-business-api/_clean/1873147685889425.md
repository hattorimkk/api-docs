# Create Upgraded Smart+ Automotive Search Ads for Inventory
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Lead Generation Search Ads Campaign > Create Upgraded Smart+ Automotive Search Ads > Create Upgraded Smart+ Automotive Search Ads for Inventory
This article explains how to create Upgraded Smart+ Automotive Search Ads for Inventory. 

These are specialized campaigns powered by an Auto-Inventory catalog.

# Prerequisite

Creating Automotive Search Ads for Inventory requires setting up an **Auto-Inventory catalog** in Business Center first.

To set up the catalog:

1. Create an Auto-Inventory catalog using [/catalog/create/](slug:create-a-catalog).

2. Upload products to the catalog using [/catalog/product/upload/](slug:upload-products-via-a-json-schema) (JSON schema), [/catalog/product/file/](slug:upload-products-via-a-file-url) (CSV feed template), or [/catalog/feed/create/](slug:create-a-feed)(online data feed schedule).

3. Check the product handling results.

- For CSV feed and JSON schema, use [/catalog/product/log/](slug:get-the-product-handling-log).

  - Pass in the `feed_log_id` obtained from Step 2. If the field `error_affected_products` in the response is not null, examine the issue details and return to Step 2 to reupload the product.

- For online feed, use [/catalog/feed/log/](slug:get-the-log-of-a-feed).

  - Pass in the `feed_id` obtained from Step 2. If the field `error_count` in the response is not 0, examine your online feed and return to Step 2 to reupload the product.

4. (Optional) Create an Auto-Inventory product set using [/catalog/set/create/](slug:create-a-product-set-by-conditions).

If you want to have products selected from a product set at the ad level, creating a product set is necessary. Otherwise, you can skip this step.

5. (Optional) Invite members to Business Center and grant the admin permission using [/bc/member/invite/](slug:invite-members-to-a-bc).

You can also choose `advertiser_role` that you want to assign to the members invited.

6. (Optional) Share a catalog with members and grant catalog management access using [/bc/asset/assign/](slug:assign-an-asset).

Make sure to specify `CATALOG` in the `asset_type` field and `ADMIN` in the `catalog_role` field.

### Example
Request
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/smart_plus/campaign/create/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id": "{{advertiser_id}}",
    "request_id": "{{request_id}}",
    "objective_type": "LEAD_GENERATION",
    "is_search_campaign": true,
    "catalog_enabled": true,
    "campaign_type": "REGULAR_CAMPAIGN",
    "campaign_name": "{{campaign_name}}",
    "budget_optimize_on": false
}'
```
Response
```http
// curl
{
    "code": 0,
```
