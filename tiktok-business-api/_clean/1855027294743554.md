# Get ad accounts linked to a TikTok account in Business Center
> Đường dẫn: API Reference > BC Assets > Get ad accounts linked to a TikTok account in Business Center
Use this endpoint to retrieve the list of ad accounts linked to a TikTok account in a Business Center.

Once an ad account is linked to a TikTok account in a Business Center, Business Center members with access to the linked ad account can use the TikTok account for ad delivery from the ad account.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/bc/asset/advertiser/assigned/

**Method** GET

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. ⏎ For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Type | Description |
|---|---|---|
| bc_id  **(Required)** | string | Business Center ID. ⏎ To obtain the list of Business Centers that you can access, use [/bc/get/](doc:1737115687501826). |
| asset_id  **(Required)** | string | The ID of a TikTok account in a Business Center. ⏎ To obtain the list of TikTok accounts within a Business Center, use [/bc/asset/get/](doc:1739432717798401) and set `asset_type` to `TT_ACCOUNT` or `MANAGED_BUSINESS_ACCOUNT`. |
| asset_type  **(Required)** | string | Asset type. ⏎ Enum values: • `TT_ACCOUNT`: TikTok account as an ad delivery asset. You can run ads from these TikTok accounts. • `MANAGED_BUSINESS_ACCOUNT`: TikTok account for Business Account management. You can run ads from these TikTok accounts, and manage messages, leads, forms, comments, product links, and insights in your TikTok account. |
| page | number | Current page number. ⏎ Value range: ≥1. ⏎ Default value: 1. |
| page_size | number | Page size. ⏎ Value range: 1-50. ⏎ Default value: 10. |

### Example

```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/bc/asset/advertiser/assigned/?bc_id={{bc_id}}&asset_type=TT_ACCOUNT&asset_id={{asset_id}}&page=1&page_size=50' \
--header 'Access-Token: {{Access-Token}}'
```

## Response

| Field | Type | Description |
|---|---|---|
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| request_id | string | The log ID of a request, which uniquely identifies the request. |
| data | object | Returned data. |
| ↳ list | object[] | The list of ad accounts linked to the TikTok account (`asset_id`) in the Business Center. |
| ↳↳ advertiser_id | string | The ID of the ad account. |
| ↳↳ advertiser_name | string | The name of the ad account. |
| ↳ page_info | object | Pagination information. |
| ↳↳ page | number | Current page number. |
| ↳↳ page_size | number | Page size. |
| ↳↳ total_number | number | Total number of results. |
| ↳↳ total_page | number | Total pages of results. |
