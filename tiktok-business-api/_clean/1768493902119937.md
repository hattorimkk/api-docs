# Get, renew or revoke a Creator access token
> Đường dẫn: API Reference > TikTok One > Get, renew or revoke a Creator access token
- To get or renew the short-term Creator access token, you can use /tt_user/oauth2/token/ and /tt_user/oauth2/refresh_token/ respectively.
	- The `/tt_user/oauth2/token/` endpoint now requires `redirect_uri` for better security. The short-term Creator access token remains valid for 24 hours, whereas the Creator refresh token remains valid for a year. You can get the access token using `/tt_user/oauth2/token/` and refresh it daily with the refresh token via `/tt_user/oauth2/refresh_token/` within one year. However, after one year, you need the creator to reauthorize it.
- To revoke a Creator access token, use /tt_user/oauth2/revoke/.

# Obtain a Creator access token 
Use this endpoint to get a Creator access token.  

## Request

**Endpoint** `https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/token/`

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| client_id **(Required)** | string | ID of your developer app. ⏎ To find the **App ID**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| client_secret **(Required)** | string | Secret of your developer app. ⏎ To find the **Secret**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| grant_type  **(Required)** | string | The way of generating the access token. ⏎ The allowed enum value:  • `authorization_code`: To generate the access token by authorization code. |
| auth_code  **(Required)** | string | The authorization code (`auth_code`) generated by your **TikTok account holder authorization URL**. ⏎ The code is valid for 10 minutes and can only be used once. ⏎ To find out how to get the authorization code based on the type of API you use, see the "**Authorization URL**" row in [Comparing authorization for different APIs](doc:1781891256601602). |
| redirect_uri  **(Required)** | string | The redirect URL which the client will be directed to. ⏎ Its value must be the same as the **TikTok account holder redirect URL** set in the app. |

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| request_id | string | The log id of the request, which uniquely identifies a request. |
| data | object | Returned data. |
| ↳ access_token | string | The short-term token for permission verification. ⏎ The token expires in one day. |
| ↳ token_type | string | The type of token. ⏎ Enum value:  • `Bearer`: Bearer token. Anyone in possession of the token can use it to access the associated resources. |
| ↳ scope | string | The scope of permissions granted to the access token. |
| ↳ expires_in | number | The time remaining until the access token expires, measured in seconds. |
| ↳ refresh_token | string | The refresh token, which can be used to renew the access token. ⏎ The refresh token is valid for one year. ⏎ **Note**: Retain this field for `access_token` renewal. |
| ↳ refresh_token_expires_in | number | The time remaining until the refresh token expires, measured in seconds. |
| ↳ open_id | string | Application specific unique ID of the TikTok account. |

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|

| client_secret **(Required)** | string | Secret of your developer app. ⏎ To find the **Secret**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |

| refresh_token **(Required)** | string | Refresh token to renew an existing access token. ⏎ You can obtain the refresh token in the response of /tt_user/oauth2/token/ endpoint when you generate an access token. |

# Revoke a Creator access token

Use this endpoint to revoke a Creator access token.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/revoke/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| client_id {Required} | string | ID of your developer application. <br><br>To find the <strong>App ID</strong>, navigate to <strong>[My Apps](https://ads.tiktok.com/marketing_api/apps/)</strong> > <strong>App Detail</strong> > <strong>Basic Information</strong>. |
| client_secret {Required} | string | Secret of your developer application.<br><br> To find the <strong>Secret</strong>, navigate to <strong>[My Apps](https://ads.tiktok.com/marketing_api/apps/)</strong> > <strong>App Detail</strong> > <strong>Basic Information</strong>. |
| access_token {Required} | string | The Creator access token that you want to revoke.<br><br> You can either create a new access token via <a href="#item-link-Get a Creator access token">/tt_user/oauth2/token/</a> or obtain a renewed access token via <a href="#item-link-Renew a Creator access token">/tt_user/oauth2/refresh_token/</a> . |
```
### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/revoke/' \
--header 'Content-Type: application/json' \
--data '{
    "client_id":"{{client_id}}",
    "client_secret":"{{client_secret}}",
    "access_token":"{{access_token}}"
}'
```
