# Get action categories
> Đường dẫn: API Reference > Tools > Get action categories
Use this endpoint to get action category enumeration values. Action categories are also referred to as behavioral categories in our documentation.

Action targeting provides advertisers with a way to serve relevant ads to users based on their recent in-app behaviors. In-app behaviors can be categorized into two types: video related actions (views, likes, comments or share), and creator related actions (following or viewed homepage). Accordingly, the `action_scene` where a developer can use action categories when calling [/adgroup/create/](doc:1739499616346114) is `CREATOR_RELATED`, or `VIDEO_RELATED`.

> **Note:** 
> We recommend that you use the Consolidated Interest and Behavior API ([/targeting/search/](doc:1796638342793218)) to search for or list targeting categories and hashtags for interests and behaviors. This API provides a consolidated and efficient approach to access the necessary targeting information.

## Request

**Endpoint**

https://business-api.tiktok.com/open_api/v1.3/tool/action_category/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| special_industries | string[] | Special ad categories. ⏎ Enum values: • `HOUSING`: Ads for real estate listings, homeowners insurance, mortgage loans or other related opportunities. • `EMPLOYMENT`: Ads for job offers, internship, professional certification programs or other related opportunities. • `CREDIT`: Ads for credit card offers, auto loans, long-term financing or other related opportunities. ⏎ **Note**: This field is generally available to advertisers registered in America or Canada. Advertisers who are not registered in America or Canada but want to target these countries with special ad categories need to apply for an additional allowlist. |
| language | string | Category name language in repsonse. Default value: `en`. ⏎ Supported languages: `en`, ` zh`, ` ja`, ` de`, ` es`, ` fr`, ` id`, ` it`, ` ko`, ` ru`, ` th`, ` tr`, ` vi`, ` ar`, ` pt`, ` ms`. ⏎ For details, see [Enumeration - Language Code](doc:1737174886619138). |

### Example

```http
// curl
curl --get -H "Access-Token:xxx" \
--data-urlencode "advertiser_id=ADVERTISER_ID" \
https://business-api.tiktok.com/open_api/v1.3/tool/action_category/
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Return code. For the complete list of response codes and descriptions, see [Appendix-Return codes](doc:1737172488964097). |
| message | string | Return message. For details, see [Appendix-Return codes](doc:1737172488964097). |
| data | object | Returned data. |
| ↳ action_categories | object[] | Action Categories list. |
| ↳↳ description | string | Action description. |
| ↳↳ action_category_id | string | Action category ID. |
| ↳↳ level | number | Level. |
| ↳↳ sub_category_ids | string[] | Subcategory ID list. |
| ↳↳ name | string | Action category name. |
| ↳↳ special_industries | string[] | Special ad categories. ⏎ Enum values:  • `HOUSING`(Ads for real estate listings, homeowners insurance, mortgage loans or other related opportunities.) • `EMPLOYMENT`(Ads for job offers, internship, professional certification programs or other related opportunities.) • `CREDIT`(Ads for credit card offers, auto loans, long-term financing or other related opportunities.) ⏎ **Note**: •  If the returned value is empty(`[]`), it means that the action categories do not support any special ad categories. |
| ↳↳ action_scene | string | Action scene. Enum values: `CREATOR_RELATED`, `VIDEO_RELATED`. |
| request_id | string | The log ID of a request, which uniquely identifies the request. |
