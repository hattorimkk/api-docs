# Get the Page ID
> Đường dẫn: API Reference > Page > Get the Page ID
Use this endpoint to get the Page ID. After a page is created, you can get the page ID and then use the page ID in your ads.

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/page/get/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id {+Conditional} | string | Either `advertiser_id` or `library_id` has to be set. ⏎ To get pages under an ad account, you must specify the advertiser ID. |
| library_id {+Conditional} | string | Either `advertiser_id` or `library_id` has to be set. ⏎ To get pages under a Business Center, you must specify the ID of the form library that contains the page and leads. You can migrate pages and leads from an ad account to a Business Center. |
| page | number | Current number of pages. ⏎ Default value: 1. Value range: ≥ 1. |
| page_size | number | Page size. ⏎ Default value: 10. Value range: 1-100. |
| status | string | Page status. ⏎ Enum values: `EDITED` (draft), `PUBLISHED` (ready). |
| title | string | The page name for filtering results. ⏎ This filter supports exact matches. |
| update_time_range | object | Filter for pages updated in the specified time range. |
| ↳ start {+Conditional} | string | Required when `update_time_range` is passed. ⏎ Start time in the format of `YYYY-MM-DD HH:MM:SS` (UTC time). ⏎ Example: `2024-01-01 00:00:00`. |
| ↳ end {+Conditional} | string | Required when `update_time_range` is passed. ⏎ End time in the format of `YYYY-MM-DD HH:MM:SS` (UTC time). ⏎ Example: `2024-01-01 00:00:00`. |
| business_type | string | Page type. ⏎ Enum values: `LEAD_GEN`(Instant Form), `STORE_FRONT`(Storefront Page), `APP_PROFILE_PAGE` (App Profile Page),`TIKTOK_INSTANT_PAGE` (Custom Page or Custom TikTok Instant Page), `SHOP_ADS_PLP` (Shop Ads Product List Page), `SHOP_ADS_PDP` (Shop Ads Product Detail Page), `POP_UP_FORM`(Direct Message Page). ⏎ Default value: `LEAD_GEN`. |
| business_types | string[] | Page types. ⏎ Enum values: `LEAD_GEN`(Instant Form), `STORE_FRONT`(Storefront Page), `APP_PROFILE_PAGE` (App Profile Page),`TIKTOK_INSTANT_PAGE` (Custom Page or Custom TikTok Instant Page), `SHOP_ADS_PLP` (Shop Ads Product List Page), `SHOP_ADS_PDP` (Shop Ads Product Detail Page), `POP_UP_FORM`(Direct Message Page). ⏎ **Note**: If it is passed concurrently with `business_type`, the value of `business_type` will be ignored. |

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/page/get/?advertiser_id={{advertiser_id}}' \
--header 'Access-Token: {{Access-Token}}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Return code, see [Appendix-Return codes](doc:1737172488964097). |
| message | string | Return Message, see [Appendix-Return codes](doc:1737172488964097). |
| data | object | Return data. |
| ↳ list | object[] | Page list. |
| ↳↳ page_id | string | Page ID. |
| ↳↳ status | string | Page status. ⏎ Enum values: `EDITED` (draft), `PUBLISHED` (ready). |
| ↳↳ title | string | Title. |
| ↳↳ preview_url | string | Preview link of the page. The link is generated after the page is ready, and will be empty when the page is only a draft. |
| ↳↳ template_id | string | The ID for the page's template. It indicates the specific template type associated with this page. |
| ↳↳ template_name | string | The name of the template type that the page uses. |
| ↳↳ supported_objectives | string[] | Returned only when the following conditions are both met: • The page is associated with a `template_id`. • The corresponding template is compatible with certain objectives.A list of campaign objectives compatible with this page template. ⏎ Enum values: `APP_PROMOTION`, `WEB_CONVERSIONS`, `LEAD_GENERATION`, `TRAFFIC`, `REACH`, `VIDEO_VIEWS`, `ENGAGEMENT`, `PRODUCT_SALES`, `RF_REACH`. ⏎ For a detailed explanation of enum values, see [Enumeration-Advertising Objective](https://business-api.tiktok.com/portal/docs/enumerations-appendix/v1.3#item-link-Advertising%20Objective). ⏎ **Note**: • Even with a supported objective, you can only use the page if it is compatible with all other campaign settings. |
| ↳↳ thumbnail | string | Page preview thumbnail image. |
| ↳↳ create_time | string | The creation time of the page in the format of `YYYY-MM-DD HH:MM:SS` (UTC time). ⏎ Example: `2024-01-01 00:00:00`. |
| ↳↳ update_time | string | The time the page was last updated in the format of `YYYY-MM-DD HH:MM:SS` (UTC time). ⏎ Example: `2024-01-01 00:00:00`. |
| ↳↳ publish_time | string | The publishing time of the page in the format of `YYYY-MM-DD HH:MM:SS` (UTC time). ⏎ Example: `2024-01-01 00:00:00`. |
| ↳↳ app_id | string | Returned for all App Profile Pages and TikTok Instant Pages where an App is specified. ⏎ The ID of the App that is specified in the page. ⏎ To filter App Profile Pages, set `business_type` to `APP_PROFILE_PAGE` or set `business_types` to `["APP_PROFILE_PAGE"]` in the request. |
| ↳↳ has_cpp | boolean | Returned only for TikTok Instant Pages. ⏎ Whether the TikTok Instant Page contains [Custom Product Page](doc:1798658439859202). ⏎ Enum values: `true`, `false`. ⏎ To filter TikTok Instant Pages, set `business_type` to `TIKTOK_INSTANT_PAGE` or set `business_types` to `["TIKTOK_INSTANT_PAGE"]` in the request. |
| ↳↳ destination_urls | string[] | Returned when your `business_type` is`LEAD_GEN`(Instant Form), `APP_PROFILE_PAGE` (App Profile Page), or `TIKTOK_INSTANT_PAGE` (Custom Page or Custom TikTok Instant Page). ⏎ Destination URLs. |
| ↳↳ messaging_app_type | string | The type of instant messaging app associated with the TikTok Instant Page. ⏎ Enum values:  • `MESSENGER`: Messenger.  • `WHATSAPP`: WhatsApp.  • `IM_URL`: No instant messaging app is associated with the TikTok Instant Page. |
| ↳↳ messaging_app_account_id | string | The ID of the instant messaging app account associated with the TikTok Instant Page. ⏎ • When `messaging_app_type` is `MESSENGER`, this field represents the Facebook Page ID. • When `messaging_app_type` is `WHATSAPP`, this field represents the WhatsApp phone number. • When `messaging_app_type` is `IM_URL`, this field will be an empty string (`""`). |
| ↳↳ transfer_status | string | Whether the page has been transferred to Business Center. ⏎ Enum values: `UNSET`, `TRANSFERRED` |
| ↳↳ user_id | string | ID of the user who created the page. |
| ↳↳ is_associated | boolean | Whether Storefront Page has been associated with some ad (Storefront Page cannot be reused, and each page can only be associated with one ad). |
| ↳↳ duplicate_id | string | Duplicate source page ID. |
| ↳ page_info | object | Pagination information. |
| ↳↳ page | number | Current page. |
| ↳↳ page_size | number | Page size. |
| ↳↳ total_number | number | Total number of results. |
| ↳↳ total_page | number | Total number of pages. |
| request_id | string | Log id of the request, uniquely identifying a request. |
