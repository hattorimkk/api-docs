# Ad Measurement
> Đường dẫn: Marketing API > Ad Measurement
You can use event data connection tools to measure the effectiveness of your ads. 

- To learn about an overview of event data connection tools and how to get started, see [Overview](doc:1757985960801281).

- To find out the detailed configuration steps and the supported App or Web Events, see [Guides](doc:1757986592010242).
	- [Events API](doc:1739583647070209)
	
	Use [App Events API](doc:1739584805049345), [Website Events API](doc:1739584809311234), and [Offline Events API](doc:1758049779688450) to measure app events, website events, and offline conversions, and send them to TikTok for downstream processing.

	- [TikTok App Events SDK](doc:1739583650172929)

	Integrate our Events SDK with your mobile apps so that events will be sent to TikTok.

	- [Mobile apps](doc:1739583651652673)

	Manage the mobile apps that you want to promote. 

	- [Pixel](doc:1739583652957185)

	Manage pixels that are used to measure the performance of your ads.
	
- To find out what APIs are available for App Events and Web Events, see [API Reference](doc:1740963089558529).
