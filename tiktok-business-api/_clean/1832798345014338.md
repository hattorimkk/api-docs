# Get trending search keywords
> Đường dẫn: API Reference > Discovery > Get trending search keywords
Use this endpoint to retrieve the top 20 search keywords trending on TikTok or search keywords personalized for your TikTok account.

## Before you start

- Obtain a TikTok account access token with `discovery.search.words` permission and the Application specific unique ID for the TikTok account by following the steps in [Authorization](slug:accounts-api-authorization) and [Authentication](slug:accounts-api-authentication).
  - To confirm whether a TikTok account access token has the `discovery.search.words` permission, use [/tt_user/token_info/get/](slug:get-the-authorized-tiktok-account-permission-scopes-via-access-token) and check the returned `scope`. If the access token doesn't have the `discovery.search.words` permission, request the TikTok account owner to approve "**Query for recommended search terms based on trends or specific keywords**" permission through the [Authorization](slug:accounts-api-authorization) workflow.

- Ensure the TikTok account is a TikTok Account with Advanced Access or Verified Business Account. Learn more [about TikTok account entitlements](https://ads.tiktok.com/resources/help/article/about-tiktok-account-entitlements). To confirm this, use [/business/get/](slug:get-profile-data-of-a-tiktok-account) and check whether the response parameter `has_advanced_access` is `true` for the TikTok account.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/discovery/trending/search/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok accounts. ⏎ To obtain a short-term TikTok account access token, use [/tt_user/oauth2/token/](doc:1738084387220481). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
|business_id {Required}|string|Application specific unique identifier for the TikTok account.<br><br>Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1738084387220481) to this field.|
|is_personalized|boolean|Whether to return personalized search keywords for the TikTok account.<br><br>Supported values:<br></li><li>`true`: To return trending search keywords that are  personalized for the TikTok account.<br></li><li>`false`: To return trending search keywords that are not personalized for the TikTok account.<br><br>Default value: `false`.|
```

### Example

```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/discovery/trending/search/?business_id={{business_id}}' \
--header 'Access-Token: {{Access-Token}}'
```
