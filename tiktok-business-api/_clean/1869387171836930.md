# Skill and MCP management
> Đường dẫn: Skill and MCP management
The **My Agentic Hub** module on the TikTok for Business Developers portal provides a unified workspace for managing and distributing your AI Skills and MCP (Model Context Protocol) servers. From this module, you can upload Skills or register MCP servers, track their review status, and publish them to [**TikTok for Business Agentic Hub**](https://ads.tiktok.com/help/article/how-to-access-the-tiktok-for-business-agentic-hub), the centralized marketplace where advertisers and developers discover, download, and manage AI-powered solutions for automated advertising on TikTok.

## Why publish to Agentic Hub?
Publishing your Skills or MCP servers delivers measurable business advantages:
- **Instant access to a global advertiser network.** Agentic Hub connects you directly with TikTok's worldwide community of advertisers who are actively searching for AI-driven automation tools. Bypass the cost and complexity of building your own distribution channel — your Skills gain visibility from day one.
- **A scalable path for proprietary AI innovations.** Listing your Skills or MCP servers today establishes your presence in a rapidly growing ecosystem. As new advertising use cases emerge and agent capabilities expand, your early adoption positions you to capture demand ahead of competitors.
- **A potential future path to sustainable revenue stream.** TikTok enforces fair, transparent marketplace policies and rewards developers who invest in high-quality solutions. Clear guidelines, consistent enforcement, and growing advertiser demand create an environment where exceptional Skills or MCP servers will generate ongoing returns.

## Skill lifecycle
Every Skill follows a defined lifecycle from upload to marketplace publication. Understanding this lifecycle helps you plan your workflow and anticipate next steps.

| Stage | Status | Description |
|---|---|---|
| 1. Upload | Pending Review | You submit your Skill file and metadata. The Skill enters the review queue. |
| 2. Review | Pending Review | The TikTok team evaluates your Skill for quality, compliance, and functionality. Reviews typically take 5–7 business days. |
| 3a. Approved | Approved | Your Skill passes review. You can publish immediately or defer to a later time. |
| 3b. Rejected | Rejected | The review identified issues. You receive actionable feedback and can resubmit. |
| 4. Publish | Published | Your Skill is live on Agentic Hub and visible to advertisers. |
| 5. Manage | Published / Unpublished | You can update versions, edit metadata, control visibility, or delete the Skill. |

## MCP server lifecycle
Every MCP server follows a defined lifecycle from registration to marketplace publication. Understanding this lifecycle helps you plan your workflow and anticipate next steps.

| Stage | Status | Description |
|---|---|---|
| 1. Upload | Pending Review | You submit your MCP server details. The MCP server enters the review queue. |
| 2. Review | Pending Review | The TikTok team evaluates your MCP server for quality, compliance, and functionality. |
| 3a. Approved | Approved | Your MCP server passes review. The server is automatically live on Agentic Hub and visible to advertisers. |
| 3b. Rejected | Rejected | The review identified issues. You receive actionable feedback and can resubmit. |
| 4. Manage | Published | You can update versions, control visibility, or delete the MCP server. |

## Key concepts
- **AI Skills (Skills):** High-level instruction sets that equip AI agents with the knowledge to accomplish specific business goals autonomously. A Skill might guide an agent through onboarding a new advertiser end-to-end, rotating ad creatives when engagement declines, or redistributing campaign budgets to maximize ROAS. Skills can be **first-party** (built by TikTok) or **third-party** (built by developers and partners like you), and they enable agents to execute multi-step workflows that would otherwise require manual oversight.
- **Agentic Hub:** The centralized marketplace on TikTok Ads where advertisers discover, install, and manage AI-powered Skills and MCP servers for automated advertising.
- **SKILL.md standard:** An open format for packaging AI Skills — a ZIP file containing a `SKILL.md` file (with YAML metadata at the top and Markdown instructions) and optional supporting files, compatible with major AI agent platforms.
- **Model Context Protocol (MCP)**: An open protocol that standardizes how AI agents discover, connect to, and interact with external platforms and services. Think of MCP as a universal adapter: any compatible agent can automatically discover and use MCP tools without custom integration work. The protocol handles authentication, capability discovery, and structured communication between agents and the server.
- **MCP server**: A developer-hosted backend service that implements the Model Context Protocol. It acts as a secure bridge between AI agents and external platforms (such as CRMs, analytics tools, or creative suites), exposing your platform's capabilities as standardized tools that agents can understand. When listed on the Agentic Hub, your MCP server allows advertisers' agents to seamlessly interact with your platform's data and capabilities as part of their automated workflows.
- **MCP tools**: Individual functions exposed by the MCP Server that represent discrete advertising operations, such as "create campaign," "get performance report," "update audience targeting," or "pause ad group." Agents call these tools as needed to perform actions, combining them in sequences to accomplish complex workflows.
