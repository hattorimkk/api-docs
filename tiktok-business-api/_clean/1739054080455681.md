# Get the fields of an Instant Form
> Đường dẫn: API Reference > Leads > Get the fields of an Instant Form
Use this endpoint to get the fields of an Instant Form (or lead form).

To retrieve the Instant Form fields, you can also choose to create a mock lead using [/page/lead/mock/create/](doc:1739047132614722) and then extract the field names. However, we recommend you use this endpoint to get Instant Form fields directly. 

## Request
**Endpoint**
https://business-api.tiktok.com/open_api/v1.3/page/field/get/

**Method** GET

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | The content type of the request. ⏎ Allowed value: "application/json". |

**Parameters**

| Field | Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| page_id  **(Required)** | string | The ID of the Instant Form. |

### Example
```http
// curl
curl -L -X GET 'https://business-api.tiktok.com/open_api/v1.3/page/field/get/?advertiser_id=ADVERTISER_ID&page_id=PAGE_ID' \
-H 'Access-Token: xxx' \
-H 'Content-Type: application/json'
```

## Response

| Field | Type | Description |
|---|---|---|
| code | number | The response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | The response message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| data | object | The returned data. |
| ↳ fields | string | The Instant Form fields. |
| ↳ meta_data | object | Metadata about the Instant Form. |
| ↳↳ page_id | string | The Instant Form ID. |
| ↳↳ create_time | datetime | The creation time of the Instant Form. |
| ↳↳ page_name | string | Page title. |
| ↳↳ page_url | string | Instant Form URL. |
| request_id | string | The unique ID of the request, which uniquely identifies a request. |

### Example
```http
// Success-Response
HTTPS/1.1 200 OK
{
    "message": "OK",
    "data": {
        "fields": [],
        "meta_data": {}
    }
}
```
