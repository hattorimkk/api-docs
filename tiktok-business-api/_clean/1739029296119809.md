# Create an export task (blocked words)
> Đường dẫn: API Reference > Ad Comments - Blocked Words > Create an export task (blocked words)
Use this endpoint to  create a blocked word export task. 

After the task is created, you can use [/blockedword/task/check/](doc:1739029311687681) to check the status of the task. When the task completes, you can call [/blockedword/task/download/](doc:1739029325203457) to download the exported data.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/blockedword/task/create/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Content type of the request. Allowed value: `application/json` |

**Parameters**

| Field | Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| blocked_words | string[] | List of blocked words that you want to export. If not specified, all blocked words will be exported. ⏎ **Note**: Unblocked words specified via this field will be ignored. Therefore, if you specify both blocked words and unblocked words at the same time via this field, only the blocked words will be exported. |
| lang | string | Language of the headers of the exported data. Enum values: `EN`, `JA`, `ZH`. Default value: `EN`. |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/blockedword/task/create/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
  "advertiser_id": "{{advertiser_id}}"
}'
```

## Response

| Field | Type | Description |
|---|---|---|
| message | string | The return message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| code | number | The return code. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| data | object | The returned data. |
| ↳ task_id | string | Task ID. |
| request_id | string | Unique ID of the request. |
