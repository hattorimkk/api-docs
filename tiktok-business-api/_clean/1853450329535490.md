# Get the TikTok Minis within an ad account
> Đường dẫn: API Reference > Tools > Get the TikTok Minis within an ad account
Use this endpoint to retrieve the list of TikTok Minis within an ad account.

To learn more about the campaign type where you can promote a TikTok Mini, see [Create an Upgraded Smart+ TikTok Growth Max: Mini Games campaign](slug:create-an-upgraded-smart-mini-games-campaign) and [Create an Upgraded Smart+ TikTok Growth Max: Mini Dramas campaign](slug:create-an-upgraded-smart-minis-campaign).

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/minis/get/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
|advertiser_id {Required}|string|Advertiser ID.|
|page|number|Current page number.<br><br>Default value: 1. Value range: ≥ 1.|
|page_size|number|Page size.<br><br>Default value: 10. Value range: 1-50.|
```

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/minis/get/?advertiser_id={{advertiser_id}}&page=1&page_size=50' \
--header 'Access-Token: {{Access-Token}}'
```
## Response

``` xtable
|Field{30%}|Type{15%}|Description{55%}|
|---|---|---|
|code|number|Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097).|
|message|string|Response message. For details, see [Appendix - Return Codes](doc:1737172488964097).|
|request_id|string|The log ID of a request, which uniquely identifies the request.|
|data|object|Returned data.|
#|list|object[]|A list of TikTok Minis within an ad account.|
##|minis_id|string|The ID of the TikTok Mini.|
##|minis_name|string|The name of the TikTok Mini.|
##|minis_icon_url|string|The URL to the app icon image of the TikTok Mini.|
##|minis_status|string|The status of the TikTok Mini.<br><br>Enum values:<ul><li>`ACTIVE`: active. You can use the TikTok Mini to create ads.</li><li>`INACTIVE`: inactive. You cannot use the TikTok Mini to create ads.</li></ul>|
##|minis_type|string|The type of the TikTok Mini.<br><br>Enum values:<ul><li>`MINI_SERIES`: mini drama.</li><li>`MINI_GAME`: mini game.</li></ul>|
##|region_codes|string[]|The region codes of the supported country or region for the TikTok Mini.<br><br>Example: `["ID", "US"]`.|
#|page_info|object|Pagination information.|
##|page|number|Current page number.|
##|page_size|number|Paging size.|
##|total_number|number|Total number of results.|
##|total_page|number|Total pages of results.|
```
