# Creative basic reports
> Đường dẫn: Marketing API > Creatives > Guides > Creative reports > Creative basic reports
Use [/creative/report/get/](doc:1740662135093314) to run a report of creative assets, and you will get basic performance metrics at the creative asset level as well as creative asset attributes like height, width, and more.  

To find out the supported metrics, see [Supported metrics in creative reports](doc:1739067551410178).
