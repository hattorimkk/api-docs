# Check the status of Terms
> Đường dẫn: API Reference > Terms > Check the status of Terms
Use this endpoint to check the status of an agreement.

If the agreement has been signed, you can get the agreement using [/term/get/](doc:1737191909315585).

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/term/check/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| term_type  **(Required)** | string | Type of agreement. Enum values: `LeadAds`. |

### Example
```http
// curl
curl --get -H "Access-Token:xxx" \
--data-urlencode "advertiser_id=< ADVERTISER_ID >" \
--data-urlencode "term_type=< TERM_TYPE >" \
https://business-api.tiktok.com/open_api/v1.3/term/check/
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Return code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097). |
| message | string | Return messages. For details, see [Appendix-Return information](doc:1737172488964097). |
| data | object | Returned data. |
| ↳ confirmed | boolean | Signing status of the agreement. `True` means "Signed successfully ", ⏎ `False` means "Not signed". |
| request_id | string | The log id of a request, which uniquely identifies the request. |

### Example
```http
// Success-Response
HTTPS/1.1 200 OK
{
  "message": "OK",
  "code": 0,
  "data": {
    "confirmed": true
  },
  "request_id": "2020022414253401011023224213472"

```
