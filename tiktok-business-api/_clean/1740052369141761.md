# Music
> Đường dẫn: API Reference > Music
Music is a type of creative assets, and you can see [Upload videos, images and music-Upload files](doc:1738963828459521) to learn about the procedure of finding suitable music. You can also use the music ID in creative tools such as [Smart Video](doc:1739352294717441), and [Smart Video Soundtrack](doc:1739089635852289).  In addition, music can be included in a video package via [/catalog/video_package/create/](doc:1740665273039873), where you would need to specify the music via `music_id`.

Music can be used in Carousel Ads. See [here](doc:1766217791987713) to learn more about how to create Carousel Ads.

This group consists of the following endpoints: 
* [Upload a piece of music](doc:1740052650395650)
* [Get the music list](doc:1740053909509122)
