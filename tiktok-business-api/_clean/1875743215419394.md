# Create an Upgraded Smart+ Catalog Search Ads Campaign for App
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Sales Search Ads Campaign > Create an Upgraded Smart+ Catalog Search Ads Campaign for App
This article explains how to create an Upgraded Smart+ Search Ads Campaign using the Sales objective and the app sales destination.

Depending on your catalog preference, you can create E-commerce, Travel, or Streaming Catalog Campaigns for your app.

- To create a campaign using an E-commerce catalog, see [Create an Upgraded Smart+ E-commerce Search Ads Campaign for App](slug:create-an-upgraded-smart-e-commerce-search-ads-campaign-for-app).
- To create a campaign using a travel (hotel, flight, or destination) catalog, see [Create an Upgraded Smart+ Travel Search Ads Campaign for App](slug:create-an-upgraded-smart-travel-search-ads-campaign-for-app).
- To create a campaign using an entertainment catalog, see [Create an Upgraded Smart+ Streaming Search Ads Campaign for App](slug:create-an-upgraded-smart-streaming-search-ads-campaign-for-app).
