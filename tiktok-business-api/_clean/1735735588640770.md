# Get ads
> Đường dẫn: API Reference > Ads > Get ads
Use this endpoint to get the data of regular ads and Smart Creative ads. 

To retrieve creative materials for Smart Creative ads, use the [/ad/aco/get/](doc:1739473020978177) endpoint.

>  **Note:** To return the deleted ads, either specify the value of `STATUS_DELETE` in the `primary_status` field or `AD_STATUS_CAMPAIGN_DELETE`/`AD_STATUS_ADGROUP_DELETE` /`AD_STATUS_DELETE` in the `secondary_status` field. Deleted data is not queried by default.

## Request

**Method** GET

**Header**

### Example

#### Retrieving ad (asset group) level data for Upgraded Smart+ Campaigns
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/ad/get/?advertiser_id={{advertiser_id}}&filtering={"campaign_automation_type":"UPGRADED_SMART_PLUS","ad_ids_v2":["{{ad_id_v2}}"]}' \
//input the ID of an Upgraded Smart+ Ad (Asset Group) through {{ad_id_v2}}
--header 'Access-Token: {{Access-Token}}'
```
#### Retrieving creative level data for Upgraded Smart+ Campaigns
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/ad/get/?advertiser_id={{advertiser_id}}&filtering={"campaign_automation_type":"UPGRADED_SMART_PLUS","ad_ids":["{{ad_id}}"]}' \
//input the ID of an Upgraded Smart+ Creative through {{ad_id}}
--header 'Access-Token: {{Access-Token}}'
```
