# Apply for Spark Ads authorization
> Đường dẫn: API Reference > TikTok One > Apply for Spark Ads authorization
Use this endpoint to send a request to apply for TikTok creator's authorization to boost their video for a TikTok One (TTO) Creator Marketplace campaign.

## Request

**Endpoint** `https://business-api.tiktok.com/open_api/v1.3/tcm/tt_video/apply/`

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by a TTO Creator Marketplace account. For details, see [Authentication](slug:obtain-authorization-and-authentication-from-a-tto-creator-marketplace-account). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| video_id  **(Required)** | string | ID of the video that is created under the creator account. ⏎ The video needs to meet the following requirement:  • The video has been uploaded and tagged as branded content, and the creator has linked the video to a TTO Creator Marketplace campaign via the invite link (`invite_link`) created via [/tto/tcm/campaign/create/](doc:1815693549459458). • You can get `video_id` via [/tto/tcm/campaign/](doc:1815693562720258) or [/tto/tcm/report/](doc:1815693573340162). |
| tcm_account_id  **(Required)** | string | The ID of the TTO Creator Marketplace account. ⏎ To obtain the IDs of the TTO Creator Marketplace accounts that you can access via `Access-Token`, use [/tto/oauth2/tcm/](doc:1815693478150146). |
| authorization_days | number | Authorization validity period (in days). ⏎ Value range: 1-365. ⏎ Default value: 30. ⏎ **Note**: You can use this field to specify the validity period of the authorization, or to request an update for the validity period of approved authorization. ⏎ The actual validity period can be different from the validity period you request, because the creator can choose any validity period (one to 365 days) when approving the request. |
| action | string | The action to take. ⏎ Enum value: • `EXTEND`: To extend the validity period of the authorization by the specified days (`authorization_days`). For instance, when `authorization_days` is 30, you'll request the authorization to be extended by 30 days. |

### Example
```http
// curl
curl --location  --request GET 'https://business-api.tiktok.com/open_api/v1.3/tcm/tt_video/apply/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "tcm_account_id":"{{tcm_account_id}}",
    "video_id":"{{video_id}}",
    "authorization_days": 30
}'
```

|---|---|---|

| data | object | Returned data. |
