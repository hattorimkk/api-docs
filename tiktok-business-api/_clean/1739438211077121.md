# Assign an asset
> Đường dẫn: API Reference > BC Assets > Assign an asset
Use this endpoint to assign an asset in the Business Center to a TikTok For Business user that is already in the Business Center. You need to be an Admin user of the Business Center.

## Request

**Endpoint** `https://business-api.tiktok.com/open_api/v1.3/bc/asset/assign/`

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Request message type ⏎ Allowed format: `"application/json"`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| bc_id  **(Required)** | string | Business Center ID. |
| user_id  **(Required)** | string | The ID of the Business Center user that you want to assign the asset to. ⏎ You can obtain the Business Center user ID via `user_id` returned by [/bc/member/get/](doc:1739939404802049). |
| asset_type  **(Required)** | string | Asset type. ⏎ Enum values: • `ADVERTISER`: ad account (advertiser account). • `CATALOG`: catalog. • `TIKTOK_SHOP`: TikTok Shop. • `LEAD`: Leads. • `TT_ACCOUNT`: TikTok account as an ad delivery asset. You can run ads from these TikTok accounts. This asset type corresponds to the identity type `BC_AUTH_TT`. Learn more from [Identities](doc:1738958351620097). • `MANAGED_BUSINESS_ACCOUNT`: TikTok account for Business Account management. You can run ads from these TikTok accounts, and manage messages, leads, forms, comments, product links, and insights in your TikTok account. |
| asset_id  **(Required)** | string | Asset ID. • If `asset_type` is `ADVERTISER`, this field is the advertiser ID. • If `asset_type` is `CATALOG`, this field is the catalog ID. • If `asset_type` is `TIKTOK_SHOP`, this field is the TikTok Shop ID. • If `asset_type` is `LEAD`, this field is the form library ID. To obtain more details about form libraries that you have access to, use [/page/library/get/](doc:1740029915327489). • If `asset_type` is `TT_ACCOUNT`, this field is the ID of a TikTok account as an ad delivery asset in a Business Center. • If `asset_type` is `MANAGED_BUSINESS_ACCOUNT`, this field is the ID of a TikTok account for Business Account management in a Business Center. |
| advertiser_role{+Conditional} | string | Required when `asset_type` is `ADVERTISER`. ⏎ Advertiser role. This is equivalent to Layer 2 of Ad Account Permissions. Enum values: `ADMIN`, `OPERATOR`, `ANALYST`. For details about these permissions, see [Manage Permissions on TikTok Business Center](https://ads.tiktok.com/help/article?aid=12791). |
| catalog_role{+Conditional} | string | Required when `asset_type` is `CATALOG`. ⏎ Business Center user's permissions to the catalog. ⏎ Enum values: •  `ADMIN`: The Business Center user has Admin permissions to the catalog.  • `AD_PROMOTE`: The Business Center user can only use the catalog for promotions. |
| form_library_role{+Conditional} | string | Required when `asset_type` is `LEAD`. ⏎ Form library role assigned to the user. Currently, only `ADMIN` is supported. |
| tt_account_roles {+Conditional} | string[] | Required when `asset_type` is `TT_ACCOUNT`. ⏎ Business Center user's ad delivery permission to the TikTok account. ⏎ Enum values: • `POST`: Existing posts permissions, including accessing your own profile info, accessing your own public videos, and accessing your own ad-authorized videos. • `PUBLISH_VIDEO_ADS_ONLY`: "Only show as ads" permission. Videos will only get paid traffic and won't be published to your TikTok profile.  • You can assign either `PUBLISH_VIDEO_ADS_ONLY` or `PUBLISH_VIDEO_SHOW_ON_TT_PROFILE_AND_ADS` at the same time, but not both, as they are mutually exclusive. • `PUBLISH_VIDEO_SHOW_ON_TT_PROFILE_AND_ADS`: "Show on TikTok profile and as ads" permission. Videos will get both organic and paid traffic and will be published to your TikTok profile. • You can assign either `PUBLISH_VIDEO_ADS_ONLY` or `PUBLISH_VIDEO_SHOW_ON_TT_PROFILE_AND_ADS` at the same time, but not both, as they are mutually exclusive. • `LIVE`: LIVE video permissions (Only available in some regions), including accessing your own profile info and accessing LIVE videos. • `SHOWCASE`: Showcase permissions (Only available in some regions), including accessing your own profile information and products from Showcase. • `DIRECT_MESSAGE`: Message ads permissions, including granting access to Read and Manage direct message features and settings (including auto reply features, auto-lead collection, AI related messaging tools, etc.), changing settings of the TikTok account to allow everyone to send you a direct message, and permission to update Privacy Policy if no current policy has been uploaded. • `SERIES`: Series permissions, including accessing your own profile information and TikTok Series. |
| business_account_roles {+Conditional} | string[] | Required only when `asset_type` is `MANAGED_BUSINESS_ACCOUNT`. ⏎ Business Center user's Business Account management permission to the TikTok account. ⏎ Enum values: • `BUSINESS_ACCOUNT_ADMIN`: Business Account admin. Business Account admins have access to all Business Account features, including verification, member management, and linking to Business Center. • `BUSINESS_ACCOUNT_OPERATOR`: Business Account operator. Business Account operators can manage TikTok analytics, posts, messages, and profile information. • `BUSINESS_ACCOUNT_ANALYST`: Business Account analyst. Business Account analysts only have access to analytics and are not able to manage posts, messages, etc. ⏎ Max size: 1. |
| store_role{+Conditional} | string | Required when `asset_type` is `TIKTOK_SHOP`. ⏎ Business Center user's permission to a TikTok Shop. ⏎ Enum values: • `AD_PROMOTION`: The Business Center user can only use the TikTok Shop for promotions. |

### Example
```cURL
// cURL
curl --location --request POST 'business-api.tiktok.com/open_api/v1.3/bc/asset/assign/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
    "bc_id": "{{bc_id}}",
    "user_id": "{{user_id}}",
    "asset_type": "ADVERTISER",
    "asset_id": "{{asset_id}}",
    "advertiser_role": "ADMIN"
}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Appendix - Return Codes](doc:1737172488964097). ⏎ **Note**: If the response code is `40002`, and the response message is "Authorization roles exceed the role range that the BC can manage.", then you need to check whether the value you pass in for `advertiser_role`, `catalog_role`,  `form_library_role`, or `tt_account_roles` in the request is allowed. |
| request_id | string | Unique ID of the request. |
| data | object | Returned data. |
