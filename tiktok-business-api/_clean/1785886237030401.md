# (To-be-deprecated) Create Product Shopping Ads
> Đường dẫn: Use Cases > Campaign creation > Create Shopping Ads > (To-be-deprecated) Create Product Shopping Ads
This article walks you through the steps to create Product Shopping Ads (PSA).

> **Important:** 
> Starting Q3, 2025, [GMV Max](doc:1822009058467842) will be the default and only supported campaign type for TikTok Shop Ads. If you create ads using the Product Sales objective and TikTok Shop as your sales destination, you will no longer be able to use the API to create, edit, or duplicate [LIVE Shopping Ads](doc:1754162402455554), [Product Shopping Ads](doc:1785886237030401), or [Video Shopping Ads](doc:1741942291730434). Please migrate to the [GMV Max API](doc:1822000911166465) as early as possible. If you have questions or need support, please contact your TikTok representative.  Learn more about [the detailed changes by ad type and endpoint](doc:1837161048383489).

> **Note:** 
> Audience size estimation is not available for PSA.

## 2. Create and manage TikTok Shops
TikTok Commerce (formerly known as TikTok Shopping) offers TikTok Shops for brands and sellers who want to sell their products directly on their TikTok account. 

You can set up TikTok Shop by creating TikTok Shops on TikTok Seller Center. For detailed instructions on how to create a TikTok Shop, see [Set Up TikTok Shop Using TikTok Seller Center](https://ads.tiktok.com/help/article?aid=10005127).

After you have created a TikTok Shop, follow the procedures below:
- i. Add the TikTok Shop to the Business Center. To learn about how to request TikTok Shop access from a Business Center, see [here](https://ads.tiktok.com/help/article?aid=10012166). 
- ii. Invite members to Business Center and grant the admin permission using [/bc/member/invite/](doc:1739939455765505). You can also choose `advertiser_role` that you want to assign to the members invited.
- iii. Share a TikTok Shop with members and grant the TikTok Shop management access using [/bc/asset/assign/](doc:1739438211077121). Make sure to specify `TIKTOK_SHOP` in the `asset_type` field and `AD_PROMOTION` in the `store_role` field.
