# Delete an identity
> Đường dẫn: API Reference > Identity > Delete an identity
Use this endpoint to delete a customized user identity (`identity_type` = `CUSTOMIZED_USER`). If you want to edit an identity, you need to first delete the identity using this endpoint, and then create a new one using [/v1.3/identity/create/](doc:1740654203526146).

## Request

**Endpoint**

https://business-api.tiktok.com/open_api/v1.3/identity/delete/ 

**Method** POST

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token{Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162).|
|Content-Type{Required}|string|The content type of the request. <br>Allowed value: `"application/json"`.|
```

**Parameters**

``` xtable
|Field|Data Type|Description|
|---|---|---|
| advertiser_id {Required} | string | Advertiser ID. |
| identity_id  {Required} | string | Identity ID.
| identity_type  {Required} | string | Identity type. Currently, this field only supports `CUSTOMIZED_USER`. 
```

### Example
```http
// curl
curl --location  --request POST 'https://business-api.tiktok.com/open_api/v1.3/identity/delete/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id":"{{advertiser_id}}",
    "identity_id":"{{identity_id}}",
    "identity_type":"CUSTOMIZED_USER"
}'
```
