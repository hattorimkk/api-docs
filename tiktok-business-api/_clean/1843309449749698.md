# Create an Upgraded Smart+ Campaign
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign
This article walks you through the steps to create an Upgraded Smart+ Campaign. 

# Introduction
The Upgraded Smart+ Campaigns feature a new, unified workflow, known as the Upgraded Smart+ experience. This streamlined process enables you to access both [manual](doc:1739315728330753) and [Smart+](doc:1765314260115458) features when creating your campaign. [Learn more about the Upgraded Smart+ experience](https://ads.tiktok.com/help/article/about-updates-to-smart-plus).

The Upgraded Smart+ API supports an enhanced campaign structure with upgraded Smart+ experience built-in campaign management. By combining **AI-powered automation** with **granular control**, this API enables advanced campaign structures, allowing you to fine-tune targeting settings while leveraging AI-driven automation capabilities to boost your ad performance.

**You can use Upgraded Smart+ API to create an Upgraded Smart+ Campaign, and this helps streamline your ad creation experience, and elevate operational efficiency and scalability.**

# Prerequisites
- You've gained access to TikTok API for Business. See [Get Started - Step by step workflow](doc:1735713609895937) for details.
  - To create an Upgraded Smart+ Campaign you need relevant permissions. See [API Reference](doc:1735713875563521) to find out permissions required for endpoints and see [Update app permissions](doc:1738855280338946) to find out how to configure permissions.

# Steps

Based on your preference for the advertising objective and whether you want to capture search traffic, you can create Upgraded Smart+ App Campaigns, TikTok Growth Max campaigns, Web Campaigns, Lead Generation Campaigns,  Catalog Ads for Apps, Ads with Website and App Optimization, or Search Ads Campaigns.

- To learn about how to create an Upgraded Smart+ App Campaign, see [Create Upgraded Smart+ App Campaigns](doc:1843309500205058).
- To learn about how to create an Upgraded Smart+ TikTok Growth Max campaign, see [Create Upgraded Smart+ Growth Max campaigns](slug:create-upgraded-smart-growth-max-campaigns).
- To learn about how to create an Upgraded Smart+ Web Campaign, see [Create Upgraded Smart+ Web Campaigns](doc:1843309514567809).
- To learn about how to create an Upgraded Smart+ Lead Generation Campaign, see [Create Upgraded Smart+ Lead Generation Campaigns](doc:1843324498993154).
- To learn about how to create Upgraded Smart+ Catalog Ads for Apps or Upgraded Smart+ Ads with Website and App Optimization, see [Create Upgraded Smart+ Catalog Ads for App](doc:1847303035303106) or [Create Upgraded Smart+ Ads with Website and App Optimization](doc:1854746404386113).
- To learn about how to create Upgraded Smart+ Search Ads Campaigns, see [Create Upgraded Smart+ Search Ads Campaigns](slug:create-upgraded-smart-search-ads-campaigns).
