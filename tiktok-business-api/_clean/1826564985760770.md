# Delete a draft anchor
> Đường dẫn: API Reference > TikTok One > Delete a draft anchor
Use this endpoint to delete an anchor in draft mode that was created on the [TikTok One](https://ads.tiktok.com/creative) platform.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tto/tcm/anchor/delete/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by a TikTok One Creator Marketplace account. ⏎ For details, see [Authentication](slug:obtain-authorization-and-authentication-from-a-tto-creator-marketplace-account). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| tto_tcm_account_id {Required} | string | The ID of the TTO Creator Marketplace account.<br><br>To obtain the IDs of the accounts that you can access via `Access-Token`, use [/tto/oauth2/tcm/](doc:1815693478150146). |
|anchor_id {Required}|string|Anchor ID.<br><br>To obtain a draft anchor within your TikTok One (TTO) Creator Marketplace account, use [/tto/tcm/anchor/get/](doc:1826564965840066) and confirm that the `status` of the anchor is `DRAFT`.|
```

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tto/tcm/anchor/delete/' \
--header 'Access-Token: {{Access_Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "tto_tcm_account_id" : "{{tto_tcm_account_id}}",
    "anchor_id" : "{{anchor_id}}"
}'
```
