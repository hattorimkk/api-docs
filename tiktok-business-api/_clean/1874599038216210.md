# O2O catalog CSV feed parameters
> Đường dẫn: Marketing API > Catalog Management > Guides > Create catalogs and add products > O2O catalog CSV feed parameters
The following table lists the parameters you can configure for an online-to-offline (O2O) catalog when passing a CSV file to the `file_url` parameter in [/catalog/product/file/](slug:upload-products-via-a-file-url).

| Field | Data Type | Description |
|---|---|---|
| listing_id  **(Required)** | string | A unique ID for the listing. ⏎ No length limit. |
| title  **(Required)** | string | The name of the listing. ⏎ Recommended length: 25 characters. ⏎ Example: `Big Mac` |
| description  **(Required)** | string | The description of the listing. ⏎ Length limit: 5,000 characters. ⏎ Recommended length: 40 characters. ⏎ Example: `Nice burger!` |
| availability  **(Required)** | string | The current availability status of the listing. ⏎ Enum values: • `in stock` • `available for order` • `preorder` • `out of stock` • `discontinued` |
| image_link  **(Required)** | string | The main image URL for the listing. ⏎ Requirements: • The URL must start with `http://` or `https://`.  • The image must be in JPG, JPEG, or PNG format. • The image must be at least 500 × 500 pixels and no larger than 1290 × 2790 pixels.  • The URL must link directly to the image file. ⏎ Example: `https://www.tiktok.com/tiktok_service_001.jpg`. |
| link | string | The web landing page URL for the listing. ⏎ The URL must start with `http://` or `https://`. ⏎ If you want to specify app deeplinks, use the `ios_url` or `android_url` parameter instead. ⏎ Example: `https://www.tiktok.com/tiktok_service` |
| brand | string | The brand name of the listing. ⏎ Length limit: 150 characters. |
| product_type | string | The category that the listing (product or service) belongs to. ⏎ Example: `Thai food`. |
| rating | double | The user rating for the listing. ⏎ Value range: 0.0-5.0. |
| condition | string | The current condition of the listing. ⏎ Enum values: • `new` • `refurbished` • `used` |
| price | double | The price of one listed item. ⏎ The catalog target country’s default currency will be used. ⏎ Ensure that the price matches the price on the landing page and checkout page. ⏎ Example: 9.99. |
| google_product_category | string | A preset category from Google's product taxonomy. ⏎ This field supports up to three levels. ⏎ Learn more about [Google product category](https://support.google.com/merchants/answer/6324436). ⏎ Example: Apparel & Accessories > Clothing > Dresses |
| item_group_id | string | The SPU ID shared by all variants of a specific product. ⏎ Items that are variants of a specific product. Provide the same `item_group_id` for all items that are variants. For example, a spicy Chicken Burger is a variant of Chicken Burger. ⏎ Example: `TikTok_1234`. |
| additional_image_link | string | A list of additional image URLs for the listing. ⏎ Requirements: • The URL must start with `http://` or `https://`.  • The image must be in JPG, JPEG, or PNG format. • The image must be at least 500 × 500 pixels and no larger than 1290 × 2790 pixels.  • The URL must link directly to the image file. • Separate multiple URLs with commas. ⏎ Up to 20 links are allowed. ⏎ Example:`https://www.tiktok.com/tiktok_service_002.jpg` |
| color | string | The color of the listing. ⏎ Example: `blue`. |
| size | string | The size of the listed item. ⏎ Example: `small`. |
| material | string | The main material of the listed item. ⏎ Example: `cotton`. |
| pattern | string | The pattern or graphic print on the listed item. ⏎ Example: `stripes1`. |
| sale_price | double | The discounted price of one listed item. ⏎ The catalog target country’s default currency will be used. ⏎ Ensure that the discounted price matches the discounted price on the landing page and checkout page. ⏎ Example: 4.99 |
| sale_price_effective_date | string | The effective date and time range for the discounted price, in the format of `YYYY-MM-DDTHH:MM+00:00/YYYY-MM-DDTHH:MM+00:00` (UTC time). ⏎ Use a start date before the end date. ⏎ Example: `2026-12-11T23:59+00:00/2026-12-15T23:59+00:00`. |
| gtin | string | The Global Trade Item Number (GTIN) for the listed item. ⏎ Specify a value of 8, 12, 13, or 14 digits. ⏎ Example: 323456789012. |
| tax | string | The tax rate for the listed item. ⏎ The catalog target country’s default currency will be used. |
| age_group | string | The intended age group for the listing. ⏎ Enum values: • `newborn` • `infant` • `toddler` • `kids` • `adult` |
| gender | string | The intended gender for the listing. ⏎ Enum values: • `male` • `female` • `unisex` |
| availability_circle_radius | string | The radius from the origin where the item can be fulfilled. This defines a circular availability area. ⏎ Value range: • When the unit is kilometer: greater than 0 and ≤ 40. • When the unit is mile: greater than 0 and ≤ 25. ⏎ Example: 20. |
| availability_circle_radius_unit | string | The unit for `availability_circle_radius`. ⏎ Enum values: • `km`: kilometer. • `mi`: mile. |
| address_street | string | The street address where the product or service is located. ⏎ Length limit: 150 characters. ⏎ Example: `1143 coleman Avenue`. |
| address_city | string | The city where the product or service is located. ⏎ Length limit: 150 characters. ⏎ Example: `San Jose`. |
| address_region | string | The state, province, or administrative region where the product or service is located. ⏎ Length limit: 150 characters. ⏎ Example: `California`. |
| address_postal_code | string | The postal or ZIP code of the product or service location. ⏎ Length limit: 150 characters. ⏎ Example: `95050`. |
| address_latitude | double | The latitude of the product or service location. ⏎ Value range: [-90, 90]. ⏎ Example: -25.5. |
| address_longitude | double | The longitude of the product or service location. ⏎ Value range: [-180, 180]. ⏎ Example: 100.5. |
| ios_url | string | The iOS app URL for the listed item. ⏎ Example: `iOS://electronic`. |
| ios_app_store_id | string | The App Store ID of the iOS app. |
| ios_app_name | string | The name of the iOS app. |
| android_url | string | The Android app URL for the listed item. ⏎ Example: `android://electronic`. |
| android_package | string | The Android package name. |
| android_app_name | string | The Android app name. |
| custom_label_0 | string | A custom label used to add information about the listing. |
| custom_label_1 | string | A custom label used to add information about the listing. |
| custom_label_2 | string | A custom label used to add information about the listing. |
| custom_label_3 | string | A custom label used to add information about the listing. |
| custom_label_4 | string | A custom label used to add information about the listing. |
| custom_number_0 | double | A custom numeric attribute for product management. |
| custom_number_1 | double | A custom numeric attribute for product management. |
| custom_number_2 | double | A custom numeric attribute for product management. |
| custom_number_3 | double | A custom numeric attribute for product management. |
| custom_number_4 | double | A custom numeric attribute for product management. |
