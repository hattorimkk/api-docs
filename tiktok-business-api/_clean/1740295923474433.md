# Download the invoices of a BC
> Đường dẫn: API Reference > BC Invoices > Download the invoices of a BC
Use these endpoints to download invoices, via synchronous downloads or asynchronous downloads. 

Both Agency and Direct Business Centers are able to perform invoice related operations.   

> **Note:** Only users with Finance Manager or Finance Analyst permission can manage payments and invoices in Business Center. You can use [/bc/member/invite/](doc:1739939455765505) and [/bc/member/update/](doc:1739696704424961) to configure or update access settings for members.

This group consists of the following endpoints: 
- [Download synchronously](doc:1754000198430722)
- [Download asynchronously](doc:1754000224141313)
  - [Create an asynchronous download task](doc:1754000448122882)
  - [Get asynchronous download tasks](doc:1754000480307265)
  - [Get asynchronous download task list](doc:1754000504437762)
