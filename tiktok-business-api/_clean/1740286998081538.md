# Creative tools
> Đường dẫn: Marketing API > Creatives > Guides > Creative tools
Creative tools provide a variety of simple and common assets (including images, videos and ads) preview, generation and optimization capabilities.
- [Instant Page Editor SDK](doc:1740307202170881): Use it to create instant pages.
- [Ads Preview](doc:1740317791125506):  Runs in asynchronous mode. Use it to preview the actual display effect of the material in the placement after delivery.
- [CTA Recommendations](doc:1740307296329730): Get standard or dynamic CTA recommendations. These CTAs can be used in ads.
- [Smart Fix](doc:1741472523309058): Helps you identify and fix video issues, such as video size and resolution, which could later get your ads disapproved or rejected during campaign creation process.
- [Image Editing](doc:1739067107903489): Runs in synchronous mode. Use it to edit an image to a size that you want.
- [Smart Text](doc:1739084248002626): This tool provides advertisers with ad text suggestions based on their industries and products.
- [Creative Fatigue Detection](doc:1767568085608450): Helps you identify fatigued ads.
- [Share creative assets](doc:1773192725768193): Share creative assets with other advertiser accounts.
