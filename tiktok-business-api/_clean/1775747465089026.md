# Supported dimensions
> Đường dẫn: Marketing API > Reporting > Guides > Report types > Business Center reports > Supported dimensions
A dimension is an attribute to group your data by. Business Center reports support the following dimensions. 

## Supported dimensions

| Dimension Name | Description |
|---|---|
| advertiser_id | Group by Advertiser ID. ⏎ All metrics in Business Center reports are supported for this dimension. To find out the complete list of metrics in Business Center reports, refer to [Business Center reports - Supported metrics](doc:1775747476019266). |
| stat_time_day | Group by day (date). ⏎ To learn about the supported metrics for this dimension, refer to [Supported metrics for a dimension in Business Center reports - Supported metrics for `stat_time_day`, `stat_time_week` or `stat_time_month`](doc:1775747492072449). |
| stat_time_week | Group by week. ⏎ To learn about the supported metrics for this dimension, refer to [Supported metrics for a dimension in Business Center reports - Supported metrics for `stat_time_day`, `stat_time_week` or `stat_time_month`](doc:1775747492072449). |
| stat_time_month | Group by month. ⏎ To learn about the supported metrics for this dimension, refer to [Supported metrics for a dimension in Business Center reports - Supported metrics for `stat_time_day`, `stat_time_week` or `stat_time_month`](doc:1775747492072449). |
| placement | Group by placement. ⏎ To learn about the supported metrics for this dimension, refer to [Supported metrics for a dimension in Business Center reports - Supported metrics for `placement`](doc:1775747492072449). |
| country_code | Group by country or region code. ⏎ To learn about the supported metrics for this dimension, refer to [Supported metrics for a dimension in Business Center reports - Supported metrics for `country_code`](doc:1775747492072449). |

  
  
 ## Dimension grouping
You can specify in the `dimensions` field of the request any of the groupings below:
- `["advertiser_id"]`
- `["stat_time_day"]`
- `["stat_time_week"]`
- `["stat_time_month"]`
- `["advertiser_id", "placement"]`
- `["advertiser_id", "country_code"]`
