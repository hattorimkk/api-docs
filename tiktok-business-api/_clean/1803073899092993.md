# (To-be-deprecated) Supported dimensions
> Đường dẫn: Marketing API > Reporting > Guides > Report types > (To-be-deprecated) GMV max ads reports > (To-be-deprecated) Supported dimensions
> **Important:** 
> GMV max ads reports only provide limited data and will be deprecated in the next API version. To ensure a smooth integration experience, run GMV Max Campaign reports for your Product GMV Max Campaigns or Live GMV Max Campaigns using [/gmv_max/report/get/](slug:run-a-gmv-max-campaign-report) instead.

A dimension is an attribute to group your data by. GMV max ads reports support the following dimensions.

## Supported dimensions

| Dimension Name | Description |
|---|---|
| advertiser_id | Group by Advertiser ID. |
| campaign_id | Group by Campaign ID. |
| stat_time_day | Group by day (date). |
| country_code | Group by country or region code. |

 ## Dimension grouping
You can specify in the `dimensions` field of the request any of the groupings below:
- `["advertiser_id"]`
- `["advertiser_id", "country_code"]`
- `["advertiser_id", "country_code","stat_time_day"]`
- `["campaign_id", "country_code"]`
- `["campaign_id", "country_code","stat_time_day"]`
