# Get all replies to a comment
> Đường dẫn: API Reference > Accounts > Comments > Get all replies to a comment
Use this endpoint to access all replies to a specific comment (along with related information) - both public and hidden - that have been created against a comment on an organic video posted by an owned TikTok Account.

>**Note:** 
>   • `/business/comment/reply/list/`currently does not support getting replies to a hidden comment.  • The comment webhook event [comment.update](doc:1810515104773122) enables you to get notifications within five minutes of a comment reply being created, deleted, or the reply visibility settings being modified on any public video associated with an owned TikTok account. To subscribe to the comment webhook, see [Subscribe to the comment update event](doc:1810521730276354).

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/comment/reply/list/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok creators. ⏎ To obtain an access token, use [/tt_user/oauth2/token/](doc:1833997638479041). |

**Parameters**

Pass params as url parameters.

| Field | Data Type | Description |
|---|---|---|
| business_id  **(Required)** | string | Application specific unique identifier for the TikTok account. ⏎ Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1833997638479041) to this field. |
| video_id  **(Required)** | string | Unique identifier for owned TikTok video to list comments on. This can be accessed via the [/business/video/list/](doc:1762228421622786) endpoint as the `item_id` for each video listed. |
| comment_id  **(Required)** | string | Unique identifier for comment on an owned TikTok video to list replies on. ⏎ This can be accessed via the [/business/comment/list/](doc:1760232109619202) endpoint as the `comment_id` for each comment listed. |
| status | string | Enumerated status of comment reply visibility. ⏎ **Enum values**:  • `PUBLIC`: Comment replies are publicly viewable by all TikTok users. • `ALL`: Comment replies are both hidden from view as well as publicly viewable by all TikTok users. ⏎ **Default value**: `ALL`. |
| sort_field | string | Specific field to sort comment replies by. ⏎ **Enum values**:  • `likes`: Sort comment replies by the number of likes in the specified `sort_order`.  • `replies`: Sort comment replies by the number of replies in the specified `sort_order`. • `create_time`: Sort comment replies chronologically in the specified `sort_order`.By default, the comment replies will be returned in a random order. |
| sort_order | string | Specific field to sort comment replies by. ⏎ **Enum values**:  • `asc`: Sort comment replies in ascending order by the specified `sort_field`. •  `desc`: Sort comment replies in descending order by the specified `sort_field`. ⏎ By default, the comment replies will be sorted according to semantics. |
| cursor | integer | Cursor for pagination. If the response parameter `has_more` is true, pass the returned cursor in this parameter in the subsequent request to receive the next page of results. ⏎ **Default value**: 0. |
| max_count | integer | The maximum number of comment replies that will be returned for each page of data. ⏎ **Default value**: 20. ⏎ **Minimum value**: 0. ⏎ **Maximum value**: 30. ⏎ **Note**: Due to our trust and safety policies, it is possible that the endpoint returns less than the `max_count` number of comments even if the response parameter `has_more` is true. |

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/business/comment/reply/list/?business_id={{business_id}}&video_id={{video_id}}&comment_id={{comment_id}}' \
--header 'Access-Token: {{Access-Token}}'
```

|---|---|---|

| X-Tt-Logid | string | Unique identifier for the API request. |
