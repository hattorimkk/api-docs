# Unassign an asset
> Đường dẫn: API Reference > BC Assets > Unassign an asset
Use this endpoint to revoke the access to an asset from a user. You need to be an Admin user of the Business Center.

## Request

**Endpoint** `https://business-api.tiktok.com/open_api/v1.3/bc/asset/unassign/`

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Request message type ⏎ Allowed format: `"application/json"`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| bc_id  **(Required)** | string | Business Center ID |
| user_id  **(Required)** | string | The ID of the Business Center user that you want to revoke the access to the asset from. ⏎ You can obtain the Business Center user ID via `user_id` returned by [/bc/member/get/](doc:1739939404802049). |
| asset_type  **(Required)** | string | Asset type. ⏎ Enum values: • `ADVERTISER`: ad account (advertiser account). • `CATALOG`: catalog. • `LEAD`: Leads. • `TT_ACCOUNT`: TikTok account as an ad delivery asset. You can run ads from these TikTok accounts. This asset type corresponds to the identity type `BC_AUTH_TT`. Learn more from [Identities](doc:1738958351620097). • `MANAGED_BUSINESS_ACCOUNT`: TikTok account for Business Account management. You can run ads from these TikTok accounts, and manage messages, leads, forms, comments, product links, and insights in your TikTok account. |
| asset_id  **(Required)** | string | Asset ID. • If `asset_type` is `ADVERTISER`, this field is the advertiser ID. • If `asset_type` is `CATALOG`, this field is the catalog ID. • If `asset_type` is `LEAD`, this field is the form library ID. To obtain more details about form libraries that you have access to, use [/page/library/get/](doc:1740029915327489). • If `asset_type` is `TT_ACCOUNT`, this field is the ID of a TikTok account as an ad delivery asset in a Business Center. • If `asset_type` is `MANAGED_BUSINESS_ACCOUNT`, this field is the ID of a TikTok account for Business Account management in a Business Center. |

### Example

```cURL
// cURL
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/bc/asset/unassign/' \
--header 'Content-Type: application/json' \
--header 'Access-Token;' \
--data '{
    "bc_id" : {{bc_id}},
    "user_id": {{user_id}},
    "asset_type": "ADVERTISER",
    "asset_id": {{asset_id}}
}'
```
