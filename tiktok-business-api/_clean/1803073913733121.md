# (To-be-deprecated) Supported metrics
> Đường dẫn: Marketing API > Reporting > Guides > Report types > (To-be-deprecated) GMV max ads reports > (To-be-deprecated) Supported metrics
> **Important:** 
> GMV max ads reports only provide limited data and will be deprecated in the next API version. To ensure a smooth integration experience, run GMV Max Campaign reports for your Product GMV Max Campaigns or Live GMV Max Campaigns using [/gmv_max/report/get/](slug:run-a-gmv-max-campaign-report) instead.

You can use the following metrics in GMV max ads reports. 

## Attribute metrics
Attribute metrics provide basic attributes of your campaigns.

| Field | Type | Description | Detail |
|---|---|---|---|
| campaign_name | string | Campaign name | Supported at Campaign level (`data_level` is `AUCTION_CAMPAIGN`). |

## Basic data metrics
Basic data metrics provide data about spend and performance of your ads.

| Field | Type | Description | Detail |
|---|---|---|---|
| spend | string | Total Cost | The estimated total amount you've spent on your ads during its schedule. |
| billed_cost | string | Net cost | The amount spent, excluding ad credit/coupons used. |
