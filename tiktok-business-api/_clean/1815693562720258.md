# Get TTO Creator Marketplace campaigns
> Đường dẫn: API Reference > TikTok One > Get TTO Creator Marketplace campaigns
Use this endpoint to retrieve the information of TikTok One (TTO) Creator Marketplace campaigns. 

## Comparing TCM and TTO Creator Marketplace endpoints
The following table outlines the differences between TCM and TTO Creator Marketplace endpoints.

| Changes | TCM Endpoint | TTO Creator Marketplace Endpoint |
|---|---|---|
| Endpoint path | /v1.3/tcm/order/get/v2/ | /v1.3/tto/tcm/campaign/ |
| Same request parameters | `page` ⏎ `page_size` | `page` ⏎ `page_size` |
| Deprecated request parameters | N/A | `tcm_account_id` ⏎ `query_type` ⏎ `order_ids` ⏎ `campaign_code` ⏎ `invite_link` ⏎ `fields` |
| New request parameters | N/A | `tto_tcm_account_id` ⏎ `campaign_ids` ⏎ `campaign_type` |
| Same response parameters | `orders.video_ids` ⏎ `page_info` ⏎ `page_info.page` ⏎ `page_info.page_size` ⏎ `page_info.total_number` ⏎ `page_info.total_page` | `campaigns.video_ids` ⏎ `page_info` ⏎ `page_info.page` ⏎ `page_info.page_size` ⏎ `page_info.total_number` ⏎ `page_info.total_page` |
| Deprecated response parameters | N/A | `orders` ⏎ `orders.order_id` ⏎ `orders.handle_name` ⏎ `orders.campaign_code` ⏎ `orders.invite_link` ⏎ `orders.quota` ⏎ `orders.quota.current_video_count` ⏎ `orders.quota.per_creator_video_limit` ⏎ `orders.quota.total_video_limit` |
| New response parameters | N/A | `campaigns` ⏎ `campaigns.campaign_id` ⏎ `campaigns.brand_name` ⏎ `campaigns.campaign_name` ⏎ `campaigns.handle_names` ⏎ `campaigns.campaign_description` ⏎ `campaigns.spark_ads_requested_authorization_days` ⏎ `campaigns.invite_link` ⏎ `campaigns.create_time` ⏎ `campaigns.country_codes` ⏎ `campaigns.advertiser_ids` ⏎ `campaigns.anchor_id` ⏎ `campaign_type` ⏎ `brand_profile_id` ⏎ `dm_info` ⏎ `business_account_handle` ⏎ `dm_allowed` |

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tto/tcm/campaign/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by a TikTok One Creator Marketplace account. ⏎ For details, see [Authentication](slug:obtain-authorization-and-authentication-from-a-tto-creator-marketplace-account). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| tto_tcm_account_id {Required} | string | The ID of the TikTok One Creator Marketplace account.<br><br>To obtain the IDs of the accounts that you can access via `Access-Token`, use [/tto/oauth2/tcm/](doc:1815693478150146). |
| campaign_ids  | string[] | The ID list of TikTok One Creator Marketplace campaigns. <br><br> Max size: 5. <br><br>To create a campaign and obtain the campaign ID, use [/tto/tcm/campaign/create/](doc:1815693549459458). |
| campaign_type | string | The type of the TTO Creator Marketplace campaign.<br><br>Enum value:<ul><li>`CAMPAIGN`: A campaign with a [campaign-level invite link](doc:1830337139853313).</li><li>`BRAND_LINK`: A campaign with a [brand-level invite link](doc:1830337139853313).</li></ul>Default value: `CAMPAIGN`. |
| page | integer | Current page number.<br><br>Value range: ≥ 1.<br>Default value: 1. |
| page_size | integer | Page size.<br><br>Value range: 1-5. <br>Default value: 5.|
```
### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/tto/tcm/campaign/?tto_tcm_account_id={{tto_tcm_account_id}}&campaign_ids=["{{campaign_id}}","{{campaign_id}}"]' \
--header 'Access-Token: {{Access-Token}}' \
```
## Response

``` xtable
|Field{35%}|Type{15%}|Description{50%}|
|---|---|---|
|code |number|Response code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097). |
|message|string|Response message. For details, see [Appendix - Return Codes](doc:1737172488964097).|
|request_id |string|The log ID of a request, which uniquely identifies the request.  |
|data |object|Returned data.|
#| campaigns | object[] | The list of TTO Creator Marketplace campaigns. |
##| campaign_id | string | The ID of the TTO Creator Marketplace campaign. |
##| campaign_type | string | The type of the TTO Creator Marketplace campaign.<br><br>Enum values:<ul><li>`CAMPAIGN`: A campaign with a [campaign-level invite link](doc:1830337139853313).</li><li>`BRAND_LINK`: A campaign with a [brand-level invite link](doc:1830337139853313).</li></ul> |
##| brand_profile_id | string | The ID of the Brand Profile associated with the campaign. |
##| brand_name | string | Brand name. |
##| campaign_name | string | Campaign name. |
##| handle_names | string[] | The handle name list of TikTok creators that the campaign is for. <ul><li>If this field is not empty, the campaign is a campaign that only the invited creators can join.</li><li>If this field is empty, the campaign is a campaign that any creator can join.</li></ul>|
##| campaign_description | string | Campaign description. |
##|anchor_id|string|The ID of the anchor that is associated with the campaign.|
##| video_ids | string[] | List of video IDs linked to the campaign. |
##| advertiser_ids | string[] | A list of ad accounts that the campaign is associated with. <br> When a creator's video is linked to the campaign, these ad accounts will automatically be granted Spark Ads authorization for the video. |
##| spark_ads_requested_authorization_days | integer | The default Spark Ads authorization days for videos uploaded to the campaign. <br><br>  Enum values: 0, 7, 30, 60, 180, 365. |
##| invite_link | string | The invite link that is associated with the TTO Creator Marketplace campaign. |
##| create_time | string | The time when the campaign was created, in the format of `YYYY-MM-DD HH:MM:SS`(UTC+0 time).<br><br> Example: `2024-01-01 00:00:01`. |
##| country_codes | string[] | The list of country or region codes associated with the TTO Creator Marketplace campaign.<br><br>This field represents the regions where the creators invited to the campaign are located. To learn about the values that might be returned for this field, see [Location code](doc:1737585867307010).<br><br>You can pass the field value to the Header parameter `Country-Code` in [/tto/tcm/report/](doc:1815693573340162) to obtain video-level reports for a specific region for a TikTok One Creator Marketplace campaign.<br><br>Example: `CA`. |
#| page_info | object | Page information. |
##| page | number | Current page number. |
##| page_size| number | Page size. |
##| total_number | number | Total number of results. |
##| total_page | number | Total number of pages. |
#|dm_info|string|Direct messaging link information.|
##|business_account_handle|string|The handle (username) of the Business Account.|
##|dm_allowed|boolean|Whether direct messaging is allowed.<br>Supported values: `true`(allowed), `false`(not allowed).|
```
