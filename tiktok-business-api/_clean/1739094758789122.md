# Cancel a subscription
> Đường dẫn: API Reference > Subscription > Cancel a subscription
Use this endpoint to cancel a subscription.

## Request
**Endpoint**
https://business-api.tiktok.com/open_api/v1.3/subscription/unsubscribe/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | The content type of the request. For this endpoint, use `application/json`. |

**Parameters**

| Field | Type | Description |
|---|---|---|
| app_id **(Required)** | string | ID of your developer application. You can find the **App ID** by navigating to **[My Apps](https://ads.tiktok.com/marketing_api/apps/)** > **App Detail** > **Basic Information**. |
| secret  **(Required)** | string | Secret of your developer application. You can find the **Secret** by navigating to **[My Apps](https://ads.tiktok.com/marketing_api/apps/)** > **App Detail** > **Basic Information**. |
| subscription_id  **(Required)** | string | The subscription ID. ⏎ You can get the IDs of subscriptions under an app via `subscription_id` returned by [/subscription/get/](doc:1739093832125442). |

### Example
```http
// curl
curl -H "Access-Token:xxx" -H "Content-Type:application/json" -X POST \
-d '{
    "secret": "SECRET", 
    "app_id": "APP_ID", 
    "subscription_id": "SUBSCRIPTION_ID"
}' \
https://business-api.tiktok.com/open_api/v1.3/subscription/unsubscribe/
```

## Response

| Field | Type | Description |
|---|---|---|
| code | number | The response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | The response message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| data | object | The returned data. |
| ↳ subscription_id | string | The subscription ID. |
| request_id | string | The unique ID of the request. |
