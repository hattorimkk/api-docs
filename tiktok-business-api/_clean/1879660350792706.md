# Request to Link a TikTok account to a Business Center
> Đường dẫn: API Reference > BC Assets > Request to Link a TikTok account to a Business Center
Use this endpoint to send a request to link a TikTok account to a Business Center. 
You can also use this endpoint to update the permissions a Business Center has for an already linked TikTok account.

## Before you start

Ensure you are an Admin of the Business Center. To confirm your permission to a Business Center, use [/bc/get/](slug:get-business-centers) and check whether the returned `user_role` is `ADMIN`.

### Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/bc/asset/tt_account/link/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](slug:marketing-api-authentication). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `application/json`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| bc_id  **(Required)** | string | Business Center ID. ⏎ To obtain the list of Business Centers that you can access, use [/bc/get/](slug:get-business-centers). |
| linking_method  **(Required)** | string | TikTok account linking method. ⏎ Enum values: • `LINK`: To ask the TikTok account user to scan a QR code to approve your link request. You will retrieve an authorization URL (`link_url`) in the API response to generate this QR code. • `HANDLE`: To send a linking request directly to a TikTok account user to approve directly in the app. • You can only use this method for a Verified Non-self-serve Direct Business Center or Non-self-serve Agency Business Center. To confirm the eligibility of the Business Center, use [/bc/get/](slug:get-business-centers) to check whether the Business Center `type` is `DIRECT` or `AGENCY` and `verification_status` is `VERIFIED`. |
| permission_level  **(Required)** | string | The permission level you are requesting from the TikTok account. ⏎ Enum values: • `MANAGE_ACCOUNT`: Manage account. This permission level includes managing leads, forms, comments, direct messages and product links, and view video and LIVE analytics with your TikTok account. Plus, launch campaigns using your TikTok content and run message ads. One TikTok account can only be managed by one Business Center. This permission level is required for accessing advanced ad tools like comments and message center. • `DELIVER_ADS`: Deliver ads. This permission level includes accessing existing posts and LIVE videos and publishing and managing new videos to create and deliver ad campaigns on TikTok. One TikTok account can authorize multiple Business Centers to deliver ads. |
| permission_detail  **(Required)** | object | Details about the specific TikTok account permissions you are requesting from the TikTok account. |
| ↳ tt_account_roles  **(Required)** | string[] | A list of TikTok account permissions you are requesting from the TikTok account. ⏎ Enum values: • `POST`: Existing posts permissions, including accessing your own profile info, accessing your own public videos, and accessing your own ad-authorized videos. • `PUBLISH_VIDEO_ADS_ONLY`: "Only show as ads" permission. Videos will only get paid traffic and won't be published to your TikTok profile. • You can assign either `PUBLISH_VIDEO_ADS_ONLY` or `PUBLISH_VIDEO_SHOW_ON_TT_PROFILE_AND_ADS` at the same time, but not both, as they are mutually exclusive. • `PUBLISH_VIDEO_SHOW_ON_TT_PROFILE_AND_ADS`: "Show on TikTok profile and as ads" permission. Videos will get both organic and paid traffic and will be published to your TikTok profile. • You can assign either `PUBLISH_VIDEO_ADS_ONLY` or `PUBLISH_VIDEO_SHOW_ON_TT_PROFILE_AND_ADS` at the same time, but not both, as they are mutually exclusive. • `LIVE`: LIVE video permissions (Only available in some regions), including accessing your own profile info and accessing LIVE videos. • `SHOWCASE`: Showcase permissions (Only available in some regions), including accessing your own profile information and products from Showcase. • `DIRECT_MESSAGE`: Message ads permissions, including granting access to Read and Manage direct message features and settings (including auto reply features, auto-lead collection, AI related messaging tools, etc.), changing settings of the TikTok account to allow everyone to send you a direct message, and permission to update Privacy Policy if no current policy has been uploaded. • `SERIES`: Series permissions, including accessing your own profile information and TikTok Series. ⏎ **Note**: If you set `permission_level` to `MANAGE_ACCOUNT`, you need to include either `PUBLISH_VIDEO_ADS_ONLY` or `PUBLISH_VIDEO_SHOW_ON_TT_PROFILE_AND_ADS` in `tt_account_roles`. Other values included in this field will be ignored. |
| tt_account_handle {+Conditional} | string | Required when `linking_method` is `HANDLE`. ⏎ The handle of the TikTok account you are requesting permissions from. ⏎ Specify an exact handle without a leading @. |
| asset_id | string | The asset ID of a TikTok account already linked to the Business Center. • If you omit this field, you will send the linking request to or generate the QR code for a new TikTok account. • If you specify this field, you will send the linking request to or generate the QR code for an existing TikTok account to update its permissions. • Note that permission updates only support upgrading the permission level from `DELIVER_ADS` to `MANAGE_ACCOUNT`, or adding additional permissions (for example, updating `tt_account_roles` from `["POST"]` to `["POST","LIVE"]`). • To reduce permissions (for example, updating `tt_account_roles` from `["POST","LIVE"]` to `["POST"]`), unlink the TikTok account using [/bc/asset/tt_account/unlink/](slug:unlink-a-tiktok-account-from-a-business-center) and link it using [/bc/asset/tt_account/link/](slug:request-to-link-a-tiktok-account-to-a-business-center) again. ⏎ To obtain the asset IDs of TikTok accounts linked to a Business Center, use [/bc/asset/get/](slug:get-assets) and set `asset_type` to `TT_ACCOUNT`. |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/bc/asset/tt_account/link/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "bc_id": "{{bc_id}}",
    "linking_method": "LINK",
    "permission_level": "MANAGE_ACCOUNT",
    "permission_detail": {
        "tt_account_roles": ["PUBLISH_VIDEO_SHOW_ON_TT_PROFILE_AND_ADS"]
    }
}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| - | - | - |
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](slug:return-codes-appendix). |
| message | string | Response message. For details, see [Appendix - Return Codes](slug:return-codes-appendix). |
| request_id | string | The log ID of the request, which uniquely identifies a request. |
| data | object | Returned data. |
| ↳ link_url | string | Returned when `linking_method` is `LINK` in the request. ⏎ The TikTok account authorization URL. ⏎ **Once you obtain the authorization URL, generate a QR code from it using a QR code generator** and share the QR code with a TikTok account user to grant TikTok account access to the Business Center. ⏎ **Note**: When `linking_method` is `HANDLE` in the request, you will not receive a URL because the system directly sends an in-app notification for the linking request. |

### Example
```http
// curl
{
    "code": 0,
    "message": "OK",
    "request_id": "{{request_id}}",
    "data": {
        "link_url": "{{link_url}}"
    }
}
```
