# Submit a verification request for your account
> Đường dẫn: API Reference > Verification > Submit a verification request for your account
Use this endpoint to submit a verification request for your Business Center account or ad account.

After you have submitted a verification request, you can monitor your approval progress using [/account/verification/status/](slug:check-the-verification-status-of-your-account).

## Before you begin
Ensure you have already uploaded your verification documents via [/account/verification/upload/](slug:upload-verification-documents) and have your `qualification_image_ids` ready.

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/account/verification/submit/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](slug:marketing-api-authentication). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `application/json`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id {+Conditional} | string | Either `advertiser_id` or `bc_id` has to be set. ⏎ The ID of the ad account that you want to submit a verification request for. • If you are submitting your own verification document, you need to hold admin or operator access to the ad account. You can verify this access by using [/bc/asset/get/](slug:get-assets), passing `ADVERTISER` as the `asset_type`, and ensuring the `advertiser_role` returns `ADMIN` or `OPERATOR`. • If you are reusing a verification document from others, you need to have the proper permissions: • To reuse a verification document from another ad account, you need to have admin or operator access to the ad account. Verify this via [/bc/asset/get/](slug:get-assets) (pass `ADVERTISER` as `asset_type` and ensure `advertiser_role` is `ADMIN` or `OPERATOR`). • To reuse a verification document from another Business Center account, you need to have admin access to the Business Center account. Verify this via [/bc/get/](slug:get-business-centers) and ensure the `user_role` returns `ADMIN`. |
| bc_id {+Conditional} | string | Either `advertiser_id` or `bc_id` has to be set. ⏎ The ID of the Business Center account that you want to submit a verification request for. ⏎ You need to have admin access to the Business Center account. ⏎ If you want to a verification document from another Business Center account, you need to have admin access to the Business Center account. Verify this via [/bc/get/](slug:get-business-centers) and ensure the `user_role` returns `ADMIN`. |
| business_form {+Conditional} | object | Either `business_form` or `individual_form` has to be set. ⏎ Details of your business verification information. ⏎ Specify this field if you want to submit a business verification request. |
| ↳ company_name {+Conditional} | string | Required when `business_form` is specified. ⏎ The business name. ⏎ The business name you specify here must exactly match the name on your verification documents. You cannot change your business name after the verification is complete. ⏎ Length limit: 128 characters. |
| ↳ website_url {+Conditional} | string | Required when `business_form` is specified. ⏎ The URL of the company website. ⏎ Length limit: 512 characters. |
| ↳ industry_code {+Conditional} | string | Required when `business_form` is specified. ⏎ The industry category that your business belongs to. ⏎ Enum values: • `NOT_APPLICABLE`: Not applicable. • `ALCOHOL`: Alcohol. • `OTC`: OTC. • `DATING_APP`: Dating app. • `FINANCIAL_SERVICES`: Financial services. |
| ↳ region_iso_code {+Conditional} | string | Required when `business_form` is specified. ⏎ The country or region code for your business (Business Center account or ad account), in ISO 3166 format. ⏎ Example: `US`. ⏎ • To retrieve the country or region code of your Business Center account, use [/bc/get/](slug:get-business-centers) and check the returned `registered_area` parameter. • To retrieve the country or region code of your ad account, use [/advertiser/info/](slug:get-ad-account-details) and check the returned `country` parameter. |
| ↳ file_type_code {+Conditional} | string | Required when `business_form` is specified. ⏎ The code of the verification document. ⏎ To obtain the code of a verification document available for your business, use [/account/verification/filetype/](slug:get-available-verification-document-types-for-a-region). |
| ↳ license_no {+Conditional} | string | Required when `business_form` is specified. ⏎ The certificate number of your verification document. ⏎ Make sure the number you specify here is the same as the number on the document. It can’t be changed after submission. ⏎ Length limit: 128 characters. |
| ↳ qualification_image_ids {+Conditional} | string[] | Required when `business_form` is specified. ⏎ A list of qualification image IDs for business verification documents. ⏎ You need to specify exactly one ID. ⏎ To obtain the qualification image ID of a business verification document, use [/account/verification/upload/](slug:upload-verification-documents). |
| individual_form {+Conditional} | object | Either `business_form` or `individual_form` has to be set. ⏎ Details of your individual identity verification information. ⏎ Specify this field when you want to submit an individual identity verification request. |
| ↳ individual_name {+Conditional} | string | Required when `individual_form` is specified. ⏎ Full legal name. ⏎ The name you specify here must exactly match the name on your verification documents. You cannot change the name after the verification is complete. ⏎ Length limit: 128 characters. |
| ↳ region_iso_code {+Conditional} | string | Required when `individual_form` is specified. ⏎ The country or region code for your business (Business Center account or ad account), in ISO 3166 format. ⏎ Example: `US`. ⏎ • To retrieve the country or region code of your Business Center account, use [/bc/get/](slug:get-business-centers) and check the returned `registered_area` parameter. • To retrieve the country or region code of your ad account, use [/advertiser/info/](slug:get-ad-account-details) and check the returned `country` parameter. |
| ↳ file_type_code {+Conditional} | string | Required when `individual_form` is specified. ⏎ The code of the verification document. ⏎ To obtain the code of a verification document available for your business, use [/account/verification/filetype/](slug:get-available-verification-document-types-for-a-region). |
| ↳ identity_no {+Conditional} | string | Required when `individual_form` is specified. ⏎ ID number. ⏎ Make sure the number you specify here matches the number on your government issued ID (driver's license, passport, etc.) This can't be changed after submission. ⏎ Length limit: 128 characters. |
| ↳ website_url {+Conditional} | string | Required when `individual_form` is specified. ⏎ The URL of the company website. ⏎ Length limit: 512 characters. |
| ↳ qualification_image_ids {+Conditional} | string[] | Required when `individual_form` is specified. ⏎ A list of qualification image IDs for personal identification documents. ⏎ You need to specify exactly two IDs, representing the front image and the back image. ⏎ To obtain the qualification image ID of a personal identification document, use [/account/verification/upload/](slug:upload-verification-documents). |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/account/verification/submit/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id": "{{advertiser_id}}",
    "business_form": {
        "company_name": "{{company_name}}",
        "website_url": "{{website_url}}",
        "industry_code": "OTC",
        "region_iso_code": "US",
        "file_type_code": "{{file_type_code}}",
        "license_no": "{{license_no}}",
        "qualification_image_ids": [
            "{{qualification_image_ids}}"
        ]
    }
}'
```
