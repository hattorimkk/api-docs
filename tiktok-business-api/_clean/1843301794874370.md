# Upgraded Smart+
> Đường dẫn: API Reference > Upgraded Smart+
The Upgraded Smart+ Campaigns feature a new, unified workflow, known as the Upgraded Smart+ experience. This streamlined process enables you to access both [manual](doc:1739315728330753) and [Smart+](doc:1765314260115458) features when creating your campaign. [Learn more about upgrades to Smart+](https://ads.tiktok.com/help/article/about-updates-to-smart-plus).
