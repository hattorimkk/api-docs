# Create an audience
> Đường dẫn: Marketing API > Audience Management > Guides > Create an audience
This topic discusses how to create audiences by using [Audience](doc:1739940398505986) API.
- Custom Audience
You can create a Custom Audience by [file](doc:1747012327159809) or [rules](doc:1739566532187138). A minimum audience size of 1,000 is required to target Custom Audiences in an ad group.
- Lookalike Audience
You can use an existing audience to [create a Lookalike Audience](doc:1747012174934018) for retargeting purposes.
- Saved Audience
You can [create a Saved Audience](doc:1780156510696449) and then apply it to your ad groups.
