# Check the status of an MMM data request
> Đường dẫn: API Reference > Media Mix Modeling > Check the status of an MMM data request
Use this endpoint to check the status of a Media Mix Modeling (MMM) data request.

Once the `status` of the data request is `completed - ready for download`, you can use [/mmm/api/download/](slug:obtain-the-download-url-for-mmm-data) to obtain a download URL for the data.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/mmm/api/check/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| mmm_request_id {Required} | string | Unique identifier for the MMM data request.<br><br> <ul><li>To create an MMM data request and obtain the data request ID, use [/mmm/api/create/](slug:create-an-mmm-data-request).</li><li>To retrieve historical MMM data requests, including data request IDs, use [/mmm/api/history/](slug:get-the-mmm-data-request-history). </li></ul>|
```

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/mmm/api/check/?mmm_request_id={{mmm_request_id}}' \
--header 'Access-Token: {{Access-Token}}'
```
## Response

``` xtable
|Field{30%}|Type{15%}|Description{55%}|
|---|---|---|
|code |number|Response code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097). |
|message|string|Response message. For details, see [Appendix - Return Codes](doc:1737172488964097).|
|request_id |string|The log ID of a request, which uniquely identifies the request.  |
|data |object|Returned data.|
#| status | string | Status of the data request. <br><br> Enum values: <ul><li>`request received`: The request was received but data processing has not started.</li><li>`in progress`: Data processing is in progress.</li><li>`completed - ready for download`: Data processing has completed and the data is ready for download.  <ul><li>To obtain a download URL for the data, use [/mmm/api/download/](slug:obtain-the-download-url-for-mmm-data).</li></ul></li><li>`failed`: The request failed.</li></ul> |
#| message | string | Returned only when `status` is `failed`. <br><br> The reason why the data request failed. |
```

### Example
```http
// Success-Response
HTTPS/1.1 200 OK
{
    "code": 0,
    "message": "OK",
    "request_id": "{{request_id}}",
    "data": {
        "status": "completed - ready for download"
    }
}
```
