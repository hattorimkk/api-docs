# Create/Delete an audience segment
> Đường dẫn: API Reference > Audience > Audience segment > Create/Delete an audience segment
Use this endpoint to create or delete an audience segment. 

Please see [About Streaming API - Important Notes for Streaming API](doc:1739566528222210) to learn about the notes about Multiple Advertisers Associated with a Business Account and Mixed Segments with IDFA/AAID, and [Guidelines for identifier normalization](doc:1850030360880129) to learn about how to normalize your identifiers.

>**Note:** To apply for access to the Streaming API (formerly known as Segment API), use [Allowlist Management](https://ads.tiktok.com/marketing_api/blog/detail/7102266224578396162) feature on the Developer Portal by selecting "Streaming API" from the drop down menu. We review applications on an ongoing basis. 

>  **Note:** 
>   • The rate limit is 1 QPS per advertiser account. • You can create up to a maximum of 400 audience segments for an advertiser account. Existing audiences need to be deleted prior to new audience creation if the advertiser account reaches this limit. This limit is at advertiser level.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/segment/audience/

**Method** POST

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token {Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162).|
|Content-Type{Required}|string|Request message type. <br>Allowed format: `application/json`.|
```

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| action  **(Required)** | string | Type of action to be performed. Enum values:  • `create`: To create an audience segment. You will also need to include `custom_audience_name` in the request.  •  `delete`: To delete an audience segment. You will also need to include `delete_audience_id` in the request. ⏎ If no value is specified, the default value is `create`. |
| custom_audience_name {+Conditional} | string | Custom audience name of audience to be created. Please note that names over 70 characters will be truncated to 67 characters with "..." appended. This field is required when the value of `action` is `create`. |
| delete_audience_id {+Conditional} | string | Audience ID to be deleted. This field is required when the value of `action` is `delete`. |

### Example

```http
// curl
curl -verbose  -i --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/segment/audience/' \
--header 'Access-Token: <put_your_access_token_here>' \
--header 'Content-Type: application/json' \
-d '{
    "custom_audience_name": "mens shoes",
    "advertiser_id": 1356789172,
    "action": "create" // create/delete (optional, default is creation)
}'
```
