# Smart Creative
> Đường dẫn: Marketing API > Campaign Management > Guides > Ad > Smart Creative
Smart Creative is a comprehensive AI-powered tool that houses creative diagnose and asset reporting, auto-generation, and delivery optimization under one roof. It helps advertisers generate more ready-for-delivery creatives with limited materials and maximize the revenue of these creatives. 

> **Warning:** You can not create Smart Creative ads under existing ad groups that already have ads created within them. 

## Create Smart Creative ads
1. Create a campaign using [/campaign/create/](doc:1739318962329602).
- Currently, Smart Creative only supports `APP_PROMOTION`,`WEB_CONVERSIONS`, `TRAFFIC`, or `LEAD_GENERATION` as advertising objective (`objective_type`) at the campaign level. 
2. Create an ad group using [/adgroup/create/](doc:1739499616346114).
- Set `creative_material_mode` to `CUSTOM`.
3. Upload creatives using the following endpoints:
- Upload videos using [/file/video/ad/upload/](doc:1737587322856449), and get `video_id` in response.
- Upload images using [/file/image/ad/upload/](doc:1739067433456642), and get `image_id` in response.
- Get standard or dynamic call-to-action texts using [/creative/cta/recommend/](doc:1739362202742785). See [CTA recommendations](doc:1740307296329730) for details.
4. Create a Smart Creative ad using [/ad/aco/create/](doc:1739473063234626).
- Set `is_smart_creative` as `true`. 
> **Note:** When `is_smart_creative` is set to `true`, the system will automatically process `creative_material_mode` as `SMART_CREATIVE` at the ad group level. 
- Enter image ID and video ID that you get from Step 3 in the `web_uri` and `video_id` fields (in `media_info`) respectively.
> **Note:** You can enter no more than 30 materials in the `media_info` object. The materials should not be duplicated.
- Enter call-to-action texts you get from Step 3 in the `call_to_action_list` or `call_to_action_id` fields.
> **Note:** You can enter no more than three call-to-action texts. These texts should not be duplicated.
- Enter ad texts in `title_list`.
> **Note:** You can enter no more than five texts. These texts should not be duplicated.
- Enter the instant page ID in the `page_id` field. • To obtain pages within your ad account, use [/page/get/](doc:1820826387779586). • To create instant pages, use [Instant Page Editor SDK](doc:1740307202170881).
