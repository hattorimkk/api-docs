# How to connect a ready-made agent to TikTok for Business MCP Server
> Đường dẫn: TikTok for Business MCP Server > How to connect a ready-made agent to TikTok for Business MCP Server
If you are using an existing, MCP-compatible AI platform, you can connect it directly to the TikTok Ads platform without writing any code. The platform will handle the connection and authorization flow for you, allowing your AI agent to execute advertising operations through standardized MCP tool calls.

This guide walks you through the connection process, from initial configuration to your first successful interaction.

If you want to build a custom agent, see [How to connect a custom agent to TikTok for Business MCP Server](slug:how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server) instead.

> **Note:** 
> In early July, Claude made a change to their MCP tools management, which caused tools over 256 to be omitted by default. As of July 20th, Claude has fixed this issue. To resolve the issue permanently, refresh the tool list once, or switch to the layered version of our MCP server (`https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer`).

## Before you start
Before you begin, ensure you have:
- **A TikTok for Business account.** This account is required to authorize TikTok for Business MCP Server so your AI agent can act on your behalf within the TikTok for Business ecosystem. If you do not have an account, [create a TikTok for Business account](slug:create-a-tiktok-for-business-account) before proceeding.
- **An MCP-compatible AI agent or platform.** Your agent or platform must support the Model Context Protocol.
> **Note:** 
> •  You do not need to [register a developer account](slug:register-as-a-developer) or [create a developer app](slug:create-a-developer-app) to connect to TikTok for Business MCP Server.
>
> •  TikTok for Business MCP Server is publicly available to all users, so you can start using it immediately without applying for any additional permissions.

## Choose your server URL
TikTok for Business MCP Server offers two server URLs. Select the one that best matches your agent's capabilities and your use case:

| Server Type | URL | When to use |
|---|---|---|
| Full Disclosure | `https://business-api.tiktok.com/open_mcp/tt-ads-mcp-flat` | All around 400 tools load at connection time. Use it when your AI platform has a large context window and can handle the full tool library without performance degradation. ⏎ Explore the full tool library in [Available tools in TikTok for Business MCP Server](slug:available-tools-in-tiktok-for-business-mcp-server). |
| Progressive Disclosure | `https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer` | Only around 40 core tools load initially; additional tools are discoverable on-demand. Use it for token-conscious setups or agents with limited context windows. |

## Step-by-step connection process
### Step 1: Configure the MCP Server in your AI agent
Add the TikTok for Business MCP Server to your agent's MCP configuration. Because the exact file name and location vary by platform, we recommend reviewing the official configuration steps for your specific AI agent: 
- [ChatGPT](slug:how-to-connect-chatgpt-to-tiktok-for-business-mcp-server)
- [Claude](slug:how-to-connect-claude-to-tiktok-for-business-mcp-server)
- [Claude Code](https://code.claude.com/docs/en/mcp#option-1-add-a-remote-http-server)
- [Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)
- [Cursor](slug:how-to-connect-cursor-to-tiktok-for-business-mcp-server)
- Doubao
- [Gemini CLI](https://geminicli.com/docs/tools/mcp-server/)
- [Hermes Agent](https://hermes-agent.nousresearch.com/docs/guides/use-mcp-with-hermes)
- [Manus](https://manus.im/docs/integrations/custom-mcp)
- [Perplexity](https://www.perplexity.ai/help-center/en/articles/13915507-adding-custom-remote-connectors)
- [Trae](https://docs.trae.ai/ide/add-mcp-servers)
- [WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/MCP-Guide)

For platforms that utilize a JSON configuration file, below is an example snippet. Add this entry to the `mcpServers` object in your configuration file, substituting `{{mcp_url}}` with your chosen server URL:

```http
// curl
{
  "mcpServers": {
    "tiktok-ads": {
      "url": "{{mcp_url}}"
    }
  }
}
```

**Configuration details:**
- **`"tiktok-ads"`**: A local alias for the server. You can rename it to any label that suits your project.
- **`"url"`**: Replace `{{mcp_url}}` with either the Full Disclosure or Progressive Discovery Server URL from the table above.

Save the configuration file. Depending on your platform, you may need to restart or reload the agent for changes to take effect.

### Step 2: Authorize the connection
When your agent first connects to TikTok for Business MCP Server, you are prompted to authorize the connection via your TikTok for Business account.
1. If you are not already signed in to TikTok Ads Manager, you are asked to sign in first.
2. Review the permissions requested.
3. Click **Authorize** to grant your AI agent access to your TikTok for Business resources.
After authorization, your agent can make tool calls on your behalf.

> **Note:** 
> Authorization lifespan: User authorization for the TikTok for Business MCP Server connection remains valid for **a 30-day window**. After 30 days, you will need to reauthorize the connection using the same TikTok for Business account.

### Step 3: Interact with your AI agent
Your agent is now connected to TikTok for Business MCP Server. Start a conversation with your agent and reference TikTok Ads operations in your prompts. The agent discovers and calls the appropriate MCP tools to fulfill your requests.

> **Note:** 
> Be aware of concurrency limits when managing Upgraded Smart+ Ads. Specifically, if you are using the `smart_plus_ad_create`, `smart_plus_ad_update`, or `smart_plus_ad_status_update` tools, restrict your creation or update calls for a single Upgraded Smart+ Ad to no more than one operation per 5 seconds. Failing to throttle these requests might trigger a concurrency error.

**Example prompts to get started:**
- "Create a new Upgraded Smart+ Campaign for my latest product."
- "Show me the performance report for all active campaigns this week."
- "Upload this E-commerce catalog and check for any diagnostic issues."
