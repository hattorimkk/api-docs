# Get blocked words
> Đường dẫn: API Reference > Ad Comments - Blocked Words > Get blocked words
Use this endpoint to get the list of  blocked words for an ad account.

## Request

**Endpoint**
https://business-api.tiktok.com/open_api/v1.3/blockedword/list/

**Method** GET

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| page_info | object | Pagination information. |
| ↳ page_size | number | Page size. The default value: `10`. Value range: [1, 500]. |
| ↳ page | number | Current page number. The default value is `1`. The value must be ≥ 1. |

### Example

```http
// curl
curl --get -H "Access-Token:xxx" \
--data-urlencode "advertiser_id=ADVERTISER_ID" \
--data-urlencode "page_size=PAGE_SIZE" \
--data-urlencode "page=PAGE" \
https://business-api.tiktok.com/open_api/v1.3/blockedword/list/
```

## Response

| Field | Type | Description |
|---|---|---|
| message | string | The return message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| code | number | The return code. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| data | object | The returned data. |
| ↳ list | object[] | List of blocked words. |
| ↳↳ bw_content | string | Blocked word. |
| ↳ page_info | object | Pagination information. |
| ↳↳ page | number | Current page number. |
| ↳↳ page_size | number | Page size. |
| ↳↳ total_number | number | Total number of results. |
| ↳↳ total_page | number | Total pages of results. |
| request_id | string | Unique ID of the request. |
