# Available tools in TikTok for Business MCP Server
> Đường dẫn: TikTok for Business MCP Server > Available tools in TikTok for Business MCP Server
TikTok for Business MCP Server includes approximately 400 tools across the categories listed below. While most tools directly wrap existing TikTok API for Business endpoints, the server now also includes specialized tools that operate independently of standard endpoints. 
- For detailed parameter schemas and usage information regarding tools based on TikTok API for Business endpoints, prompt your AI agent (for example, "What parameters do I need for the `smart_plus_ad_create` tool?") or read the [TikTok API for Business documentation](slug:api-reference).
- For detailed parameter schemas and usage information regarding tools not based on standard endpoints, simply prompt your AI agent.

> **Note:** 
> Be aware of concurrency limits when managing Upgraded Smart+ Ads. Specifically, if you are using the `smart_plus_ad_create`, `smart_plus_ad_update`, or `smart_plus_ad_status_update` tools, restrict your creation or update calls for a single Upgraded Smart+ Ad to no more than one operation per 5 seconds. Failing to throttle these requests might trigger a concurrency error.
