# Get Creator insights
> Đường dẫn: Organic API > TikTok One API > Guides > Get Creator insights
The following endpoints are available for Creator insights.  within the TikTok One (TTO) Creator Marketplace. 

## Search and Discovery
- [Discover TTO Creators](doc:1825017307843585): Use this endpoint to search for Creators based on specific criteria. 

## Authorized Insights
- [Get Authorized TTO Account Insights](slug:get-authorized-tto-creator-insights): Use this endpoint to get the authorized Account Level insights of the Creator.
- [Get Authorized TTO Media Insights](slug:get-authorized-tto-media-insights): Use this endpoint to get the authorized Video Level insights of the Creator.

## Public Insights
- [Get TTO Public Account Insights](doc:1828185358712897): Use this endpoint to get the basic profile information of a TTO Creator Marketplace Creator.
- [Get TTO Public Media Insights](doc:1828185411810305): Use this endpoint to get information about the videos of a TTO Creator Marketplace Creator.
