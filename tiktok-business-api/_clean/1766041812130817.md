# FAQs
> Đường dẫn: Marketing API > Get started > Authentication > FAQs
This article collects some common questions and error messages about authentication. 
# Questions
**For an existing access token, will it be available to new advertiser accounts as these accounts are being created, or do I need to generate a new authentication code and a new access token every time a new account is created?**

If the authentication user receives access to a new ad account, you will not need to re-authenticate and create the access token again. The developer application will automatically have access to the data from this new ad account. 

# Common error messages

Common error message
Cause
Solution

"Access token is invalid, when you call access_token or refresh_token api, old token will become invalid".
The access token has expired or does not exist.
Ensure you are using the latest access token and the access token is entered correctly.

"Advertiser xxxx doesn't exist or has been deleted."

Ensure that you enter the correct advertiser ID.

"No access to operation advertiser xxx".
The access token does not match the advertiser ID.
Ensure that you enter the correct access token for the advertiser ID.
