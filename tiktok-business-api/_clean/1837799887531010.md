# Check TTO Creator Status
> Đường dẫn: API Reference > TikTok One > Check TTO Creator Status
Use this endpoint to check if TikTok users have already become TikTok One (TTO) Creators. 

You can check the statuses of up to 20 users at the same time, using `tto_tcm_account_id` and `handle_names`.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tto/tcm/creator/status/get/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token   **(Required)** | string | Access token authorized by TTO Creator Marketplace accounts. ⏎ For details, see [Authentication](slug:obtain-authorization-and-authentication-from-a-tto-creator-marketplace-account). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| tto_tcm_account_id  **(Required)** | string | The ID of the TTO Creator Marketplace account. ⏎ To obtain the IDs of the accounts that you can access via `Access-Token`, use [/tto/oauth2/tcm/](doc:1815693478150146). |
| handle_names  **(Required)** | string[] | The handle names of TikTok Creators. ⏎ Max size: 20. |

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/tto/tcm/creator/status/get/?tto_tcm_account_id={{tto_tcm_account_id}}&handle_names=["{{handle_name}}","{{handle_name}}","{{handle_name}}"]' \
--header 'Access-Token: {{Access-Token}}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Appendix - Return Information](doc:1737172488964097). |
| request_id | string | The log ID of a request, which uniquely identifies the request. |
| data | object | Returned data. |
| ↳ onboarding_status | object[] | The onboarding status data for Creators. |
| ↳↳ handle_name | string | The handle name that was checked. |
| ↳↳ status | string | The onboarding status of the Creator. ⏎ Enum values: • `IN`: The Creator has joined TTO Creator Marketplace. • `NOT_IN`: The Creator has not joined TTO Creator Marketplace. • `INVALID`: The specified handle name (`handle_name`) is invalid. |
