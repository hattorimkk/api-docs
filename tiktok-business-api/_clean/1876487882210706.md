# Upgrading the SDK
> Đường dẫn: Marketing API > Ad Measurement > Guides > TikTok App Events SDK > Upgrading the SDK
> **Note:** 
> Before upgrading the TikTok App Events SDK, review the latest changes in [Release history](slug:tiktok-app-events-sdk-overview) to understand any potential impact to your existing installation.

## Android
### 1. Upgrade your dependency
#### 1.1 Maven
Update the SDK version in your app-level `build.gradle`:
```http
// curl
dependencies {
    // Update the version number to the latest release
    implementation 'com.github.tiktok:tiktok-business-android-sdk:1.7.1'
}
```

Sync your Gradle project to download the updated dependency.

> **Note:** 
> Check the [GitHub releases page](https://github.com/tiktok/tiktok-business-android-sdk/releases) for the latest version number and any companion dependency version changes noted in the release notes.

#### 1.2 Manual installation
a. Download the latest `.aar` binary from the [GitHub releases page](https://github.com/tiktok/tiktok-business-android-sdk/releases/latest/).

b. Replace the existing `.aar` file in your `app/libs` directory with the new one.

c. Update the `implementation files(...)` line in your app-level `build.gradle` to match the new filename.

d. Sync your Gradle project.

### 2. Recompile your app
Clean and rebuild your project to ensure the new SDK version is picked up:

```http
// curl
./gradlew clean assembleDebug
```

### 3. Test and release
a. Enable debug mode in your SDK configuration and launch the app.

b. Verify events appear correctly in the [test events UI](https://business-api.tiktok.com/portal/docs/android-integration-steps/v1.3#anchor-0-6), either via codeless test events or manually.

c. Check for deprecation warnings in Logcat under the `TikTokBusinessSdk` tag.

d. Once verified, disable debug mode, build a release variant, and distribute.

## iOS
### 1. Upgrade your dependency
#### 1.1 CocoaPods
To upgrade to the latest version, run:

```http
// curl
pod update TikTokBusinessSDK
```

Then run `pod install`.

#### 1.2 Swift Package Manager
a. In Xcode, go to your project's **Package Dependencies** tab.

b. Select the `tiktok-business-ios-sdk` package.

c. Update the version rule to the desired version or select **Up to Next Major Version**.

d. Xcode will resolve and fetch the updated package automatically.

#### 1.3 Manual installation
a. Download the latest `TikTokBusinessSDK`framework from the [GitHub releases page](https://github.com/tiktok/tiktok-business-ios-sdk/releases/latest). Both static and dynamic frameworks are provided.

b. Unzip the downloaded file.

c. In your Xcode project, remove the existing `TikTokBusinessSDK.xcframework` from **Frameworks, Libraries, and Embedded Content**.

d. Drag and drop the new `TikTokBusinessSDK.xcframework` into the same section.

e. Ensure **Embed & Sign** is selected for the framework.

### 2. Recompile your app
Clean your build folder (**Product → Clean Build Folder** or ⇧⌘K) and rebuild. If using CocoaPods, also run `pod install` after updating to ensure the workspace is in sync.

### 3. Test and release
a. Enable debug mode in your SDK configuration and launch the app.

b. Verify events appear correctly in the [test events UI](https://business-api.tiktok.com/portal/docs/ios-integration-steps/v1.3#anchor-0-6), either via codeless test events or manually.

c. Check the Xcode console for any deprecation warnings from `TikTokBusiness`.

d. Once verified, disable debug mode, archive, and distribute.

## Unity
### 1. Get the latest Unity SDK package
The Unity SDK is distributed as a `.unitypackage` file from the [GitHub repository](https://github.com/tiktok/tiktok-business-unity-sdk). To get the latest version:

a. Go to [https://github.com/tiktok/tiktok-business-unity-sdk](https://github.com/tiktok/tiktok-business-unity-sdk).

b. Download `TikTokBusinessSDK.unitypackage` from the repository root.

> **Note:** 
> The Unity SDK does not use a package manager or versioned releases. The `.unitypackage` on the `main` branch is always the latest version. Check the repository commit history or the [Release history](slug:tiktok-app-events-sdk-overview) page to confirm what changed.

### 2. Replace the SDK in your Unity project
**a. Remove the existing SDK.**

In the Unity Editor Project window, right-click the `Assets/TikTokBusinessSDK` folder and select **Delete**. This ensures no stale scripts or native binaries remain from the previous version.

![Remove the existing SDK.](https://images.ctfassets.net/5jqet0ab9qci/5ONJAC8bfFCewrjLuOkL8K/298631486d8b674184002e5858102e8b/Remove_the_existing_SDK..png)

**b. Import the new package.**

Go to **Assets → Import Package → Custom Package**, select the downloaded `TikTokBusinessSDK.unitypackage`, then click **All** and **Import**.

![Go to Assets → Import Package → Custom Package](https://images.ctfassets.net/5jqet0ab9qci/5gboLiGwAV9yfHwCyBYSQB/a8645786c75075eac20c37c400b8af4e/5f9e1f32-f559-4ac7-9ea7-a3a24de4a475.png)

![Select the downloadedpackage, then click All and Import.](https://images.ctfassets.net/5jqet0ab9qci/IQQvNQ1mlcGOH9osf7hRY/c0ed0d65e2ca8c22ca32673820a25ec8/select_the_downloaded_TikTokBusinessSDK.unitypackage__then_click_All_and_Import..png)

**c. Wait for recompilation.**

Unity will recompile all scripts after import. Resolve any compiler errors before proceeding — errors typically indicate a naming or API change documented in the release history.

> **Note:** 
> Do not import over the top of an existing `Assets/TikTokBusinessSDK` folder. Importing without deleting first can leave orphaned files that cause duplicate symbols or missing reference errors at build time.

### 3. Test and release
a. Open your scene and perform a **Build and Run** targeting a test device (Android or iOS).

b. Enable debug mode in your `TikTokConfig` and confirm events are logged:

```http
// curl
TikTokConfig config = new TikTokConfig(/*...*/);
config.EnableDebugMode();
TikTokBusinessSDK.InitializeSdk(config);
```

c. Verify events appear correctly in the [test events UI](https://business-api.tiktok.com/portal/docs/unity-integration-steps/v1.3#anchor-0-7), either via codeless test events or manually.

d. Once verified, remove `config.EnableDebugMode()`, rebuild in release configuration, and distribute.

## React Native
### 1. Upgrade the npm package
```http
// curl
# Using npm
npm install @tiktok-for-business/react-native-sdk@latest

# Using Yarn
yarn add @tiktok-for-business/react-native-sdk@latest
```

To upgrade to a specific version instead of `@latest`, replace it with the target version number (e.g. `@0.1.3`).

### 2. Rebuild and test
```http
// curl
# iOS
npx react-native run-ios

# Android
npx react-native run-android
```

After rebuilding:
- Verify events appear correctly in the [test events UI](https://business-api.tiktok.com/portal/docs/react-native-installation/v1.3#anchor-0-7), either via codeless test events or manually.
- Check for any deprecation warnings or breaking changes noted in the release history.
