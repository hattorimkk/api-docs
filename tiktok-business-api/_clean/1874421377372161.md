# Create Upgraded Smart+ Lead Generic Catalog Ads
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Lead Generation Campaigns > Create Upgraded Smart+ Lead Generic Catalog Ads
This article explains how to create Upgraded Smart+ Lead Generic Catalog Ads.

Upgraded Smart+ Lead Generic Catalog Ads are Upgraded Smart+ Lead Generation Campaigns that use generic catalog products to deliver ads.

# Prerequisites
Creating Upgraded Smart+ Lead Generic Catalog Ads requires setting up a generic catalog in your Business Center first.

To set up the catalog, see [Create a generic catalog](slug:create-a-generic-catalog).

# Steps
