# Get playable assets
> Đường dẫn: API Reference > Playable Ads > Get playable assets
Use this endpoint to get a list of playable assets.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/playable/get/

**Method** GET

**Header**
``` xtable
| Field | Type | Description |
|---|---|---|
| Access-Token {Required} | string | Authorized access token. For details, see [Authentication](doc:1738373164380162).|
```
**Parameters**
``` xtable
| Field | Type | Description |
|---|---|---|
| advertiser_id {required} | string | Advertiser ID. |
|playable_id|string|Playable asset ID to filter the results by.|
|playable_name|string|Playable asset name to filter the results by.|
|playable_url|string|Playable URL.|
|status|string|Playable asset status .<br><br>Enum values:`AUDIT_FAIL`, `AUDIT_SUCCESS`,`VALIDATE_FAIL`,`VALIDATE_SUCCESS`,`VALIDATING`.|
|operation_status|string|Playable asset operation status.<br><br>Enum values:`UPLOADED`,`SAVED`,`DELETED`.<br>Default value: `SAVED`.|
|page|number|Current number of pages.<br><br> Value range: ≥ 1.<br> Default value: 1.|
|page_size|number|Page size. <br><br>Value range: 1-100.<br>Default value: 10. |
```

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/playable/get/?advertiser_id={{advertiser_id}}&page=1&page_size=100' \
--header 'Access-Token: {{Access-Token}}'
```
