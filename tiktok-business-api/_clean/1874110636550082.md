# Get the result of a creative pre-review task
> Đường dẫn: API Reference > Creative Pre-review > Get the result of a creative pre-review task
Use this endpoint to retrieve the result of a pre-review task for creatives.

# Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/creative/pre_review/task/get/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](slug:marketing-api-authentication). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| task_id  **(Required)** | string | The ID of the pre-review task. ⏎ To create a pre-review task and obtain the task ID, use any of the following endpoints: • [/creative/pre_review/task/create/](slug:create-a-creative-pre-review-task) • [/file/video/ad/upload/](slug:upload-a-video) • [/file/image/ad/upload/](slug:upload-an-image-reference) ⏎ **Note**: If the `task_id` doesn't match the `advertiser_id`, an error will occur. |

## Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/creative/pre_review/task/get/?advertiser_id={{advertiser_id}}&task_id={{task_id}}' \
--header 'Access-Token: {{Access-Token}}'
```

# Response

| Field | Data Type | Description |
|---|---|---|
| - | - | - |
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](slug:return-codes-appendix). |
| message | string | Response message. For details, see [Appendix - Return Codes](slug:return-codes-appendix). |
| request_id | string | The log ID of the request, which uniquely identifies a request. |
| data | object | Returned data. |
| ↳ task_status | string | The status of the pre-review task. ⏎ Enum values: • `PROCESSING`: The task is being processed. • `SUCCESS`: The task has been completed. |
| ↳ pre_review_result_list | object[] | The list of results for the pre-reviews of the creatives. |
| ↳↳ pre_review_status | string | The result of the pre-review for the creative. ⏎ Enum values: • `APPROVED`: Approved by the pre-review. • `REJECTED`: Rejected during pre-review. • `UNSURE`: Result cannot be determined. • `UNAVAILABLE`: Result unavailable. |
| ↳↳ material_type | string | The material type of the creative. ⏎ Enum values: • `VIDEO`: video. • `IMAGE`: image. • `AD_TEXT`: ad text. • `LANDING_PAGE_URL`: landing page URL. |
| ↳↳ material_id | string | The ID or content of the creative. • When `material_type` is `VIDEO`, this field represents the video ID of the video. • When `material_type` is `IMAGE`, this field represents the image ID of the image. • When `material_type` is `AD_TEXT`, this field represents the ad text. • When `material_type` is `LANDING_PAGE_URL`, this field represents the landing page URL. |
| ↳↳ result_creation_time | string | The time when the pre-review result was generated, in the format of `YYYY-MM-DD HH:MM:SS` (UTC+0). ⏎ Example: `2025-01-01 00:00:01`. |
| ↳↳ result_expiration_time | string | The time when the pre-review result will expire, in the format of `YYYY-MM-DD HH:MM:SS` (UTC+0). ⏎ Example: `2025-01-01 00:00:01`. ⏎ Each pre-review result is valid for 180 days. |
| ↳↳ location_code | string | The code of the location to target. ⏎ For enum values, see [List of values for `location_codes` or `location_code`](https://business-api.tiktok.com/portal/docs/get-the-result-of-a-creative-pre-review-task/v1.3#anchor-2-1). ⏎ Example: `US`. |
| ↳↳ is_ecommerce | boolean | Whether the creatives will be used in E-commerce ads including [GMV Max Campaigns](slug:create-gmv-max-campaigns) and Catalog Ads. ⏎ Supported values: `true`, `false`. |
| ↳↳ reject_info_list | object[] | The list of reasons for the rejection of the creatives. |
| ↳↳↳ reason | string | The specific reason provided for the rejection of the creative. |
| ↳↳↳ suggestion | string | The suggestion for resolving the rejection issues. |
