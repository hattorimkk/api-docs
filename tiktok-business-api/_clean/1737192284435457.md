# Sign Terms
> Đường dẫn: API Reference > Terms > Sign Terms
Use this endpoint to sign the agreement for the Lead Generation Ads feature. 

After signing an agreement, you can use [/term/check/](doc:1737192304571394) to check the status of the agreement.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/term/confirm/

**Method** POST

**Header**

| Field | Data Type | Desciption |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Request message type. Allowed format: `"application/json"`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| term_type  **(Required)** | string | Agreement type. Enum values: `LeadAds`. |

### Example
```http
// curl
curl -H "Access-Token:xxx" -H "Content-Type:application/json" -X POST \
-d '{
    "advertiser_id": "ADVERTISER_ID",
    "term_type": "TERM_TYPE"
}' \
https://business-api.tiktok.com/open_api/v1.3/term/confirm/
```

|---|---|---|

| message | string | Return messages. For details, see [Appendix-Return information](doc:1737172488964097). |
| data | object | Return data (Empty). |
| request_id | string | The log id of a request, which uniquely identifies the request. |
