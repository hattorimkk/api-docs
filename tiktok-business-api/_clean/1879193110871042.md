# Test creatives using the creative testing agent
> Đường dẫn: TikTok for Business MCP Server > Available tools in TikTok for Business MCP Server > Test creatives using the creative testing agent
The creative testing agent helps you evaluate creatives inside an ad group that is already delivering. Use the `tiktok_ads_creative_testing_agent` tool in the TikTok for Business MCP Server to create a test plan, confirm its budget and duration, monitor delivery, and review the final report.

Testing inside the existing ad group preserves its delivery context. The tool creates an additional ad for the selected creatives and applies a separate test budget allocation. You can collect useful performance signals without creating a new ad group or restarting its learning process.

## Why use creative testing agent
New creatives can struggle to receive traffic when they enter an ad group with established top performers. Limited delivery produces too little evidence to judge whether a new video deserves more investment.
- **Controlled creative budget allocation**: Assign a daily test budget to selected creatives instead of waiting for standard delivery to distribute traffic.
- **Faster testing evidence**: Test within an active ad group and avoid rebuilding delivery history in a separate ad group.
- **Clear approval boundaries**: Review the selected creatives, dates, daily budget, and estimated maximum budget allocation before the agent starts the test.
- **Actionable reporting**: Compare delivery and outcome metrics, then use the agent's summary to decide which creatives to scale, revise, or retire.

## What the tool does
The tool validates the requested ad group and creatives, drafts a test plan, and waits for confirmation. After launch, it reports status and spend. When the test ends, it returns a read-only report with creative-level metrics and suggested next actions.

The test budget is a daily allocation for the test period. For example, a test budget of 15 USD per day over seven days represents a planned allocation of 105 USD. **Actual test spend can be higher than the planned test budget, so review the budget controls in the draft before confirming.**

## Workflow
The workflow has four phases: define the scope, review the plan, run the test, and use the report. Eligibility failures return to the scope phase. Plan revisions return to the review step. An incomplete test remains in monitoring until the end date or until you stop it.

## Eligibility requirements
The agent checks these requirements before it drafts a launchable plan. If an item is not eligible, ask the agent which setting or creative must change, then run the check again.

| Level | Requirement |
|---|---|
| Test plan | One plan targets one ad group. ⏎ A plan contains 1 to 50 creatives. ⏎ The daily test budget is at least one unit of the ad account's local currency. ⏎ The duration is at least three days. |
| Ad group | The ad group is an Upgraded Smart+ ad group. ⏎ The bidding strategy is Maximum Delivery. ⏎ The budget mode is Daily Budget. ⏎ The ad group recorded spend during the previous 24 hours. |
| Ad | The ad contains no more than 50 creatives. |
| Creative | Each creative is eligible to deliver and has no review, qualification, or delivery blocker. ⏎ Each creative is a video. Image, carousel, and TikTok post formats are not supported. ⏎ No selected creative belongs to another active test plan for the same ad group. ⏎ The creative matches the ad destination. For example, an app-install creative should direct users to the relevant app destination. |

## Run a creative test
### 1. Request a test
You can request a test by providing all details (the ad account, ad group, creative scope, daily test budget, and duration) upfront, or you can ask the agent to help you identify eligible ad groups or creatives.

**Sample prompt**

Use the prompt that best matches your scenario:
- Scenario 1: Explicit ad group and creatives. You know exactly where and what to test.
```http
// curl
Use 15 USD per day to test Creative A, Creative B, and Creative C in ad group <AD_GROUP_ID> under ad account <AD_ACCOUNT_ID> for three days.
```

- Scenario 2: Unspecified ad group and explicit creatives. You have the creatives, but need the agent to find a high-performing ad group.
```http
// curl
Help me find an ad group with strong spend, and create a 3-day test under ad account <AD_ACCOUNT_ID> for new Creatives A, B, and C with a daily budget of 15 USD.
```

- Scenario 3: Explicit ad group and unspecified creatives. You have a stable ad group, but need the agent to find eligible new creatives.
```http
// curl
I have a stable ad group <AD_GROUP_ID>. Help me find eligible new creatives under ad account <AD_ACCOUNT_ID> to test for three days with a daily budget of 15 USD.
```

**Sample response**

Regardless of the scenario prompt you use, the agent will validate the inputs and suggest next steps. For example, a successful request might return the following draft plan for your review:
```http
// curl
I checked the ad group and the three creatives. They are eligible for creative testing.

Draft plan
- Ad group: <AD_GROUP_ID>
- Creatives: Creative A, Creative B, and Creative C
- Duration: October 11 through October 13, 2026
- Daily test budget: 15 USD
- Allocation: 5 USD per creative per day
- Total added test budget: 45 USD

The ad group currently has a 200 USD daily budget. During the test, planned daily delivery can reach roughly 215 USD (the baseline 200 USD plus the 15 USD test budget).

No test has been initiated. Review the scope, dates, and budget. Reply “Start the test” to approve this plan, or specify required modifications.
```

### 2. Review and confirm the plan
Once the agent identifies an eligible ad group and creatives and has provided the test plan, check the creative list, budget allocation, dates, and maximum added budget. Ask the agent to adjust the creative list, change the budget split, or choose another valid duration when the draft does not match your intent.

**Sample prompt**
```http
// curl
Start the test.
```

**Sample response**
```http
// curl
Creative test <CREATIVE_TEST_ID> is running.

- Ad group: <AD_GROUP_ID>
- Test period: October 11 through October 13, 2026
- Daily test budget: 15 USD
- Daily allocation: 5 USD per creative
- Creatives: 3

I created one test. No duplicate test was created. You can ask for the current status at any time. To end the test early, ask me to stop creative test <CREATIVE_TEST_ID>.
```

Store the test ID returned by the agent. Use it in later status, stop, or support requests when more than one test exists.

### 3. Check progress
Request a status update while the test is running. Interim data helps you confirm that delivery is active and spend is progressing.

**Sample prompt**
```http
// curl
Check the status of creative test <CREATIVE_TEST_ID>.
```

**Sample response**
```http
// curl
Creative test <CREATIVE_TEST_ID> is running on day 2 of 3.

Test-ad spend through October 12
- Creative A: 10.10 USD
- Creative B: 11.40 USD
- Creative C: 5.20 USD
- Total: 26.70 USD

Combined ad-group spend for October 11 and October 12 is 295.50 USD. Combined delivery includes both regular ads (your established top performers) and the test ad, so do not compare this value directly with your test-only budget.

Delivery remains uneven across the three creatives. Because the test has one day remaining, please treat the current data as directional. Ask again after the end date for the finalized report.
```

### 4. Review the final report
After the test ends, ask for the status again. The completed test becomes read-only and the response includes a final analysis. Review the combined-delivery view first for overall business impact, then use the test-ad-only view to inspect the controlled test signal.

```http
// curl
Get the final report for creative test <CREATIVE_TEST_ID>.
```

## Interpret the report

| View | What It Includes | How to Use It |
|---|---|---|
| Combined delivery | Regular delivery and test delivery for each creative during the report period. | Understand total business impact and compare the complete delivery context. |
| Test ads only | Metrics attributed to the separate test ad created by the tool. | Evaluate the controlled test signal and the test-budget allocation. |

## Common questions
### Does the tool replace normal delivery?
No. The tool creates a separate test ad inside the selected ad group. Regular delivery continues, and the combined-delivery report can include performance from both regular ads and the test ad. Use the test-ad-only view when you want to inspect the budget assigned specifically for the creative test.

### Does the agent start a test when it creates a plan?
No. Drafting and execution are separate actions. The agent must show the proposed scope, budget, and dates, then wait for an explicit approval such as “Start the test.”

### Can I test only one creative?
Yes. A plan can contain one to 50 eligible creatives. A one-creative test can help a new asset receive delivery, but it does not provide a direct head-to-head comparison. Interpret the result against an appropriate benchmark or prior period instead of calling the asset a winner by default.

### Can the test run for one day?
No. The minimum duration is three days. If you need a smaller allocation, reduce the daily test budget or use the three-day minimum.
### Can I stop a running test?
Yes. Send the creative test ID with a stop request. The stop action preserves completed delivery and makes the partial report available for review.

### Why is spend uneven across creatives?
The allocation defines the intended budget, while auction and delivery conditions affect actual spend. Uneven delivery does not automatically make the test invalid, but it reduces comparability. State the imbalance in the report and run a follow-up test when the decision requires a closer comparison.

### Will the planned test budget serve as a strict spending cap for the test?
Not necessarily. Because budgets are controlled at the campaign or ad group level, your test creatives can continue to consume spend once the planned test budget is exhausted, provided the campaign or ad group still has available funds. If the delivery algorithm determines that the test creatives have high performance potential, they may overspend their allocated test budget and draw funds away from your delivering creatives.

### What should I do if the test budget is too high?
Revise the draft before confirmation. Reduce the daily amount, remove creatives, or choose another valid duration. Do not shorten the test below three days. Review the existing ad group budget and the added test budget together, because both can contribute to daily delivery during the test.
