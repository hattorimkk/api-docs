# Get available attribution sources and data sources for an app
> Đường dẫn: API Reference > Tools > Get available attribution sources and data sources for an app
Use this endpoint to retrieve the attribution sources and data sources available for your mobile app when you create Upgraded Smart+ Ad Groups.

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tool/available/attribution_source/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| app_id  **(Required)** | string | App ID. ⏎ To retrieve the App ID of a mobile app, use [/app/list/](slug:get-the-app-list). |
| optimization_event | string | Optimization event (Conversion event). ⏎ To learn about the enum values, see List of values for `optimization_event`. |
| campaign_type | string | Campaign type. ⏎ Enum values: • `REGULAR_CAMPAIGN`: a campaign with the iOS 14 Dedicated Campaign setting disabled. • `IOS14_CAMPAIGN`: a campaign with the iOS 14 Dedicated Campaign setting enabled. ⏎ Default value: `REGULAR_CAMPAIGN`. |

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/tool/available/attribution_source/?advertiser_id={{advertiser_id}}&app_id={{app_id}}&campaign_type=REGULAR_CAMPAIGN' \
--header 'Access-Token: {{Access-Token}}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| - | - | - |
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](slug:return-codes-appendix). |
| message | string | Response message. For details, see [Appendix - Return Codes](slug:return-codes-appendix). |
| request_id | string | The log ID of the request, which uniquely identifies a request. |
| data | object | Returned data. |
| ↳ connected_data_source | string[] | The list of data sources that the app is connected to. ⏎ Enum values: • `MMP`: MMP (mobile measurement partner). • `EVENT_SDK`: TikTok App Events SDK. • `EVENT_API`: TikTok Events API. |
| ↳ available_attribution_source_list | object[] | The details of the attribution sources and data sources you can configure for the app when creating Upgraded Smart+ Ad Groups. ⏎ You can pass the values from `available_attribution_source` and `available_data_source` to the `app_attribution_source` and `app_data_source` parameters when you call [/smart_plus/adgroup/create/](slug:create-an-upgraded-smart-ad-group). |
| ↳↳ available_attribution_source | string | The attribution source that you can configure for the app when creating Upgraded Smart+ Ad Groups. ⏎ The attribution source you choose will be used for optimization, bidding, and reporting. ⏎ Enum values: • `MMP`: MMP (mobile measurement partner) attribution. Signals from your selected MMP will be used for attribution. • `SAN`: SAN (self-attribution network) attribution. Signals from TikTok SAN will be used for attribution. |
| ↳↳ available_data_source | string[] | The list of data sources that you can configure for the app when creating Upgraded Smart+ Ad Groups. ⏎ The attribution signals you select will be used for reporting. ⏎ Enum values: • `MMP`: MMP signals. Signals from your MMP will be used for reporting. • `EVENT_SDK`: App Events SDK signals. Signals from TikTok App Events SDK will be used for reporting. • `EVENT_API`: Events API signals. Signals from TikTok Events API will be used for reporting. |
