# User
> Đường dẫn: API Reference > User
# Get user information

Use this endpoint to obtain information about users who are authorized to access the developer App.

## Request
**Endpoint**  
https://business-api.tiktok.com/open_api/v1.3/user/info/

**Method** GET

**Header**

| field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

### Example

``` xcodeblock
(code curl http)
curl --get -H "Access-Token:xxx" \
https://business-api.tiktok.com/open_api/v1.3/user/info/
(/code)
```

## Response

``` xtable
|Field|Data Type|Description|
|---|---|---|
|code|number|Return code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097)|
|message |string|Return message. For details, see [Appendix-Return message](doc:1737172488964097)|
|data|object|Returned data. |
#|display_name |string| User's username.|
#|email |string| User's E-mail. <br><p><span style="color:darkred"><b>Note</b></span>: E-mails are data-masked.|
#|core_user_id|string|The TikTok for Business user ID.|
#|create_time|timestamp| User's creation time.|
#| avatar_url | string | The URL of the user's avatar.|
|request_id |string|The log id of a request, which uniquely identifies the request.|
```
