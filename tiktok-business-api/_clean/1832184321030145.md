# API Reference
> Đường dẫn: Business Messaging API > API Reference
Messaging is an integral part of how businesses manage their presence as well as doing business with users on social media platforms. Business Messaging API is a suite of interfaces enabling authorized TikTok accounts to exchange direct messages with TikTok users through API-integrated platforms.

You can see [Guides](doc:1832184100272338) to learn more about the authorization and authentication procedure, webhook schema, and more.
