# Create an Upgraded Smart+ Lead Generation Campaign with multiple location selection
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Lead Generation Campaigns > Create an Upgraded Smart+ Lead Generation Campaign with multiple location selection
This article walks you through the steps to create an Upgraded Smart+ Lead Generation Campaign with multiple location selection.

Multiple location selection enables you to deliver multiple lead conversion journeys, such as Instant Form and Website, simultaneously within a single Smart+ Lead Generation campaign. Our system automatically directs users to the destination where they’re most likely to convert — based on their behavior and preferences —helping you drive better results, effortlessly.

> **Note:** 
> Creating an Upgraded Smart+ Lead Generation Campaign with multiple location selection is currently an allowlist-only feature. If you would like to access it, please contact your TikTok representative.

###  Available destinations for different optimization location combinations

Each optimization location configured at the ad group level corresponds to a destination to be configured at the ad level. To configure the destination for each optimization location at the ad group level, follow the instructions in the following table.

Ad group-level optimization locationCorresponding ad-level destination**Parameter**How to configure the parameter

WebsiteWebsite URLmulti_dest_list.dest_typeEXTERNAL_WEBSITE
multi_dest_list.landing_page_urlSpecify the landing page URL of the website that has the Website Form
Instant formInstant Formmulti_dest_list.dest_typeINSTANT_PAGE
multi_dest_list.page_idSpecify the page ID of an Instant Form. • To obtain the page IDs of Instant Forms within your ad account, use [/page/get/](https://business-api.tiktok.com/portal/docs/get-the-page-id/v1.3) and set business_type to LEAD_GEN. • To create an Instant Form, use [Instant Page Editor SDK](https://business-api.tiktok.com/portal/docs/instant-page-editor-sdk/v1.3) and set businessType to 1.
TikTok direct messagesMessage templatemulti_dest_list.dest_typeTT_DIRECT_MESSAGAE
multi_dest_list.auto_message_idSpecify a message template (welcome message). • To obtain a list of welcome messages within your ad account, use [/creative/auto_message/get/](https://business-api.tiktok.com/portal/docs/get-welcome-messages-within-an-ad-account/v1.3). • To create a welcome message within your ad account, use [/creative/auto_message/create/](https://business-api.tiktok.com/portal/docs/create-a-welcome-message-within-an-ad-account/v1.3).

For example, if you have set your optimization location combination to Website and Instant form at the ad group level, configure your ad-level destinations as a Website URL and an Instant Form via the following parameters:

```http
// curl
"multi_dest_list": [
  {
    "dest_type": "EXTERNAL_WEBSITE",
    "landing_page_url": "{{landing_page_url}}"
  },
  {
    "dest_type": "INSTANT_PAGE",
    "page_id": "{{page_id}}"
  }
],
```
