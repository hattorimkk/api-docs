# Delete a test lead
> Đường dẫn: API Reference > Leads > Delete a test lead
Use this endpoint to delete an existing test lead.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/page/lead/mock/delete/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | The content type of the request. For this endpoint, use `application/json`. |

**Parameters**

| Field | Type | Description |
|---|---|---|
| advertiser_id {+Conditional} | string | Required when the test lead is under an ad account. ⏎ Advertiser ID. |
| library_id {+Conditional} | string | Required when the test lead is under a form library of a Business Center. ⏎ ID of a form library. |
| lead_id  **(Required)** | string | The ID of the test lead that you want to delete. ⏎ To obtain the ID of the existing test lead, use [/page/lead/mock/get/](doc:1739048460493826). |

### Example
```http
// curl
curl -H "Access-Token:xxx" -H "Content-Type:application/json" -X POST \
-d '{
    "advertiser_id": "ADVERTISER_ID", 
    "lead_id": "LEAD_ID"
}' \
https://business-api.tiktok.com/open_api/v1.3/page/lead/mock/delete/
```
