# Get additional interest categories
> Đường dẫn: API Reference > Tools > Get additional interest categories
Use this group of endpoints to get additional interest categories (interest keywords). Note that only effective additional interest categories (`status` = `EFFECTIVE`) can be used in ad groups to target audiences.

- If you want to search for additional interest categories based on seed keywords, see [/tool/interest_keyword/recommend/](doc:7). 
- If you want to use IDs to get additional interest categories, see [/tool/interest_keyword/get/](doc:7). 

> **Important:** Please use the keyword tool responsibly. You are responsible for your targeting decisions, including their legal compliance.
