# Object ID uniqueness
> Đường dẫn: Appendix > Object ID uniqueness
Each object within the TikTok API for Business is usually assigned an ID. The following table illustrates the uniqueness of common ID fields. 

To learn more about these common IDs, see [Concepts](doc:1738928364967937).

| ID type | Scope of Uniqueness | Globally Unique? |
|---|---|---|
| --- | --- | - |
| `app_id` | Global | Yes |
| `core_user_id` | Global | Yes |
| `advertiser_id` | Global | Yes |
| `campaign_id` | Global | Yes |
| `adgroup_id` | Global | Yes |
| `ad_id` | Global | Yes |
| `identity_id` | Global | Yes |
| `material_id` | Global | Yes |
| `tiktok_item_id` | Global | Yes |
| `video_id` | Global | Yes ⏎ **Note**: If the same video is uploaded multiple times, different video IDs will be generated, but these video IDs correspond to the same material ID  (`material_id`). |
| `image_id` | Global | Yes |
| `music_id` | Global | Yes |
| `file_id` | Global | Yes |
| `page_id` | Global | Yes |
| `creative_portfolio_id` | Global | Yes |
| `card_id` | Global | Yes |
| `call_to_action_id` | Global | Yes |
