# Get details of contextual tags
> Đường dẫn: API Reference > Tools > Get details of contextual tags
Use this endpoint to get the detailed information of contextual tags. In your query, you need to specify the advertiser ID and contextual tag ID that you get from the response of [/tool/contextual_tag/get/](doc:1747747118654465).

See [here](doc:1745292519923713) to find out how to use contextual targeting. 
>**Note:**  Contextual targeting is currently an allowlist-only feature. If you would like to access it, please contact your TikTok representative.

## Request

**Endpoint**  https://business-api.tiktok.com/open_api/v1.3/tool/contextual_tag/info/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| advertiser_id {required} | string | Advertiser ID. |
| contextual_tag_ids {required} | string[] | Contextual tag IDs.|
```

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/tool/contextual_tag/info/?advertiser_id={{advertiser_id}}&contextual_tag_ids=["53","82","51"]' \
--header 'Access-Token: {{Access-Token}}'
```

## Response

``` xtable
|Field{30%}|Type{15%}|Description{55%}|
|-|-|-|
|code |number|Response code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097). |
|message|string|Response message. For details, see [Appendix - Return Codes](doc:1737172488964097).|
|request_id |string|The log ID of a request, which uniquely identifies the request.  |
|data |object|Returned data.|
#| contextual_tag_list | object[] | Contextual tag list. <br><p><span style="color:darkred"><b>Note</b></span>: Contextual targeting is currently an allowlist-only feature. The returned value will be empty(`[]`) if you don't apply for the allowlisting. |
##| contextual_tag_id | string | Contextual tag ID. <br><p><span style="color:darkred"><b>Note</b></span>: Currently contextual tags can only be used together with audience targeting settings that target the following countries: <ul><li>General tags: `US` (the United States), `CA` (Canada), `GB` (the United Kingdom), `DE` (Germany), `FR` (France), `IT` (Italy) , `ES` (Spain), `JP` (Japan), `KR` (South Korea), `AU` (Australia)，`BR` (Brazil), `MX`(Mexico).</li><li>Premium tags: `US` (the United States), `CA` (Canada), `GB` (the United Kingdom), `DE` (Germany), `FR` (France), `IT` (Italy) , `ES` (Spain), `JP` (Japan), `KR` (South Korea), `AU` (Australia)，`BR` (Brazil), `MX`(Mexico).</li></ul> |
##| name | string | Contextual tag name. |
##| type | string | Contextual tag category. Enum values: `GENERAL` (general category), `PREMIUM`(premium category). |
##| content_lineup_type | string | Content lineup type.<br><br>Enum values: <ul><li>`MAX_PULSE`: Max Pulse. Your ads will show next to top content from any topics on TikTok.</li><li>`CUSTOM` : Your ads will show next to one of the custom lineups you've previously created.</li><li>`CATEGORY`: Category lineups. Your ads will show next to top content from the categories you select.</li><li>`SEASONAL`: Seasonal lineups. Your ads will show next to top content from a seasonal event you select. </li></ul><br><p><span style="color:darkred"><b>Note</b></span>: Currently, you can run Max Pulse targeting `AE` (United Arab Emirates), `AU` (Australia), `BR` (Brazil), `CA` (Canada), `DE` (Germany), `ES` (Spain), `FR` (France), `GB` (United Kingdom), `IT` (Italy), `MX` (Mexico), `SA` (Saudi Arabia), `TR` (Turkey), and `US` (United States), and Category Lineups targeting `US`(the United States), `CA`(Canada), `BR`(Brazil), `AU`(Australia), `GB`(the United Kingdom), `FR`(France), `IT`(Italy), `ES`(Spain), `DE`(Germany). Both features are allowlist only. If you want to use them in the above markets, please contact your TikTok representative. |
##| status | string | Contextual tag status. Enum: `ONLINE`, `OFFLINE`. Only `ONLINE` tags can be used to create ads. |
##| description | string | Contextual tag description. |
##| objective_types | string[] | The advertising objectives that the contextual tag supports. |
##| region_codes | string[] | The country or region codes that the contextual tag supports. |
```
