# Unlink a TikTok account from an ad account in Business Center
> Đường dẫn: API Reference > BC Assets > Unlink a TikTok account from an ad account in Business Center
Use this endpoint to unlink a TikTok account from an ad account in a Business Center.

Once the linkage is removed, Business Center members with access to the ad account that is previously linked to the TikTok account can no longer use the TikTok account for ad delivery from the ad account.

## Before you start
- You need to be an Admin user of the Business Center. To confirm your permission to a Business Center, use [/bc/get/](doc:1737115687501826) and confirm whether the returned `user_role` is `ADMIN`.
- Ensure you [have previously linked a TikTok account to an ad account in Business Center](doc:1846868953025538).

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/bc/asset/advertiser/unassign/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. ⏎ For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `application/json`. |

**Parameters**

| Field | Type | Description |  |
|---|---|---|---|
| bc_id  **(Required)** | string | Business Center ID. ⏎ To obtain the list of Business Centers that you can access, use [/bc/get/](doc:1737115687501826). |  |
| asset_id  **(Required)** | string | The ID of a TikTok account in a Business Center. ⏎ To obtain the list of TikTok accounts within a Business Center, use [/bc/asset/get/](doc:1739432717798401) and set `asset_type` to `TT_ACCOUNT` or `MANAGED_BUSINESS_ACCOUNT`. |  |
| asset_type  **(Required)** | string | Asset type. ⏎ Enum values: • `TT_ACCOUNT`: TikTok account as an ad delivery asset. You can run ads from these TikTok accounts. • `MANAGED_BUSINESS_ACCOUNT`: TikTok account for Business Account management. You can run ads from these TikTok accounts, and manage messages, leads, forms, comments, product links, and insights in your TikTok account. |  |
| advertiser_id  **(Required)** | string | The ID of an ad account within the same Business Center to unlink the TikTok account from. ⏎ To obtain the list of ad accounts already linked to a TikTok account within a Business Center, use [/bc/asset/advertiser/assigned/](doc:1855027294743554). |  |

### Example

```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/bc/asset/advertiser/unassign/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "bc_id": "{{bc_id}}",
    "asset_type": "MANAGED_BUSINESS_ACCOUNT",
    "asset_id": "{{asset_id}}",
    "advertiser_id": "{{advertiser_id}}"
}'
```
