# React Native installation
> Đường dẫn: Marketing API > Ad Measurement > Guides > TikTok App Events SDK > Getting started > React Native installation
> **Important:** 
> Use of the TikTok App Events SDK is governed by the [TikTok For Business Commercial Terms of Service](https://ads.tiktok.com/i18n/official/policy/commercial-terms-of-service). By using the TikTok App Events SDK, you also agree to the [TikTok Business Products (Data) Terms](https://ads.tiktok.com/i18n/official/policy/business-products-terms) and that you will not share sensitive data with TikTok.

The TikTok App Events SDK for React Native is maintained in a [public GitHub repository](https://github.com/tiktok/tiktok-business-react-native-sdk) and published on npm as [`@tiktok-for-business/react-native-sdk`](https://www.npmjs.com/package/@tiktok-for-business/react-native-sdk). It provides a typed TypeScript API over the TikTok for Business native iOS and Android SDKs.

## Prerequisites
Before you begin, ensure you have the following from your TikTok for Business account:
- Your app's **App ID** — the Android package name (e.g., `com.example.app`) or the numeric Apple App Store ID (e.g., `123456789`), depending on the target platform.
- A **TikTok App ID** from your app's settings page in Events Manager, for each platform.
- An **App Secret** for verification, from your app's settings page in Events Manager.
If you do not have these, refer to [Getting started](slug:tiktok-app-events-sdk-getting-started) before proceeding further.

## Add the SDK as a build dependency
### Install the npm package
```http
// curl
npm install @tiktok-for-business/react-native-sdk
# or
pnpm add @tiktok-for-business/react-native-sdk
# or
yarn add @tiktok-for-business/react-native-sdk
```

### iOS
After adding the npm package, install the native iOS pods:
```http
// curl
cd ios
bundle exec pod install
```

### Android
Ensure JitPack is available in your project's repository configuration:
```http
// curl
// settings.gradle or build.gradle (repositories block)
maven { url 'https://jitpack.io' }
```

### Migrating to React Native from existing native Android or iOS SDKs
Developers who have already integrated the native TikTok App Events SDKs for Android (Java, Kotlin) or iOS (Swift, Objective-C) may migrate to the React Native SDK by:
- Replacing the native SDK dependencies with the `@tiktok-for-business/react-native-sdk` npm package (which bundles the native SDKs), and
- Replacing any existing native SDK configurations and method calls with the React Native TypeScript API. Mixing native and React Native interfaces may lead to conflicts and is not recommended or supported.

## Configure and initialize the SDK
Initialize the SDK as early as possible in your application's lifecycle, before tracking any events. Call `initialize()` once — typically in your root component or app entry point.

> **Note:** 
> •    The SDK only supports initialization and use in the main process and main thread.
> •    On the first initialization, the Android SDK will obtain the device user agent using WebView. To prevent lock conflicts, please use WebView only after initialization is successful.
> •    If you work with multiple Ad Accounts, you can provide an array of TikTok App IDs. Each array entry should be one ID with no commas or spaces. The first ID in the array is used for Test Events in Events Manager.
> •    Since React Native apps are built per-platform, supply the platform-appropriate `appId` at runtime (e.g., Android package name or iOS Apple ID) using `Platform.select()` or your config layer.

```http
// curl
import TikTokBusinessSDK from '@tiktok-for-business/react-native-sdk';

// Initialize with your credentials
await TikTokBusinessSDK.initialize({
  appId: 'YOUR_APP_ID',             // Android package name or iOS Apple ID
  accessToken: 'YOUR_APP_SECRET', // From Events Manager
  tiktokAppId: ['YOUR_TIKTOK_APP_ID'],
});

// For multiple TikTok App IDs:
// await TikTokBusinessSDK.initialize({
//   appId: 'YOUR_APP_ID',
//   accessToken: 'YOUR_APP_SECRET',
//   tiktokAppId: ['TIKTOK_APP_ID_1', 'TIKTOK_APP_ID_2'],
// });
```

For cross-platform apps, use `Platform.select()` to pass the correct credentials per platform:
```http
// curl
import { Platform } from 'react-native';

await TikTokBusinessSDK.initialize({
  appId: Platform.select({
    ios: 'YOUR_IOS_APPLE_ID',
    android: 'YOUR_ANDROID_PACKAGE_NAME',
  })!,
  accessToken: Platform.select({
    ios: 'YOUR_IOS_APP_SECRET',
    android: 'YOUR_ANDROID_APP_SECRET',
  })!,
  tiktokAppId: Platform.select({
    ios: ['YOUR_IOS_TIKTOK_APP_ID'],
    android: ['YOUR_ANDROID_TIKTOK_APP_ID'],
  })!,
});
```

### Delaying event transmission
When integrating TikTok App Events SDK, clients may need to configure the SDK to delay data transmission and event collection pursuant to jurisdictional-specific legal requirements. TikTok offers resources to support clients' compliance with these laws and can be integrated by following [Resources for data sharing after user consent](slug:resources-for-data-sharing-after-user-consent).

## Platform setup notes
### Android: Permissions, Proguard, and Gradle options
- **Permissions**: In your `AndroidManifest.xml` file, declare the `INTERNET` and `AD_ID` permissions.
```http
// curl
<!-- AndroidManifest.xml -->
<manifest ...>
    <uses-permission android:name="android.permission.INTERNET" />
    <!-- Required for advertising and analytics purposes on Android 13+ -->
    <uses-permission android:name="com.google.android.gms.permission.AD_ID" />

    <application ...>
        ...
    </application>
</manifest>
```

- **Proguard**: To prevent the SDK from being removed in release builds, add these rules to your `proguard-rules.pro` file:
```http
// curl
# proguard-rules.pro

# TikTok SDK
-keep class com.tiktok.** { *; }

# Google Play Billing Library
-keep class com.android.billingclient.api.** { *; }

# Google Install Referrer
-keep class com.android.installreferrer.api.** { *; }

# Android Lifecycle
-keep class androidx.lifecycle.** { *; }
```

- **Gradle Options**: The package's `build.gradle` already targets Java 8. If your app-level `build.gradle` does not, ensure it also targets Java 8:
```http
// curl
// app/build.gradle
android {
  compileOptions {
    sourceCompatibility JavaVersion.VERSION_1_8
    targetCompatibility JavaVersion.VERSION_1_8
  }
}
```

### iOS: AppTrackingTransparency (ATT) and SKAdNetwork
**App Tracking Transparency (ATT)**: To access the device's advertising identifier (IDFA) on iOS 14.5+, you must request user consent. Add the `NSUserTrackingUsageDescription` key to your `Info.plist` with a message explaining why you need tracking permission. You can then call `requestTrackingAuthorization()` from the SDK at the appropriate moment in your app's consent flow.

```http
// curl
// Request ATT at your app's preferred consent moment (iOS only)
const status = await TikTokBusinessSDK.requestTrackingAuthorizationWithCompletionHandler();
```

**SKAdNetwork (SKAN)**:

The SDK supports SKAN for privacy-preserving attribution. To avoid conflicts, if you use another SDK (like an MMP) to manage SKAN updates in your app, you must disable the App Events SDK's SKAdNetwork support.

```http
// curl
// In your initialization config
await TikTokBusinessSDK.initialize({
  appId: 'YOUR_APP_ID',
  accessToken: 'YOUR_APP_SECRET',
  tiktokAppId: ['YOUR_TIKTOK_APP_ID'],
  ios: {
    disableSKAdNetworkSupport: true,
  },
});
```

A schema map is required to accurately report the conversion values received from Apple. To configure this map, refer to [SKAdNetwork reporting and schema mapping](slug:skadnetwork-reporting-and-schema-mapping).

## App event reporting
### Automatically logged events
The SDK automatically logs the following events if they are not disabled during configuration.

| Event | Description |
|---|---|
| `InstallApp` | First-time app launch after installation. ⏎ You may notice an increase in reported install events when the SDK is integrated for the first time. This is expected, as installs are measured based on the first detectable app launch by the SDK. If this is a concern, allow a few days for your existing user base to update their apps before running paid campaigns. |
| `LaunchAPP` | On every app launch. |
| `2DRetention` | App is opened the day after the first app launch. |
| `Purchase` | A successful transaction is completed via Apple's StoreKit or the Google Play Billing Library. This includes consumable, non-consumable, and subscription purchases. |

You have the option to disable automatic event logging. Disabling automatic event logging means that events such as app installs and app launches will no longer be tracked by default.

If you require these events for measurement or analytics, you must implement manual logging in your app code to capture and send them.
```http
// curl
await TikTokBusinessSDK.initialize({
  appId: 'YOUR_APP_ID',
  accessToken: 'YOUR_APP_SECRET',
  tiktokAppId: ['YOUR_TIKTOK_APP_ID'],

  // Option 1: Disable ALL automatic events
  disableAutoTrack: true,

  // Option 2: Disable specific automatic events
  disableInstallTrack: true,
  disableLaunchTrack: true,
  disableRetentionTrack: true,
  disablePayTrack: true,
});
```

### Manually logged events
#### Standard events
For simple events without properties, use `trackEvent()` with an event constant from `TikTokEventNames`. For a full list of event name constants, refer to [Standard event constants and classes](slug:standard-event-constants-and-classes).

**Example:** **`Registration`** **Event**
```http
// curl
import TikTokBusinessSDK, { TikTokEventNames } from '@tiktok-for-business/react-native-sdk';

// Example: A user completes a registration
await TikTokBusinessSDK.trackEvent(TikTokEventNames.Registration);
```

#### Adding properties to standard events
For events that include details about products or value, use `trackContentEvent()` with a content event constant from `TikTokContentEventNames`. The following content event types are supported:

| Standard event | Content event name |
|---|---|
| Add to Cart | `TikTokContentEventNames.AddToCart` |
| Add to Wishlist | `TikTokContentEventNames.AddToWishlist` |
| Checkout | `TikTokContentEventNames.Checkout` |
| Purchase | `TikTokContentEventNames.Purchase` |
| View Content | `TikTokContentEventNames.ViewContent` |

**Example:** **`AddToCart`** **content event**
```http
// curl
import TikTokBusinessSDK, { TikTokContentEventNames } from '@tiktok-for-business/react-native-sdk';

// Example: A user adds an item to the cart
await TikTokBusinessSDK.trackContentEvent(TikTokContentEventNames.AddToCart, {
  properties: {
    description: 'Description of the product',
    contentId: 'ABC-123',
    contentType: 'product_group',
    currency: 'USD',
    value: 4.99,
  },
  contents: [
    {
      price: 4.99,
      quantity: 1,
      brand: 'AwesomeBrand',
      contentName: 'The Best Product',
      contentId: 'ABC-123',
    },
  ],
});
```

**Example:** **`CompleteTutorial`** **event with properties**

For other standard events with standard properties, use `trackEvent()` with a constant from `TikTokEventNames` and a properties object.

```http
// curl
// Example: A user completes the onboarding tutorial
await TikTokBusinessSDK.trackEvent(TikTokEventNames.CompleteTutorial, {
  properties: {
    currency: 'USD',
    value: 9.99,
    contentId: 'CONTENT_ID',
    contentType: 'CONTENT_TYPE',
    price: 9.99,
    quantity: 1,
  },
});
```

> **Note:** 
> For a full list of supported standard properties, refer to the [Properties object reference](https://business-api.tiktok.com/portal/docs/setup-guide-for-app/v1.3#anchor-2-1-1-2). Custom property keys are not supported and will be discarded.

#### In-app ad revenue
In-app advertising mediation revenue data can be reported using `trackAdRevenueEvent()`. Refer to [In-app ad revenue reporting](slug:in-app-ad-revenue-reporting) for detailed implementation guidelines for AppLovin Max, ironSource, and Google AdMob.

```http
// curl
await TikTokBusinessSDK.trackAdRevenueEvent({
  adNetwork: 'example-network',
  adPlatform: 'example-platform',
  revenue: 1.25,
  currency: 'USD',
  adUnit: 'rewarded-video',
});
```

#### Custom events
To track an event not listed in the standard events, use `trackCustomEvent()` with a custom event name string.

```http
// curl
// Example: A user shares content
await TikTokBusinessSDK.trackCustomEvent('ShareContent');
```

## Enable advanced matching
To improve audience matching, use `identify()` to set advanced matching properties when user information becomes available (e.g., after login or sign-up), and `logout()` to clear it.

```http
// curl
// When user logs in or signs up
await TikTokBusinessSDK.identify({
  externalId: 'user-external-id-123',   // externalId
  externalUserName: 'user-name-456',    // externalUserName
  phoneNumber: '+15551234567',          // phoneNumber (E.164 format)
  email: 'user@example.com',           // email
});

// When user logs out
await TikTokBusinessSDK.logout();
```

**Supported Properties**

Property
Formatting Requirements
Example

externalId Unique ID from the advertiser, such as loyalty membership ID or user ID.
Unhashed plaintext. Trim leading/trailing spaces.
"user-id-abc"

externalUserName Username from the advertiser.
Unhashed plaintext. Trim leading/trailing spaces.
"testuser"

email
Unhashed plaintext. Trim leading/trailing spaces and lowercase all characters.
"email@example.com"

phoneNumber
Unhashed plaintext. Normalize to E.164 format (e.g., +[country code][number]).
"+15551234567"

The React Native layer does not hash, persist, normalize, or rewrite email or phone values. It passes runtime values to the native SDK, which handles official Advanced Matching behavior.

## Verify your integration
Use TikTok Events Manager to verify that events are being received correctly. This sends events to a separate endpoint for testing and does not affect your production data.
### Codeless test events (recommended)
This method enables device-specific event debugging without code changes. Before you start, ensure that:
- The latest version of the TikTok app is installed on your test device.
- (iOS only) You have granted App Tracking Transparency (ATT) permission for both your app and the TikTok app.

| Step | Instructions |
|---|---|
| Generate QR Code | • In **Events Manager** for your app, go to the **Test Events** tab. • Click **Generate QR code**. A QR code is generated, valid for 24 hours. • To force expiry before the 24 hours is over, click **Disable code**. |
| Bind Device | • Open the TikTok app on your test device and go to your **Profile**. • Tap the menu icon (☰) in the top right, then select **My QR code**. • Tap the scan icon in the top right and scan the QR code from Events Manager. • Tap **Authorize** to bind your device and enable test mode. |
| Verify Events | • Trigger events in your app. They will appear in the **Test Event** tab in real-time. • If you configured multiple TikTok App IDs, test events will only appear in the Events Manager for the **first** ID in the list. |

### Manual debug mode
> **Important:** 
> Remember to disable debug mode and verbose logging before releasing your app to production. Test events are discarded and not used for campaign reporting.

#### Enabling debug mode
Add the `debug` configuration to your `initialize()` call. You can also set the `logLevel` for more detailed output.
```http
// curl
await TikTokBusinessSDK.initialize({
  appId: 'YOUR_APP_ID',
  accessToken: 'YOUR_APP_SECRET',
  tiktokAppId: ['YOUR_TIKTOK_APP_ID'],
  debug: {
    enabled: true,
    logLevel: 'verbose', // Options: 'none', 'error', 'warning', 'info', 'debug', 'verbose'
  },
});
```

#### Disabling debug mode
Once your integration is verified, remove the `debug` configuration or set `enabled: false` before submitting your app.
```http
// curl
// Remove or disable debug mode for production
await TikTokBusinessSDK.initialize({
  appId: 'YOUR_APP_ID',
  accessToken: 'YOUR_APP_SECRET',
  tiktokAppId: ['YOUR_TIKTOK_APP_ID'],
  // debug: { enabled: true, logLevel: 'verbose' },  // REMOVE THIS
});
```

### Generate and verify events
After enabling debug mode, run your app and trigger some events. You can view the events as they arrive in real-time under the **Test Events** tab in your app's Events Manager page.

If multiple TikTok App IDs are present in your SDK configuration, test events will only show in the Events Manager ad account associated with the **first** TikTok App ID in the array.
