# Get Creative Fatigue Detection results
> Đường dẫn: API Reference > Creative Tools > Get Creative Fatigue Detection results
Use this endpoint to detect whether Creative Fatigue occurred for creatives within a specified time range in the past. 

To find out a detailed introduction of the Creative Fatigue Detection feature, see [here](slug:creative-fatigue-detection). 

> **Important**
> This endpoint has been completely revamped with an updated schema. Review the new schema details below to successfully migrate your existing integration.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/creative_fatigue/get/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| advertiser_id {Required} | string | Advertiser ID. |
| ad_id {-Deprecated} | string | The ID of the ad that you want to get Creative Fatigue detection results for. |
|adgroup_id {Required}|string|Ad group ID.<br><br>To obtain ad group IDs, use [/smart_plus/adgroup/get/](slug:get-upgraded-smart-ad-groups).|
|ad_material_ids {Required}|string[]|A list of ad material IDs for creatives to operate on.<br>An ad material ID is an ad-specific material ID generated when a particular creative is used in an ad.<br><br>This ID differs from the creative ID you receive when uploading the creative to your ad account’s Creative Library.<br><br>Max size: 100.<br><br>To obtain ad material IDs associated with an ad, use [/smart_plus/ad/get/](slug:get-upgraded-smart-ads).<br><br><p><span style="color:darkred"><b>Note</b></span>: For images within a carousel, you need to provide the `ad_material_id` from [/smart_plus/ad/review_info/](slug:get-the-review-info-of-upgraded-smart-ads), not the one from [/smart_plus/ad/get/](slug:get-upgraded-smart-ads) which identifies the entire carousel.|
| filtering {Required} | object | Filtering conditions. |
#| start_date {Required} | string | Query start date (closed interval), in the format of `YYYY-MM-DD` (advertiser account time zone). <br>You can only specify a date within the last 14 days. |
#| end_date {Required} | string | Query end date (open interval), in the format of `YYYY-MM-DD` (advertiser account time zone). <br>You can only specify a date within the last 14 days. |
| page | number | Current page number. <br>Default value: 1. <br>Value range: ≥ 1. |
| page_size | number | Page size. <br> Default value: 10.<br>Value range: [1, 500]. |
```
### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/creative_fatigue/get/?advertiser_id={{advertiser_id}}&adgroup_id={{adgroup_id}}&filtering={"start_date":"{{start_date}}", "end_date":"{{end_date}}"}&ad_material_ids=["{{ad_material_id}}"]' \
--header 'Access-Token: {{Access-Token}}'
```
