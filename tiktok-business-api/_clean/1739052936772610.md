# Create a lead download task
> Đường dẫn: API Reference > Leads > Create a lead download task
Use this endpoint to create a download task for all the leads for the `page_id` or `ad_id` passed in the request.

After the asynchronous download task is created, call `/page/lead/task/` again to check whether the task is complete (`status` = `SUCCEED`). Once the task is complete, use [/page/lead/task/download/](doc:1739053563877378) to download all the leads.

Leads data is stored in various locations. Depending on the locations that your ads target, you might need to use different URLs to access the `/page/lead/task/` and [/page/lead/task/download/](doc:1739053563877378) endpoints. To determine the locations that your ads target, which also correspond to the locations where the leads data is stored, use [/adgroup/get/](doc:1739314558673922). The targeted locations will be returned through `location_ids`, or `zipcode_ids`, or both.
- If you want to access leads for the European Economic Area (EEA), Switzerland (CH), or the United Kingdom (UK), use `https://business-api.tiktok.com/open_api/` and include the header `x-lead-region: eu`.
> **Note:** 
 The new URL with the `eu` header above is effective from July 13th (UTC+0), 2023. After July 13th (UTC+0), if you continue using the old URL `https://ads.us.tiktok.com/open_api/`, you will only receive US leads. If you use the URL `https://business-api.tiktok.com/open_api/` without specifying the region in the header, you will only receive leads from other countries/regions.

- If you want to access leads for the US, use one of the following:
  -  (recommended) `https://business-api.tiktok.com/open_api/` with the header `x-lead-region: us`.
  -  `https://ads.us.tiktok.com/open_api/` (planned to be deprecated in future versions)

- If you want to access leads for other countries/regions,  use `https://business-api.tiktok.com/open_api/` without the `x-lead-region` header.

>**Note:**  To protect customer information, only ad account admins can create and query lead download tasks or download the leads. Ad account roles are configured in the Business Center. The leads file will expire in 10 minutes after it was generated. You will get a `file not exist` error if the file has expired.

## Request
**Endpoint** 
- **For leads data in EEA/CH/UK**:  `https://business-api.tiktok.com/open_api/v1.3/page/lead/task/` and the header `x-lead-region: eu`

- **For leads data in US:** 
  - (recommended) `https://business-api.tiktok.com/open_api/v1.3/page/lead/task/` with the header `x-lead-region: us`
  - **[Or]** `https://ads.us.tiktok.com/open_api/v1.3/page/lead/task/`(planned to be deprecated in future versions)

- **For leads data in other countries/regions**:  `https://business-api.tiktok.com/open_api/v1.3/page/lead/task/` 

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id {+Conditional} | string | Either `advertiser_id` or `library_id` has to be set.  • If you haven't migrated the leads of the ad account to a Business Center via [/page/library/transfer/](doc:1740029931324417), specify the `advertiser_id`. • If you have migrated the leads of the ad account to a Business Center via [/page/library/transfer/](doc:1740029931324417), specify the `library_id`. ⏎ Advertiser ID. |
| library_id {+Conditional} | string | Either `advertiser_id` or `library_id` has to be set.  • If you haven't migrated the leads of the ad account to a Business Center via [/page/library/transfer/](doc:1740029931324417), specify the `advertiser_id`. • If you have migrated the leads of the ad account to a Business Center via [/page/library/transfer/](doc:1740029931324417), specify the `library_id`. ⏎ Form library ID. ⏎ To obtain the IDs of form libraries that you can access, use [/page/library/get/](doc:1740029915327489). |
| ad_id {+Conditional} | string | Either `ad_id` or `page_id` has to be set.  • If you specify `ad_id`, you will create a lead download task for a specific ad. • If you specify `page_id`, you will create a lead download task for a specific Instant Form. ⏎ Ad ID. ⏎ Specify the ID of an ad that uses an Instant Form to collect leads. To learn about how to create such ads, see [Create a Lead Generation ad with optimization location as Instant Form](doc:1774482920012801). ⏎ To obtain the IDs of ads within an ad account, use [/ad/get/](doc:1735735588640770). |
| page_id {+Conditional} | string | Either `ad_id` or `page_id` has to be set.  • If you specify `ad_id`, you will create a lead download task for a specific ad. • If you specify `page_id`, you will create a lead download task for a specific Instant Form. ⏎ Instant form ID. ⏎ To obtain the IDs of Instant Forms within an ad account, use [/page/get/](doc:1820826387779586) and set `business_type` to `LEAD_GEN`. |
| task_id | string | Task ID. • If you do not pass in this field, the request will create a lead download task and you will get the `task_id` in the response. • If you pass in this field, the request will poll the task status to check whether the task has been completed (`status` = `SUCCEED`). |

### Example
#### Create a lead download task for an Instant Form within a form library (EEA/CH/UK region)
```http
// curl
curl --location  --request POST 'https://business-api.tiktok.com/open_api/v1.3/page/lead/task/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'x-lead-region: eu' \
--data '{
    "library_id":"{{library_id}}",
    "page_id":"{{page_id}}"
}'
```

# coding=utf-8
import json
import requests

from six import string_types
from six.moves.urllib.parse import urlencode, urlunparse  # noqa

ACCESS_TOKEN = "xxx"
PATH = "/open_api/v1.3/page/lead/task/"

def build_url(path, query=""):
    # type: (str, str) -> str
    """
    Build request URL
    :param path: Request path
    :param query: Querystring
    :return: Request URL
    """
    scheme, netloc = "https", "ads.tiktok.com"
    return urlunparse((scheme, netloc, path, "", query, ""))

def post(json_str):
    # type: (str) -> dict
    """
    Send GET request
    :param json_str: Args in JSON format
    :return: Response in JSON format
    """
    args = json.loads(json_str)
    query_string = urlencode({k: v if isinstance(v, string_types) else json.dumps(v) for k, v in args.items()})
    url = build_url(PATH, query_string)
    headers = {
        "Access-Token": ACCESS_TOKEN,
    }
    rsp = requests.post(url, headers=headers)
    return rsp.json()

if __name__ == '__main__':

    # Args in JSON format

// PHP
$ACCESS_TOKEN = "xxx";
$PATH = "/open_api/v1.3/page/lead/task/";

/**
 * Build request URL
 * @param $path : Request path
 * @return string
 */
function build_url($path)
{
    return "https://ads.tiktok.com" . $path;
}

/**
 * Send GET request
 * @param $json_str : Args in JSON format
 * @return bool|string : Response in JSON format
 */
function get($json_str)
{
    global $ACCESS_TOKEN, $PATH;
    $curl = curl_init();

    $args = json_decode($json_str, true);

    /* Values of querystring is also in JSON format */
    foreach ($args as $key => $value) {
        $args[$key] = is_string($value) ? $value : json_encode($value);
    }

    $url = build_url($PATH) . "?" . http_build_query(
            $args
        );

    curl_setopt_array($curl, array(
        CURLOPT_URL => $url,
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_ENCODING => "",
        CURLOPT_MAXREDIRS => 10,
        CURLOPT_TIMEOUT => 0,
        CURLOPT_FOLLOWLOCATION => true,
        CURLOPT_HTTP_VERSION => CURL_HTTP_VERSION_1_1,
        CURLOPT_CUSTOMREQUEST => "GET",
        CURLOPT_HTTPHEADER => array(
            "Access-Token: " . $ACCESS_TOKEN,
        ),
    ));

    $response = curl_exec($curl);
    curl_close($curl);
    return $response;
}

$advertiser_id = ADVERTISER_ID;
$page_id = PAGE_ID;

/* Args in JSON format */
$my_args = sprintf("{\"advertiser_id\": \"%s\", \"page_id\": \"%s\"}", $advertiser_id, $page_id);

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Return code. For the complete list of response codes and descriptions, see [Appendix-Return codes](doc:1737172488964097). |
| message | string | Return message. For details, see [Appendix-Return codes](doc:1737172488964097). |
| data | object | Return data. |
| ↳ status | string | Task status. ⏎ Enum values: `CREATED`, `FAILED`, `RUNNING`, `SUCCEED` |
| ↳ task_id | string | Task ID. ⏎ You can pass in `task_id` in the request to poll the task status to check whether the task has been completed (`status` = `SUCCEED`). |
| ↳ file_name | string | Returned only when `status` is `SUCCEED`. ⏎ File name of the lead file. |
| ↳ file_type | string | Returned only when `status` is `SUCCEED`. ⏎ File type of the lead file. ⏎ Enum values: `csv`, `zip`. |
| request_id | string | Log id of the request, which uniquely identifies a request. |
