# API reference
> Đường dẫn: Marketing API > Ad Measurement > API reference
> **Important:** 
> By using Events API endpoints, you agree to the [TikTok Business Products (Data) Terms](https://ads.tiktok.com/i18n/official/policy/business-products-terms) and that you will not share sensitive data with TikTok.

Events API consists of three endpoint groups: App Events, Pixel Events (Web Events), and Offline Events endpoints.

# App Events API

> **Note:** Events API - App is currently in Beta. If you'd like to use this API, please contact your TikTok representative.  Your accounts need to be allowlisted before you can report events using [/v1.3/app/track/](doc:1740859196043266) or [/v1.3/app/batch/](doc:1740859218541569).
