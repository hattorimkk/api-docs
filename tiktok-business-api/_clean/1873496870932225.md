# Refresh an MCP access token
> Đường dẫn: API Reference > MCP Authorization > Refresh an MCP access token
Use this endpoint to exchange a valid refresh token for a new access token.

You need to call this before your current access token expires, using the same token endpoint you used for the authorization code exchange.

# Request
**Endpoint** https://business-api.tiktok.com/open_mcp/{server}/oauth/token/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/x-www-form-urlencoded`. |

**Path parameters**

| Field | Data Type | Description |
|---|---|---|
| server  **(Required)** | string | The specific TikTok for Business MCP server URL. ⏎ Enum values: `tt-ads-mcp-flat`, `tt-ads-mcp-layer`. ⏎ To learn more about how these server URLs differ, see [Choose your server URL](https://business-api.tiktok.com/portal/docs/how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server/v1.3#anchor-3). |

**Body parameters**

| Field | Data Type | Description |
|---|---|---|
| grant_type  **(Required)** | string | The method for granting tokens. ⏎ Enum value: • `refresh_token`: To exchange your refresh token for a new access token. |
| refresh_token  **(Required)** | string | The refresh token that was issued to you [when you obtained the access token](slug:exchange-an-mcp-authorization-code-for-tokens). |

## Example

> **Note:** 
> The example below uses `tt-ads-mcp-layer` as the `{server}` value. You can replace this with your chosen server value.

```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer/oauth/token' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'grant_type=refresh_token' \
--data-urlencode 'refresh_token={{refresh_token}}'
```

# Response

A successful refresh returns HTTP `200 OK`.

| Field | Data Type | Description |
|---|---|---|
| access_token | string | The new access token issued to you. |
| refresh_token | string | The refresh token issued to you for future token renewals. |
| token_type | string | The type of token issued. ⏎ Enum value: • `bearer`: Bearer token, an OAuth 2.0 access token where possession of the token itself is sufficient for access. |
| expires_in | integer | The remaining validity period of the access token, expressed in seconds. |
| refresh_token_expires_in | integer | The remaining validity period of the refresh token, expressed in seconds. |
| scope | string | The specific permission scope granted to your token. ⏎ Enum value: • `mcp:tt4b`: the necessary permissions to access TikTok for Business MCP server features. |

## Example
```http
// curl
{
    "access_token": "{{access_token}}",
    "expires_in": 86399,
    "refresh_token": "{{refresh_token}}",
    "refresh_token_expires_in": 2591941,
    "scope": "mcp:tt4b",
    "token_type": "bearer"
}
```

## Error response

A failure returns HTTP `400 Bad Request`.

| Field | Data Type | Description |
|---|---|---|
| error | string | Error code. ⏎ To learn about the possible errors and descriptions, see [List of possible errors](https://business-api.tiktok.com/portal/docs/refresh-an-mcp-access-token/v1.3#anchor-2-2-1). |
| error_description | string | The human-readable description of the error. ⏎ To learn about the possible errors and descriptions, see [List of possible errors](https://business-api.tiktok.com/portal/docs/refresh-an-mcp-access-token/v1.3#anchor-2-2-1). |

### List of possible errors

| error | error_description |
|---|---|
| `invalid_request` | `grant_type is required` |
| `invalid_request` | `refresh_token is required` |
| `unsupported_grant_type` | `grant_type is not supported` |
| `invalid_grant` | `refresh token not found` |
| `invalid_grant` | `refresh token revoked` |
| `invalid_grant` | `refresh token expired` |
| `invalid_grant` | `refresh token is bound to a different MCP server` |
