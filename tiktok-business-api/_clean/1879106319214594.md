# Get started with MCP server management
> Đường dẫn: Skill and MCP management > Get started with MCP server management
This article outlines what you need to prepare to ensure your Model Context Protocol (MCP) server registration on the developer portal goes smoothly.

## Prerequisites
Before you can register MCP servers on the TikTok for Business Developers portal, you must:
1. [Create a TikTok for Business account](slug:create-a-tiktok-for-business-account). This gives you access to the TikTok for Business ecosystem.
2. [Register as a developer](slug:register-as-a-developer). This unlocks the **My Agentic Hub** module and MCP server registration capabilities.
> **Note:** 
> If you have previously used any TikTok API for Business endpoints, you already meet both prerequisites and can proceed directly to preparing your MCP server infrastructure.

## Prepare your MCP server infrastructure
To prevent delays during the review process, we strongly recommend preparing the following four components before you begin the registration form:

| Category | What you need | Action required |
|---|---|---|
| Endpoint and network configuration | A remote MCP server URL that uses the Streamable HTTP transport protocol. | Ensure you have set up a remote MCP server URL that uses the Streamable HTTP transport protocol. |
| Tools configuration CSV | A completed CSV file that maps out every tool your server offers. Download the official [Tools Configuration Template](https://bytedance.my.larkoffice.com/sheets/AIgpsEGB8hPxbmt1tO0mWtC4yHh). | Include the following for every single tool: ⏎ •  The `tool_name` and the exact `tool_signature` (for example, `get_order_summary(store_id: string)`). ⏎ •  A clear `display_title` and a human-readable `description`. ⏎ •  The `safety_annotation`, which must be written exactly as `readOnlyHint`, `writeHint`, or `destructiveHint`. ⏎ •  An `example_prompt` and the `expected_tool_sequence`. |
| Authentication setup | A finalized decision on how your server handles user security. | •  If your tools only provide public data, select "No authentication". ⏎ •  If they access specific advertiser data, set up OAuth 2.0/2.1 with PKCE. Keep your Authorization URL accessible, as it is required for the registration form. Additionally, you must allowlist TikTok's redirect URI (https://business.tiktok.com/agentic/oauth/callback) in your identity provider settings to ensure the OAuth handshake succeeds. |
| Test account credentials | A dedicated test account configured specifically for the TikTok review team. | Create a secure test environment populated with representative sample data. Document the exact login credentials and step-by-step instructions for testing your tools. Missing or invalid test credentials are the most common cause of review delays. |
| Legal and support documentation | •  Documentation URL: The URL to the official documentation page for your MCP server. ⏎ •  Privacy policy URL: The link to the privacy policy document for your MCP server. ⏎ •  Terms of service URL: The link to the terms of service document for your MCP server. ⏎ •  Support channel: The URL or email address for your helpdesk, community forum, or dedicated support inbox. | •  Ensure your official documentation is publicly accessible and clearly explains how to use your server's tools. ⏎ •  Your privacy policy must be live and accurately describe your data handling practices. ⏎ •  Provide a valid link to the terms of service governing the use of your MCP server. ⏎ •  Establish a clear channel where advertisers can reach out for technical assistance. |

## Next steps
Once your MCP server infrastructure is ready, proceed to [Register MCP servers](slug:register-mcp-servers).
