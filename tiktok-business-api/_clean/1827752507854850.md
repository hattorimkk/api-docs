# Create Automotive Ads for Inventory
> Đường dẫn: Use Cases > Campaign creation > Create Lead Generation ads > Create a Lead Generation ad with optimization location as Website > Create Automotive Ads for Inventory
This article walks you through the steps to create Automotive Ads for Inventory.

# Introduction
Automotive Ads for Inventory leverage the vehicle and dealership information stored in your Auto-Inventory catalog to showcase the most relevant vehicles to potential buyers. Buyers can interact with the ads to enter their zip code, then view and filter available vehicles on an Instant Product Page based on attributes like condition, make, model, price, year, and more. This gives buyers a streamlined way to browse and identify vehicles that meet their needs directly from your ad.

**You can use Campaign Management API to create Automotive Ads for Inventory, and this helps you streamline your ad creation experience, and elevate operational efficiency and scalability.**

# Prerequisites
- You've gained access to TikTok API for Business. See [Get Started - Step by step workflow](doc:1735713609895937) for details. 
  - To create Automotive Ads for Inventory, you need relevant permissions. See [API Reference](doc:1735713875563521) to find out permissions required for endpoints (including the endpoints listed in the "Steps" section) and see [Update app permissions](doc:1738855280338946) to find out how to configure permissions.  
- Creating Automotive Ads for Inventory requires setting up an Auto-Inventory catalog in Business Center first.
To set up the catalog:
  1. Create an Auto-Inventory catalog using [/catalog/create/](doc:1740306481704961). 
  2. Upload products to the catalog using [/catalog/product/upload/](doc:1740497429681153) (JSON schema), [/catalog/product/file/](doc:1740496787164161) (CSV feed template), or [/catalog/feed/create/](doc:1740665161957377)(online data feed schedule).
  3. Check the product handling results using [/catalog/product/log/](doc:1740570027173889). 
Pass in the `feed_log_id` obtained from Step 2. If the field `warn_affected_products` in the response is not null, examine the issue details and return to Step 2 to reupload the product.
  4. (Optional) Create an Auto-Inventory product set using [/catalog/set/create/](doc:1740572891104257).
If you want to have products selected from a product set at the ad level, creating a product set is necessary. Otherwise, you can skip this step.
  5. (Optional) Invite members to Business Center and grant the admin permission using [/bc/member/invite/](doc:1739939455765505). 
You can also choose `advertiser_role` that you want to assign to the members invited.
  6. (Optional) Share a catalog with members and grant catalog management access using [/bc/asset/assign/](doc:1739438211077121). 
Make sure to specify `CATALOG` in the `asset_type` field and `ADMIN` in the `catalog_role` field.
