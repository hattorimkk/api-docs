# Return codes
> Đường dẫn: Business Messaging API > Return codes
The following table lists the common return codes for unsuccessful calls to Business Messaging API.

| Code | Description |
|---|---|
| 40001 | No permission to perform the related operation. ⏎ **Error handling**: Ensure that you have the necessary permissions and try again. |
| 40002 | Parameter error. Please see error message for details. ⏎ **Common causes**: • missing required fields. • incorrect format of field values. • unsupported field values or fields. • incompatibility between passed fields or field values. ⏎ **Error handling**: Refer to the API documentation for the correct usage of the parameters and try again. |
| 40007 | The operation/object does not exist. ⏎ **Common causes**: • specifying an object that doesn't exist. • specifying a deprecated URL or a file that doesn't exist. ⏎ **Error handling**: Ensure that the object you are operating on exists and validate any URLs used, then try again. |
| 40100 | Requests made too frequently. ⏎ **Common causes**: The rate limit level has been reached, thus your request is throttled. ⏎ **Error handling**: Refer to [Rate limits](doc:1740029171730433) to learn about global rate limits or contact TikTok representative to find out which rate limit rule restricts your requests. |
| 40105 | Invalid or incorrect access token. ⏎ **Error handling**: Use a valid access token and try again. ⏎ To learn about how to generate an access token for Business Messaging API, refer to [Authentication](doc:1832184175482945). |
| 40908 | The file type is unsupported. ⏎ **Error handling**: Ensure that you use a supported file type and try again. |
| 40064 | The message is blocked due to limitation of direct message rules. ⏎ **Error handling**: Contact TikTok representative to find out which rule restricts your messages. |
| 51065 | System error. ⏎ **Error handling**: Retry the call. If retries don't work, contact TikTok representative for help. |
