# Obtain a long-term access token
> Đường dẫn: API Reference > Authentication > Obtain a long-term access token
Use one of the two endpoints to generate a long-term access token: `/oauth2/access_token/` and `/oauth/token/`. 

A long-term access token is a type of token that you can obtain after receiving authorization from an ad account, a Business Center account, or a TikTok One Creator Marketplace account. The token does not expire. If you want to revoke a long-term access token, use [/oauth2/revoke_token/](doc:1739965949088770).

>  **Note:** 
>  **`/oauth2/access_token/` only supports `Content-Type` as `application/json`, while `/oauth/token/` supports `Content-Type` as `application/json` or `application/x-www-form-urlencoded`.**

## /oauth2/access_token/
Use this endpoint to get a long-term access token that does not expire.

The only supported `Content-Type` value is `application/json`. To generate an access token via `Content-Type` as `application/x-www-form-urlencoded`, see the **/oauth/token/** section below.

### Request 

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/oauth2/access_token/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type ⏎ Accepted format: `"application/json"` |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| app_id **(Required)** | string | ID of your developer app. ⏎ To find the **App ID**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| secret **(Required)** | string | Secret of your developer app. ⏎ To find the **Secret**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| auth_code  **(Required)** | string | The authorization code (`auth_code`) generated by your **Advertiser authorization URL**. ⏎ The code is valid for one hour and can only be used once. ⏎ To find out how to get the authorization code based on the type of API you use, see the "**Authorization URL**" row in [Comparing authorization for different APIs](doc:1781891256601602). |
| return_advertiser_ids | boolean | Whether to return the full list of ad accounts that the generated token can access through `advertiser_ids` in the response. ⏎ Supported values: `true`, `false`. ⏎ Default value: `true`. ⏎ **Note**: If you have access to thousands of ad accounts or more, setting this field to `false` can prevent timeouts when retrieving the full list of all advertiser IDs in the response. |

#### Example
```http
// curl
curl --location -request POST 'https://business-api.tiktok.com/open_api/v1.3/oauth2/access_token/' \
--header 'Content-Type: application/json' \
--data '{
    "app_id": "{{app_id}}",
    "secret": "{{secret}}",
    "auth_code": "{{auth_code}}"
}'
```

### Response

| Field | Type | Description |
|---|---|---|
| code | number | Return code. For the complete list of response codes and descriptions, see [Return codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Return codes](doc:1737172488964097). |
| request_id | string | The unique ID of the request. |
| data | object | Return data. |
| ↳ access_token | string | The long-term access token for permission verification |
| ↳ advertiser_ids | string[] | The list of ad accounts that the token can access. ⏎ When `return_advertiser_ids` is set to `false` in the request, this field will be an empty string array (`[]`). |
| ↳ scope | number[] | The scope of permissions granted to the access token. ⏎ See [Permission scope](doc:1753986142651394) to learn about the permission that a scope ID (value of `scope`) corresponds to. |

#### Example
```http
// Success-Response
HTTPS/1.1 200 OK
{
  "message": "OK",
  "code": 0,
  "data": {
    "access_token": "xxxxxxxxxxxxx",
    "scope": [
      4
    ],
    "advertiser_ids": [
      "123456789",
      "123456781"
    ]
  },
  "request_id": "2020042715295501023125104093250"
}
```
## /oauth/token/
Use this endpoint to get an access token. The supported `Content-Type` values are `application/x-www-form-urlencoded` and `application/json`. This is a new endpoint in TikTok API for Business v1.3.
 
### Request 
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/oauth/token/

**Method** POST
 
**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type ⏎ Accepted format: [`application/x-www-form-urlencoded`, `application/json`] |

 
**Parameters**

| Field | Data Type | Description |
|---|---|---|
| client_id  **(Required)** | string | ID of your developer app. ⏎ To find the **App ID**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| client_secret  **(Required)** | string | Secret of your developer app. ⏎ To find the **Secret**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| code  **(Required)** | string | The authorization code (`auth_code`) generated by your **Advertiser authorization URL**. ⏎ The code is valid for one hour and can only be used once. ⏎ To find out how to get the authorization code based on the type of API you use, see the "**Authorization URL**" row in [Comparing authorization for different APIs](doc:1781891256601602). |
| grant_type  **(Required)** | string | The way of generating the access token. ⏎ The allowed enum value: `authorization_code` (To generate the access token by authorization code). |

#### Example

##### `Content-Type` as `application/x-www-form-urlencoded`
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/oauth/token/' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'grant_type=authorization_code' \
--data-urlencode 'client_id={{client_id}}' \
--data-urlencode 'client_secret={{client_secret}}' \
--data-urlencode 'code={{code}}'
```
 
##### `Content-Type` as `application/json`
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/oauth/token/' \
--header 'Content-Type: application/json' \
--data-raw '{
    "grant_type": "authorization_code",
    "client_id": "{{client_id}}",
    "client_secret": "{{client_secret}}",
    "code": "{{code}}"
}'
```
 
### Response

| Field | Type | Description |
|---|---|---|
| code | number | Response code. For the complete list of response codes and descriptions, see [Return codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Return codes](doc:1737172488964097). |
| request_id | string | The log ID of a request, which uniquely identifies the request. |
| access_token | string | The long-term access token for permission verification. |
| token_type | string | Token type. Enum values: `Bearer` (Bearer token. Anyone in possession of the token can use it to access the associated resources). |
| advertiser_ids | string[] | The list of ad accounts that the token can access. |
| scope | number[] | The endpoints that the token can access. ⏎ See [Permission scope](doc:1753986142651394) to learn about the permission that a scope ID (value of `scope`) corresponds to. |
