# Get a suggested bid
> Đường dẫn: API Reference > Tools > Get a suggested bid
Use this endpoint to get a suggested bid value for your ad group based on basic campaign and ad group settings like objectives, conversion events, and locations. Note that the suggested bid can only be used with Cost Cap bidding strategy (`bid_type = BID_TYPE_CUSTOM`).

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tool/bid/recommend/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| campaign_id | string | Campaign ID. |
| objective_type  **(Required)** | string | Campaign objective. The current API endpoint only supports Traffic and Website conversions objectives. For enum values and descriptions, see [Objectives](doc:1737585562434561). ⏎ **Note**: This API is being revamped to support larger function scope and more accurate result. Please stay tuned for updates. |
| location_ids  **(Required)** | string[] | IDs of the locations that you want to target. |
| external_action | string | Conversion event for the ad group. |

### Example

```http
// curl
curl -H "Access-Token:xxx" -H "Content-Type:application/json" -X POST \
-d '{
    "advertiser_id": "ADVERTISER_ID",
    "campaign_id": "CAMPAIGN_ID",
    "objective_type": "OBJECTIVE_TYPE",
    "locations": [
        "LOCATIONS"
    ],
    "external_action": "EXTERNAL_ACTION"
}' \
https://business-api.tiktok.com/open_api/v1.3/tool/bid/recommend/
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Response code. For the complete list of error codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| request_id | string | The log ID of a request, which uniquely identifies the request. |
| data | object | Returned data. |
| ↳ bid | number | Recommended bid value. |
