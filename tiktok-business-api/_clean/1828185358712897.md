# Get TTO Public Account Insights
> Đường dẫn: API Reference > TikTok One > Get TTO Public Account Insights
Use this endpoint to get the basic profile information of a creator on [TikTok One (TTO) Creator Marketplace](https://ads.tiktok.com/creative/creatormarketplace).

## Comparing TCM and TTO Creator Marketplace endpoints

The following table outlines the differences between TikTok Creator Marketplace (TCM) and TTO Creator Marketplace endpoints.

| Changes | TCM Endpoint | TTO Creator Marketplace Endpoint |
|---|---|---|
| Endpoint path | /v1.3/tcm/creator/public/ | /v1.3/tto/tcm/creator/public/ |
| Same request parameters | `handle_name` | `handle_name` |
| Deprecated request parameters | N/A | `tcm_account_id` |
| New request parameters | N/A | `tto_tcm_account_id` |
| Same response parameters | `profile_image` ⏎ `handle_name` ⏎ `display_name` ⏎ `followers_count` ⏎ `likes_count` ⏎ `videos_count` ⏎ `creator_id` ⏎ `bio` | `profile_image` ⏎ `handle_name` ⏎ `display_name` ⏎ `followers_count` ⏎ `likes_count` ⏎ `videos_count` ⏎ `creator_id` ⏎ `bio` |
| New response parameters | N/A | `following_count` ⏎ `median_views` ⏎ `engagement_rate` ⏎ `creator_price` ⏎ `currency` ⏎ `industry_labels` ⏎ `content_labels` ⏎ `reached_audience_ages` ⏎ `reached_audience_countries` ⏎ `reached_audience_devices` ⏎ `reached_audience_followers` ⏎ `reached_audience_genders` ⏎ `reached_audience_personas` ⏎ `engaged_audience_ages` ⏎ `engaged_audience_countries` ⏎ `engaged_audience_devices` ⏎ `engaged_audience_followers` ⏎ `engaged_audience_genders` ⏎ `engaged_audience_personas` ⏎ `audience_ages` ⏎ `audience_countries` ⏎ `audience_devices` ⏎ `audience_usages` ⏎ `audience_genders` ⏎ `creator_labels` ⏎ `country_code` |

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tto/tcm/creator/public/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by a TTO Creator Marketplace account. ⏎ For details, see [Authentication](slug:obtain-authorization-and-authentication-from-a-tto-creator-marketplace-account). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|---|---|---|
|tto_tcm_account_id {Required}|string|The ID of the TTO Creator Marketplace account.<br><br>To obtain the IDs of the accounts that you can access via `Access-Token`, use [/tto/oauth2/tcm/](doc:1815693478150146).|
|handle_name {Required}|string|The handle name of the TTO Creator Marketplace creator that you want to search for.<br><br>The exact match is supported.<br><br><span style="color:darkred"><b>Note</b></span>: If you specify the handle name of a creator that is not on TTO Creator Marketplace yet, an error will occur.|
``` 

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/tto/tcm/creator/public/?tto_tcm_account_id={{tto_tcm_account_id}}&handle_name={{handle_name}}' \
--header 'Access-Token: {{Access-Token}}'
```
