# Register a client application
> Đường dẫn: API Reference > MCP Authorization > Register a client application
Use this endpoint to register a client application with the authorization server and receive a `client_id`.

You only need to register once, and then you can reuse the returned `client_id` for every subsequent authorization request.

# Request
**Endpoint** https://business-api.tiktok.com/open_mcp/{server}/oauth/register/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Path parameters**

| Field | Data Type | Description |
|---|---|---|
| server  **(Required)** | string | The specific TikTok for Business MCP server URL. ⏎ Enum values: `tt-ads-mcp-flat`, `tt-ads-mcp-layer`. ⏎ To learn more about how these server URLs differ, see [Choose your server URL](https://business-api.tiktok.com/portal/docs/how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server/v1.3#anchor-3). |

**Body parameters**

| Field | Data Type | Description |
|---|---|---|
| client_name  **(Required)** | string | The human-readable name of your client application. Provide a non-empty string after trimming. ⏎ Length limit: 128 characters. |
| redirect_uris  **(Required)** | string[] | A list of redirect URIs (callback URLs) for your client application. ⏎ These act as the allowed "return addresses" where the server will redirect the user along with the authorization code after they grant access. ⏎ Max size: 5. ⏎ Length limit per URI: 1024 characters. ⏎ Provide non-empty URIs that include a scheme, omitting any fragments (`#...`) or user info (`user:pass@...`). You may use `http://` exclusively for loopback hosts (`localhost`, `127.0.0.1`, `::1`), while `javascript:`, `data:`, and `file:` schemes are strictly rejected. |
| token_endpoint_auth_method | string | The authentication method for the token endpoint. ⏎ Enum value: • `none`: You do not need to provide a client secret or additional authentication credentials. ⏎ Default value: `none`. |
| grant_types | string[] | The requested methods for granting tokens. ⏎ Enum values: • `authorization_code`: To exchange an authorization code for an access token. •  `refresh_token`: To exchange your refresh token for a new access token.. ⏎ Default value: `["authorization_code", "refresh_token"]`. |
| response_types | string[] | The list of requested response types. ⏎ Enum value: • `code`: You will receive an authorization code to exchange for a token. ⏎ Default value: `["code"]`. |

## Example

> **Note:** 
> The example below uses `tt-ads-mcp-layer` as the `{server}` value. You can replace this with your chosen server value.

```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer/oauth/register' \
--header 'Content-Type: application/json' \
--data '{
    "client_name": "{{client_name}}",
    "redirect_uris": [
        "{{redirect_uri}}"
    ],
    "token_endpoint_auth_method": "none",
    "grant_types": [
        "authorization_code",
        "refresh_token"
    ],
    "response_types": [
        "code"
    ]
}'
```

# Response

A successful registration returns HTTP `201 Created`.

| Field | Data Type | Description |
|---|---|---|
| client_id | string | The registered client ID assigned to your client application. |
| client_id_issued_at | integer | The time when the client registration occurred, in the format of an Epoch/Unix timestamp in seconds. ⏎ Example: 1784928815. |
| redirect_uris | string[] | The list of registered redirect URIs associated with your client application. |
| token_endpoint_auth_method | string | The token endpoint authentication method assigned to your registration. ⏎ Enum value: • `none`: You do not need to provide a client secret or additional authentication credentials. |
| grant_types | string[] | The list of grant types configured for your client. ⏎ Enum values: • `authorization_code`: To exchange an authorization code for an access token. •  `refresh_token`: To get a new access token when the old one expires. |
| response_types | string[] | The list of response types configured for your application. ⏎ Enum value: • `code`: You will receive an authorization code to exchange for a token. |

## Example
```http
// curl
{
    "client_id": "{{client_id}}",
    "client_id_issued_at": 1784928815,
    "grant_types": [
        "authorization_code",
        "refresh_token"
    ],
    "redirect_uris": [
        "{{redirect_uri}}"
    ],
    "response_types": [
        "code"
    ],
    "token_endpoint_auth_method": "none"
}
```

## Error response

A failure returns HTTP `400 Bad Request`.

| Field | Data Type | Description |
|---|---|---|
| error | string | Error code. ⏎ Registration validation failures return `invalid_client_metadata`. |
| error_description | string | The human-readable description of the error. |
