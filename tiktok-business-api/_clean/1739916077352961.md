# Check the status of a download task
> Đường dẫn: API Reference > Change Log > Check the status of a download task
Use this endpoint to check whether a change log download task has completed or not.

## Request

**Endpoint**  
https://business-api.tiktok.com/open_api/v1.3/changelog/task/check/

**Method** GET

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token {Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162). |
```

**Parameters**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|advertiser_id {Required}|string| Advertiser ID. |
|task_id {Required}|string| Task ID. |
```

### Example

``` xcodeblock
(code curl http)
curl --get -H "Access-Token:xxx" \
--data-urlencode "advertiser_id=ADVERTISER_ID" \
--data-urlencode "task_id=TASK_ID" \
https://business-api.tiktok.com/open_api/v1.3/changelog/task/check/
(/code)
```

## Response
``` xtable
|Field|Data Type|Description|
|---|---|---|
|code |number|Return code, see [Appendix-Return code](doc:1737172488964097). |
|message |string|Return messages, see [Appendix-Return information](doc:1737172488964097).|
|data |object|Return data|
#|status |string| Task status values: <ul><li>`PROCESSING`</li> <li>`SUCCESS`</li><li>`FAILED`</li></ul>|
|request_id |string|The log id of a request, which uniquely identifies the request.|
```
