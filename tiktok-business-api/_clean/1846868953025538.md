# Link a TikTok account to an ad account in Business Center
> Đường dẫn: API Reference > BC Assets > Link a TikTok account to an ad account in Business Center
Use this endpoint to link a TikTok account to an ad account in a Business Center.

Once the linkage is completed, Business Center members with access to the linked ad accounts can use the TikTok account for ad delivery across these ad accounts.

## Before you start
You need to be an Admin user of the Business Center. To confirm your permission to a Business Center, use [/bc/get/](doc:1737115687501826) and confirm whether the returned `user_role` is `ADMIN`.

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/bc/asset/advertiser/assign/

**Method** POST

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. ⏎ For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `application/json`. |

**Parameters**

| Field | Type | Description |
|---|---|---|
| bc_id  **(Required)** | string | Business Center ID. ⏎ To obtain the list of Business Centers that you can access, use [/bc/get/](doc:1737115687501826). |
| asset_type | string | Asset type. ⏎ Enum values: • `TT_ACCOUNT`: TikTok account as an ad delivery asset. You can run ads from these TikTok accounts. • `MANAGED_BUSINESS_ACCOUNT`: TikTok account for Business Account management. You can run ads from these TikTok accounts, and manage messages, leads, forms, comments, product links, and insights in your TikTok account. ⏎ Default value: `TT_ACCOUNT`. |
| asset_id  **(Required)** | string | The ID of a TikTok account in a Business Center. ⏎ To obtain the list of TikTok accounts within a Business Center, use [/bc/asset/get/](doc:1739432717798401) and set `asset_type` to `TT_ACCOUNT` or `MANAGED_BUSINESS_ACCOUNT`. |
| advertiser_id  **(Required)** | string | The ID of an ad account within the same Business Center to link the TikTok account to. ⏎ To obtain the list of ad accounts within a Business Center, use [/bc/asset/get/](doc:1739432717798401) and set `asset_type` to `ADVERTISER`. |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/bc/asset/advertiser/assign/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "bc_id": "{{bc_id}}",
    "asset_id": "{{asset_id}}",
    "advertiser_id": "{{advertiser_id}}"
}'
```
