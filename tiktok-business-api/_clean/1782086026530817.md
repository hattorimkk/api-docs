# Create Traffic ads
> Đường dẫn: Use Cases > Campaign creation > Create Traffic ads
This article walks you through the steps to create Traffic ads.

# Introduction
Traffic is an ad objective that drives people to a destination. For instance, you can send people to your website or mobile app.
 
**You can use Campaign Management API to create Traffic ads, and this helps you streamline your ad creation experience, and elevate operational efficiency and scalability.**

# Prerequisites
- You've gained access to TikTok API for Business. See [Get Started - Step by step workflow](doc:1735713609895937) for details. 
  - To create Traffic ads, you need relevant permissions. See [API Reference](doc:1735713875563521) to find out permissions required for endpoints (including the endpoints listed in the "Steps" section) and see [Update app permissions](doc:1738855280338946) to find out how to configure permissions.  

# Use Cases
