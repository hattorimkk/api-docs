# Get languages
> Đường dẫn: API Reference > Tools > Get languages
Use this endpoint to get the enum values of language codes.

After you obtain the language codes, you can pass them to `languages` in [/adgroup/create/](doc:1739499616346114) for language targeting.

## Request

**Endpoint**
https://business-api.tiktok.com/open_api/v1.3/tool/language/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID |

### Example
```http
// curl
curl --get -H "Access-Token:xxx" \
--data-urlencode "advertiser_id=ADVERTISER_ID" \
https://business-api.tiktok.com/open_api/v1.3/tool/language/
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Return code. For the complete list of response codes and descriptions, see [Appendix-Return codes](doc:1737172488964097). |
| message | string | Return message. For details, see [Appendix-Return codes](doc:1737172488964097). |
| data | object | Returned data. |
| ↳ languages | object[] | Language list. |
| ↳↳ code | string | Language code. You can pass the value of this field to `languages` in [/adgroup/create/](doc:1739499616346114) for language targeting. ⏎ Example: `en`. |
| ↳↳ name | string | Language name. ⏎ Example: `English`. |
| request_id | string | The log id of a request, which uniquely identifies the request. |
