# Save a playable asset
> Đường dẫn: API Reference > Playable Ads > Save a playable asset
Use this endpoint to save a playable asset.

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/playable/save/

**Method** POST

**Header**
``` xtable
| Field | Type | Description |
|---|---|---|
| Access-Token {Required} | string | Authorized access token. For details, see [Authentication](doc:1738373164380162).|
| Content-Type {Required} | string | Request Message Type <br> Allowable value: `application/json` |
```
**Parameters**
``` xtable
| Field | Type | Description |
|---|---|---|
| advertiser_id {required} | string | Advertiser ID. |
| playable_id {required} | string | Playable asset ID. |
| playable_name {required} | string | Playable asset name. |
```

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/playable/save/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "advertiser_id": "{{advertiser_id}}",
    "playable_id": "{{playable_id}}",
    "playable_name": "{{playable_name}}"
}'
```

## Response
``` xtable
| Field | Type | Description |
|---|---|---|
|code |number|Return code. For the complete list of response codes and descriptions, see [Appendix-Return code](doc:1737172488964097).  |
|message |string|Return message. For details, see [Appendix-Return information](doc:1737172488964097).  |
| request_id | string | The log id of a request, which uniquely identifies the request. |
|data |object|Returned data.|
#| playable_id | string | Playable asset ID. |
#| playable_url | string | Playable URL. |
#| playable_name | string | Playable asset name. |
#| playable_orientation | string | Playable asset orientation.<br><br>Enum values:<ul><li>`BOTH`: vertical or horizontal.</li><li>`LANDSCAPE`: horizontal.</li><li>`PORTRAIT`: vertical.</li></ul>|
#| status | string | Playable asset status. <br><br>Enum values:`AUDIT_FAIL`,`AUDIT_SUCCESS`, `VALIDATE_FAIL`, `VALIDATE_SUCCESS`, `VALIDATING`. |
```
