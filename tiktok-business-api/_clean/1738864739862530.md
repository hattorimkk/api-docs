# Reporting
> Đường dẫn: Marketing API > Reporting
You can use Reporting API to run a report on your auction ads and reservation ads data, in synchronous mode or asynchronous mode. 
- To learn about an overview of Reporting API, see [Overview](doc:1751087777884161).  
- To learn about synchronous and asynchronous reports, and different report types,  see [Guides](doc:1751087792726017). 
  - [Synchronous and asynchronous reports](doc:1751088469160001): Introduces how to run synchronous and asynchronous reports.
  - [Report types](doc:1738864835805186): Introduces the **use cases** of basic reports, audience reports, playable ads reports, DSA reports, Business Center reports, and GMV max ads reports, and their supported dimensions, metrics and filters. 
  - [Best practices](doc:1738864817670145): Introduces the best practices to avoid or reduce time-outs in synchronous reports. 
  - [Data latency for reports](doc:1738864894606337): Introduces the data latency you might expect when using Reporting API. 
  - [FAQs](doc:1738864850353154): Introduces common questions about Reporting API. 
- To find out what APIs are available for running a report, see [API reference](doc:1740649343188994).
