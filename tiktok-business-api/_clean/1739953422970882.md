# Update the statuses of ads
> Đường dẫn: API Reference > Ads > Update the statuses of ads
Use this endpoint to enable, disable or delete an ad or ads. 

> **Note:** 
> The operation status of a deleted ad or an ad in a deleted ad group or campaign cannot be modified. You can use [/campaign/get/](doc:1739315828649986), [/adgroup/get/](doc:1739314558673922), or [/ad/get/](doc:1735735588640770) to get the operation status of a campaign, an ad group or an ad via `operation_status`.

## Request

**Endpoint** `https://business-api.tiktok.com/open_api/v1.3/ad/status/update/`

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |
| Content-Type  **(Required)** | string | Request message type. Allowed format: `"application/json"`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| ad_ids {+Conditional} | string[] | A list of ad IDs. Allowed quantity: `1-20`. Either `ad_ids` or `aco_ad_ids` has to be set. |
| aco_ad_ids{+Conditional} | string[] | A list of ACO ad IDs. Only support `ENABLE` and `DISABLE` for ACO ads.  Allowed quantity: `1-20`. Either `ad_ids` or `aco_ad_ids` has to be set. |
| advertiser_id  **(Required)** | string | Advertiser ID |
| operation_status  **(Required)** | string | The operation being made. ⏎ Enum values: `DELETE` (delete),` DISABLE` (pause), `ENABLE` (enable). ⏎ **Note**: The status of deleted ads or ads in deleted campaigns or ad groups cannot be modified. |

### Example

```http
// curl
curl -H "Access-Token:xxx" -H "Content-Type:application/json" -X POST \
-d '{
    "advertiser_id": "ADVERTISER_ID",
    "operation_status": "OPT_STATUS",
    "ad_ids": [
        "AD_IDS"
    ]
}' \
https://business-api.tiktok.com/open_api/v1.3/ad/status/update/
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Return code, see [Appendix-Return Code](doc:1737172488964097). |
| message | string | Return message, see [Appendix-Return information](doc:1737172488964097). |
| data | object | Return data |
| ↳ ad_ids | string[] | List of updated ad IDs |
| ↳ aco_ad_ids | string[] | List of updated ACO ad IDs |
| ↳ status | string | The operation that was executed. Enum values: `DELETE`,`DISABLE`, `ENABLE` |
| request_id | string | The log id of a request, which uniquely identifies the request. |
