# (To be deprecated) Create Legacy Smart+ Web Campaigns
> Đường dẫn: Use Cases > Campaign creation > (To be deprecated) Create a Legacy Smart+ Campaign > (To be deprecated) Create Legacy Smart+ Web Campaigns
This article introduces how to create Smart+ Web Campaigns.

Based on your preference for the specific type of web campaign, you can create regular Smart+ Web Campaigns, Smart+ Catalog Ads, or (to-be-deprecated) Smart Performance Web campaigns. For detailed instructions on creating each type, refer to their respective sections: "Create a regular Smart+ Web Campaign",  "Create Smart+ Catalog Ads", and "Create a Smart Performance Web Campaign".

> **Note:** 
> Smart Performance Web Campaigns will be deprecated in the next API version. To ensure a smooth API integration, we recommend that you upgrade to Smart+ Web Campaigns as soon as possible. Smart+ Web Campaigns are a new AI-powered automation solution that leverages machine learning to drive business outcomes for advertisers.

# Create a regular Smart+ Web Campaign
A regular Smart+ Web Campaign is a Smart+ Web Campaign that doesn't use catalog products to deliver ads. For such campaigns, you can set `web_all_in_one_catalog_status` to `UNSET` or leave the `web_all_in_one_catalog_status` parameter unspecified.

## Steps
Note that the following requirements must be met. To find a complete list of parameters, see [/campaign/spc/create/](doc:1767334204047362).

> **Note:** 
> Regular Smart+ Web ad groups cannot be used in [/split_test/create/](doc:1742666471475201) to create split test groups.

# Create Smart+ Catalog Ads
Smart+ Catalog Ads are Smart+ Web Campaigns that use catalog products to deliver ads. For such campaigns, you need to set `web_all_in_one_catalog_status` to `OPEN`. By utilizing Smart+ Catalog Ads, you can automatically generate ads in diverse formats such as catalog video, catalog carousel, and single video.

## Prerequisite
Creating Smart+ Catalog Ads requires setting up an E-commerce catalog in your Business Center first.

To set up the catalog:
1. Create an **E-commerce** catalog using [/catalog/create/](doc:1740306481704961). 
2. Upload products to the catalog using [/catalog/product/upload/](doc:1740497429681153) (JSON schema), [/catalog/product/file/](doc:1740496787164161) (CSV feed template), or [/catalog/feed/create/](doc:1740665161957377)(online data feed schedule).
3. Check the product handling results using [/catalog/product/log/](doc:1740570027173889). 
Pass in the `feed_log_id` obtained from Step 2. If the field `warn_affected_products` in the response is not null, examine the issue details and return to Step 2 to reupload the product.
4. (Optional) Create an E-commerce product set using [/catalog/set/create/](doc:1740572891104257).
If you want to have products selected from a product set, creating a product set is necessary. Otherwise, you can skip this step.
5. (Optional) Invite members to Business Center and grant the admin permission using [/bc/member/invite/](doc:1739939455765505). 
You can also choose `advertiser_role` that you want to assign to the members invited.
6. (Optional) Share a catalog with members and grant catalog management access using [/bc/asset/assign/](doc:1739438211077121). 
Make sure to specify `CATALOG` in the `asset_type` field and `ADMIN` in the `catalog_role` field.

For all catalog APIs, see [here](doc:1739578477445121).

Note that the following requirements must be met. To find a complete list of parameters, see [/campaign/spc/create/](doc:1767334204047362).
