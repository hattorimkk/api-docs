# Smart Creative
> Đường dẫn: API Reference > Smart Creative
Smart Creative is a TikTok automated creative solution that optimizes ad creative combinations through ad group fatigue detection and auto-refresh strategies. This feature reduces ad fatigue, prolongs ad group lifespan, and improves cost efficiency over time.

To learn about how to enable Smart Creative for your ad groups, see [Smart Creative](doc:1767322784934914).

This group consists of the following endpoints: 
* [Create Smart Creative ads](doc:1739473063234626)
* [Get Smart Creative materials](doc:1739473020978177)
* [Update Smart Creative materials](doc:1739473077112833)
* [Update the statuses of Smart Creative materials](doc:1739506701165570)
