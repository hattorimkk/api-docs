# Upload a playable asset
> Đường dẫn: API Reference > Playable Ads > Upload a playable asset
Use this endpoint to upload a playable asset.

## Request

**Endpoint**
https://business-api.tiktok.com/open_api/v1.3/playable/upload/

**Method** POST

**Header**
``` xtable
| Field | Type | Description |
|---|---|---|
| Access-Token {Required} | string | Authorized access token. For details, see [Authentication](doc:1738373164380162).|
| Content-Type {Required} | string | Request message type <br> Allowable value:`"multipart/form-data"` |
```
**Parameters**
``` xtable
| Field | Type | Description |
|---|---|---|
| advertiser_id {Required} | string | Advertiser ID. |
| upload_type | string | The way you upload your playable assets. <br><br>Enum values: `UPLOAD_BY_FILE`, `UPLOAD_BY_FILE_ID`.<br>Default value: `UPLOAD_BY_FILE`. |
| playable_package {+Conditional} | file |Required when `upload_type` is `UPLOAD_BY_FILE`.<br><br> The playable asset file. <br><br> Specification requirements:<br> 1. The format is ZIP, and the size is no more than 5 MB. <br> 2. Playable JS-SDK has been accessed, and the calling method is `window.openAppStore();`<br> 3. The main HTML file needs to be named `index.html` and located in the primary directory. <br> 4. The `playable_orientation` field should be stored in the `config.json` file and located in the first directory, with a value of 0 (`BOTH`), 1 (`PORTRAIT`), or 2 (`LANDSCAPE`). Example: `&#123; "playable_orientation": 0, &#125;`.<br> 5. File names only support uppercase and lowercase letters, numbers, minus signs and underscores. <br> 6. The `mraid.js` format is not allowed in the file. <br>7. The file is not allowed to load dynamic material over an external network. <br> 8. JS redirection is not allowed in the file. <br>9. The file does not allow an HTTP request. <br> 10. A file with empty content is not allowed. |
|file_id{+Conditional}| string | Required when `upload_type` is `UPLOAD_BY_FILE_ID`.<br><br>The `file_id` of the file that you want to upload. This field is for files that are uploaded to the file repository. <br>You can get `file_id` via the [Files](slug:files) endpoints. |
```
### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/playable/upload/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: multipart/form-data' \
--form 'advertiser_id="{{advertiser_id}}"' \
--form 'upload_type="UPLOAD_BY_FILE"' \
--form 'playable_package=@"{{playable_package}}"'
```
