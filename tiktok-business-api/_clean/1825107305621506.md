# Rate limits for Mentions API
> Đường dẫn: Organic API > Mentions API > Guides > Get started > Rate limits for Mentions API
Global rate limits are applicable to Mentions API endpoints. To learn about the global rate limits for a developer application, refer to [Developer app-level rate limits](https://business-api.tiktok.com/portal/docs/rate-limits/v1.3#anchor-1).

We recommend limiting your calls to each Mentions endpoint for each TikTok account to no more than one time per day. The data for the previous day will be refreshed daily between 0 am and 7 am UTC Time the following day. Therefore, we recommend pulling the data after 7 am UTC to ensure you have the most up-to-date information. Excessive calls to the endpoints within the same day are unnecessary.
