# Get the authorized TikTok account permission scopes via access token
> Đường dẫn: API Reference > Accounts > Access token inspector > Get the authorized TikTok account permission scopes via access token
Use this endpoint to get the permission scopes of a TikTok account that are authorized by the TikTok account user. 

If you want to get the permission scopes of a TikTok creator account (which is a TikTok Personal Account) authorized by a creator on TikTok Creator Marketplace, see [here](slug:obtain-the-authorized-creator-permissions).

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tt_user/token_info/get/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| app_id  **(Required)** | string | ID of your developer application. ⏎ You can find the **App ID** by navigating to **[My Apps](https://ads.tiktok.com/marketing_api/apps/)** > **App Detail** > **Basic Information**. |
| access_token  **(Required)** | string | Access token authorized by TikTok accounts. ⏎ For details, see [Authentication](doc:1738084387220481). |

### Example

```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tt_user/token_info/get/'
--header 'Content-Type: application/json'
--data-raw '{
    "app_id":"{{app_id}}",
    "access_token":"{{access_token}}"
}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | The return code. For the complete list of error codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | The return message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| request_id | string | The log id of a request, which uniquely identifies the request. |
| data | object | Returned data. |
| ↳ app_id | string | ID of your developer application. |
| ↳ scope | string | Scope of permissions for the specified access token. ⏎ For instance, `"user.info.basic,video.list"`. |
| ↳ creator_id | string | Application specific unique ID of the TikTok Account. ⏎ **Note**: You can pass the value of this field to the parameter `business_id` in [Accounts API](doc:1737944775511041) requests. |
