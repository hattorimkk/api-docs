# Check the verification status of your account
> Đường dẫn: API Reference > Verification > Check the verification status of your account
Use this endpoint to retrieve the current verification status of your Business Center or ad account.

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/account/verification/status/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id {+Conditional} | string | Either `advertiser_id` or `bc_id` has to be set. ⏎ The ID of the ad account that you want to check the verification status for. ⏎ To retrieve the list of ad accounts that you can access, use [/bc/asset/get/](slug:get-assets) and set `asset_type` to `ADVERTISER`. |
| bc_id {+Conditional} | string | Either `advertiser_id` or `bc_id` has to be set. ⏎ The ID of the Business Center account that you want to check the verification status for. ⏎ To retrieve the list of Business Centers that you can access, use [/bc/get/](slug:get-business-centers). |

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/account/verification/status/?advertiser_id={{advertiser_id}}' \
--header 'Access-Token: {{Access-Token}}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| - | - | - |
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](slug:return-codes-appendix). |
| message | string | Response message. For details, see [Appendix - Return Codes](slug:return-codes-appendix). |
| request_id | string | The log ID of the request, which uniquely identifies a request. |
| data | object | Returned data. |
| ↳ qualification_id | string | The qualification image ID of the verification document you submitted for your Business Center or ad account. ⏎ If you want to create Organization Accounts within an Agency Business Center, you can pass this ID to `qualification_id` in [/bc/oa/create/](slug:create-an-organization-account-in-a-business-center). |
| ↳ verification_status | string | The current verification status of the ad account or Business Center account. ⏎ Enum values: • `NOT_SUBMITTED`: The verification has not been submitted. • `REVIEWING`: The verification is currently under review. • `VERIFIED`: The account has been verified successfully. • `FAILED`: The verification has failed. • `EXPIRED`: The verification has expired. |
| ↳ rejection_reason | string | Returned only when `verification_status` is `FAILED`. ⏎ The reason for rejecting the verification request. ⏎ For common rejection reasons and troubleshooting suggestions, see [List of common rejection reasons and suggestions for verification failures](https://ads.tiktok.com/help/article/list-of-common-rejection-reasons-and-suggestions-for-verification-failures). |
| ↳ audit_time | string | The time when the review of the verification request was completed, in the format of `YYYY-MM-DD HH:MM:SS` (UTC+0 time). ⏎ Example: `2026-07-08 10:30:58`. |
