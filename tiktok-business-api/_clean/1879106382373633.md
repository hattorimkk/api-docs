# Troubleshoot MCP server issues
> Đường dẫn: Skill and MCP management > Get started with MCP server management > Troubleshoot MCP server issues
This section covers recovery workflows for common issues encountered during the MCP server registration lifecycle.

## Resubmit a rejected MCP server
If your MCP server is rejected during the initial review, the TikTok team provides specific, actionable feedback explaining the issues. Address the feedback, update your MCP server, and resubmit for another evaluation cycle. Resolving all identified issues thoroughly reduces the likelihood of repeated rejections.

**Steps**

1. On the My Agentic Hub page, locate the MCP server displaying a **Rejected** status and click **Manage**.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/6Fk04a9Pd2MkxUT1WuSbAm/5a4a8950ff96b7c528323e239a546b5e/locate_the_MCP_server_displaying_a_Rejected_status_and_click_Manage.png)

2. On the MCP server detail page, carefully review the rejection reasons provided by the TikTok review team. Each rejection includes specific feedback.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/69UA2xRhLxLBBNF9OvGSMG/f3a035cdd7d71c20a5339ffaf735ee53/carefully_review_the_rejection_reasons.png)

3. Click **Resubmit for Review** to re-open the upload form.

4. Update the relevant fields to address the feedback.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/6MsyRy4DHGPkYDIL8M1bOV/8e7684a0919d3c3a918226035b52efd4/Update_the_relevant_fields.png)

> **Important:** 
> The **Server name** field is permanent and cannot be modified after the initial upload. If the rejection feedback relates to your Server name, you must delete the server and register a new one with the desired name. See [Register a new MCP server](https://business-api.tiktok.com/portal/docs/register-mcp-servers/v1.3#anchor-0-2).

5. Click **Submit Version** to finalize your resubmission.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/6YMubldABNagC5O0e9xdEA/fa60091dea278ce75963e0342e68c76f/Click_Submit_Version_for_resubmission.png)

**What happens next**

Your MCP server re-enters the review queue. Track the status from the **My Agentic Hub** page.

## Handle a rejected version update
When you upload a new version of a published MCP server and that new version is rejected, your existing published version remains live and unaffected. Advertisers experience no disruption.

**How to identify a rejected version update**
- On the **My Agentic Hub** page, your MCP server continues to display a **Published** status (because the original version is still live).

![Asset](https://images.ctfassets.net/5jqet0ab9qci/1RkTl0RqxcBEFt8yCw56BU/dfc740e66de5f67417bf1f52534329bb/your_MCP_server_continues_to_display_a_Published_status.png)

- On the MCP server detail page, the new version displays a **Rejected** status alongside the reviewer's feedback.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/5mhjaOo5qD5mrchu8gQlZG/f48479c7c365b7f1e6dcdc399d7e99f7/The_new_version_shows_a_Rejected_status.png)

**Steps to resolve**

1. On the My Agentic Hub page, locate the MCP server and click **Manage**.

2. On the MCP server detail page, review the rejection feedback for the new version.

3. Click **Resubmit for Review** to re-open the upload form.

![Asset](https://images.ctfassets.net/5jqet0ab9qci/6nLaPVroX941TthO6jvE3E/3d790e2ad8159e171fc271abb7a6c019/Click_Resubmit_for_Review_to_re-open_the_upload_form.png)

4. Address the identified issues by updating the relevant fields.

5. Click **Submit Version** to resubmit.

After submission, the new version enters the review queue.
