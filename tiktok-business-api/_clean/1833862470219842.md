# Get valid brand mention hashtags for a TikTok account
> Đường dẫn: API Reference > Mentions > Get valid brand mention hashtags for a TikTok account
Use this endpoint to retrieve a list of valid hashtags that you can enable for a TikTok account. The results will include up to 100 top hashtags related to the TikTok account.  

To be valid for a TikTok account hashtag, the Hashtag must meet the following requirements:
- The hashtag is used in at least 3 post captions, published either by the TikTok account or in a post that mentions the TikTok account Handle.

You can enable valid hashtags for a TikTok account using [/business/mention/hashtag/add/](slug:enable-brand-hashtags-for-a-business-account). Once enabled, the hashtags will be factored into the results of [/business/mention/hashtag/video/list/](slug:get-mention-content-for-top-1000-brand-hashtag-posts). 

> **Note:** 
This endpoint is designed for accounts with substantial organic mention activity. Test accounts or newly created accounts may not return valid hashtags and should not be relied on for validation. For accurate testing results, you need to use a production account that receives real organic mentions.

## Before you start
- Ensure the TikTok account is a TikTok Account with Advanced Access or Verified Business Account. Learn more [about TikTok account entitlements](https://ads.tiktok.com/resources/help/article/about-tiktok-account-entitlements). To confirm this, use [/business/get/](slug:get-profile-data-of-a-tiktok-account) and check whether the response parameter `has_advanced_access` is `true` for the TikTok account.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/mention/hashtag/verify/list/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok accounts. ⏎ To obtain an access token, use [/tt_user/oauth2/token/](https://business-api.tiktok.com/portal/docs/mentions-api-authentication/v1.3#anchor-1). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
|business_id {Required}|string|Application specific unique identifier for the TikTok account.<br><br>You can get the ID through the `open_id` field returned by [/tt_user/oauth2/token/](https://business-api.tiktok.com/portal/docs/mentions-api-authentication/v1.3#anchor-1).|
| username {Required}  | string | The username (handle) of the TikTok account. |
```

### Example
```http
// curl
curl --location  --request GET 'https://business-api.tiktok.com/open_api/v1.3/business/mention/hashtag/verify/list/?business_id={{business_id}}&username={{username}}' \
--header 'Access-Token: {{Access-Token}}'
```
## Response

``` xtable
|Field{30%}|Type{15%}|Description{55%}|
|---|---|---|
|code |number|Response code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097). |
|message|string|Response message. For details, see [Appendix - Return Codes](doc:1737172488964097).|
|request_id |string|The log ID of a request, which uniquely identifies the request.  |
|data |object|Returned data.|
#| hashtag_list | object[] | The list of valid hashtags that you can enable for the TikTok account.|
##| hashtag | string | A valid hashtag that you can enable for the TikTok account.|
##| post_count | number | The total number of posts containing the hashtag in the post caption in the last 90 days.|
##| like_count | number | The total number of likes on posts containing the hashtag in the post caption in the last 90 days.|
##| mention_post_rank | number | The rank of the hashtag among all the valid hashtags for the TikTok account.|
```
