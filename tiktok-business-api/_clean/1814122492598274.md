# (To be deprecated) Create Legacy Smart+ App Campaigns
> Đường dẫn: Use Cases > Campaign creation > (To be deprecated) Create a Legacy Smart+ Campaign > (To be deprecated) Create Legacy Smart+ App Campaigns
This article introduces how to create Smart+ App Campaigns.

## Steps

Call [/campaign/spc/create/](doc:1767334204047362) to create Smart+ App Campaigns (`objective_type` = `APP_PROMOTION`). 

> **Note:** 
> Smart Performance App Campaigns have been automatically upgraded to Smart+ App Campaigns. 

The following table lists only some related parameters. To find a complete list of parameters, refer to the [/campaign/spc/create/](doc:1767334204047362) endpoint article and the following code example.  

| Setting | Requirement | Parameter | How to configure the parameter |
|---|---|---|---|
| Advertising objective | App promotion | `objective_type` | `APP_PROMOTION` |
| App promotion type | App install | `app_promotion_type` | `APP_INSTALL` |
| Optimization location ⏎ (Promotion type) | One of the following types:  • Android App •  iOS App | `promotion_type` ⏎ `app_id` | • To specify optimization location as Android App:  • Set `promotion_type` to `APP_ANDROID`. • Specify an Android App via `app_id`. • To specify optimization location as iOS App: • Set `promotion_type` to `APP_IOS`. • Specify an iOS App via `app_id`. To obtain the list of Apps under your ad account, use [/app/list/](doc:1740859313270786).  • For Android Apps, the returned `platform` will be `ANDROID`. • For iOS Apps, the returned `platform` will be `IOS`. |
| Placement | • For Android Apps, use **Automatic Placement**. • For iOS Apps, use **Automatic Placement**. | `placement_type` ⏎ `placements` | • If `promotion_type` is `APP_ANDROID`, and do not pass `placement_type` and `placements`.  • The system will automatically configure placements for your Smart+ Android App Campaigns based on your other settings and select high-quality traffic from various placements to deliver better results. If provided, the parameters `placement_type` and `placements` will be ignored overwritten as `PLACEMENT_TYPE_AUTOMATIC` and `["PLACEMENT_TIKTOK","PLACEMENT_PANGLE"]` separately.  • To retrieve the exact placement setting of a Smart+ App Campaign, use [/campaign/spc/get/](doc:1767334299811842). • If `promotion_type` is `APP_IOS`, do not pass `placement_type` and `placements`. • Starting June 30th, 2025, the system will automatically configure placements for your Smart+ iOS App Campaigns based on your other settings and select high-quality traffic from various placements to deliver better results. If provided after June 30th, 2025, the parameters `placement_type` and `placements` will be ignored overwritten as `PLACEMENT_TYPE_AUTOMATIC` and `["PLACEMENT_TIKTOK","PLACEMENT_PANGLE"]` separately.  • To retrieve the exact placement setting of a Smart+ App Campaign, use [/campaign/spc/get/](doc:1767334299811842). |
