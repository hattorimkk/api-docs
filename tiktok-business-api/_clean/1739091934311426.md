# Creative Portfolios
> Đường dẫn: API Reference > Creative Portfolios
A creative portfolio is a combination of creative assets like CTAs and Download Cards. You can include creative assets in a creative portfolio, and then use the portfolio in an ad.

This group consists of the following endpoints:
* [Create a portfolio](doc:1739091950439426)
* [Get a portfolio by ID](doc:1739092113671170)
* [Get portfolios within an ad account](doc:1766324010279938)
* [Delete portfolios](doc:1834560049625089)
