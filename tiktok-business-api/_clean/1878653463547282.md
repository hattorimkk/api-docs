# Authenticate MCP Server requests with an API access token in a custom agent
> Đường dẫn: TikTok for Business MCP Server > How to connect a custom agent to TikTok for Business MCP Server > Authenticate MCP Server requests with an API access token in a custom agent
When [connecting a custom agent to TikTok for Business MCP Server](slug:how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server), you have the option to authenticate requests using an API access token. This guide explains the benefits of this approach and provides step-by-step instructions for implementation.

# Why use an API access token
Using an API access token offers several significant advantages for your custom agent integration:
- **Long-term authorization:** Standard user authorization for the MCP Server is valid for a 30-day window, requiring reauthorization after expiration. An API access token provides long-term access, remaining valid indefinitely unless the advertiser explicitly revokes it or the token is invalidated via the [/oauth2/revoke_token/](slug:revoke-a-long-term-access-token) endpoint.
- **Streamlined setup for existing developers:** If you have an existing integration with the TikTok [Marketing API](slug:marketing-api), you can reuse your current Marketing API token to authenticate MCP requests. This eliminates the need to complete a separate authorization process.
- **Granular permission control:** Obtaining an API access token utilizes the standard API authorization workflow. This allows advertisers to review and select precise, granular permissions, minimizing the risk of over-sharing.
- **Increased rate limits:** Standard MCP authorization limits requests to 6 queries per second (QPS) per tool, per user. In contrast, API access tokens utilize standard API rate limits based on your developer app's rate limit level. Even the default Basic level provides 10 QPS per tool, per developer app. For more details, refer to [Rate limits](slug:rate-limits).

# Steps

## 1. Obtain your API access token
If you already have a Marketing API access token, you can skip to [Step 2](#item-link-anchor-2-2). Otherwise, follow these steps to generate one:

a. [**Create a developer app**](slug:create-a-developer-app)**:** Begin by creating a developer app in the TikTok for Business developer portal. This app helps manage permission scopes and rate limits.

b. [**Complete the authorization workflow**](slug:marketing-api-authorization)**:** Navigate the Marketing API Authorization workflow to acquire an authorization code.

c. [**Generate the token**](slug:marketing-api-authentication)**:** Exchange the authorization code for an API access token. Below is an example for generating an API access token.

**Example**

Request
```http
// curl
curl --location -request POST 'https://business-api.tiktok.com/open_api/v1.3/oauth2/access_token/' \
--header 'Content-Type: application/json' \
--data '{
    "app_id": "{{app_id}}",
    "secret": "{{secret}}",
    "auth_code": "{{auth_code}}"
}'
```

Response
```http
// curl
HTTPS/1.1 200 OK
{
  "message": "OK",
  "code": 0,
  "data": {
    "access_token": "{{access_token}}",
    "scope": [
      4
    ],
    "advertiser_ids": [
      "{{advertiser_id}}",
      "{{advertiser_id}}"
    ]
  },
  "request_id": "{{request_id}}"
}
```

## 2. Configure the authorization header
To authenticate [your MCP tool calls](https://business-api.tiktok.com/portal/docs/how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server/v1.3#anchor-5-2-2), include the API access token in the request header using the `Authorization: Bearer {{Access-Token}}` format.

**Example** **`tools/list`** **call using an API access token**
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer' \
--header 'Authorization: Bearer {{Access-Token}}' \ //Pass the API access token to {{Access-Token}}
--header 'Content-Type: application/json' \
--data '{
    "jsonrpc": "2.0",
    "id": {{id}},
    "method": "tools/list",
    "params": {}
}'
```
