# Hide/unhide an existing comment on an owned video
> Đường dẫn: API Reference > Accounts > Comments > Hide/unhide an existing comment on an owned video
Use this endpoint to hide or unhide an existing comment on an organic video posted by an owned TikTok Account.

> **Note:** 
> - Unhiding a comment might not always take effect due to factors such as moderation actions, user privacy settings, or other system-level filters. In these scenarios, the comment will remain hidden. To verify the current visibility status of a comment, you can either subscribe to the relevant comment webhook event or retrieve the comment's status (`status`) by making a request to the [/business/comment/list/](doc:1760232109619202) endpoint.
> - The comment webhook event [comment.update](doc:1810515104773122) enables you to get notifications within five minutes of a comment or reply being hidden or unhidden on any public video associated with  an owned TikTok account. To subscribe to the comment webhook, see [Subscribe to the comment update event](doc:1810521730276354).

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/comment/hide/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok creators. ⏎ To obtain an access token, use [/tt_user/oauth2/token/](doc:1833997638479041). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

``` xtable
|Field{20%}|Data Type{10%}| Param Location{15%}|Description{55%}|
|--- |--- |--- |--- |
| business_id {Required} | string | Body | Application specific unique identifier for the TikTok account. <br>Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1833997638479041) to this field.|
| comment_id {Required} | string | Body |Unique identifier for comment on an owned TikTok video to hide/unhide. This can be accessed via the [/business/comment/list/](doc:1760232109619202) endpoint as the `comment_id` for each comment listed. |
| video_id {Required} | string | Body | Unique identifier for owned TikTok video. This can be accessed via the [/business/video/list/](doc:1762228421622786) endpoint as the `item_id` for each video listed. |
|action {Required} | string | Body | Specific operation to be performed on the comment -  hide or unhide. <br><br><strong>Enum values</strong>: `HIDE`, `UNHIDE`. <br><br><strong>Example</strong>: `HIDE`. |
```
### Example
```http
// curl
curl --location  --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/comment/hide/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "business_id" : "{{business_id}}",
    "comment_id" : "{{comment_id}}",
    "video_id": "{{video_id}}",
    "action": "HIDE"
}'
```
