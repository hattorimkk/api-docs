# Get bid protection statuses
> Đường dẫn: API Reference > Tools > Get bid protection statuses
Use this endpoint to retrieve the current bid protection statuses for a list of Upgraded Smart+ Campaigns or Upgraded Smart+ Ad Groups.

# Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/report/bid_protection/status/get/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](slug:marketing-api-authentication). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| data_level  **(Required)** | string | The data level you want to query. ⏎ Enum values: • `CAMPAIGN`: Campaign level. • `ADGROUP`: Ad group level. |
| query_ids  **(Required)** | string[] | The list of IDs you want to query. ⏎ Max size: 200. • When `data_level` is `CAMPAIGN`, specify a list of Upgraded Smart+ Campaign IDs. • To retrieve these IDs, use [/smart_plus/campaign/get/](slug:get-upgraded-smart-campaigns). • When `data_level` is `ADGROUP`, specify a list of Upgraded Smart+ Ad Group IDs. • To retrieve these IDs, use [/smart_plus/adgroup/get/](slug:get-upgraded-smart-ad-groups). ⏎ All IDs must belong to the same advertiser. |

## Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/report/bid_protection/status/get/?advertiser_id={{advertiser_id}}&data_level=CAMPAIGN&query_ids=["{{query_id}}"]' \
--header 'Access-Token: {{Access-Token}}'
```

# Response

| Field | Data Type | Description |
|---|---|---|
| - | - | - |
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](slug:return-codes-appendix). |
| message | string | Response message. For details, see [Appendix - Return Codes](slug:return-codes-appendix). |
| request_id | string | The log ID of the request, which uniquely identifies a request. |
| data | object | Returned data. |
| ↳ list | object[] | The bid protection status information for your queried campaigns or ad groups. |
| ↳↳ data_level | string | The data level. ⏎ Enum values: • `CAMPAIGN`: Campaign level. • `ADGROUP`: Ad group level. |
| ↳↳ query_id | string | The specific ID you queried. • When `data_level` is `CAMPAIGN`, this field represents an Upgraded Smart+ Campaign ID. • When `data_level` is `ADGROUP`, this field represents an Upgraded Smart+ Ad Group ID. |
| ↳↳ bid_protection_status | string | The current bid protection status for the campaign or ad group. ⏎ Enum values: • `ACTIVE`: Bid protection is active for the campaign or ad group. You’re eligible for ad credits when costs exceed your bid. You can query historical records through [/report/bid_protection/detail/get/](slug:get-bid-protection-history). • `INVALID`: Bid protection is temporarily ineligible for the campaign or ad group because the campaign or ad group was paused or deleted within the first 3 days after creation. • `INACTIVE`: Bid protection is permanently ineligible for the campaign or ad group. |
| ↳↳ compensation_category | string | The bid protection compensation category. ⏎ Enum values: • `FULL_LIFE_CYCLE`: Full lifecycle compensation.[Bid Protection (Full Lifecycle)](https://ads.tiktok.com/resources/help/article/about-smart-plus-bid-protection) is the default solution, covering the campaign's entire duration. • `THREE_DAY`: Three-day compensation. Only bidding strategies that are currently unsupported in the Full Lifecycle version will use [Bid Protection (Learning Phase)](https://ads.tiktok.com/help/article/incentive-offer). This covers the first three full consecutive days from the day you activate the campaign. |
