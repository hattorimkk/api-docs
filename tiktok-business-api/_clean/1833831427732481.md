# Enable brand hashtags for a TikTok account
> Đường dẫn: API Reference > Mentions > Enable brand hashtags for a TikTok account
Use this endpoint to enable hashtags for a TikTok account. 

Once enabled, the hashtags will be factored into the results of [/business/mention/hashtag/video/list/](doc:1825108001123522).  

TikTok accounts can either use hashtags returned from [/business/mention/hashtag/verify/list/](doc:1833862470219842) or use hashtags that include the full handle name. You can enable a maximum of 50 hashtags for a brand, with a limit of 10 hashtags per request.

> **Note:** 
> - Once you enable  a hashtag  for a brand, you cannot remove it in the next seven days.
> - The brand mentions data for the newly enabled  hashtags will be included in [/business/mention/hashtag/video/list/](doc:1825108001123522) 24 hours after you enable these hashtags for a brand.

## Before you start
- Ensure the TikTok account is a TikTok Account with Advanced Access or Verified Business Account. Learn more [about TikTok account entitlements](https://ads.tiktok.com/resources/help/article/about-tiktok-account-entitlements). To confirm this, use [/business/get/](slug:get-profile-data-of-a-tiktok-account) and check whether the response parameter `has_advanced_access` is `true` for the TikTok account.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/mention/hashtag/add/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok accounts. ⏎ To obtain an access token, use [/tt_user/oauth2/token/](https://business-api.tiktok.com/portal/docs/mentions-api-authentication/v1.3#anchor-1). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `application/json`. |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
|business_id {Required}|string|Application specific unique identifier for the TikTok account.<br><br>You can get the ID through the `open_id` field returned by [/tt_user/oauth2/token/](https://business-api.tiktok.com/portal/docs/mentions-api-authentication/v1.3#anchor-1).|
| username {Required}  | string | The username (handle) of the TikTok account. |
| hashtags{Required} | string[] | A list of hashtags to enable for the brand.<br><br>You can include hashtags from [/business/mention/hashtag/verify/list/](doc:1833862470219842) or include the full TikTok account handle as a substring of the hashtag.<br><br>For example, if the TikTok account handle is `@TikTok`, the hashtag `#drinktiktok` would be valid.<br><br>Max size: 10. |
```

### Example
```http
// curl
curl --location  --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/mention/hashtag/add/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "business_id":"{{business_id}}",
    "username":"{{username}}",
    "hashtags":["{{hashtag}}","{{hashtag}}"]
}'
```
## Response

``` xtable
|request_id |string|The log ID of a request, which uniquely identifies the request.  |
|data |object|Returned data.|
#|hashtag_list | object[] | The list of hashtags enabled for the TikTok account (brand). |
##|hashtag | string | A hashtag that has been enabled for the TikTok account. |
##|create_date | string | The date when the hashtag was enabled for the brand, in the format of `YYYY-MM-DD` (UTC+0 time).<br><br>Example: `2025-01-01`. |
```
