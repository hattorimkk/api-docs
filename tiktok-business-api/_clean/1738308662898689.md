# Get OS versions
> Đường dẫn: API Reference > Tools > Get OS versions
Use this endpoint to get the enumeration values of operating system version.

## Request

**Endpoint**
https://business-api.tiktok.com/open_api/v1.3/tool/os_version/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| os_type  **(Required)** | string | OS type. Enum values: `ANDROID`,`IOS`. |

### Example
```http
// curl
curl --location request GET 'https://business-api.tiktok.com/open_api/v1.3/tool/os_version/?advertiser_id={{advertiser_id}}&os_type=IOS' \
--header 'Access-Token: {{Access-Token}}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Return code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097). |
| message | string | Return message. For details, see [Appendix-Return information](doc:1737172488964097). |
| data | object | Returned data. |
| ↳ os_versions | object[] | OS versions list. |
| ↳↳ os_id | string | OS versions ID. |
| ↳↳ os_type | string | OS type. |
| ↳↳ version | string | OS version. |
| ↳↳ name | string | OS version name. |
| request_id | string | The log ID of a request, which uniquely identifies the request. |
