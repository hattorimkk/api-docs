# Create an Upgraded Smart+ Lead Generation Search Ads Campaign
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Lead Generation Search Ads Campaign
Depending on your preferred optimization location and whether you are integrating a catalog, you can route your Lead Generation Search Ads to an Instant Form, a Website, TikTok direct messages, instant messaging apps, or a phone call. Alternatively, you can create Automotive Search Ads.

- To create a campaign without a catalog that routes to an Instant Form, see [Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as Instant Form](slug:create-an-upgraded-smart-lead-generation-search-ads-campaign-with-optimization-location-as-instant-form).
- To create a campaign without a catalog that routes to a Website, see [Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as Website](slug:create-an-upgraded-smart-lead-generation-search-ads-campaign-with-optimization-location-as-website).
- To create a campaign without a catalog that routes to TikTok direct messages, see [Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as TikTok direct messages](slug:create-an-upgraded-smart-lead-generation-search-ads-campaign-with-optimization-location-as-tiktok-direct-messages).
- To create a campaign without a catalog that routes to instant messaging apps, see [Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as instant messaging apps](slug:create-an-upgraded-smart-lead-generation-search-ads-campaign-with-optimization-location-as-instant-messaging-apps).
- To create a campaign without a catalog that routes to a phone call, see [Create an Upgraded Smart+ Lead Generation Search Ads Campaign with optimization location as phone call](slug:create-an-upgraded-smart-lead-generation-search-ads-campaign-with-optimization-location-as-phone-call).
- To create a campaign using an Auto-Inventory or Auto-Model catalog, see [Create Upgraded Smart+ Automotive Search Ads](slug:create-upgraded-smart-automotive-search-ads).
