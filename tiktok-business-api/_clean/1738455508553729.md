# Get authorized ad accounts
> Đường dẫn: API Reference > Ad Accounts > Get authorized ad accounts
Use this endpoint to obtain a list of advertiser accounts that authorized an app.

## Request

**Endpoint**  https://business-api.tiktok.com/open_api/v1.3/oauth2/advertiser/get/

**Method**  GET

**Header**

| field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| field | Data Type | Description |
|---|---|---|
| app_id **(Required)** | string | The App id applied by the developer, which can be found on the ⏎ [Application Management](https://ads.tiktok.com/marketing_api/apps/) page. |
| secret **(Required)** | string | The private key of the developer's application, which can be found on the ⏎ [Application Management](https://ads.tiktok.com/marketing_api/apps/) page. |

### Example

```http
// curl
curl --get -H "Access-Token:<access_token>" \
--data-urlencode "secret=<secret>" \
--data-urlencode "app_id=<app_id>" \
https://business-api.tiktok.com/open_api/v1.3/oauth2/advertiser/get/
```

## Response 

| Field | Data Type | Description |
|---|---|---|
| code | number | Return code, see [Return Codes](doc:1737172488964097) |
| message | string | Return messages, see [Return Codes](doc:1737172488964097) |
| data | object | Return data |
| ↳ list | object | Advertiser information list |
| ↳↳ advertiser_id | string | Authorising Advertiser ID |
| ↳↳ advertiser_name | string | Authorising Advertiser Name |
| request_id | string | Request log ID. Uniquely identifying a request. |
