# Generic catalog CSV feed parameters
> Đường dẫn: Marketing API > Catalog Management > Guides > Create catalogs and add products > Generic catalog CSV feed parameters
The following table lists the parameters you can configure for a generic catalog when passing a CSV file to the `file_url` parameter in [/catalog/product/file/](slug:upload-products-via-a-file-url).

| Field | Data Type | Description |
|---|---|---|
| item_id  **(Required)** | string | A unique, self-defined ID for the product or service. ⏎ Length limit: 100 characters. ⏎ Ensure you use valid Unicode characters. |
| title  **(Required)** | string | The name of the product or service. ⏎ You can use the same product title from your landing page. ⏎ Length limit: 500 characters. ⏎ Ensure you use valid Unicode characters. |
| description | string | A detailed description of the product or service. ⏎ Length limit: 5,000 characters. |
| availability | string | The current inventory status of the product or service. ⏎ Enum values: • `in stock` • `available` • `preorder` • `out of stock` • `discontinued` • `unavailable` |
| image_link  **(Required)** | string | The URL to the main image of the product or service. ⏎ Requirements: • Provide a directly accessible URL with a verified domain. • The URL must start with `http://` or `https://`. • The image must be in JPG or PNG format. • The image must be at least 500 × 500 pixels and no larger than 1290 x 2790 pixels.   • The URL must link directly to the image file. ⏎ Recommendations: • The recommended image aspect ratio is 1:1. |
| video_link | string | A link to the video of the product or service. • Provide a directly accessible URL with a verified domain. • The URL must start with `http://` or `https://`. • Recommended video aspect ratio 9: 16 (Vertical). • Recommended resolution for TikTok placement: ≥ 720*1280. • Recommended bitrate for TikTok placement: ≥ 516 kbps. • Sound: enabled with subtitles. |
| link | string | A link to the landing page of the product or service. • Provide a directly accessible URL with a verified domain. • The URL must start with `http://` or `https://`. |
| rating | double | The user rating for the product or service. ⏎ Value range: 0.0-5.0. |
| price | double | The price of a single product or service unit. ⏎ The system will use the default currency of your catalog's target country. ⏎ Ensure that the price matches the price on the landing page and checkout page. ⏎ Example: 9.99. |
| additional_image_link | string | A list of additional image URLs for the product or service. ⏎ Up to 20 links are allowed. ⏎ Requirements: • Provide a directly accessible URL with a verified domain. • The URL must start with `http://` or `https://`. • The image must be in JPG or PNG format. • The image must be at least 500 × 500 pixels and no larger than 1290 x 2790 pixels.  • The URL must link directly to the image file. • Separate multiple URLs with commas. ⏎ Example:`https://www.example.com/products/images/headphones-side.jpg, https://www.example.com/products/images/headphones-box.jpg` |
| sale_price | double | The discounted price of a single product or service unit. ⏎ The system will use the default currency of your catalog's target country. ⏎ Ensure that the price matches the price on the landing page and checkout page. ⏎ To display both `sale_price` and `price` on ads, keep the `sale_price` lower than `price`. ⏎ Example: 4.99. |
| availability_type | string | The method used to define the geographic areas where the product can be sold or the service can be provided. ⏎ Enum values: • `region`: Locations or regions. Set locations or regions where your product or service is available via `availability_region`. • `dma`: DMAs. Set DMAs where your product or service is available via `availability_dma`. • `radius`: Radius range. Set a custom radius around where your product or service is available via `availability_circle_radius` and `availability_circle_radius_unit`. • `postal_code`: Postal code. Set specific postal codes or zip codes where your product or service is available via `availability_postal_codes`. |
| availability_region {+Conditional} | string[][] | Required when `availability_type` is `region`. ⏎ A list of regions where the product can be sold or the service can be provided. ⏎ Specify an array of string arrays, where each string array represents a specific location. ⏎ You can specify up to 998 locations. For each location, you can include up to 2 strings per array, with each string limited to 499 characters. These strings represent the administrative levels L1 and L2 of the region. Arrange them in this exact hierarchical order, or your region targeting will not take effect. ⏎ For U.S. locations, you can use the format ["State", "City"]. ⏎ Example: `[["Arizona","Peoria"],["Alabama","Birmingham"]]` is a valid array containing two location arrays, each with 2 strings under the 499-character limit. |
| availability_dma {+Conditional} | string[] | Required when `availability_type` is `dma`. ⏎ A list of DMAs where the product can be sold or the service can be provided. ⏎ Provide a comma-separated list of 3-digit integers, up to a maximum size of 500. ⏎ Example: `501,803` (New York and Los Angeles) ⏎ **Note**: This field is only available for catalogs targeting the U.S. To retrieve and confirm the targeting region of a catalog, use [/catalog/get/](slug:get-catalogs) and check whether the returned `country` is `US`. |
| availability_circle_radius {+Conditional} | string | Required when `availability_type` is `radius`. ⏎ The ad targeting circle radius of the product or service defining a circular availability area. ⏎ Value range: • When the unit is kilometer: greater than 0 and ≤ 40. • When the unit is mile: greater than 0 and ≤ 25. ⏎ Example: `20`. ⏎ **Note**: This field is only available for catalogs targeting Indonesia, Malaysia, Thailand, or Vietnam. To retrieve and confirm the targeting region of a catalog, use [/catalog/get/](slug:get-catalogs) and check whether the returned `country` is `TH`, `ID`, `MY`, or `VN`. |
| availability_circle_radius_unit {+Conditional} | string | Required when `availability_type` is `radius`. ⏎ The unit for `availability_circle_radius`. ⏎ Enum values: • `km`: kilometer. • `mi`: mile. ⏎ **Note**: This field is only available for catalogs targeting Indonesia, Malaysia, Thailand, or Vietnam. To retrieve and confirm the targeting region of a catalog, use [/catalog/get/](slug:get-catalogs) and check whether the returned `country` is `TH`, `ID`, `MY`, or `VN`. |
| availability_postal_codes {+Conditional} | string[] | Required when `availability_type` is `postal_code`. ⏎ A list of postal codes representing the areas where the product can be sold or the service can be provided. ⏎ You can include up to 500 postal codes, with each postal code limited to 20 characters. ⏎ Example: `10001,90001` ⏎ **Note**: This field is only available for catalogs targeting the U.S. or Canada. To retrieve and confirm the targeting region of a catalog, use [/catalog/get/](slug:get-catalogs) and check whether the returned `country` is `US` or `CA`. |
| address_street | string | The street address where the product or service is located. ⏎ Length limit: 150 characters. ⏎ Example: `1143 coleman Avenue`. |
| address_city | string | The city where the product or service is located. ⏎ Length limit: 150 characters. ⏎ Example: `San Jose`. |
| address_region | string | The state, province, or administrative region where the product or service is located. ⏎ Length limit: 150 characters. ⏎ Example: `California`. |
| address_postal_code | string | The postal or zip code of the product or service location. ⏎ Length limit: 150 characters. ⏎ Example: `95050`. |
| address_longitude | double | The longitude of the product or service location. ⏎ Value range: [-180, 180]. ⏎ Example: 100.5. |
| address_latitude | double | The latitude of the product or service location. ⏎ Value range: [-90, 90]. ⏎ Example: -25.5. |
| ios_url | string | The URL of your iOS app. ⏎ Example: `iOS://electronic`. |
| ios_app_store_id | string | The App Store ID of the iOS app. ⏎ Ensure that the App Store ID and the iOS URL direct to the same app. |
| ios_app_name | string | The name of the iOS app. |
| android_url | string | The URL of your Android app. ⏎ Example: `android://electronic`. |
| android_package | string | The Android package name. ⏎ Ensure that the Android package name and the Android URL direct to the same app. |
| android_app_name | string | The Android app name. |
| custom_label_0 | string | A custom label used to add information about the product. ⏎ Length limit: 500 characters. |
| custom_label_1 | string | A custom label used to add information about the product. ⏎ Length limit: 500 characters. |
| custom_label_2 | string | A custom label used to add information about the product. ⏎ Length limit: 500 characters. |
| custom_label_3 | string | A custom label used to add information about the product. ⏎ Length limit: 500 characters. |
| custom_label_4 | string | A custom label used to add information about the product. ⏎ Length limit: 500 characters. |
| custom_label_5 | string | A custom label used to add information about the product. ⏎ Length limit: 500 characters. |
| custom_label_6 | string | A custom label used to add information about the product. ⏎ Length limit: 500 characters. |
| custom_number_0 | double | A custom numeric attribute for product management. ⏎ No length limit. |
| custom_number_1 | double | A custom numeric attribute for product management. ⏎ No length limit. |
| custom_number_2 | double | A custom numeric attribute for product management. ⏎ No length limit. |
| custom_number_3 | double | A custom numeric attribute for product management. ⏎ No length limit. |
| custom_number_4 | double | A custom numeric attribute for product management. ⏎ No length limit. |
