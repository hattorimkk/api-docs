# Renew a short-term access token
> Đường dẫn: API Reference > Authentication > Renew a short-term access token
Use this endpoint to renew a short-term access token by `refresh_token`.

A short-term access token is a type of token that you can obtain after receiving authorization from a TikTok account. The token expires in one day.

## Before you start
Obtain a refresh token for generating a new short-term token using [/tt_user/oauth2/token/](doc:1833997638479041).

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/refresh_token/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| client_id  **(Required)** | string | ID of your developer app. ⏎ To find the **App ID**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| client_secret  **(Required)** | string | Secret of your developer app. ⏎ To find the **Secret**, navigate to [My Apps](https://ads.tiktok.com/marketing_api/apps/) > **App Detail** > **Basic Information**. |
| grant_type  **(Required)** | string | The way of generating the access token. ⏎ The allowed enum value:  • `refresh_token`: To generate the access token by refresh token. |
| refresh_token  **(Required)** | string | Refresh token to renew an existing access token. ⏎ You can obtain the refresh token in the response of [/tt_user/oauth2/token/](doc:1833997638479041) endpoint when you generate an access token. |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/refresh_token/' \
--header 'Content-Type: application/json' \
--data '{
    "client_id":"{{client_id}}",
    "client_secret":"{{client_secret}}",
    "grant_type":"refresh_token",
    "refresh_token":"{{refresh_token}}"
}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097). |
| message | string | Response message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| data | object | Returned data. |
| request_id | string | The log ID of the request, which uniquely identifies a request. |
| ↳ access_token | string | The new short-term token for permission verification. ⏎ The token expires in one day. |
| ↳ token_type | string | The type of token. ⏎ Enum value:  • `Bearer`: Bearer token. Anyone in possession of the token can use it to access the associated resources. |
| ↳ scope | string | The scope of permissions granted to the access token. |
| ↳ expires_in | number | The time remaining until the access token expires, measured in seconds. |
| ↳ refresh_token | string | The refresh token, which can be used to renew the access token. ⏎ The refresh token is valid for one year. ⏎ **Note**: Retain this field for `access_token` renewal. |
| ↳ refresh_token_expires_in | number | The time remaining until the refresh token expires, measured in seconds. |
| ↳ open_id | string | Application specific unique ID of the TikTok account. |
