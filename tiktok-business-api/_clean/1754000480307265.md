# Get asynchronous download tasks
> Đường dẫn: API Reference > BC Invoices > Download the invoices of a BC > Download asynchronously > Get asynchronous download tasks
Use this endpoint to check whether the `BILLING_REPORT`  task has completed. If the tasks have been completed, you will get the Excel file stream. 

Both Agency and Direct Business Centers are able to perform invoice related operations.   

> **Note:** Only users with Finance Manager or Finance Analyst permission can manage payments and invoices in a Business Center. You can use [/bc/member/invite/](doc:1739939455765505) and [/bc/member/update/](doc:1739696704424961) to configure or update access settings for members.

## Request

**Endpoint**  https://business-api.tiktok.com/open_api/v1.3/bc/invoice/task/get/

**Method** GET

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token {Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162).|
```

**Parameters**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|bc_id {Required}|string| Business Center ID. |
|task_id {Required}|string| Task ID. |
```
### Example
```http
// curl
curl --location --request GET https://business-api.tiktok.com/open_api/v1.3/bc/invoice/task/get/?bc_id={{bc_id}}&task_id={{task_id}}
--header 'Access-Token: {{Access-Token}}'
```

## Response

``` xtable
|Field|Data Type|Description|
|---|---|---|
|code |number|Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](doc:1737172488964097).|
|message |string|Response message. For details, see [Appendix - Return Codes](doc:1737172488964097).|
|data |object|Returned data.|
#|download_url|string|A url to download the task file. |
#|status|string|Asynchronous download task status. Enum values: `FAILED`, `CREATED`, `RUNNING`, `SUCCEED`, `POLLING`. If the task is successfully completed, xlsx file streams will be in response.|
#|error_msg|string|If the action failed, this field returns the error message.|
|request_id |string|The log id of the request, which uniquely identifies a request. |
```
