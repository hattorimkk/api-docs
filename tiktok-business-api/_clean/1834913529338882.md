# Get Authorized TTO Creator Insights
> Đường dẫn: API Reference > TikTok One > Get Authorized TTO Creator Insights
Use this endpoint to get information and insights about a TikTok creator who has joined TikTok One (TTO).

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/tto/creator/authorized/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok creators. ⏎ Use [/tt_user/oauth2/token/](https://business-api.tiktok.com/portal/docs/get-renew-or-revoke-a-creator-access-token/v1.3#item-link-Obtain%20a%20Creator%20access%20token) or [/tt_user/oauth2/refresh_token/](https://business-api.tiktok.com/portal/docs/get-renew-or-revoke-a-creator-access-token/v1.3#item-link-Renew%20a%20Creator%20access%20token) endpoint to get or renew an access token. |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
|creator_id {Required}|string|Application specific unique ID of the TikTok account.<br><br> Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](https://business-api.tiktok.com/portal/docs/get-renew-or-revoke-a-creator-access-token/v1.3#item-link-Obtain%20a%20Creator%20access%20token) or [/tt_user/oauth2/refresh_token/](https://business-api.tiktok.com/portal/docs/get-renew-or-revoke-a-creator-access-token/v1.3#item-link-Renew%20a%20Creator%20access%20token) to this field.|
|fields|string[]|Requested fields. <br><br>If this field is not set, the default fields (`profile_image` and `display_name`) will be returned.|
```

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/tto/creator/authorized/?creator_id={{creator_id}}&fields=["handle_name","display_name","profile_image","bio","followers_count","following_count","videos_count","likes_count","creator_rate","country_code","content_labels","industry_labels","audience_countries","audience_genders","audience_ages","audience_devices","audience_usages"]' \
--header 'Access-Token: {{Access-Token}}'
```
