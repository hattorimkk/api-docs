# Check the statuses of words
> Đường dẫn: API Reference > Ad Comments - Blocked Words > Check the statuses of words
Use this endpoint to check if a list of words are blocked.

## Request

**Endpoint**
https://business-api.tiktok.com/open_api/v1.3/blockedword/check/

**Method** GET

**Header**

| Field | Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| blocked_words  **(Required)** | string[] | List of words that you want to check. |

### Example

```http
// curl
curl --get -H "Access-Token:xxx" \
--data-urlencode "advertiser_id=ADVERTISER_ID" \
--data-urlencode "blocked_words=[\"BLOCKED_WORDS\"]" \
https://business-api.tiktok.com/open_api/v1.3/blockedword/check/
```

## Response

| Field | Type | Description |
|---|---|---|
| message | string | The return message. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| code | number | The return code. For details, see [Appendix - Return Codes](doc:1737172488964097). |
| data | object | Returned data. |
| ↳ results | object[] | Results. |
| ↳↳ word | string | Word being checked. |
| ↳↳ blocked | boolean | Enum values: `True` (word is blocked), `False` (word is not blocked). |
| request_id | string | Unique ID of the request. |

### Example

```http
// Success-Response
HTTPS/1.1 200 OK
{
    "message": "OK",
    "code": 0,
    "data": {}
}
```
