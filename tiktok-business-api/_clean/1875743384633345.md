# Create an Upgraded Smart+ E-commerce Search Ads Campaign for App
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Sales Search Ads Campaign > Create an Upgraded Smart+ Catalog Search Ads Campaign for App > Create an Upgraded Smart+ E-commerce Search Ads Campaign for App
This article explains how to create an Upgraded Smart+ Search Ads Campaign for App using the Sales objective, the app sales destination, and an E-commerce catalog.

This campaign type dynamically leverages your E-commerce catalog products to populate and deliver targeted app ads.

To configure this campaign type, set `sales_destination` to `APP` and `catalog_type` to `ECOMMERCE` at the campaign level. By leveraging Search Ads Campaigns for App, you can effectively grow your user base through two primary strategies: acquiring new users (Prospecting) and re-engaging your existing audience (Retargeting).

Depending on your requirements for [Dedicated Campaigns](slug:dedicated-campaign) (DC), you can create either a non-DC or a DC Search Ads Campaign for App. For detailed instructions on creating each type, refer to their respective sections: "[Create an Upgraded Smart+ E-commerce non-DC Search Ads Campaign for App](#item-link-anchor-2)", "[Create an Upgraded Smart+ E-commerce DC Search Ads Campaign for App](#item-link-anchor-3)".

# Prerequisites

Creating E-commerce Search Ads Campaigns for App requires setting up an E-commerce catalog in your Business Center first.

To set up the catalog:

1. Create an E-commerce catalog using [/catalog/create/](slug:create-a-catalog).

2. Upload products to the catalog using [/catalog/product/upload/](slug:upload-products-via-a-json-schema) (JSON schema), [/catalog/product/file/](slug:upload-products-via-a-file-url) (CSV feed template), or [/catalog/feed/create/](slug:create-a-feed)(online data feed schedule).

3. Check the product handling results using [/catalog/product/log/](slug:get-the-product-handling-log). Pass in the `feed_log_id` obtained from Step 2. If the field `error_affected_products` in the response is not null, examine the issue details and return to Step 2 to reupload the product.

4. (Optional) Create a product set using [/catalog/set/create/](slug:create-a-product-set-by-conditions). If you want to have products selected from a product set, creating a product set is necessary. Otherwise, you can skip this step.

5. (Optional) Invite members to Business Center and grant the admin permission using [/bc/member/invite/](slug:invite-members-to-a-bc). You can also choose `advertiser_role` that you want to assign to the members invited.

6. (Optional) Share a catalog with members and grant catalog management access using [/bc/asset/assign/](slug:assign-an-asset). Make sure to specify `CATALOG` in the `asset_type` field and `ADMIN` in the `catalog_role` field. 

# Create an Upgraded Smart+ E-commerce non-DC Search Ads Campaign for App
Upgraded Smart+ E-commerce non-DC Search Ads Campaigns for App are Upgraded Smart+ Sales Campaigns that use E-commerce catalog products to deliver ads, with the iOS 14 dedicated campaign setting disabled. For such campaigns, set the `campaign_type` parameter to `REGULAR_CAMPAIGN` or leave `campaign_type` unspecified.
