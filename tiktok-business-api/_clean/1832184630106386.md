# Delete the automatic message for a TikTok account
> Đường dẫn: API Reference > Business Messaging > Automatic messages > Delete the automatic message for a TikTok account
Use this endpoint to delete an automatic message for a TikTok account.

## Before you start
- Because of the sensitive nature of direct message data, TikTok has implemented a higher level of due diligence for developers that will process automatic messages on behalf of TikTok account users. Ensure that you [have completed the necessary data security and privacy reviews and obtained access to Business Messaging API](slug:access-to-business-messaging-api) before calling this endpoint.
- Ensure the TikTok account is a TikTok Account with Advanced Access or Verified Business Account. Learn more [about TikTok account entitlements](https://ads.tiktok.com/resources/help/article/about-tiktok-account-entitlements). To confirm this, use [/business/get/](slug:get-profile-data-of-a-tiktok-account) and check whether the response parameter `has_advanced_access` is `true` for the TikTok account.
- Ensure the TikTok account owner is over 18 years old.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/message/auto_message/delete/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | A short-term access token authorized by the TikTok account owner. ⏎ For details, see [Authentication](doc:1832184175482945). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `application/json`. |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| business_id {Required}| string | Application specific unique identifier for the TikTok account. <br><br> Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](doc:1832184175482945) to this field. |
| auto_message_type{Required} | string | The type of automatic message.<br><br>Enum values: <ul><li>`SUGGESTED_QUESTION`: suggested question. A suggested question is a frequently asked question displayed at the beginning of a chat. When the user selects a suggested question, the user will automatically receive the corresponding preset answer.</li><li>`CHAT_PROMPT`: chat prompt. A chat prompt is an interactive button displayed above the input box. When users tap a chat prompt, the system will automatically generate a corresponding question for users to start the conversation.</li></ul><br><p><span style="color:darkred"><b>Note</b></span>:  <ul><li>The welcome message for a TikTok account cannot be deleted. You can only turn off the welcome message via [/business/message/auto_message/status/update/](doc:1832184596566017).</li><li>The new follower message for a TikTok account cannot be deleted. You can only turn off the new follower message via [/business/message/auto_message/status/update/](slug:turn-on-or-turn-off-an-automatic-message-for-a-business-account).</li></ul> |
| auto_message_id{Required} | string | The ID of the automatic message. <br><br>To retrieve the automatic messages for a TikTok account, use [/business/message/auto_message/get/](doc:1832184619749377).|
```

### Example
#### Delete a suggested question for a TikTok account
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/message/auto_message/delete/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "business_id": "{{business_id}}",
    "auto_message_type": "SUGGESTED_QUESTION",
    "auto_message_id": "{{auto_message_id}}"
}'
```
#### Delete a chat prompt for a TikTok account
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/business/message/auto_message/delete/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "business_id": "{{business_id}}",
    "auto_message_type": "CHAT_PROMPT",
    "auto_message_id": "{{auto_message_id}}"
}'
```
