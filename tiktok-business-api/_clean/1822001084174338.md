# Check the availability of a TikTok Shop for Product GMV Max Campaigns
> Đường dẫn: API Reference > GMV Max > Check the availability of a TikTok Shop for Product GMV Max Campaigns
Use this endpoint to check whether a TikTok Shop has been occupied by enabled[ Video Shopping Ads](doc:1750361719059457) or [Product Shopping Ads](doc:1785886237030401), and whether the TikTok Shop can be used to create Product GMV Max Campaigns by promoting all products in the TikTok Shop.

## Request

**Endpoint** https://business-api.tiktok.com/open_api/v1.3/gmv_max/store/shop_ad_usage_check/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. ⏎ For details, see [Authentication](doc:1738373164380162). |

**Parameters**

``` xtable
|Field{30%}|Data Type{15%}|Description{55%}|
|--- |--- |--- |
| advertiser_id {Required} | string | Advertiser ID. |
| store_id {Required} | string | The ID of the TikTok Shop.<br><br> To obtain a TikTok Shop that is available for GMV Max Campaigns, use [/gmv_max/store/list/](doc:1822001044479041) and confirm that the returned `is_gmv_max_available` is `true`. |
```

### Example
```http
// curl
curl --location  --request GET 'https://business-api.tiktok.com/open_api/v1.3/gmv_max/store/shop_ad_usage_check/?advertiser_id={{advertiser_id}}&store_id={{store_id}}' \
--header 'Access-Token: {{Access-Token}}'
```
## Response

``` xtable
|Field{30%}|Type{15%}|Description{55%}|
|---|---|---|
|code |number|Response code. For the complete list of response codes and descriptions, see [Appendix-Return Code](doc:1737172488964097). |
|message|string|Response message. For details, see [Appendix - Return Codes](doc:1737172488964097).|
|request_id |string|The log ID of a request, which uniquely identifies the request.  |
|data |object|Returned data.|
#| promote_all_products_allowed | boolean | Whether the TikTok Shop can be used to create Product GMV Max Campaigns by promoting all products in the TikTok Shop. <br> <br>Supported values: `true`, `false`. |
#| is_running_custom_shop_ads | boolean| Whether the TikTok Shop is being used in enabled Video Shopping Ads or Product Shopping Ads. <br> <br>Supported values: `true`, `false`. |
```
