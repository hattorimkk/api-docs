# Create an Upgraded Smart+ Search Ads Campaign for Website and App
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Sales Search Ads Campaign > Create an Upgraded Smart+ Search Ads Campaign for Website and App
This article explains how to create an Upgraded Smart+ Search Ads Campaign using the Sales objective and the website and app sales destination (Website and App Optimization).

Website and App Optimization is available for businesses with both website and app channels. The feature is designed to unlock the full potential of user interest and conversion opportunity by combining both website and app audiences in a unified campaign strategy.

Based on your preference for using a catalog to promote your ads, you have the flexibility to create two types of ads with Website and App Optimization:

- **Catalog Search Ads Campaign for Website and App**: This ad type uses a catalog to promote your ads. For detailed instructions on creating such ads, see [Create an Upgraded Smart+ Catalog Search Ads Campaign for Website and App](slug:create-an-upgraded-smart-catalog-search-ads-campaign-for-website-and-app).
- **Non-Catalog Search Ads Campaign for Website and App**: This ad type doesn't use a catalog to promote your ads. For detailed instructions on creating such ads, see [Create an Upgraded Smart+ Non-Catalog Search Ads Campaign for Website and App](slug:create-an-upgraded-smart-non-catalog-search-ads-campaign-for-website-and-app).
