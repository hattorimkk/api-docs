# Events API for Web
> Đường dẫn: Marketing API > Ad Measurement > Guides > Events API 2.0 > Events API for Web
> **Important:** 
> By using Events API endpoints, you agree to the [TikTok Business Products (Data) Terms](https://ads.tiktok.com/i18n/official/policy/business-products-terms) and that you will not share sensitive data with TikTok.

> **Note:** 
> The Events API 2.0 ([/event/track/](doc:1771101303285761)) is now the recommended endpoint for reporting events from all sources, including web, app, offline and CRM (Customer relationship management) systems. This endpoint provides a unified API schema to help advertisers simplify and streamline their integration.
To ensure a smooth transition, the following six Events API 1.0 endpoints will be sunset in H2 2024: • [/pixel/track/](doc:1740858531237890) and [/pixel/batch/](doc:1740858565852225) • [/offline/track/](doc:1758428013689857) and [/offline/batch/](doc:1758428053652482) • [/app/track/](doc:1740859196043266) and [/app/batch/](doc:1740859218541569)
We highly recommend that new users directly integrate with the Events API 2.0 endpoint, and existing Events API 1.0 users start upgrading to the Events API 2.0 as soon as possible. By doing so, you can take advantage of the benefits of the latest version.
