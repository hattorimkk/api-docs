# Get authorization server metadata
> Đường dẫn: API Reference > MCP Authorization > Get authorization server metadata
Use this endpoint to retrieve the TikTok for Business MCP authorization server metadata, including endpoint URLs and supported capabilities. 

Fetch this data so you can dynamically adapt your client to endpoint changes instead of hardcoding URLs.

# Request
**Endpoint** https://business-api.tiktok.com/open_mcp/{server}/oauth/.well-known/openid-configuration/

**Method** GET

**Path parameters**

| Field | Data Type | Description |
|---|---|---|
| server  **(Required)** | string | The specific TikTok for Business MCP server URL. ⏎ Enum values: `tt-ads-mcp-flat`, `tt-ads-mcp-layer`. ⏎ To learn more about how these server URLs differ, see [Choose your server URL](https://business-api.tiktok.com/portal/docs/how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server/v1.3#anchor-3). |

## Example

> **Note:** 
> The example below uses `tt-ads-mcp-layer` as the `{server}` value. You can replace this with your chosen server value.

```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer/oauth/.well-known/openid-configuration'
```

# Response

| Field | Data Type | Description |
|---|---|---|
| issuer | string | The issuer URL of the authorization server. |
| authorization_endpoint | string | The browser authorization endpoint that you use to prompt user consent. |
| token_endpoint | string | The endpoint URL that you use to request or refresh access tokens. |
| registration_endpoint | string | The endpoint URL that you use for dynamic client registration. |
| revocation_endpoint | string | The endpoint URL that you use to revoke existing tokens. |
| response_types_supported | string[] | The list of response types that the server supports. ⏎ Enum value: • `code`: You will receive an authorization code to exchange for a token. ⏎ Example: `["code"]`. |
| grant_types_supported | string[] | The list of grant types that the server supports. ⏎ Enum values: • `authorization_code`: To exchange an authorization code for an access token. •  `refresh_token`: To get a new access token when the old one expires. ⏎ Example: `["authorization_code", "refresh_token"]`. |
| code_challenge_methods_supported | string[] | The list of supported PKCE (Proof Key for Code Exchange)code challenge methods. PKCE is a security feature that makes sure your authorization request is safe from hackers. ⏎ Enum value: • `S256`: You need to use SHA-256 hashing to secure your authorization request. ⏎ Example: `["S256"]`. |
| token_endpoint_auth_methods_supported | string[] | The list of supported authentication methods for the token endpoint. ⏎ Enum value: • `none`: You do not need to provide a client secret or additional authentication credentials. ⏎ Example: `["none"]`. |
| scopes_supported | string[] | The list of supported permission scopes for your authorization request. ⏎ Enum value: • `mcp:tt4b`: the necessary permissions to access TikTok for Business MCP server features. ⏎ Example: `["mcp:tt4b"]`. |
