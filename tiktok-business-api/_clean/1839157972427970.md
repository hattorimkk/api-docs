# Manage Payment Portfolios
> Đường dẫn: Marketing API > Business Center > Guides > Finance > Manage Payment Portfolios
This article walks you through how to manage Payment Portfolios using Payment Portfolios API.

# Introduction
Payment Portfolio is a one stop workspace that allows you to view and and manage your options for making payments, including credit lines, cash balance, ad credit, and payment methods, in a unified manner across TikTok for Business platforms.

To learn more about Payment Portfolio, see [About Payment Portfolio](https://ads.tiktok.com/help/article/about-payment-portfolio).

# Prerequisites
- You've gained access to TikTok API for Business. See [Get Started - Step by step workflow](doc:1735713609895937) for details. 
  - To manage Payment Portfolios, you need relevant permissions. See [API Reference](doc:1735713875563521) to find out permissions required for endpoints (including the endpoints listed in the "Steps" section) and see [Update app permissions](doc:1738855280338946) to find out how to configure permissions.
