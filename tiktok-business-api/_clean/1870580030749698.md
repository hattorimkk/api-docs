# Get the location tags for a TikTok account
> Đường dẫn: API Reference > Accounts > Posts > Get the location tags for a TikTok account
Use this endpoint to retrieve the list of available location tags for a TikTok account.

You can include these location tags when you publish a video or photo post, allowing your post to display a location. By adding a location tag, you help local audiences and users searching for that area discover your post. This can also boost your engagement by making your content more relevant to nearby users.

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/business/publish/location/

**Method** GET

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Access token authorized by TikTok creators. ⏎ To obtain an access token, use [/tt_user/oauth2/token/](slug:obtain-a-short-term-access-token). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| business_id  **(Required)** | string | Application specific unique identifier for the TikTok account. ⏎ Pass the value of the `open_id` field returned in the response of [/tt_user/oauth2/token/](slug:obtain-a-short-term-access-token) to this field. |
| search_query  **(Required)** | string | The query you provide to search for a location that can be added to the TikTok account's posts. ⏎ Length limit: 100 characters. |

### Example
```http
// curl
curl --location --request GET 'https://business-api.tiktok.com/open_api/v1.3/business/publish/location/?business_id={{business_id}}&search_query=new' \
--header 'Access-Token: {{Access-Token}}'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| - | - | - |
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](slug:return-codes-appendix). |
| message | string | Response message. For details, see [Appendix - Return Codes](slug:return-codes-appendix). |
| request_id | string | The log ID of the request, which uniquely identifies a request. |
| data | object | Returned data. |
| ↳ locations | object[] | A list of the locations. ⏎ You can retrieve a maximum of 20 locations. |
| ↳↳ location_name | string | The name of the location. |
| ↳↳ location_id | string | The ID of the location tag. ⏎ You can pass this ID, along with the `location_name`, to [/business/video/publish/](slug:publish-a-public-video-post-to-an-owned-account) or [/business/photo/publish/](slug:publish-a-photo-post-to-an-owned-account) to display the associated location on your published post. |
| ↳↳ location_address | string | The additional information associated with the location. ⏎ The content you receive varies and may include, but is not limited to: • Country only: `United Kingdom` • Region/State + country: `Florida, United States`, `Illinois, United States` • City + country: `Cairo, Egypt` • Full street address: `300 West 47th Street, New York, New York 10036, USA` |
