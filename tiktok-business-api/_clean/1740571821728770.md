# Appeal a rejection
> Đường dẫn: API Reference > Ad Review > Appeal a rejection
Use this endpoint to appeal the rejection decision, that is, to request for the ad group to be re-evaluated, when your ad group is rejected during review. 

After the appeal, you need to wait for some time and call the [/adgroup/review_info/](doc:1740554277061634) endpoint to check the appeal status and see if the review status is updated.

## Request

**Endpoint**

https://business-api.tiktok.com/open_api/v1.3/adgroup/appeal/

**Method** POST

**Header**

``` xtable
|Field|Data Type|Description|
|---|---|---|
|Access-Token{Required}|string|Authorized access token. For details, see [Authentication](doc:1738373164380162).|
|Content-Type{Required}|string|The content type of the request. <br>Allowed value: `"application/json"`.|
```

**Parameters**

``` xtable
|Field|Data Type|Description|
|---|---|---|
| advertiser_id {Required} | string | Advertiser ID. |
| adgroup_id {Required} | string| Ad group ID. |
| ad_id | string | Ad ID. Optional. |
| appeal_reason | string | The reason for the appeal. |
| attachment_list | string[] | List of attachment links. |
```

### Example

```http
// curl
curl -H "Access-Token:xxx" -H "Content-Type:application/json" -X POST \
-d '{
    "advertiser_id": "ADVERTISER_ID",
    "adgroup_id": "ADGROUP_ID",
    "ad_id": "AD_ID",
    "appeal_reason": "APPEAL_REASON",
    "attachment_list": [
        "ATTACHMENT_LIST"
    ]
}' \
https://business-api.tiktok.com/open_api/v1.3/adgroup/appeal/
```
