8/31/2026
iOS: 1.7.2 Unity: 1.7.2 React: 0.1.3
• [Fix] iOS: Do not report unfinished StoreKit transactions in automatically logged IAP events. You may observe a drop in automatically reported Purchase events if transactions are not marked as finished in your app. • [Fix] iOS: Explicit completion handlers added for ATT requests and SDK initialisation. • [Feature] [React Native bridge](https://github.com/tiktok/tiktok-business-react-native-sdk/), built on SDK version 1.7.2

7/24/2026
iOS: 1.7.1 Unity: 1.7.1
• [Fix] Fixed a race condition edge case where messages were sent to Unity during teardown, resulting in null pointer exceptions if the process was opened and killed in quick succession.

6/30/2026
1.7.0
• [Feature] Android: Auto-IAP reporting for Google Pay billing library V8. • [Feature] iOS: Auto-IAP reporting for StoreKit 2.0, supporting mixed programming of Objective-C & Swift. Dynamic and static libraries are both available as release artifacts. • [Fix] Performance optimizations to ensure timely clearing of local cache. • [Fix] Unity: Optimize reporting performance, enhance user experience, and reduce the probability of stuttering.

4/6/2026
1.6.1
This version focuses on stability, accuracy, and performance improvements. Developer documentation is also restructured and rewritten for clarity. • [Fix] Double-hashing protections for advanced matching fields. • [Fix] Crash reports are now sent with the version of the SDK related to the crash, in case the SDK dependency was updated before the crash report was sent. • [Fix] Moved event reporting off the main thread to improve performance. • [Fix] Android: Gracefully degrade automatic IAP reporting in Play Billing Library V8+ environments until officially supported. • [Fix] iOS: Fixed an issue where automatically logged Purchase events would be sent multiple times before getting deduplicated at server side. • [Fix] iOS: Multiple optimisations for queue management, logging, and request handling. • [Fix] Unity: Fixed a compile error in the Android bridge layer. • [Fix] Unity: Fixed an issue where disablePayTrack was silently ignored.

[Feature] Subscription-related parameter support for automatic transaction reporting. Server-side Play Console/App Store Connect subscription reporting is not supported at this time. [Feature] Deferred deeplink requests now return an associated click timestamp where available. [Fix] Stability optimisations
