# Create an Upgraded Smart+ Catalog Search Ads Campaign for Website and App
> Đường dẫn: Use Cases > Campaign creation > Create an Upgraded Smart+ Campaign > Create Upgraded Smart+ Search Ads Campaigns > Create an Upgraded Smart+ Sales Search Ads Campaign > Create an Upgraded Smart+ Search Ads Campaign for Website and App > Create an Upgraded Smart+ Catalog Search Ads Campaign for Website and App
This article walks you through the steps to create an Upgraded Smart+ Catalog Search Ads Campaign for Website and App.

Upgraded Smart+ Catalog Search Ads Campaigns for Website and App are Upgraded Smart+ Sales Search Ads Campaigns that use catalog products to drive sales on both your website and your app. To configure this campaign type, set the following campaign-level parameters:
- `objective_type`: `WEB_CONVERSIONS`
- `sales_destination`: `WEB_AND_APP`
- `catalog_enabled`: `true`

# Prerequisites

Creating Search Ads Campaigns for Website and App requires setting up a catalog in your Business Center first.

To set up the catalog:

1. Create a catalog using [/catalog/create/](slug:create-a-catalog).
The catalog type can be any of the following:

- E-commerce
- hotel
- flight
- destination
- entertainment

2. Upload products to the catalog using [/catalog/product/upload/](slug:upload-products-via-a-json-schema) (JSON schema), [/catalog/product/file/](slug:upload-products-via-a-file-url) (CSV feed template), or [/catalog/feed/create/](slug:create-a-feed)(online data feed schedule).

3. Check the product handling results.

- For CSV feed and JSON schema, use [/catalog/product/log/](slug:get-the-product-handling-log).
  - Pass in the `feed_log_id` obtained from Step 2. If the field `error_affected_products` in the response is not null, examine the issue details and return to Step 2 to reupload the product.
- For online feed, use [/catalog/feed/log/](slug:get-the-log-of-a-feed).
  - Pass in the `feed_id` obtained from Step 2. If the field `error_count` in the response is not 0, examine your online feed and return to Step 2 to reupload the product.

4. (Optional) Create a product set using [/catalog/set/create/](slug:create-a-product-set-by-conditions).
If you want to have products selected from a product set, creating a product set is necessary. Otherwise, you can skip this step.

5. (Optional) Invite members to Business Center and grant the admin permission using [/bc/member/invite/](slug:invite-members-to-a-bc).
You can also choose `advertiser_role` that you want to assign to the members invited.

6. (Optional) Share a catalog with members and grant catalog management access using [/bc/asset/assign/](slug:assign-an-asset).
Make sure to specify `CATALOG` in the `asset_type` field and `ADMIN` in the `catalog_role` field.

### Customize the ad format combinations in Upgraded Smart+ Catalog Search Ads Campaigns for Website and App

#### When using an E-commerce catalog

If you use an e-commerce catalog and enable auto-selection of catalog creatives (`catalog_creative_toggle` is `true`), the system will automatically create ads using combinations of three possible formats: catalog carousel, catalog video, and single video.

The possible ad format combinations for your ads are illustrated in the following table.

| Is the catalog carousel format available? | Is the catalog video format available? | Is the single video format available? | Ad format combination for your ads |
|---|---|---|---|
| ✅ | ❌ | ❌ | Catalog carousel only |
| ✅ | ❌ | ✅ | Catalog carousel and single video |
| ✅ | ✅ | ❌ | Catalog carousel and catalog video |
| ✅ | ✅ | ✅ | Catalog carousel, catalog video, and single video |

To ensure certain ad formats are available in the ads, follow the instructions in the following table.
