# Create an Offline Event set
> Đường dẫn: API Reference > Events 1.0 > Offline Events > Create an Offline Event set
Use this endpoint to create a new Offline Event set.

> **Important:** 
> By using Events API endpoints, you agree to the [TikTok Business Products (Data) Terms](https://ads.tiktok.com/i18n/official/policy/business-products-terms) and that you will not share sensitive data with TikTok.
## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/offline/create/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed format: `"application/json"`. |
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](doc:1738373164380162). |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| advertiser_id  **(Required)** | string | Advertiser ID. |
| name **(Required)** | string | Event set name. ⏎ Length limit: 40 characters. ⏎ Example: in_store_purchases. ⏎ **Note**: You cannot specify a name that has been used by another event set. Otherwise, an error will occur. |
| description | string | Event set description. ⏎ Example: in_store_purchases_blackfriday. |
| auto_tracking | boolean | Whether to enable Auto Tracking. If this field is set to true, new campaigns created afterwards under this advertiser account will use this event set for ad tracking and attribution. Enum values: `true`, `false`. ⏎ **Note**: The maximum number of auto-tracking Offline Event sets under an advertiser account is 10. If the limit is reached, you cannot create another auto-tracking Offline Event set. |

### Example
> **Note:** You need to replace the dummy data in the example with your own data.

```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/offline/create/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data-raw '{
  "advertiser_id": "123456", 
  "name": "EVENT_SET_NAME", 
  "description": "In_store_purchases_blackfriday_2021",
  "auto_tracking": true
}
'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| event_set_id | string | The event set ID that you just created. |
