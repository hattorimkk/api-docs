# Upload verification documents
> Đường dẫn: API Reference > Verification > Upload verification documents
Use this endpoint to upload your verification documents.

After successfully uploading your documents, call [/account/verification/submit/](slug:submit-a-verification-request-for-your-account) to officially submit your account verification request.

## Before you begin
- Confirm the supported business or personal identification document types for your account by calling [/account/verification/filetype/](slug:get-available-verification-document-types-for-a-region).
- Familiarize yourself with common pitfalls by reviewing the [List of common rejection reasons and suggestions for verification failures](https://ads.tiktok.com/help/article/list-of-common-rejection-reasons-and-suggestions-for-verification-failures).

## Request
**Endpoint** https://business-api.tiktok.com/open_api/v1.3/account/verification/upload/

**Header**

| Field | Data Type | Description |
|---|---|---|
| Access-Token  **(Required)** | string | Authorized access token. For details, see [Authentication](slug:marketing-api-authentication). |
| Content-Type  **(Required)** | string | Request message type. ⏎ Allowed value: `multipart/form-data`. |

**Parameters**

| Field | Data Type | Description |
|---|---|---|
| image_file1  **(Required)** | file | A verification document. ⏎ You can specify either a business verification document or a personal identification document. ⏎ For a personal identification verification request which usually requires two images (front and back), you can provide the front image via `image_file1` and the back image via `image_file2`. ⏎ File size: within 10 MB. ⏎ Supported formats: JPEG, PNG, and JPG. |
| image_file2 | file | An additional verification document. ⏎ You can specify either a business verification document or a personal identification document. ⏎ For a personal identification verification request which usually requires two images (front and back), you can provide the front image via `image_file1` and the back image via `image_file2`. ⏎ File size: within 10 MB. ⏎ Supported formats: JPEG, PNG, and JPG. |

### Example
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/account/verification/upload/' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: multipart/form-data' \
--form 'image_file1=@"{{image_file1}}"'
```

## Response

| Field | Data Type | Description |
|---|---|---|
| - | - | - |
| code | number | Response code. For the complete list of response codes and descriptions, see [Appendix - Return Codes](slug:return-codes-appendix). |
| message | string | Response message. For details, see [Appendix - Return Codes](slug:return-codes-appendix). |
| request_id | string | The log ID of the request, which uniquely identifies a request. |
| data | object | Returned data. |
| ↳ qualification_image_ids | string[] | A list of qualification image IDs. ⏎ The number of IDs can be 1 or 2, depending on the total number of files you uploaded. |

### Example
```http
// curl
HTTPS/1.1 200 OK
{
    "code": 0,
    "message": "OK",
    "request_id": "{{request_id}}",
    "data": {
        "qualification_image_ids": [
            "{{qualification_image_id}}"
        ]
    }
}
```
