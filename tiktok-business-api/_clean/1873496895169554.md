# Use MCP tools
> Đường dẫn: API Reference > MCP Authorization > Use MCP tools
Use this endpoint to send MCP requests to the server path using a bearer access token, ensuring the token you present is valid for this specific MCP server path.

# Request
**Endpoint** https://business-api.tiktok.com/open_mcp/{server}/

**Method** POST

**Header**

| Field | Data Type | Description |
|---|---|---|
| Authorization  **(Required)** | string | The access token in the format of `Bearer {{Access-Token}}`. ⏎ The access token must be valid for the specific MCP `server` path. |

**Path parameters**

| Field | Data Type | Description |
|---|---|---|
| server  **(Required)** | string | The specific TikTok for Business MCP server URL. ⏎ Enum values: `tt-ads-mcp-flat`, `tt-ads-mcp-layer`. ⏎ To learn more about how these server URLs differ, see [Choose your server URL](https://business-api.tiktok.com/portal/docs/how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server/v1.3#anchor-3). |

**Body parameters**

| Field | Data Type | Description |
|---|---|---|
| jsonrpc  **(Required)** | string | The version of the JSON-RPC protocol you are using. ⏎ Enum value: `2.0`. |
| id  **(Required)** | integer | A unique identifier you assign to the request. ⏎ You will receive this same ID in the response so you can match them. |
| method  **(Required)** | string | The specific MCP method you want to use. ⏎ Enum values: • `tools/list`: To retrieve available tools. • `tools/call`: To execute a specific tool. |
| params  **(Required)** | object | The parameter payload you supply for the method. • When `method` is `tools/list`, provide an empty object (`{}`) . • When `method` is `tools/call`, provide specific tool arguments. |

## Example

> **Note:** 
> The example below uses `tt-ads-mcp-layer` as the `{server}` value. You can replace this with your chosen server value.

### Retrieve available tools
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer' \
--header 'Authorization: Bearer {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "jsonrpc": "2.0",1
    "id": {{id}},
    "method": "tools/list",
    "params": {}
}'
```

### Execute a specific tool
```http
// curl
curl --location --request POST 'https://business-api.tiktok.com/open_mcp/tt-ads-mcp-layer' \
--header 'Access-Token: {{Access-Token}}' \
--header 'Content-Type: application/json' \
--data '{
    "jsonrpc": "2.0",
    "id": {{id}},
    "method": "tools/call",
    "params": {
        "name": "advertiser_info_get",
        "arguments": {
            "advertiser_ids": [
                "{{advertiser_ids}}"
            ],
            "fields": [
                "name",
                "status",
                "currency",
                "timezone"
            ]
        }
    }
}'
```

# Response

| Field | Data Type | Description |
|---|---|---|
| jsonrpc | string | The version of the JSON-RPC protocol. ⏎ Enum value: `2.0`. |
| id | integer | The identifier you originally sent, which you use to map this response to the correct request. |
| result | object | The outcome of your request. You will find the list of tools or the tool execution output here. |
| ↳ tools | object[] | Returned only when `method` is set to `tools/list` in the request. ⏎ The list of tools you can access on this server. ⏎ You can inspect the `name`, `description`, and `inputSchema` of each tool to construct future execution calls. |
| ↳ content | object[] | Returned only when `method` is set to `tools/call` in the request. ⏎ The output generated by the tool you called. ⏎ You will extract the tool's specific output data from this array. |

## Error response
When accessing MCP tools, authentication errors follow standard OAuth 2.0 Bearer Token semantics (RFC 6750). The server will return a `WWW-Authenticate` header containing the exact reason for the failure.

| HTTP Status Code | Meaning | Note |
|---|---|---|
| `401` | Missing token | A `WWW-Authenticate` challenge is returned. |
| `401` | Invalid, expired, or revoked token | `WWW-Authenticate: Bearer error="invalid_token"` is returned. |
| `403` | Insufficient scope | `WWW-Authenticate: Bearer error="insufficient_scope"` may be returned. |
